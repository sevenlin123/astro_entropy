Input:
    • N_target              # number of TNOs to analyze
    • For each target t ∈ {1,…,N_target}:
          * M_t                  # number of photometric measurements
          * m_t[1…M_t]           # observed magnitudes
          * σ_t[1…M_t]           # observational uncertainties
          * Filter_t[i]          # i‑th filter transmission curve T_i(λ)
          * ZP_t[i]              # zero‑point of filter i
    • λ_grid[1…N_λ]         # common wavelength grid (e.g., 4000–10 000 Å)
    • Prior model parameters:
          * μ_prior[1…N_λ]       # mean reflectance (from training set)
          * Σ_prior[1…N_λ,N_λ]   # covariance matrix (or diagonal)

Output for each target t:
    • Posterior samples {R_t^(k)}_{k=1}^{K}
    • Summary spectrum (mean, ±1σ bands)
    • Optional taxonomy likelihoods

--------------------------------------------------------------------
Step 1 – Pre‑compute filter integrals (once for all targets)

For each unique filter F in all targets:
    1.1 Normalize its throughput:  T_F_norm(λ) = T_F(λ) / max(T_F(λ))
    1.2 Compute weighted wavelength moments:
            W_F[j] = T_F_norm(λ_grid[j]) * Δλ      for j = 1…N_λ
    1.3 Store W_F as a vector of length N_λ

--------------------------------------------------------------------
Step 2 – Define forward model (photometry from reflectance)

Function synth_mag(R[1…N_λ], W_F[1…N_λ], ZP):
    # R : candidate reflectance spectrum
    # W_F: filter weight vector for one filter
    # Compute flux through filter:
        F = Σ_{j=1}^{N_λ} R[j] * W_F[j]
    # Convert to magnitude:
        m = -2.5 * log10(F / F_ref) + ZP
    Return m

(Note: F_ref is a constant reference flux; it cancels if relative magnitudes are used.)

--------------------------------------------------------------------
Step 3 – Log‑prior for reflectance

Function log_prior(R):
    # Assume multivariate normal prior (can be truncated to non‑negative values)
    δ = R - μ_prior
    logp = -0.5 * (δᵀ Σ_prior⁻¹ δ) - 0.5 * N_λ * log(2π) - 0.5 * log(det(Σ_prior))
    Return logp

--------------------------------------------------------------------
Step 4 – Log‑likelihood for a target

Function log_likelihood(t, R):
    ll = 0
    For i = 1 to M_t:
        m_pred = synth_mag(R, W_Filter_t[i], ZP_t[i])
        ll += -0.5 * ((m_t[i] - m_pred) / σ_t[i])²
    Return ll

--------------------------------------------------------------------
Step 5 – Posterior log‑probability

Function log_posterior(t, R):
    return log_prior(R) + log_likelihood(t, R)

--------------------------------------------------------------------
Step 6 – MCMC sampler for each target

For t = 1 to N_target:
    6.1 Initialize an ensemble of walkers:
         For w = 1 to N_walkers:
             R_w = draw_random_from_prior()   # e.g., Gaussian around μ_prior
    6.2 For step = 1 to N_steps:
         For w = 1 to N_walkers:
             Propose new R_prop by adding small Gaussian perturbation to R_w
             Compute α = exp( log_posterior(t, R_prop) - log_posterior(t, R_w) )
             With probability min(1, α), accept R_prop → R_w
    6.3 Discard first N_burnin steps, thin remaining samples
    6.4 Store the retained {R_w} as posterior samples {R_t^(k)}

--------------------------------------------------------------------
Step 7 – Post‑processing

For each target t:
    7.1 Compute point estimate:
         R_mean[j] = mean_k( R_t^(k)[j] )    for j = 1…N_λ
    7.2 Compute 68% credible interval:
         Lower[j], Upper[j] = quantiles_{16%,84%}( {R_t^(k)[j]} )
    7.3 (Optional) Taxonomy classification:
         • Project each sample R_t^(k) onto a pre‑computed eigenspectra basis
         • Compute distances to template spectra
         • Estimate class probabilities by kernel density on distances

--------------------------------------------------------------------
Step 8 – Output results

Return for each target t:
    • Posterior samples {R_t^(k)}
    • R_mean, Lower, Upper
    • (Optional) Class probabilities
