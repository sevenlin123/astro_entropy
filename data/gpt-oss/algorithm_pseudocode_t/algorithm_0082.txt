Input:
    - Photometry table P[i][j]   (i = object, j = filter)
    - Flux uncertainties σ[i][j]
    - Observation geometry G[i] (phase angle, heliocentric distance, etc.)
    - Filter transmission curves T[j](λ)

Output:
    - Normalized photometric vector y[i]
    - Covariance matrix C[i] (diagonal of σ²)

text
Input:
    - Library L of reference TNO spectra S_k(λ) (k = class)
    - Optional synthetic templates generated by mixing primitive end‑members

Output:
    - Basis matrix B[k][λ]  (k rows, λ wavelength samples)
    - Class labels L_k

text
Function F(coeffs, B, T, G):
    Input:
        coeffs : vector c_k (k=1…K), coefficients for basis spectra
        B      : basis matrix (K × Nλ)
        T      : filter responses (M × Nλ)
        G      : geometry parameters for one object
    Output:
        model fluxes f_m (m = 1…M)

    Steps:
        1. Reconstruct reflectance R(λ) = Σ_k c_k * B[k, λ]
        2. Apply phase–function correction using G (e.g., linear phase law)
        3. For each filter m:
               f_m = ∫ R(λ) * T[m, λ] dλ   (numerical integration)
        4. Return vector f = [f_1 … f_M]

text
Likelihood L_i(coeffs | data) =
    exp(-0.5 * (y_i - F(coeffs))ᵀ · C[i]⁻¹ · (y_i - F(coeffs)))

text
Prior over coefficients:
    - Dirichlet(α)  (non‑negative, sum to 1)
    - α may be uniform (α = 1) or informative (α derived from known class fractions)

text
For each object i:
    1. Define target posterior:
           p(coeffs | y_i, C[i], G[i]) ∝ L_i(coeffs) * Dirichlet(α)
    2. Initialize sampler (e.g., Hamiltonian Monte Carlo or Metropolis‑Hastings)
    3. Run MCMC for N_iter steps, discarding burn‑in
    4. Collect posterior samples {c_k^(s)}_{s=1}^{N_s}

text
For each retained sample s:
    1. Compute reconstructed spectrum R^(s)(λ) = Σ_k c_k^(s) * B[k, λ]
    2. Compute predicted fluxes f^(s) = F(c^(s), B, T, G[i])
    3. Store R^(s) and f^(s)

Aggregate:
    - Posterior mean spectrum:  μ_R(λ) = (1/N_s) Σ_s R^(s)(λ)
    - Posterior median spectrum:  med_R(λ) = median_s{R^(s)(λ)}
    - Credible intervals per λ:  CI_95(λ) = percentile_{2.5,97.5} of {R^(s)(λ)}

text
Define class indicator vector z_k:
    z_k = 1 if class k dominates the mixture (e.g., c_k > threshold)
    else z_k = 0

For each sample s:
    1. Determine dominant class k*(s) = argmax_k c_k^(s)
    2. Record indicator I_k(s) = 1 if k = k*(s), else 0

After sampling:
    - Class posterior probability for class k:
          p_k = (1/N_s) Σ_s I_k(s)

text
For each object i:
    1. Compute posterior predictive residuals:
           r_i^(s) = y_i – f^(s)
    2. Estimate predictive χ²:
           χ²_i = (1/N_s) Σ_s  r_i^(s)ᵀ · C[i]⁻¹ · r_i^(s)
    3. Flag as outlier if χ²_i > threshold (e.g., χ²_i > χ²_critical for df=M)

text
For each object i:
    - Return:
        * Posterior coefficient samples {c_k^(s)}
        * Posterior mean spectrum μ_R(λ)
        * Credible interval CI_95(λ)
        * Class probabilities {p_k}
        * Outlier flag
