INPUT:
    P = { (f_i, σ_i, λ_i) | i = 1 … N }          // observed fluxes, uncertainties, filter wavelengths
    T = {T_j(λ) | j = 1 … J}                     // filter transmission curves
    B = {b_k(λ) | k = 1 … K}                     // basis spectra (or template class spectra)

OUTPUT:
    Posterior samples of spectral coefficients {a_k}
    Class membership probabilities {p_c}
    Outlier score S_out

--------------------------------------------------------------------
1. PREPROCESSING
   1.1. For each filter j:
            Compute synthetic filter vector F_j(λ) = T_j(λ)
   1.2. For each basis spectrum k:
            Normalize b_k(λ) such that ∫ b_k(λ) dλ = 1

--------------------------------------------------------------------
2. MODEL CONSTRUCTION
   2.1. Define spectral model S(λ; a) = Σ_{k=1}^K a_k * b_k(λ)
   2.2. For each observation i:
            Compute predicted flux:
                f_pred_i(a) = ∫ S(λ; a) * F_{λ_i}(λ) dλ
   2.3. Likelihood function:
            L(a) = Π_{i=1}^N  N(f_i | f_pred_i(a), σ_i^2)
   2.4. Prior on coefficients:
            Choose prior P(a) (e.g., independent Gaussian N(0, τ^2) or Dirichlet if coefficients are proportions)

--------------------------------------------------------------------
3. BAYESIAN INFERENCE (MCMC Sampling)
   3.1. Initialize a^(0) (e.g., zeros or random values)
   3.2. For iteration t = 1 … M:
            3.2.1. Propose new coefficient vector a' = a^(t-1) + ε
                 where ε ~ N(0, Σ_prop)  (proposal covariance)
            3.2.2. Compute acceptance probability:
                    α = min(1,
                            [L(a') * P(a')] / [L(a^(t-1)) * P(a^(t-1))]
                          )
            3.2.3. Draw u ~ Uniform(0,1)
            3.2.4. If u < α:
                    a^(t) = a'
                else:
                    a^(t) = a^(t-1)
   3.3. Discard first B iterations as burn‑in
   3.4. Store remaining samples {a^(t)} as posterior sample set

--------------------------------------------------------------------
4. POSTERIOR ANALYSIS
   4.1. For each coefficient k:
            Compute posterior mean μ_k and 95% credible interval CI_k
   4.2. Reconstruct most probable spectrum:
            S_best(λ) = Σ_{k=1}^K μ_k * b_k(λ)

--------------------------------------------------------------------
5. TAXONOMY CLASSIFICATION
   5.1. For each class c with prototype spectrum p_c(λ):
            5.1.1. Compute class‑specific likelihood:
                     L_c = Π_{i=1}^N N(f_i | ∫ p_c(λ)*F_{λ_i}(λ)dλ , σ_i^2)
            5.1.2. Compute posterior class probability:
                     p_c = L_c * π_c / Σ_{c'} L_{c'} * π_{c'}
              where π_c is prior class probability (e.g., uniform)
   5.2. Return vector {p_c}

--------------------------------------------------------------------
6. OUTLIER DETECTION
   6.1. For each posterior sample a^(t):
            Compute likelihood L_t = L(a^(t))
   6.2. Estimate predictive likelihood:
            L_pred = mean(L_t over all samples)
   6.3. Compute outlier score:
            S_out = -log(L_pred)   // higher value indicates poorer fit

--------------------------------------------------------------------
7. OUTPUT
   Return:
        - Posterior coefficient samples {a^(t)}
        - Posterior means {μ_k} and credible intervals {CI_k}
        - Reconstructed spectrum S_best(λ)
        - Class probabilities {p_c}
        - Outlier score S_out
END
