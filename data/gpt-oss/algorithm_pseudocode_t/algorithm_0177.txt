INPUT:
    - Spectral library L = {S_k(λ)} for k = 1 … K (e.g., 5 taxonomic classes)
    - Filter set F = {R_i(λ)} for i = 1 … N (e.g., ugrizJHK)
    - For each object j:
        * Photometric magnitudes m_{j,i} with errors σ_{m,j,i}
        * Observation identifiers

OUTPUT (for each object j):
    - Posterior coefficient vector c_j (size K)
    - Covariance matrix Σ_c,j
    - Reconstructed reflectance spectrum R_j(λ)
    - Class probability vector P_j(k)
    - Outlier score O_j

--------------------------------------------------------------------
1. PRECOMPUTE SPECTRAL RESPONSE MATRIX
---------------------------------------------------------------
For every filter i and template k:
    G_{i,k} = ∫ S_k(λ) * R_i(λ) dλ          // Synthetic flux in filter i
Store G as an N×K matrix.

--------------------------------------------------------------------
2. FOR EACH OBJECT j
---------------------------------------------------------------
2.1 CONVERT MAGNITUDES TO FLUXES
    For each observed filter i:
        If m_{j,i} is valid:
            F_{j,i}      = 10^(–0.4 * m_{j,i})             // Flux
            σ_{F,j,i}    = (ln 10 / 2.5) * F_{j,i} * σ_{m,j,i}
        Else:
            Mark filter i as missing (remove from subsequent steps)

    Let M_j be the number of available filters.
    Build vector f_j of length M_j containing F_{j,i} for valid i.
    Build diagonal weight matrix W_j of size M_j × M_j:
        W_j(i,i) = 1 / σ_{F,j,i}²

    Build sub‑matrix G_j by selecting rows of G corresponding to valid filters.

2.2 DEFINE PRIOR ON COEFFICIENTS
    Prior mean μ_c = 0_K                      // Zero‑mean Gaussian
    Prior covariance Σ_p = τ² * I_K           // Isotropic precision τ²
    // τ can be set from training data or user input

2.3 POSTERIOR ESTIMATION (MAP & Uncertainty)
    A_j = G_jᵀ * W_j * G_j + Σ_p⁻¹              // Precision matrix
    b_j = G_jᵀ * W_j * f_j
    c_j  = A_j⁻¹ * b_j                         // MAP estimate of coefficients
    Σ_c,j = A_j⁻¹                               // Posterior covariance

2.4 RECONSTRUCT SPECTRUM
    R_j(λ) = Σ_{k=1..K} c_j(k) * S_k(λ)        // Linear combination of templates

2.5 CLASS PROBABILITIES
    For each class k:
        χ²_k = Σ_{i∈valid} [ (G_{i,k} * c_j(k) – f_{j,i})² / σ_{F,j,i}² ]
        Likelihood L_k = exp( –0.5 * χ²_k )
    Normalize:
        P_j(k) = L_k / Σ_{q=1..K} L_q

2.6 OUTLIER SCORE
    Compute Mahalanobis distance to nearest class center:
        For each class k:
            δ_k² = (c_j – μ_k)ᵀ * Σ_c,j⁻¹ * (c_j – μ_k)   // μ_k = unit vector for class k
        O_j = min_k δ_k²                                  // Smaller → more inlier

2.7 STORE RESULTS
    Record c_j, Σ_c,j, R_j(λ), P_j, O_j for object j

END FOR
