PROCEDURE RECONSTRUCT_SPECTRUM(PHOTOMETRY, FILTERS, BASIS_SPECTRA, PRIOR_PARAMS)

1. INPUT
   1.1 PHOTOMETRY: list of tuples (band_i, flux_i, error_i) for each object
   1.2 FILTERS: dictionary mapping band_i → transmission curve T_i(λ)
   1.3 BASIS_SPECTRA: list of N basis spectra S_k(λ) (e.g., taxonomic templates)
   1.4 PRIOR_PARAMS: parameters defining priors on class weights and noise scaling

2. PREPROCESSING
   2.1 Normalize each basis spectrum S_k(λ) to unit area over λ
   2.2 For every filter band_i:
          Compute expected synthetic magnitude m_{ik} = 
              -2.5 * log10( ∫ S_k(λ) * T_i(λ) dλ / ∫ T_i(λ) dλ )
          Store matrix M[i,k] = m_{ik}

3. MODEL SPECIFICATION
   3.1 Define weight vector w = (w_1,…,w_N), where w_k ≥ 0 and Σ w_k = 1
   3.2 Define reconstructed synthetic magnitudes:
          μ_i(w) = Σ_{k=1}^{N} w_k * M[i,k]
   3.3 Define measurement error model:
          Flux_i ~ Normal(10^{-0.4*μ_i(w)}, σ_i^2)
          where σ_i = error_i (converted to flux units if necessary)

4. PRIORS
   4.1 Prior on weights: Dirichlet(α) with α derived from PRIOR_PARAMS
   4.2 Optional prior on global noise scaling factor τ (if modeling heteroscedasticity)

5. LIKELIHOOD
   5.1 For each observation i, compute likelihood:
          L_i = Normal_PDF(flux_i | μ_i(w), σ_i)
   5.2 Total likelihood:
          L_total = Π_i L_i

6. BAYESIAN INFERENCE
   6.1 Define posterior:
          P(w | PHOTOMETRY) ∝ L_total * Dirichlet_PDF(w | α)
   6.2 Initialize MCMC chain with random weight vector w^(0) satisfying constraints
   6.3 For iteration t = 1 … N_samples:
         6.3.1 Propose new weights w' by drawing from a symmetric proposal
               (e.g., Dirichlet centered at current w^(t-1))
         6.3.2 Compute μ_i(w') for all bands
         6.3.3 Evaluate likelihood L_total' and posterior density π'
         6.3.4 Compute acceptance ratio r = min(1, π'/π_current)
         6.3.5 With probability r accept w^(t)=w', else w^(t)=w^(t-1)
   6.4 After burn‑in, collect posterior samples {w^(t)}.

7. POSTPROCESSING
   7.1 Compute posterior mean weights: w̄_k = mean_k({w^(t)})
   7.2 Compute posterior uncertainty (e.g., 16th/84th percentiles) for each w_k
   7.3 Derive taxonomic class probabilities:
          P_class_j = sum_{k∈class j} w̄_k
   7.4 Reconstruct full spectrum:
          S_recon(λ) = Σ_k w̄_k * S_k(λ)

8. OUTPUT
   8.1 Return:
        - Posterior weight samples {w^(t)}
        - Posterior mean weights w̄ and uncertainties
        - Class probabilities P_class
        - Reconstructed spectrum S_recon(λ)

END PROCEDURE
