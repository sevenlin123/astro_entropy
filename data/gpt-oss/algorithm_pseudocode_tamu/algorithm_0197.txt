Input:  Spectral library L = {S_i(λ)}   // 51 calibrated TNO spectra
Step 1.1: Compute mean spectrum μ_S = mean(L)
Step 1.2: Center spectra: C_i = S_i – μ_S
Step 1.3: Perform Principal Component Analysis (PCA) on {C_i}
          → Eigenvectors V = [v_1 … v_K]   (K ≈ 8–10)
          → Projection coefficients for each spectrum:
                c_i = Vᵀ · C_i            //  K‑dimensional vector
Output:  Basis V, coefficient matrix C = {c_i}

Input:  Coefficient matrix C
Step 2.1: Fit a non‑parametric Kernel Density Estimate (KDE)
          using Gaussian kernels with bandwidth h ≈ 0.5
Step 2.2: Sample M synthetic latent vectors {s_j} from KDE
          → M ≈ 5 000 (enough to cover manifold)
Step 2.3: Reconstruct synthetic spectra:
          S_j_syn = μ_S + V · s_j
Output:  Synthetic spectra set {S_j_syn}

Input:  Synthetic spectra {S_j_syn}
        Filter response set {F_k(λ)}  // e.g., JWST/NIRCam
        Photometric noise σ_rel = 0.20
For each synthetic spectrum S_j_syn:
    Step 3.1: Compute noiseless fluxes:
              f_k = ∫ S_j_syn(λ) · F_k(λ) dλ / ∫ F_k(λ) dλ
    Step 3.2: Add Gaussian noise:
              m_k = f_k · (1 + N(0, σ_rel))
    Step 3.3: Store photometry vector m_j = [m_1 … m_N]
Output:  Training set {(m_j , s_j)}   // photometry ↔ latent coefficient

Input:  {(m_j , s_j)} training pairs
Step 4.1: Use AutoML (e.g., AutoGluon) to train an ensemble
          of Gradient‑Boosted Decision Trees (GBDT)
          that maps photometry m → latent vector s
          *Model outputs: predictive mean μ̂(m) and covariance Σ̂(m)
Output:  Encoder model E

Input:  {(s_i , label_i)}  // original spectra coefficients and known taxonomies
Step 5.1: Train an AutoML classifier C (e.g., XGBoost)
          on latent vectors s_i to predict taxonomy labels
Output:  Classifier C

Input:  New photometry m* (N‑band values)
Step 6.1: Predict latent distribution:
          μ̂*, Σ̂* = E(m*)                // mean & covariance
Step 6.2: Draw R samples from Gaussian Copula:
          For r = 1 … R:
              draw s*_r ~ GaussianCopula(μ̂*, Σ̂*)
              reconstruct spectrum:
                  S*_r = μ_S + V · s*_r
Step 6.3: Aggregate reconstructions:
          Spectrum estimate: S̄* = mean_r(S*_r)
          Uncertainty bands: e.g., 2.5th–97.5th percentiles of {S*_r}
Step 6.4: (Optional) Taxonomy prediction:
          label_r = C(s*_r)  for each sample
          Posterior class probs = fraction of samples per class
Output:  Reconstructed spectrum S̄*(λ) with confidence interval
        Taxonomy probability distribution (if desired)
