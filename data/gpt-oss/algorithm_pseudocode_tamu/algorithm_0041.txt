text
INPUT
    - N_obs spectra   :  {S_i(λ)}  i = 1 … N_obs      (high‑resolution reflectance)
    - Filter throughputs  :  {T_f(λ)} f = 1 … F          (instrument response)
    - Optional: taxonomic labels  {L_i}

PARAMETERS
    - K               : number of principal components (≈5–10)
    - h_KDE           : KDE bandwidth  (≈0.5)
    - σ_noise         : relative photometric noise (≈0.20)
    - M_aug           : number of synthetic latent samples per real spectrum (≈500)
    - n_samples_post  : number of posterior draws for reconstruction (≈1000)

--------------------------------------------------------------------
STEP 1 – BUILD THE LATENT MANIFOLD (PRIOR)
--------------------------------------------------------------------

1.1   Standardise each spectrum S_i(λ) to unit variance over λ.
1.2   Construct data matrix X ∈ ℝ^(N_obs × B)  (B = # wavelength bins).
1.3   Perform PCA on X:
        - Compute eigenvectors E_k(λ) , k = 1…K  (principal components).
        - Project each spectrum to latent coefficients:
              z_i = X_i · E_k   →  z_i ∈ ℝ^K .
1.4   Store:
        * Basis matrix E = [E_1 … E_K]     (size B×K)
        * Coefficient set Z = {z_i}         (size N_obs × K)

--------------------------------------------------------------------
STEP 2 – AUGMENT THE MANIFOLD WITH KDE
--------------------------------------------------------------------

2.1   Fit a multivariate kernel density estimate (Gaussian kernel) to Z:
        p_Z(z)  ←  KDE(Z, bandwidth = h_KDE).

2.2   Sample M_total synthetic latent vectors:
        z_j*  ←  draw from p_Z(z), j = 1 … M_total
        (M_total ≈ N_obs × M_aug).

2.3   For each synthetic latent vector z_j*:
        a) Reconstruct high‑resolution spectrum:
               S_j*(λ) = z_j* · E^T            // inverse PCA
        b) Save (S_j*, z_j*).

--------------------------------------------------------------------
STEP 3 – FORWARD‑MODEL SYNTHETIC PHOTOMETRY
--------------------------------------------------------------------

For every synthetic spectrum S_j*(λ):

3.1   Convolve with each filter throughput:
        m_f,j = (∫ S_j*(λ) · T_f(λ) dλ) / (∫ T_f(λ) dλ)
        → gives mean reflectance in band f.

3.2   Inject Gaussian noise:
        m_f,j ← m_f,j + 𝒩(0, (σ_noise · m_f,j)^2).

3.3   Store training tuple:
        (photometry vector m_j = [m_1,j … m_F,j],  latent coeff. z_j*).

Result: Training set  ℱ = { (m_j , z_j*) }  of size M_total.

--------------------------------------------------------------------
STEP 4 – TRAIN ENCODER (PHOTOMETRY → LATENT)
--------------------------------------------------------------------

4.1   Use AutoML (e.g., AutoGluon, GBRT + NN ensemble) to fit a regression model:
        Φ : ℝ^F → ℝ^K
        Target: z_j* ; Input: m_j.

4.2   Train‑validation split (e.g., 80/20) on ℱ; optimise hyper‑parameters automatically.

4.3   Save trained encoder Φ̂.

--------------------------------------------------------------------
STEP 5 – TRAIN CLASSIFIER (LATENT → TAXONOMY)
--------------------------------------------------------------------

5.1   For each real spectrum S_i, label L_i (Water, CO₂, Organic, Methanol).

5.2   Fit a probabilistic classifier Ĉ on latent set Z with labels L_i
        (e.g., AutoML classifier, soft‑max output).

--------------------------------------------------------------------
STEP 6 – INFERENCE FOR NEW OBJECT
--------------------------------------------------------------------

Given new sparse photometry m_new = [m_1,new … m_F,new]:

6.1   Predict mean latent vector:
        μ_z = Φ̂(m_new)          // point estimate

6.2   Estimate posterior over latent space:
        a) Approximate Φ̂ as a probabilistic mapping (e.g., via quantile regression
           or by sampling from the GBRT ensemble predictions).
        b) Obtain marginal predictive distributions {p_k(z_k | m_new)} for each component.
        c) Build a Gaussian copula with correlation matrix Σ (learned from training residuals).
        d) Draw n_samples_post samples {z_s} from the joint posterior.

6.3   For each sampled latent vector z_s:
        a) Decode to spectrum:
               S_s(λ) = z_s · E^T
        b) Store S_s(λ).

6.4   Aggregate spectra:
        - Mean spectrum: ⟨S⟩(λ) = (1/n) Σ S_s(λ)
        - Credible interval at each λ: e.g., 2.5% & 97.5% percentiles of {S_s(λ)}.

6.5   Taxonomic probabilities:
        - For each sampled z_s, compute class posterior Ĉ(z_s).
        - Average over samples to obtain P(class | m_new).

--------------------------------------------------------------------
OUTPUT
--------------------------------------------------------------------

- Reconstructed high‑resolution spectrum with credible intervals.
- Expected values of spectral diagnostics (slope, absorption depths).
- Probability distribution over taxonomic classes.
