INPUT
    - Seed spectra set S_seed = {s_i(λ)}  i = 1 … N (high‑resolution reflectance)
    - Filter set F = {f_j}  j = 1 … J   (throughput curves)
    - Target number of principal components K  (≤ 10)
    - KDE bandwidth h
    - Noise level σ_noise (relative, e.g., 20%)
    - New photometric measurements m_new = {m_j}  j = 1 … J  (reflectance in each filter)

OUTPUT
    - Posterior samples of latent coefficients θ (size K)
    - Reconstructed spectra s_rec(λ) (high‑resolution)
    - Taxonomic probability vector p_tax (e.g., H₂O, CO₂, Org, Met)

--------------------------------------------------------------------
STEP 0 : Pre‑processing
--------------------------------------------------------------------
  0.1  Normalize every seed spectrum s_i(λ) to unit average reflectance
       (or any common scaling) so that PCA captures shape variations only.
  0.2  Discretise spectra to a common wavelength grid λ_grid (e.g., 0.8–5 μm).

--------------------------------------------------------------------
STEP 1 : Latent‑space definition (PCA)
--------------------------------------------------------------------
  1.1  Compute data matrix X ∈ ℝ^{N × L} where each row = s_i(λ_grid).
  1.2  Subtract mean μ_X from X.
  1.3  Perform Singular Value Decomposition:  X = U Σ Vᵀ.
  1.4  Take first K right‑singular vectors v_k (columns of V) → PCA basis B ∈ ℝ^{L×K}.
  1.5  Project each seed spectrum to latent vector:  
        θ_i = Bᵀ (s_i − μ_X)   (θ_i ∈ ℝ^K).

--------------------------------------------------------------------
STEP 2 : Prior augmentation (KDE in latent space)
--------------------------------------------------------------------
  2.1  Fit a multivariate Gaussian kernel density estimator to {θ_i} with bandwidth h.
  2.2  Sample M synthetic latent vectors {θ_syn_m}  (e.g., M = 5000) from the KDE.
  2.3  For each θ_syn_m, reconstruct synthetic spectrum:
        s_syn_m = μ_X + B θ_syn_m   (high‑resolution vector).

--------------------------------------------------------------------
STEP 3 : Forward‑modeling of photometry
--------------------------------------------------------------------
  3.1  For each synthetic spectrum s_syn_m:
          For each filter f_j:
              Compute theoretical reflectance in filter: 
                 r_j(m_syn_m) = ∫ s_syn_m(λ) * f_j(λ) dλ / ∫ f_j(λ) dλ .
          Store vector r_syn_m = {r_j}.
  3.2  Inject Gaussian noise:
          For each r_j in r_syn_m:
              r_j_noisy = r_j + 𝒩(0, σ_noise * r_j).
          Result: noisy photometry set R_syn = {r_syn_m_noisy}.

--------------------------------------------------------------------
STEP 4 : Train AutoML encoder (regression)
--------------------------------------------------------------------
  4.1  Define training pairs: (R_syn, θ_syn)  for all m.
  4.2  Use AutoML framework (e.g., AutoGluon) to build an ensemble of regression models
       (GBDT, neural nets, etc.) that map R_syn → θ_pred.
  4.3  Output trained regressor Model_Reg.

--------------------------------------------------------------------
STEP 5 : Train AutoML classifier (taxonomy)
--------------------------------------------------------------------
  5.1  Assign taxonomic label y_i to each seed spectrum s_i (e.g., 4 classes).
  5.2  Use θ_i as features and y_i as targets to train a multi‑class classifier
       with AutoML (ensemble of tree & NN models).  Output Model_Cls.

--------------------------------------------------------------------
STEP 6 : Inference for new observation
--------------------------------------------------------------------
  6.1  Input photometry m_new → vector r_new (already measured reflectance per filter).
  6.2  Predict posterior distribution of latent coefficients:
          • Pass r_new through Model_Reg → obtain point estimate θ_hat.
          • Approximate predictive distribution p(θ|r_new) as a multivariate Gaussian
            centered at θ_hat with covariance estimated from regressor variance
            or via bootstrap on the ensemble predictions.
  6.3  Sample N_post latent vectors {θ_post_n}  from p(θ|r_new) (e.g., N_post = 1000).
  6.4  For each sampled θ_post_n:
          – Decode to spectrum:  s_post_n = μ_X + B θ_post_n.
          – Store s_post_n.
  6.5  Construct posterior predictive spectrum:
          • Mean spectrum  s_mean(λ) = (1/N_post) Σ s_post_n(λ).
          • Credible intervals at each λ from percentiles of {s_post_n(λ)}.

--------------------------------------------------------------------
STEP 7 : Taxonomic probabilities
--------------------------------------------------------------------
  7.1  Feed θ_hat (or each θ_post_n) into Model_Cls to get class probabilities.
  7.2  Average class probabilities over the posterior samples to obtain
       p_tax = (1/N_post) Σ p_cls(θ_post_n).
  7.3  Return p_tax along with reconstructed spectra.

--------------------------------------------------------------------
OUTPUT
--------------------------------------------------------------------
  - Posterior samples of spectra {s_post_n(λ)}.
  - Summary spectrum (mean + credible intervals).
  - Taxonomic probability vector p_tax.
