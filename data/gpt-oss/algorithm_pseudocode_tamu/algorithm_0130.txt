INPUT
    S_raw[1..N]          – Reference high‑resolution spectra (flux vs λ)
    F_eff[b]             – Effective filter throughput curves
    M_obs[1..n_filters] – Sparse photometry for a target body
    K                    – Number of principal components to retain
    h_KDE                – Bandwidth for Kernel Density Estimation
    N_syn                – Number of synthetic latent samples to draw
    σ_noise              – Relative photometric noise level (e.g. 0.20)

OUTPUT
    S_rec[λ]             – Reconstructed high‑resolution spectrum
    CI[λ]                – Credible‑interval envelope (e.g. 68%, 95%)
    P_type[species]      – Posterior probabilities for taxonomy classes

--------------------------------------------------------------------
1. PREPROCESSING & LATENT SPACE DEFINITION
--------------------------------------------------------------------
1.1  Convert all reference spectra to reflectance R_i[λ] = S_raw[i]/S_sun[λ]
1.2  Assemble data matrix X ∈ ℝ^(N×L) with rows = R_i[λ]
1.3  Mean‑center X → X_centered
1.4  Perform PCA on X_centered:
        [U, Σ, V] = eig(cov(X_centered))
        Select first K columns of V → PCs[1..K]
        Compute latent coefficients:
            C_real[j,k] = PCs_k · (R_j − μ_X)   for j = 1..N, k = 1..K
1.5  Build probability density over latent space:
        Estimate KDE density p(C) using Gaussian kernel with bandwidth h_KDE
1.6  Draw N_syn latent vectors:
        C_syn[n,k] ~ p(C)   (sample from KDE)
1.7  Reconstruct synthetic spectra:
        R_syn[n,λ] = μ_X + Σ_k=1^K C_syn[n,k] * PCs_k[λ]
1.8  Forward‑model photometry for each synthetic spectrum:
        For each filter b:
            m_syn[n,b] = ∫ R_syn[n,λ] * F_eff[b](λ) dλ
        Store vector m_syn[n,*]
1.9  Inject noise to mimic observation:
        For each n,b:
            m_noisy[n,b] = m_syn[n,b] * (1 + Normal(0, σ_noise))
1.10 Train AutoML encoder:
        Input: m_noisy[n,*]
        Target: C_syn[n,*]
        Model: ensemble (GBDT + NN) → f_enc(m_noisy) → μ_C_pred
        (Optionally store prediction variance σ_C_pred if supported)

--------------------------------------------------------------------
2. INFERENCE ON NEW TARGET
--------------------------------------------------------------------
2.1 Compute target photometry vector m_target[ ] (already in same units)
2.2 Predict latent mean:
        μ_C_hat = f_enc(m_target)
2.3 Estimate latent covariance:
        Use residuals from training set or regression output to form Σ_C_hat
2.4 Construct joint posterior of latent coefficients:
        Assume multivariate normal N(μ_C_hat, Σ_C_hat)
        (Optionally replace with Gaussian Copula if dependence structure known)
2.5 Sample M latent draws:
        For i = 1 … M:
            C_i = Sample from N(μ_C_hat, Σ_C_hat)
    M typically 10 000
2.6 Decode each sample to full spectrum:
        R_i[λ] = μ_X + Σ_k C_i[k] * PCs_k[λ]
2.7 Transform reflectance back to flux if needed:
        S_i[λ] = R_i[λ] * S_sun[λ]

--------------------------------------------------------------------
3. POST‑PROCESSING & INTERVAL ESTIMATION
--------------------------------------------------------------------
3.1 For each λ compute:
        median[λ] = median_i S_i[λ]
        lower[λ] = 16th percentile of {S_i[λ]}
        upper[λ] = 84th percentile of {S_i[λ]}      // 68% CI
        lower95[λ] = 2.5th percentile
        upper95[λ] = 97.5th percentile
3.2 Set S_rec[λ] = median[λ];  CI[λ] = [lower[λ], upper[λ]]
3.3 Taxonomy classification:
        For each species s:
            Compute class probability P_s = proportion of samples whose
            latent vector lies within the species region (defined by training labels)
        Return normalized P_type[species]

--------------------------------------------------------------------
RETURN
    S_rec[λ], CI[λ], P_type[species]
