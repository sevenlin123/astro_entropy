# ---------- 1. TRAINING PHASE ----------
# Input: 
#   S_real[1..N]        – N high‑resolution reflectance spectra
#   λ[1..L]             – wavelength grid of spectra
#   F[1..M]             – M photometric filter transmission curves
#   K                   – desired number of PCA components (e.g., 8–10)
#   h                    – KDE bandwidth (≈0.5)

# Step 1.1: PCA of reference spectra
Compute mean spectrum μ_s = mean(S_real)
Center spectra: X = S_real - μ_s
Perform PCA on X → eigenvectors V[1..K], eigenvalues Λ
Project spectra to latent space:
   z_real[i] = Vᵀ · (S_real[i] - μ_s)          # i = 1..N

# Step 1.2: Build continuous prior over latent space
Fit Gaussian Kernel Density Estimator (KDE) to {z_real}
Sample S_aug[1..N_aug] latent vectors from KDE
For each sampled z:
   Reconstruct synthetic spectrum:
       S_aug[i] = μ_s + V · z                # inverse PCA
   Store (z, S_aug)

# Step 1.3: Forward‑model synthetic photometry
For each synthetic spectrum S_aug[i]:
   For each filter j:
       m_true[j] = ∫ S_aug[i](λ) * F[j](λ) dλ / ∫ F[j](λ) dλ   # reflectance in band
   Add Gaussian noise:
       σ_rel = 0.20                              # 20 % relative error
       m_noisy[j] = m_true[j] + Normal(0, σ_rel * m_true[j])
   Save pair (m_noisy , z) as training example

# Step 1.4: Train photometry→latent regressor
Use AutoML (e.g., AutoGluon) to fit regression model R:
   Input: photometry vector m_noisy[1..M]
   Target: latent vector z[1..K]
   Loss: e.g., weighted L2 over K components
Store trained regressor R

# Step 1.5: Train taxonomy classifier
Map each z_real[i] to taxonomic label L[i] (e.g., H₂O, CO₂, ORGANIC, METHANOL)
Train classifier C (AutoML) on pairs (z_real, L)

# ---------- 2. INFERRING PHASE ----------
# Input:
#   m_obs[1..M]    – observed photometric reflectance in M filters
#   σ_obs[1..M]    – measurement uncertainties

# Step 2.1: Predict latent posterior
Apply regressor R to m_obs → obtain point estimate ẑ = R(m_obs)
Obtain per‑component prediction variance Σ_z from R (if available);
otherwise approximate using ensemble of trees.

# Step 2.2: Sample latent draws with Gaussian Copula
Construct correlation matrix ρ from training latent covariances
For n = 1..N_draw:
   Draw u ~ Uniform(0,1)^K
   Transform to normal: y = Φ⁻¹(u)   # Φ⁻¹ inverse CDF of standard normal
   Correlate: y_corr = L * y          # L Cholesky of ρ
   Map back to marginal posteriors:
       z_draw[n][k] = inverseCDF_k( y_corr[k] )   # using KDE marginals
   # If marginal posteriors are Gaussian:
       z_draw[n] = ẑ + chol(Σ_z) * y_corr

# Step 2.3: Reconstruct spectra
For each draw n:
   S_recon[n] = μ_s + V · z_draw[n]
Store ensemble {S_recon[n]}.

# Step 2.4: Derive summary statistics
Compute posterior mean spectrum:
   S_mean = mean_over_n(S_recon[n])
Compute credible intervals per wavelength:
   For each λ_j:
       ci_low[λ_j], ci_high[λ_j] = percentile(S_recon[:,j], [2.5, 97.5])

# Step 2.5: Taxonomy probabilities
For each draw n:
   p_tax[n] = C(z_draw[n])              # classifier returns probability vector
Aggregate:
   p_tax_mean = mean_over_n(p_tax[n])

# ---------- 3. OUTPUT ----------
Return:
   - Posterior mean spectrum S_mean[1..L]
   - Credible interval bounds ci_low[1..L], ci_high[1..L]
   - Taxonomy probability vector p_tax_mean
