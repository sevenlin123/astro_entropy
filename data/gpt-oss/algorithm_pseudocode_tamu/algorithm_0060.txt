Input:
    - Spectral library S_real = {s_1 , … , s_N}   // N ≈ 50 high‑resolution TNO spectra
    - Filter set F = {f_1 , … , f_M}              // e.g. JWST NIRCam throughput curves
    - Desired latent dimension K (default 5–10)

Steps:

1.1  Align all spectra to common wavelength grid λ = {λ_1,…,λ_L}.
     Store each spectrum as vector s_i[1..L].

1.2  Perform Principal Component Analysis (PCA):
       - Compute mean spectrum μ_s = mean(S_real).
       - Center spectra: s_i' = s_i – μ_s.
       - Build data matrix X = [s_1', … , s_N']ᵀ (size N×L).
       - Compute covariance C = (1/(N−1)) * Xᵀ X.
       - Eigen-decompose C → eigenvalues λ_k, eigenvectors v_k (k=1..K).
       - Form PCA basis V = [v_1 … v_K] (size L×K).
       - Project each centered spectrum onto basis: c_i = Vᵀ (s_i – μ_s)   // latent vector length K.

1.3  Estimate continuous latent density with Kernel Density Estimation (KDE):
       - Choose Gaussian kernel with bandwidth h (≈ 0.5).
       - Define density p_c(c) ∝ Σ_{i=1}^{N} exp(−||c − c_i||² / (2h²)).
       - Sample M_aug ≫ N latent vectors {c_j} from p_c(c)   // e.g. 10 000 samples.

1.4  Generate synthetic spectra from sampled latent vectors:
       For each sampled c_j:
           - Reconstruct spectrum: s̃_j = μ_s + V c_j
           - Store pair (c_j , s̃_j).

1.5  Forward‑model synthetic photometry for each synthetic spectrum:
       For each s̃_j:
           For each filter f_m ∈ F:
               - Compute modeled band reflectance:
                 m_j,m = ∫ s̃_j(λ) · R_f_m(λ) dλ  /  ∫ R_f_m(λ) dλ
                     where R_f_m(λ) is filter throughput.
               - Add Gaussian noise:
                 σ_noise = 0.20 * m_j,m      // 20 % relative error
                 m_obs_j,m = m_j,m + Normal(0, σ_noise).
           - Assemble noisy photometric vector m_j = {m_obs_j,1,…,m_obs_j,M}.

1.6  Train encoder (photometry → latent space) using AutoML:
       - Input features: m_j (length M)
       - Target labels: c_j (length K)
       - Use AutoGluon Tabular or equivalent to build ensemble of gradient‑boosted trees + neural nets.
       - Optimize over hyperparameters automatically.
       - Output trained regressor R_enc.

1.7  Train latent‑space taxonomic classifier:
       - Labels for each c_i from known taxonomy (H₂O, CO₂, Organic, Methanol).
       - Train separate AutoML classifier C_tax on {c_i, label_i}.

Input:
    - New sparse photometric observation m_new = {m_new,1,…,m_new,M}
    - Trained encoder R_enc
    - PCA basis V and mean μ_s
    - Trained taxonomic classifier C_tax

Steps:

2.1  Predict latent coefficient distribution:
        - Apply R_enc to m_new → estimated latent vector ĉ_new.
        - Optionally obtain predictive variance σ̂ from regressor ensemble (if available).

2.2  Construct posterior over latent space:
        - Assume multivariate Gaussian: p(c | m_new) ≈ N(ĉ_new, Σ̂),
          where Σ̂ derived from ensemble variance or calibrated using validation set.
        - Alternatively, generate N_samples samples {c_k} from this Gaussian.

2.3  Sample spectra from posterior:
        For each sampled c_k:
            - Reconstruct spectrum: s_k = μ_s + V c_k
            - Store s_k.

2.4  Aggregate sampled spectra:
        - Compute posterior mean spectrum: ⟨s⟩ = (1/N_samples) Σ_k s_k
        - Compute confidence intervals per wavelength (e.g., 16th–84th percentile).

2.5  Taxonomic prediction:
        - Apply C_tax to ĉ_new → probability vector P_tax over classes.
        - Optionally compute P_tax for each sampled c_k and aggregate.

Output:
    - Posterior mean spectrum ⟨s⟩ (continuous reflectance vs wavelength)
    - Credible interval envelopes (e.g., ±1σ)
    - Taxonomic probability distribution P_tax

3.1  Detect low‑probability posterior samples:
        - Identify c_k that lie outside high‑density region of KDE (e.g., Mahalanobis distance > threshold).
        - Flag corresponding spectra as potential outliers.

3.2  Refine posterior with Gaussian Copula:
        - Fit correlation matrix Σ_corr from training latent vectors {c_i}.
        - Replace independent Gaussian sampling with copula sampling to preserve physical dependencies.
