INPUT
    SPECTRA[]        // high‑resolution reflectance spectra of training TNOs
    FILTER_CURVES[]  // throughput curves for each desired photometric filter
    PHOTOMETRY_NEW   // sparse photometry (magnitudes or reflectances) of a target
    N_SYNTH          // number of synthetic latent samples to generate
    H_KDE            // bandwidth for kernel density estimation

OUTPUT
    RECONSTRUCTED_SPECTRUM      // full‑resolution reflectance vector
    CONFIDENCE_INTERVALS         // per‑wavelength credible interval
    TAXONOMIC_PROBS              // posterior probabilities for each taxonomic class

----------------------------------------------------------------------
Step 1 – Build Latent Space (Prior)

1.1  Center spectra:  S_centered[i] = SPECTRA[i] - mean(SPECTRA)
1.2  Perform PCA on {S_centered[i]} → eigenvectors V[1..K], eigenvalues λ[1..K]
1.3  Project each spectrum onto PCs: 
        L[i][k] = dot(V[k], S_centered[i])   for k = 1..K
    // L is the matrix of latent coefficients (size N x K)

----------------------------------------------------------------------
Step 2 – Augment Prior with KDE

2.1  Fit multivariate KDE to latent coefficients L  
     p_latent(l) = (1/N) Σ_i  exp(-½ (l-L[i])ᵀ Σ⁻¹ (l-L[i])) / ( (2π)^(K/2) |Σ|^(1/2) )
     (use Gaussian kernel with bandwidth H_KDE)

2.2  Sample N_SYNTH latent vectors {l_syn[j]} ~ p_latent(l)

2.3  Decode each sampled latent vector to synthetic spectrum:
        S_syn[j] = V @ l_syn[j] + mean(SPECTRA)

----------------------------------------------------------------------
Step 3 – Forward Model to Synthetic Photometry

For each synthetic spectrum S_syn[j]:
    3.1  For each filter f in FILTER_CURVES:
             m_syn[j][f] = ∫ S_syn[j](λ) * T_f(λ) dλ   // effective reflectance
    3.2  Add Gaussian noise:
             m_noisy[j][f] = m_syn[j][f] * (1 + Normal(0, σ_f))
             // σ_f chosen so that overall relative error ≈ 20%

Store pairs (m_noisy[j], l_syn[j]) for training.

----------------------------------------------------------------------
Step 4 – Train Encoder (Photometry → Latent Coefficients)

4.1  Split synthetic pairs into training set (e.g., 80%) and validation set (20%)
4.2  Use AutoML (e.g., AutoGluon) to build an ensemble regressor:
        INPUT: m_noisy[j]  (vector of length = number of filters)
        OUTPUT: l_pred[j]  (vector of length K)
4.3  Train until convergence; evaluate MAE on validation set (ignore for core algorithm).

----------------------------------------------------------------------
Step 5 – Train Taxonomic Classifier

5.1  For each training spectrum i:
        label[i] = known taxonomic class (e.g., H₂O, CO₂, Org, Meth)
5.2  Train a second AutoML classifier on latent coefficients L[i] with labels[label[i]]
5.3  Store classifier model.

----------------------------------------------------------------------
Step 6 – Inference for a New Target

6.1  Input PHOTOMETRY_NEW (vector of length = number of filters)

6.2  Encode to latent posterior:
        a.  Predict mean latent vector: μ_enc = Encoder.predict_mean(PHOTOMETRY_NEW)
        b.  Predict covariance (if regressor provides) or approximate:
                Cov_enc ≈ diagonal(var of predictions over ensemble members)
        c.  Sample N_POST latent vectors from Gaussian N(μ_enc, Cov_enc):
                l_post[s] ~ N(μ_enc, Cov_enc)

6.3  Decode each sampled latent vector to spectrum:
        S_post[s] = V @ l_post[s] + mean(SPECTRA)

6.4  Compute confidence intervals:
        For each wavelength λ:
            CI_low[λ]  = percentile(S_post[:, λ], 2.5)
            CI_high[λ] = percentile(S_post[:, λ], 97.5)

6.5  Taxonomy probabilities:
        For each sampled latent vector l_post[s]:
            probs[s] = Classifier.predict_prob(l_post[s])
        Aggregate:
            TAXONOMIC_PROBS = mean(probs, axis=0)   // average over samples

----------------------------------------------------------------------
Return:
    RECONSTRUCTED_SPECTRUM = μ_enc decoded via V (i.e., V @ μ_enc + mean)
    CONFIDENCE_INTERVALS   = (CI_low, CI_high)
    TAXONOMIC_PROBS
END
