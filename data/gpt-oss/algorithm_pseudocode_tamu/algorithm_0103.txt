Inputs
-------
- S_ref   : array[N_spec, N_wave] of high‑resolution spectra (reflectance)
- M_ref   : array[N_spec, N_phot] of corresponding photometric vectors
            (filter magnitudes or reflectances)
- T_ref   : array[N_spec] of taxonomic labels
- Filters : list of filter transmission curves {F_j(λ)}

Parameters
----------
- K       : number of principal components to retain (default 8–10)
- h_KDE   : kernel bandwidth for KDE (default 0.5)
- N_aug   : number of synthetic latent samples to generate (e.g. 10 000)
- σ_noise : relative photometric noise level (default 0.20)

Outputs
-------
- Reconstructed spectrum S_rec(λ) for a new photometric vector m
- Uncertainty band U(λ) (e.g. 68 % CI)
- Taxonomic probability vector P_tax

1.1  Center spectra:
        μ_S = mean(S_ref, axis=0)
        S_center = S_ref – μ_S

1.2  PCA decomposition:
        U, Σ, Vt = svd(S_center, full_matrices=False)
        PC_coeffs = S_center @ Vt.T[:, :K]          # shape (N_spec, K)
        PC_basis  = Vt.T[:, :K]                    # shape (N_wave, K)

1.3  KDE of latent space:
        fit a Gaussian KDE to PC_coeffs with bandwidth h_KDE
        KDE_pdf(x) ∝ Σ_i exp( - ||x - PC_coeffs[i]||² / (2 h_KDE²) )

1.4  Augment training set:
        Draw N_aug samples x_aug ~ KDE_pdf
        For each x_aug:
            synth_spectrum = μ_S + PC_basis @ x_aug
            synth_phot     = forward_model(synth_spectrum, Filters)
            add Gaussian noise: synth_phot_noisy = synth_phot * (1 + N(0,σ_noise))
        Store pairs (synth_phot_noisy, x_aug) as training data
        Also store original pairs (M_ref, PC_coeffs) for reference

2.1  Encoder (photometry → latent):
        Assemble training set:
            X_enc = concatenate( M_ref , synth_phot_noisy )   # shape (N_train, N_phot)
            Y_enc = concatenate( PC_coeffs , x_aug )         # shape (N_train, K)
        Use AutoML regressor (e.g. XGBoost + NN ensemble):
            regressor.fit(X_enc, Y_enc)

2.2  Classifier (latent → taxonomy):
        X_cls = PC_coeffs
        Y_cls = T_ref
        classifier.fit(X_cls, Y_cls)

2.3  Optional: calibrate predictive variance:
        If regressor outputs mean μ_pred and std σ_pred per coefficient,
        store these for inference.

Input: m_new  (vector of observed photometric points)

3.1  Predict latent distribution:
        μ_lat , σ_lat = regressor.predict(m_new)        # shape (K,) each
        # sample N_sample draws from multivariate normal:
        for i in 1..N_sample:
            x_i = multivariate_normal(μ_lat, diag(σ_lat²))

3.2  Decode spectra:
        For each x_i:
            s_i = μ_S + PC_basis @ x_i
        S_rec  = median(s_i over i)                      # point estimate
        U_low  = 16th percentile(s_i)
        U_high = 84th percentile(s_i)                   # 68 % CI

3.3  Taxonomy probabilities:
        For each x_i:
            p_i = classifier.predict_proba(x_i)
        P_tax = average(p_i over i)

Return S_rec(λ), U(λ), P_tax

forward_model(spectrum, Filters):
    For each filter j:
        R_j = ∫ spectrum(λ) * Filters[j](λ) dλ
               / ∫ Filters[j](λ) dλ
    Return vector [R_1, …, R_M]
