Input:  
    S_real = {s_j(λ)}   j = 1 … N   (high‑resolution reflectance spectra)  
    F_i(λ)               i = 1 … P   (filter throughput curves)  
Parameters:  
    K                     (number of principal components)  
    h                     (KDE bandwidth)  
    M                     (number of synthetic latent samples)  
    σ_phot                (relative photometric noise, e.g. 0.20)  

Steps:  
1.1  Resample all s_j to a common wavelength grid λ_k, k = 1 … L.  
1.2  Compute mean spectrum μ(λ) = (1/N) Σ_j s_j(λ).  
1.3  Center spectra:  Ŝ_j(λ) = s_j(λ) – μ(λ).  
1.4  Perform PCA on {Ŝ_j}:  
        * Obtain eigenvectors e_1,…,e_K (each length L).  
        * Store projection matrix E = [e_1 … e_K].  
1.5  Project centered spectra onto PCs:  
        α_j = Eᵀ · Ŝ_j   (α_j is K‑dimensional).  
1.6  Build prior over latent space:  
        * Fit Gaussian KDE to {α_j} with bandwidth h.  
        * Sample M latent vectors β_m ~ KDE.  
1.7  For each β_m:  
        a.  Decode to spectrum:  
                s*_m(λ) = μ(λ) + Σ_{k=1}^{K} β_{m,k}·e_k(λ).  
        b.  Forward‑model photometry:  
                m_{m,i} = ∫ s*_m(λ)·F_i(λ)dλ  /  ∫ F_i(λ)dλ   for i = 1…P.  
        c.  Add Gaussian noise:  
                m'_{m,i} = m_{m,i} · (1 + 𝒩(0,σ_phot)).  
1.8  Construct training set T:  
        T = { (m'_m, β_m) }   for m = 1…M.  
1.9  Train an AutoML regressor R (e.g., ensemble of GBDTs)  
        to map photometry → latent coefficients:  
                R: m'  ↦  β̂.  
1.10  Train an AutoML classifier C on {α_j} with taxonomic labels  
        to predict class probabilities from latent coordinates.

Input:  
    m_obs = {m_i}   i = 1 … P   (observed sparse photometry)  

Steps:  
2.1  Predict latent coefficients:  
        α̂ = R(m_obs).  
2.2  Estimate posterior of α:  
        * Compute prediction residual covariance Σ_res from training.  
        * Define multivariate normal N(α̂, Σ_res).  
        * Optionally impose a Gaussian Copula to enforce realistic
          dependence structure among PCs.  
2.3  Draw N_samples draws {α^(s)} from posterior.  
2.4  For each draw α^(s):  
        a.  Decode to spectrum:  
                s^(s)(λ) = μ(λ) + Σ_{k=1}^{K} α^{(s)}_k·e_k(λ).  
2.5  Aggregate spectra:  
        * Mean spectrum:  ⟨s(λ)⟩ = (1/N_samples) Σ_s s^(s)(λ).  
        * Credible interval at each λ:  e.g., 2.5th & 97.5th percentiles.  
2.6  Classify taxonomy:  
        p_class = C(α̂).   (probabilities over taxonomic labels)  

Output:  
    • Reconstructed spectrum ⟨s(λ)⟩ with credible intervals.  
    • Taxonomic probability vector p_class.
