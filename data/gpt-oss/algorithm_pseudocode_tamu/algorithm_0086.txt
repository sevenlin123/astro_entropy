Input: 
   - Seed spectra set  S_real = {S_1,…,S_N}  (reflectance vectors sampled on a fixed wavelength grid)
   - Filter set  F = {f_1,…,f_M}  (instrumental throughput curves)
   - Desired latent dimensionality K  (e.g. 8–10)
   - KDE bandwidth h  (e.g. 0.5)
   - Noise level σ_noise  (relative reflectance uncertainty, e.g. 20%)
   - Number of synthetic samples L  (e.g. 10 000)

Output:
   - PCA basis B = [b_1,…,b_K]
   - Mean spectrum μ_S
   - Trained regressor R  (photometry → latent coefficients)
   - Trained classifier C  (latent → taxonomic class probabilities)

1.1.1 Center spectra:  S_centered = S_real – mean(S_real)
1.1.2 Perform Singular Value Decomposition:  S_centered = U Σ V^T
1.1.3 Take first K right‑singular vectors:  B = V[:,1:K]      // K×N matrix
1.1.4 Store mean spectrum μ_S = mean(S_real)

For each S_i in S_real:
    z_i = B^T · (S_i – μ_S)          // K‑dimensional coefficient vector
Collect all z_i into matrix Z ∈ ℝ^{K×N}

Use Gaussian kernel K_h(z) = exp( -||z - z_i||² / (2 h²) ) / ( (2π h²)^{K/2} )
Define density p(z) = (1/N) Σ_{i=1}^{N} K_h(z – z_i)

Generate L samples {z*_1,…,z*_L} from p(z)  (e.g. by Monte Carlo rejection or direct sampling if available)

For each z* in synthetic samples:
    S* = μ_S + B · z*            // inverse PCA → full spectrum
Store pairs (z*, S*)  // latent → full spectrum

For each pair (z*, S*):
    For each filter f_m in F:
        μ_fm = ⟨ S* × T_fm ⟩ / ⟨ S⊙ × T_fm ⟩     // reflectance in filter m (solar spectrum removed)
        Add Gaussian noise:  m_fm = μ_fm + Normal(0, σ_noise·μ_fm)
    Concatenate all noisy filter values into vector m* = [m_f1,…,m_fM]
Store training example (m*, z*)  // photometry → latent

Fit a robust AutoML regression model R (e.g., Gradient‑Boosted Trees + Neural Nets) to map m* → z*
Loss: mean squared error over all training samples
Validate on a hold‑out subset to avoid overfitting

Label each z* by the taxonomic class of its parent seed spectrum (water, CO₂, organic, methanol).
Fit an AutoML classifier C to map z* → class probability vector.

Input: New photometric observation m_obs = [m_obs,1,…,m_obs,M]
Output:
    - Posterior samples of spectra {Ŝ_j}_{j=1..N_samp}
    - Class probability vector P_class
    - Summary statistics (median, 68% CI) for any spectral metric

1. Use trained regressor R to obtain point prediction:  ẑ = R(m_obs)
2. Estimate uncertainty of ẑ (e.g., via predictive variance from ensemble or bootstrapped model)
3. Construct multivariate Gaussian (mean=ẑ, covariance=Σ̂) as approximate posterior over latent space

4. Fit a correlation matrix ρ from training latent samples Z
5. Convert multivariate Gaussian samples to copula space:
       u_j = Φ( (z_j – μ_z) / σ_z )     // Φ = standard normal CDF
6. Apply Cholesky decomposition of ρ to maintain dependencies
7. Transform back to latent space:  z*_sample = μ_z + L·Φ^{-1}(u_sample)
   where L is lower‑triangular Cholesky factor of ρ
Generate N_samp independent draws {z*_k}

For each sample k:
    S_k = μ_S + B · z*_k
Store {S_k}

Compute class probabilities:  P_class = C(ẑ)  (or average over samples if desired)

Compute median spectrum:  S_med = median({S_k})
Compute 68% credible interval per wavelength:  CI_lower, CI_upper = percentile({S_k}, 16,84)
Return:
    - S_med
    - (CI_lower, CI_upper)
    - P_class

If any posterior sample S_k lies far outside the convex hull of training spectra in latent space
    Flag as potential outlier
Optionally refine KDE bandwidth or add new seed spectra for augmentation
