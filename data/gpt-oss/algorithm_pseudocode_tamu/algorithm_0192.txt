INPUT:
    S_ref   – Matrix of N_ref reference spectra (wavelength × flux)
    λ_ref   – Wavelength array for reference spectra
    F       – List of M filter transmission curves (each has λ_filter, T_filter)
    phot_obs– Observed photometry for new object: 
             { m_i ± σ_i }  for i = 1..M
    K_comp  – Number of principal components to retain (default 5–10)
    h_kde   – KDE bandwidth (default ≈0.5)
    n_syn   – Number of synthetic latent samples for training (default 10 000)

--------------------------------------------------------------------
1.  PREPROCESS & NORMALIZE
    ------------------------------------------------------------------
    1.1  Resample all reference spectra onto common λ_ref if needed.
    1.2  Normalize each spectrum (e.g., divide by flux at a reference λ).

--------------------------------------------------------------------
2.  BUILD PRIOR MANIFOLD (PCA + KDE)
    ------------------------------------------------------------------
    2.1  Compute PCA on S_ref → eigenvectors V[1..K_comp], eigenvalues λ_eig
    2.2  Project each reference spectrum onto PCs:
         z_ref[n] = Vᵀ · (s_ref[n] – μ_ref)      // μ_ref = mean spectrum
    2.3  Fit multivariate KDE to {z_ref[n]} using Gaussian kernel and bandwidth h_kde
    2.4  Draw n_syn latent vectors {z_syn[m]} ~ KDE

--------------------------------------------------------------------
3.  GENERATE SYNTHETIC TRAINING DATA
    ------------------------------------------------------------------
    3.1  For each synthetic latent vector z_syn[m]:
         3.1.1  Reconstruct high‑res spectrum:
                 s_syn[m] = μ_ref + V · z_syn[m]
         3.1.2  For each filter i:
                 m_syn[i] = ∫ s_syn[m](λ) · T_filter[i](λ) dλ / ∫ T_filter[i](λ) dλ
         3.1.3  Add Gaussian noise to each band:
                 m_noisy[i] = m_syn[i] + N(0, σ_noise²)
                 σ_noise = 0.20 * m_syn[i]          // 20 % relative uncertainty
    3.2  Store training pairs:
         X_train[m] = {m_noisy[1..M]}
         Y_train[m] = z_syn[m]

--------------------------------------------------------------------
4.  TRAIN AUTO‑ML REGRESSOR (ENCODER)
    ------------------------------------------------------------------
    4.1  Initialize AutoML framework (e.g., AutoGluon).
    4.2  Train regressor R on (X_train, Y_train) to predict latent vector.
         // Model outputs mean and, optionally, covariance of posterior
    4.3  Save trained regressor R.

--------------------------------------------------------------------
5.  TRAIN TAXONOMY CLASSIFIER (OPTIONAL)
    ------------------------------------------------------------------
    5.1  Label each reference spectrum with taxonomic class.
    5.2  Train classifier C on latent vectors z_ref → class labels.
    5.3  Save classifier C.

--------------------------------------------------------------------
6.  INFERENCE FOR NEW OBSERVATIONS
    ------------------------------------------------------------------
    INPUT: phot_obs = {m_i ± σ_i}

    6.1  Use regressor R to predict posterior over latent space:
         (μ_z, Σ_z) = R.predict_posterior(phot_obs)
    6.2  Construct Gaussian Copula:
         - Marginals: normal distributions with means μ_z[j], std dev √Σ_z[jj]
         - Correlation matrix ρ extracted from Σ_z
    6.3  Draw N_samples latent draws {z_draw[k]} from copula
    6.4  For each draw:
         6.4.1  Reconstruct spectrum:
                 s_draw[k] = μ_ref + V · z_draw[k]
    6.5  Compute statistics:
         - Posterior mean spectrum: ⟨s⟩ = average over k
         - Credible intervals: percentile bounds of {s_draw[k]}
    6.6  OPTIONAL: Predict taxonomic probabilities:
         class_probs = C.predict_probabilities(μ_z)

OUTPUT:
    - Reconstructed spectrum ⟨s⟩ with wavelength array λ_ref
    - Credible interval bands (e.g., 68 %, 95 %) per λ
    - Class probability vector (if classifier used)
