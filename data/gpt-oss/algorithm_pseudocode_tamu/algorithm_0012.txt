Input:
    S_ref[1..N]   – reference high‑resolution TNO spectra (wavelength array λ, reflectance R)
    F = {F_1,…,F_M} – filter throughput curves (effective bandpasses)
    m_obs         – new sparse photometry (reflectance in M filters)
    K             – number of PCA components to retain
    h             – KDE bandwidth (≈0.5)
    N_aug         – number of synthetic latent vectors to generate (≈5×10³)

Output:
    S_rec(λ)      – reconstructed spectrum
    CI(λ)         – spectral credible interval (e.g. 95 %)
    P_taxo         – posterior probability vector for each taxonomic class

--------------------------------------------------------------------
1. PRE‑PROCESSING
--------------------------------------------------------------------
1.1   Align all reference spectra to common λ grid (interpolate if needed).
1.2   Compute mean spectrum μ_R = mean(R_i) over i.
1.3   Center spectra: R'_i = R_i – μ_R  for all i.

--------------------------------------------------------------------
2. PRINCIPAL COMPONENT ANALYSIS (Latent Space Definition)
--------------------------------------------------------------------
2.1   Compute covariance matrix C = (R'^T · R') / (N–1).
2.2   Perform eigen‑decomposition: C = U Λ U^T.
2.3   Select first K eigenvectors U_K (columns 1..K).
2.4   Project reference spectra to latent space:
        z_i = U_K^T · R'_i          (z_i ∈ ℝ^K)

--------------------------------------------------------------------
3. PRIOR ESTIMATION (KDE AUGMENTATION)
--------------------------------------------------------------------
3.1   Fit Gaussian KDE to {z_i} with bandwidth h.
3.2   Draw N_aug synthetic latent vectors {z*} from the KDE.
3.3   For each z*, reconstruct a synthetic spectrum:
        R*_i  = U_K · z*_i  + μ_R
        Store (z*_i , R*_i).

--------------------------------------------------------------------
4. FORWARD MODELING (Synthetic Photometry Generation)
--------------------------------------------------------------------
4.1   For each synthetic spectrum R*_i:
        4.1.1   For each filter F_j:
                    m*_ij = ∫ R*_i(λ) · F_j(λ) dλ   (numerical integration)
        4.1.2   Add Gaussian noise:
                    σ_noise = 0.20 · m*_ij           // 20 % relative
                    m*_ij ← m*_ij + 𝒩(0, σ_noise²)
        4.1.3   Store pair (m*_i, z*_i).

Resulting training set:  { (m*_i , z*_i) }  for i = 1…N_aug.

--------------------------------------------------------------------
5. TRAINING THE ENCODER (AutoML Regressor)
--------------------------------------------------------------------
5.1   Feed the training set into an AutoML framework (e.g., AutoGluon).
5.2   Specify output dimension = K (latent coefficient vector).
5.3   Train the regressor to minimize mean‑squared error between predicted and true z*.
5.4   Validate convergence (hold‑out split or cross‑validation).
5.5   Save the trained model E(·)  // Encoder

--------------------------------------------------------------------
6. TRAINING THE CLASSIFIER (Optional)
--------------------------------------------------------------------
6.1   Label each reference spectrum with its taxonomic class.
6.2   Train a second AutoML model C(·) that maps z_i → class probabilities.
6.3   Save classifier C(·).

--------------------------------------------------------------------
7. INFERENCE ON NEW PHOTOMETRY
--------------------------------------------------------------------
7.1   Predict latent vector:
        ẑ  = E(m_obs)                     // point estimate
7.2   Optional: obtain predictive covariance Σ̂ from the regressor (if available).

--------------------------------------------------------------------
8. POSTERIOR SAMPLING (Gaussian Copula / KDE Weighted)
--------------------------------------------------------------------
8.1   For each synthetic latent vector z*_i with photometry m*_i:
        Compute likelihood weight:
            w_i = exp( –‖m_obs – m*_i‖² / (2 σ²) )      // σ taken from step 4.1.2
8.2   Normalize weights: W_i = w_i / Σ_j w_j
8.3   Resample N_post latent vectors {z_p} from {z*_i} according to {W_i}
        (e.g., multinomial draw with replacement).
8.4   For each sampled latent vector z_p:
        Reconstruct spectrum:
            R_p(λ) = U_K · z_p  + μ_R
8.5   Aggregate the {R_p} to obtain:
        - Point estimate: S_rec(λ) = mean_p [R_p(λ)]
        - Credible interval: e.g., 95 % CI = percentiles 2.5 % and 97.5 % of {R_p(λ)}
        - Taxonomic probabilities: P_taxo = C(ẑ)  // or average C(z_p) over samples

--------------------------------------------------------------------
9. OUTPUT
--------------------------------------------------------------------
Return:
    S_rec(λ)          – reconstructed reflectance spectrum
    CI(λ)             – spectral credible interval
    P_taxo            – posterior class probabilities
