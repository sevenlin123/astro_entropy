pseudocode
INPUT: 
    - SPECTRA = { s_i }   // high‑resolution reflectance spectra of N_ref ≈ 50 TNOs
    - FILTERS  = { f_j }   // effective throughput curves for the chosen instrument
    - K        // number of principal components (default: 5 or 8–10)
    - h        // KDE bandwidth (default: 0.5)
    - M        // number of synthetic latent samples to generate (e.g., 10 000)

--------------------------------------------------------------------
1.  Pre‑process spectra
    FOR each spectrum s_i IN SPECTRA:
        1.1  Interpolate s_i onto a common wavelength grid λ
        1.2  Normalise (e.g., divide by mean reflectance)
    END

--------------------------------------------------------------------
2.  Principal Component Analysis (PCA)
    2.1  Stack normalised spectra into matrix X (shape N_ref × N_λ)
    2.2  Compute mean spectrum μ_X
    2.3  Center data: X_c = X – μ_X
    2.4  Perform eigen‑decomposition of cov(X_c)
    2.5  Select first K eigenvectors V_K  (columns: PC1…PK)
    2.6  Project spectra onto PCs:
            LATENT_REAL = X_c · V_K      // shape N_ref × K

--------------------------------------------------------------------
3.  Construct prior density with Kernel Density Estimation (KDE)
    3.1  Fit multivariate KDE to LATENT_REAL using Gaussian kernel,
         bandwidth = h
    3.2  Sample M latent vectors:
            LATENT_SYNTH = KDE.sample(M)      // shape M × K

--------------------------------------------------------------------
4.  Generate synthetic spectra from sampled latents
    4.1  For each latent vector l in LATENT_SYNTH:
            4.1.1  Reconstruct spectrum:
                     s_syn = μ_X + l · V_Kᵀ   // inverse PCA
            4.1.2  Store s_syn
        END
    4.2  Collect all synthetic spectra into SYNTH_SPECTRA

--------------------------------------------------------------------
5.  Forward‑model synthetic photometry
    5.1  For each synthetic spectrum s_syn:
            5.1.1  For each filter f_j:
                     m_j = ∫ s_syn(λ) · f_j(λ) dλ / ∫ f_j(λ) dλ
            5.1.2  Assemble photometry vector m = [m_1 … m_Nf]
            5.1.3  Add Gaussian noise:
                     m_noisy = m + N(0, σ²) ,
                     σ = 0.2 · m    // 20 % relative uncertainty
            5.1.4  Store (m_noisy, latent l)
        END
    5.2  Compile training set TRAIN_SET = {(m_noisy, l)}

--------------------------------------------------------------------
6.  Train AutoML encoder (regressor)
    6.1  INPUT  = photometry vectors (length Nf)
    6.2  TARGET = latent coefficients (length K)
    6.3  Use AutoML framework (e.g., AutoGluon) to build an ensemble of
         gradient‑boosted decision trees / neural nets
    6.4  Fit the model on TRAIN_SET → MODEL_ENCODER

--------------------------------------------------------------------
7.  Train AutoML classifier
    7.1  FEATURE  = LATENT_REAL (K‑dimensional)
    7.2  LABEL    = known taxonomy (Water, CO₂, Organic, Methanol, …)
    7.3  Fit classifier on FEATURE → MODEL_CLASSIFIER

--------------------------------------------------------------------
OUTPUT:
    MODEL_ENCODER , MODEL_CLASSIFIER ,
    PCA_mean μ_X , PCA_basis V_K ,
    KDE_prior (for future density checks)

pseudocode
INPUT:
    - m_obs = observed photometry vector (length Nf)
    - MODEL_ENCODER, MODEL_CLASSIFIER, μ_X, V_K

--------------------------------------------------------------------
1.  Predict latent coefficient posterior
    1.1  Use MODEL_ENCODER to predict mean latent vector:
            l̂ = MODEL_ENCODER.predict(m_obs)
    1.2  Estimate uncertainties (e.g., via quantile regression outputs
          or by sampling from the ensemble predictions)
          → obtain covariance Σ_l (K×K) or separate marginal stds

--------------------------------------------------------------------
2.  Sample posterior latent vectors with Gaussian copula
    2.1  Define marginal distributions (e.g., Gaussian with means l̂
          and stds from step 1.2)
    2.2  Construct correlation matrix R from Σ_l
    2.3  Draw N_MC samples {l_k} from the Gaussian copula
          (typical N_MC ≈ 500–1000)

--------------------------------------------------------------------
3.  Decode to spectra
    3.1  For each sampled latent l_k:
            s_k = μ_X + l_k · V_Kᵀ      // inverse PCA
        END
    3.2  Collect all s_k → RECONSTRUCTED_SPECTRA

--------------------------------------------------------------------
4.  Summarise reconstruction
    4.1  Compute point estimate (e.g., mean spectrum):
            s_mean = mean(RECONSTRUCTED_SPECTRA, axis=0)
    4.2  Compute credible intervals per wavelength:
            lower, upper = percentile(RECONSTRUCTED_SPECTRA, [2.5, 97.5])

--------------------------------------------------------------------
5.  Taxonomic classification
    5.1  Feed l̂ (or its posterior mean) into MODEL_CLASSIFIER
    5.2  Obtain class probabilities P(class | m_obs)

--------------------------------------------------------------------
OUTPUT:
    - s_mean          // reconstructed spectrum
    - lower, upper    // 95 % credible band
    - P(class | m_obs) // taxonomy posterior
