Input:
    S_ref[1..N]   // Reference spectra (high‑resolution reflectance vectors)
    λ_ref[1..L]   // Wavelength grid of reference spectra
    F_j[1..M]     // Throughput curves of M photometric filters
    σ_noise       // Relative photometric noise level (e.g., 0.20)
    K             // Number of PCA components (e.g., 8–10)
    h_KDE         // KDE bandwidth (≈0.5)
    N_aug         // Number of synthetic latent samples (e.g., 5000)

Output:
    Reconstruction function R( m ) → posterior distribution of spectrum
    Classifier C( m ) → taxonomic probability vector

Procedure:

1. **Principal Component Basis Construction**
   1.1 Center spectra: S_centered = S_ref – mean(S_ref)
   1.2 Compute covariance matrix C = (S_centeredᵀ * S_centered) / (N−1)
   1.3 Perform eigendecomposition: C = U Λ Uᵀ
   1.4 Select first K eigenvectors: P = U[:,1:K]
   1.5 Project reference spectra to latent space:
        z_ref[i] = Pᵀ * (S_ref[i] – mean(S_ref))   for i = 1..N

2. **Latent Manifold Augmentation (KDE)**
   2.1 Fit multivariate KDE to {z_ref} with bandwidth h_KDE
   2.2 Sample N_aug latent vectors:
        {z_syn[j]} = KDE.sample()   for j = 1..N_aug
   2.3 For each z_syn[j], reconstruct synthetic spectrum:
        S_syn[j] = mean(S_ref) + P * z_syn[j]

3. **Forward Model Photometry Generation**
   3.1 For each synthetic spectrum S_syn[j]:
        For each filter f = 1..M:
            m_f[j] = ∫ S_syn[j](λ) * F_f(λ) dλ   // Convolution
   3.2 Add Gaussian noise:
        m_f_noisy[j] = m_f[j] * (1 + Normal(0, σ_noise))

4. **Training Data Assembly**
   4.1 Input features X = {m_noisy[j]}   // Shape (N_aug × M)
   4.2 Target outputs Y = {z_syn[j]}   // Shape (N_aug × K)
   4.3 Train regressor R_model (AutoML, e.g., Gradient‑Boosted Trees) on (X, Y)

5. **Taxonomy Classifier (Optional)**
   5.1 Label each reference spectrum with taxonomic class T[i]
   5.2 Train classifier C_model on (z_ref[i], T[i])

6. **Inference for New Observation**
   Given new photometric measurement m_obs[1..M] with uncertainties σ_m:
   6.1 Predict latent coefficient mean and covariance:
        [μ_z , Σ_z] = R_model.predict_with_uncertainty(m_obs)
   6.2 Construct Gaussian Copula:
        - Draw N_samples latent vectors z_sample[k] ~ Copula( μ_z, Σ_z )
   6.3 Decode spectra:
        For each k:
            S_k = mean(S_ref) + P * z_sample[k]
   6.4 Estimate posterior statistics:
        - Posterior mean spectrum = mean_k( S_k )
        - Credible interval per wavelength = percentile_k( S_k , α/2, 1-α/2 )
   6.5 Taxonomy probabilities:
        For each class c:
            p_c = average_k( C_model.predict_prob( z_sample[k] = c ) )

Return:
    Posterior mean spectrum, credible intervals, and taxonomy probability vector
