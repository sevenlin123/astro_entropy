INPUT:
    - Reference spectra S_ref[1…Ns]   (high‑resolution reflectance vectors, λ = 1…L)
    - Corresponding taxonomic labels C_ref[1…Ns]   (H2O, CO2, Organic, Methanol)
    - Filter transmission curves {T_b(b)}   (b = 1…B)
    - New sparse photometry m_new[1…B]        (reflectance in each filter)

PARAMETERS:
    - K          : number of principal components (e.g. 8–10)
    - h          : KDE bandwidth (≈0.5)
    - M          : number of synthetic latent samples (e.g. 5000)
    - σ_noise    : relative photometric noise (20 %)
    - N_samp     : number of posterior samples (e.g. 1000)

--------------------------------------------------------------------
1.  PREPARATION – PCA
    ------------------------------------------------------------------
    1.1  Compute mean spectrum μ_S  = mean(S_ref)
    1.2  Center spectra: S_c = S_ref – μ_S
    1.3  Perform PCA on S_c:
           U , Σ = eigen‑decomposition of covariance(S_c)
           Retain first K eigenvectors U_K
    1.4  Project each reference spectrum onto PCA space:
           C_ref = S_c · U_K          // K‑dimensional coefficient vectors

--------------------------------------------------------------------
2.  PRIOR ESTIMATION – KDE
    ------------------------------------------------------------------
    2.1  Fit multivariate Gaussian KDE to {C_ref} with bandwidth h
    2.2  Draw M synthetic coefficient samples:
           C_syn[1…M]  ~ KDE(C_ref)
    2.3  Reconstruct synthetic spectra:
           S_syn[i] = μ_S + U_K · C_syn[i]^T      // L‑dimensional vectors

--------------------------------------------------------------------
3.  FORWARD MODELING – Synthetic Photometry
    ------------------------------------------------------------------
    3.1  For each synthetic spectrum S_syn[i]:
            For each filter b:
                f_syn[i,b] = ∫ S_syn[i](λ) · T_b(λ) dλ / ∫ T_b(λ) dλ
            // f_syn[i,:] are noiseless fluxes in B filters
    3.2  Add Gaussian noise:
            For each i, b:
                m_syn[i,b] = f_syn[i,b] · (1 + N(0,σ_noise))
    3.3  Compile training set:
            Features  X = {m_syn[i,:]}   // shape (M × B)
            Targets   Y = {C_syn[i,:]}   // shape (M × K)
            Labels    Z = {C_ref}        // shape (Ns × 1)

--------------------------------------------------------------------
4.  MODEL TRAINING
    ------------------------------------------------------------------
    4.1  Train AutoML regressor R:
            Input: X
            Output: Predicted latent coefficients  Ĉ  (mean prediction)
            (R may internally produce predictive variance or an ensemble)

    4.2  Train AutoML classifier T:
            Input: C_ref
            Output: Class probabilities P(class|latent)

--------------------------------------------------------------------
5.  INFERENCE – Posterior Sampling
    ------------------------------------------------------------------
    5.1  Predict latent mean and covariance from R:
            μ̂_C , Σ̂_C = R.predict_with_uncertainty(m_new)
    5.2  Construct Gaussian Copula (optional):
            • Compute correlation matrix ρ from training latent samples
            • Transform μ̂_C, Σ̂_C into correlated multivariate normal
    5.3  Draw N_samp samples of latent coefficients:
            For s = 1 … N_samp:
                C_samp[s] ~ MVNormal(μ̂_C, Σ̂_C)   // respecting ρ if using copula
    5.4  Decode spectra:
            For each s:
                S_rec[s] = μ_S + U_K · C_samp[s]^T
    5.5  Aggregate results:
            • Posterior mean spectrum μ_Srec = mean(S_rec)
            • Credible interval at each λ: e.g. 2.5th & 97.5th percentiles
    5.6  Classify:
            P_cls = T.predict_probabilities(μ̂_C)

OUTPUT:
    - μ_Srec              : reconstructed spectrum (mean)
    - CI_Srec[λ]          : credibility intervals per wavelength
    - P_cls               : probability distribution over taxonomic classes
