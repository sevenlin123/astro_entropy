INPUT:
    - Spectral library S = {s_i(λ)}   // N_ref ≈ 50 high‑resolution TNO spectra
    - Taxonomic labels L = {l_i}       // H₂O, CO₂, Organic, Methanol
    - Filter set F = {F_j(λ)}          // e.g., JWST NIRCam bands
    - New photometric observation m_new = {m_j}  // j = 1…N_phot

CONSTANTS:
    - K          // number of retained principal components (4–10)
    - h_KDE      // bandwidth for Gaussian KDE (≈0.5)
    - M_samples  // number of synthetic latent vectors to generate (e.g., 5000)
    - N_draws    // number of posterior samples for inference (e.g., 1000)

--------------------------------------------------------------------
STEP 1 – TRAINING PHASE
--------------------------------------------------------------------

1.1  Pre‑process spectra:
        • Normalize each s_i(λ) to unit mean reflectance.
        • Interpolate to common wavelength grid λ_grid.

1.2  Perform Principal Component Analysis (PCA):
        • Compute covariance matrix C over S.
        • Obtain eigenvalues {σ_k²} and eigenvectors {e_k(λ)}.
        • Select first K eigenvectors; form basis matrix E = [e_1 … e_K].
        • Project spectra onto basis:
              z_i = Eᵀ · s_i   // z_i ∈ ℝ^K   (latent coordinates)

1.3  Kernel Density Estimation (KDE) in latent space:
        • Fit Gaussian KDE with bandwidth h_KDE to {z_i}.
        • For r = 1 … M_samples:
              • Sample latent vector ζ_r from KDE.
              • Store ζ_r.

1.4  Generate synthetic training pairs:
        For each ζ_r:
            a. Reconstruct spectrum:
                  s_syn(λ) = E · ζ_r + μ_s        // μ_s = mean spectrum
            b. Forward‑model photometry:
                  For each filter j:
                      m_syn,j = ∫ s_syn(λ) · F_j(λ) dλ / ∫ F_j(λ) dλ
            c. Perturb photometry with Gaussian noise (σ_noise = 0.20 × m_syn,j):
                  m_syn,j ← m_syn,j + Normal(0, σ_noise)
            d. Store pair (m_syn, ζ_r).

1.5  Train AutoML encoder (regressor):
        • Input: noisy photometry vector m_syn (dimension N_phot).
        • Target: latent vector ζ_r (dimension K).
        • Use AutoML framework (e.g., AutoGluon) to fit a model R(m) → ζ̂.
        • Save trained regressor R.

1.6  Train AutoML classifier in latent space:
        • Input: latent vectors {z_i} from real spectra.
        • Target: taxonomy label l_i.
        • Fit classifier C(z) → P(l | z).
        • Save trained classifier C.

--------------------------------------------------------------------
STEP 2 – INFERENCE PHASE (for each new observation)
--------------------------------------------------------------------

2.1  Predict latent distribution from photometry:
        • Compute point estimate:
              ζ̂_mean = R(m_new)
        • Estimate covariance Σ̂ (e.g., via ensemble variance of R or by
          fitting a Gaussian to training residuals).
        • Form Gaussian copula representation of posterior:
              p(z | m_new)  ≈  N(ζ̂_mean, Σ̂)  with KDE‑derived correlations.

2.2  Sample latent vectors:
        For n = 1 … N_draws:
            • Draw z_n from N(ζ̂_mean, Σ̂) respecting copula correlation.
            • Optionally truncate to physically valid region using KDE support.

2.3  Reconstruct spectra:
        For each z_n:
            • s_n(λ) = E · z_n + μ_s
        • Store ensemble {s_n(λ)}.

2.4  Compute posterior summaries:
        • Posterior mean spectrum:
              s_post(λ) = (1/N_draws) Σ_n s_n(λ)
        • Credible intervals (e.g., 68%, 95%) at each λ:
              CI_lower(λ), CI_upper(λ) = percentile_{16,84}( {s_n(λ)} )

2.5  Taxonomic classification:
        • Evaluate classifier:
              P(l | m_new) = C(ζ̂_mean)
        • Report probability vector over classes.

OUTPUT:
    - Reconstructed spectrum s_post(λ) with credible intervals.
    - Taxonomy probabilities P(l | m_new).
