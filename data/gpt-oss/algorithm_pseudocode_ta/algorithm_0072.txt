INPUT
    Training spectra {S_i(λ)}  i = 1 … N   (flux vs wavelength)
    Filter set {F_f}              f = 1 … M
    Target photometry {m_f, σ_f}  (magnitudes & uncertainties)

OUTPUT
    Reconstructed spectrum S_rec(λ)
    Spectral uncertainty σ_rec(λ)

----------------------------------------------------------
1. Pre‑process training spectra
   1.1 Resample all S_i(λ) onto a common wavelength grid λ_j
   1.2 Normalize each spectrum (e.g., divide by mean flux or set reference band)

2. Principal‑Component Analysis (PCA)
   2.1 Compute mean spectrum μ_s(λ) = (1/N) Σ_i S_i(λ)
   2.2 Center spectra: X_i(λ) = S_i(λ) – μ_s(λ)
   2.3 Form data matrix X  (size N × L, L = #wavelength points)
   2.4 Compute covariance C = (1/(N−1)) Xᵀ X
   2.5 Eigen‑decompose C → eigenvalues {λ_k} and eigenvectors {PC_k(λ)}
        (k = 1 … N)
   2.6 Select K components that explain desired variance
        (e.g., K ≈ 8–10).  
        Retain {PC_k, λ_k, k = 1…K}

3. Project PCs onto filter space
   For each filter f:
       For each component k:
           p_{k,f} = ∫ PC_k(λ) · R_f(λ) dλ / ∫ R_f(λ) dλ
   Also compute mean photometry for training set:
       μ_m_f = mean of {∫ μ_s(λ)·R_f(λ) dλ / ∫ R_f(λ) dλ}  over i

4. Build Bayesian model for coefficient vector z = [z_1 … z_K]ᵀ
   4.1 Likelihood (Gaussian):
        L(z) ∝ exp{ −½ Σ_f [ (m_f − μ_m_f − Σ_k z_k p_{k,f}) / σ_f ]² }
   4.2 Prior (Gaussian, zero mean, variance λ_k):
        π(z) ∝ exp{ −½ Σ_k z_k² / λ_k }

5. Compute posterior over z (analytic for Gaussian–Gaussian case)
   5.1 Define design matrix P (size K × M) with entries P_{k,f} = p_{k,f}
   5.2 Diagonal prior covariance Λ = diag(λ_1 … λ_K)
   5.3 Posterior covariance:
        Σ_post = ( P diag(σ_f⁻²) Pᵀ + Λ⁻¹ )⁻¹
   5.4 Posterior mean:
        μ_post = Σ_post · P diag(σ_f⁻²) · (m − μ_m)   // vectors of length K
   5.5 Optional: draw samples z^(s) ~ N(μ_post, Σ_post)

6. Reconstruct spectrum
   6.1 Point estimate:
        S_rec(λ) = μ_s(λ) + Σ_k μ_post_k · PC_k(λ)
   6.2 Uncertainty per wavelength:
        σ_rec²(λ) = Σ_{i,j} PC_i(λ) · Σ_post_{ij} · PC_j(λ)

7. Return S_rec(λ) and σ_rec(λ)
