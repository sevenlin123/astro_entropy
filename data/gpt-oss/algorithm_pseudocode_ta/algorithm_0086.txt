Input:
    S_spec   – matrix of training near‑IR spectra (N_spec × N_wave)
    W        – list of wavelength grid points (N_wave)
    Filt     – list of photometric filter response functions f_k(λ) for k=1…K
    m_phot   – observed photometry vector for target object (K)
    σ_phot   – observational uncertainties for each filter (K)

Output:
    S_rec    – reconstructed full spectrum (N_wave)
    Cov_rec  – covariance matrix of reconstruction at each wavelength

-----------------------------------------------------------------------
1. Principal Component Analysis (PCA) on Training Spectra
   -------------------------------------------------------------------
   1.1 Compute mean spectrum μ = (1/N_spec) Σ_i S_spec[i,:]
   1.2 Center spectra: X = S_spec - μ
   1.3 Perform Singular Value Decomposition (SVD):
          X = U · Σ · V^T
      where columns of V (size N_wave×N_wave) are eigenvectors
   1.4 Select leading M PCs (M ≈ 8–10 for reconstruction fidelity):
          PC = V[:, 1:M]           // N_wave × M matrix
   1.5 Compute training scores (latent coefficients):
          C_train = X · PC          // N_spec × M

2. Forward Model: Predicted Photometry from Latent Coefficients
   ----------------------------------------------------------------
   Define function PhotometryFromCoeffs(c):
       # c : M‑dimensional coefficient vector
       S = μ + PC · c               # reconstructed spectrum (N_wave)
       for each filter k:
           p_k = ∫ S(λ) · f_k(λ) dλ / ∫ f_k(λ) dλ
       return p   // K‑dimensional predicted photometry vector
   Note: Integrals can be approximated by weighted sums over wavelength grid.

3. Bayesian Inference of Latent Coefficients
   -----------------------------------------
   Prior on c: Gaussian with zero mean and diagonal covariance
                Σ_prior = diag(σ_prior^2)   // σ_prior derived from training scores
   Likelihood:  p(m_phot | c) ∝ exp[ -0.5 Σ_k ((m_k - PhotometryFromCoeffs(c)_k)/σ_phot_k)^2 ]

   3.1 Compute posterior analytically (conjugate case) or numerically:
       - Option A (linear Gaussian): Solve weighted linear system
           J = ∂Photometry/∂c evaluated at c=0  // Jacobian, size K×M
           Σ_post = (J^T·W_inv·J + Σ_prior^{-1})^{-1}
           μ_post = Σ_post · J^T · W_inv · m_phot
           where W_inv = diag(1/σ_phot^2)
       - Option B (MCMC): run Hamiltonian Monte Carlo to draw samples {c_s}.

   3.2 Store posterior mean μ_post and covariance Σ_post
       (or sample set {c_s}).

4. Reconstruction of Full Spectrum
   ---------------------------------
   4.1 Expected spectrum:
         S_rec = μ + PC · μ_post
   4.2 Uncertainty propagation:
         For each wavelength λ_i:
             Cov_rec(i,i) = PC[i,:] · Σ_post · PC[i,:]^T
         (covariance between different λ points can be computed similarly if needed)

5. Output
   ----------
   Return S_rec and Cov_rec (optionally the posterior samples {c_s}).
