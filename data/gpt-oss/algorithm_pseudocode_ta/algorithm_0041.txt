Input:
    S_train = {s_k(λ)}   // n_train spectra sampled on common wavelength grid λ
    F = {filter_j(λ)}     // n_filters filter transmission curves
    phot_obs = {p_j}      // observed photometry for a new target
    err_obs = {σ_j}       // measurement uncertainties for photometry

Parameters:
    k_min, k_max          // range of PCs to test (e.g. 4–10)
    prior_variance        // variance of Gaussian prior on PC coefficients

Output:
    spec_pred(λ)          // reconstructed spectrum (posterior mean)
    spec_unc(λ)           // posterior standard deviation per wavelength
    coeff_post_mean       // posterior mean of PC coefficients
    coeff_post_cov        // posterior covariance matrix of PC coefficients

------------------------------------------------------------------
Step 0 – Pre‑processing of training spectra
------------------------------------------------------------------
1.1   Interpolate all s_k onto a common wavelength grid λ.
1.2   Normalize each spectrum (e.g. divide by value at reference λ0).
1.3   Compute mean spectrum μ(λ) = mean_k[s_k(λ)].
1.4   Center spectra: X_k(λ) = s_k(λ) – μ(λ).

------------------------------------------------------------------
Step 1 – Principal‑Component Analysis
------------------------------------------------------------------
2.1   Construct data matrix X  of size (n_train × n_λ) where rows are X_k.
2.2   Compute singular‑value decomposition: X = U Σ Vᵀ.
2.3   Select first k PCs: V_k = Vᵀ[:k]  (each row is a PC over λ).
2.4   Project training spectra onto PCs:
        C_k = U[:, :k] * Σ[:k]          // PC coefficient matrix (n_train × k)
2.5   Store PCs V_k and mean μ.

------------------------------------------------------------------
Step 2 – Forward photometric model of the PCs
------------------------------------------------------------------
3.1   For each filter j:
        Compute mean photometry:
            m_j = ∫ μ(λ) * filter_j(λ) dλ
        For each PC i (1…k):
            r_{j,i} = ∫ V_k[i](λ) * filter_j(λ) dλ
3.2   Assemble response matrix R of size (n_filters × k) with entries r_{j,i}.
3.3   Assemble mean vector M of length n_filters with entries m_j.

------------------------------------------------------------------
Step 3 – Bayesian inference of PC coefficients
------------------------------------------------------------------
4.1   Define Gaussian prior on coefficients:
        p(c) ~ N(0, Λ)   where Λ = prior_variance * I_k
4.2   Define Gaussian likelihood:
        p(p | c) ~ N(M + R c, diag(err_obs²))
4.3   Compute weight matrix W = diag(1 / err_obs²).
4.4   Compute posterior covariance:
        Σ_post = (Rᵀ W R + Λ⁻¹)⁻¹
4.5   Compute posterior mean:
        μ_post = Σ_post (Rᵀ W (phot_obs – M))
4.6   Return μ_post (coeff_post_mean) and Σ_post (coeff_post_cov).

------------------------------------------------------------------
Step 4 – Reconstruction of the spectrum
------------------------------------------------------------------
5.1   Posterior‑predictive mean spectrum:
        spec_pred(λ) = μ(λ) + Σ_i μ_post[i] * V_k[i](λ)
5.2   Propagate uncertainties:
        For each λ, compute variance:
            var(λ) = Σ_{i,j} V_k[i](λ) * Σ_post[i,j] * V_k[j](λ)
        spec_unc(λ) = sqrt(var(λ))

------------------------------------------------------------------
Optional Step 5 – Sampling for full posterior predictive
------------------------------------------------------------------
6.1   Draw N samples c^(n) ~ N(μ_post, Σ_post).
6.2   For each sample, construct spec^(n)(λ) = μ(λ) + V_k · c^(n).
6.3   Estimate credible intervals at each λ from the collection {spec^(n)(λ)}.

------------------------------------------------------------------
End of algorithm
------------------------------------------------------------------
