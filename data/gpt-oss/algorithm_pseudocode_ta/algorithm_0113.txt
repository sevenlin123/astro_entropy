INPUT
    Training spectra {S_j(λ)}   j = 1 … N_train
    Common wavelength grid {λ_k}   k = 1 … K
    Filter set {F_f}              f = 1 … N_filter
        with transmission profiles T_f(λ_k)
    Target photometric measurements {y_f}
        and measurement uncertainties {σ_f}

PARAMETERS
    Number of principal components M      (e.g., M = 8–10)

OUTPUT
    Reconstructed full spectrum ŝ(λ_k)
    Uncertainty band σ_s(λ_k)  (e.g., ±1σ credible interval)

--------------------------------------------------------------------
STEP 1 – Pre‑process training spectra
--------------------------------------------------------------------
1.1  For each spectrum S_j:
        1.1.1  Interpolate/resample onto common grid {λ_k}
        1.1.2  Store as column vector S_j ∈ ℝ^K

1.2  Compute mean spectrum:
        μ = (1/N_train) Σ_{j=1}^{N_train} S_j          // μ ∈ ℝ^K

1.3  Center spectra:
        X_j = S_j – μ                                 // X_j ∈ ℝ^K

--------------------------------------------------------------------
STEP 2 – Principal Component Analysis
--------------------------------------------------------------------
2.1  Compute covariance matrix of centered spectra:
        C = (1/(N_train – 1))  X^T X                   // C ∈ ℝ^{K×K}

2.2  Eigen‑decompose C:
        [λ_vals, V] = eig(C)                          // V columns are eigenvectors

2.3  Sort eigenpairs by decreasing λ_vals
        Keep first M eigenvectors → B ∈ ℝ^{K×M}
            B(:,l) = V(:,l)  for l = 1 … M

--------------------------------------------------------------------
STEP 3 – Build coefficient statistics
--------------------------------------------------------------------
3.1  For each training spectrum j:
        a_j = B^T (S_j – μ)                           // a_j ∈ ℝ^M

3.2  Compute coefficient prior statistics:
        μ_a = (1/N_train) Σ_j a_j                      // ≈ 0 after centering
        Σ_a = (1/(N_train – 1)) Σ_j (a_j – μ_a)(a_j – μ_a)^T   // Σ_a ∈ ℝ^{M×M}

--------------------------------------------------------------------
STEP 4 – Forward model for photometry
--------------------------------------------------------------------
4.1  For each filter f:
        4.1.1  Compute baseline flux of mean spectrum:
                b_f = Σ_k T_f(λ_k) * μ(λ_k) * Δλ_k
        4.1.2  Compute linear operator from coefficients to flux:
                For l = 1 … M:
                    A_{f,l} = Σ_k T_f(λ_k) * B(k,l) * Δλ_k
    // Result: A ∈ ℝ^{N_filter × M},  b ∈ ℝ^{N_filter}

--------------------------------------------------------------------
STEP 5 – Bayesian inference of coefficients
--------------------------------------------------------------------
5.1  Assemble observation vector y ∈ ℝ^{N_filter}  (given photometry)
5.2  Construct measurement noise covariance:
        C_y = diag(σ_1^2, …, σ_{N_filter}^2)

5.3  Compute posterior covariance:
        Σ_post = ( A^T C_y^{-1} A + Σ_a^{-1} )^{-1}          // Σ_post ∈ ℝ^{M×M}

5.4  Compute posterior mean of coefficients:
        a_hat = Σ_post ( A^T C_y^{-1} (y – b) + Σ_a^{-1} μ_a )

--------------------------------------------------------------------
STEP 6 – Reconstruct full spectrum and uncertainties
--------------------------------------------------------------------
6.1  Reconstructed spectrum:
        ŝ = μ + B * a_hat                                 // ŝ ∈ ℝ^K

6.2  Uncertainty propagation:
        Var_s = diag( B * Σ_post * B^T )                  // variance per λ_k
        σ_s = sqrt(Var_s)                                  // 1‑σ credible interval

--------------------------------------------------------------------
RETURN
    ŝ(λ_k)   // reconstructed full spectrum
    σ_s(λ_k)   // associated uncertainty band
