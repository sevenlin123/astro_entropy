Input: 
    - Training spectra matrix S  [N_spec × N_wave]  
    - Desired number of PCs K  (e.g., 8–10)

Steps:
1.1 Compute mean spectrum μ_wave = mean(S, axis=0).
1.2 Center data:  S_c = S – μ_wave  (broadcast subtraction).
1.3 Perform Singular Value Decomposition:  
        U, Σ, Vt = svd(S_c, full_matrices=False)
   where Vt contains the right singular vectors (PCs).
1.4 Select the first K PCs:  
        PCs = Vt[:K, :]      # shape [K × N_wave]
1.5 Store: μ_wave, PCs, Σ[0:K]  (singular values for later scaling).

Input: 
    - PCs  [K × N_wave] 
    - Mean spectrum μ_wave [N_wave] 
    - List of filters {F_j} with transmission curves T_j(λ)

Steps:
2.1 For each filter F_j:
        • Integrate mean spectrum: μ_filter[j] = ∫ μ_wave(λ) * T_j(λ) dλ / ∫ T_j(λ) dλ
        • Integrate each PC:   
              PC_filter[k,j] = ∫ PCs[k,λ] * T_j(λ) dλ / ∫ T_j(λ) dλ
2.2 Assemble design matrix B:  
        B = [ μ_filter  ,  PC_filter ]    # shape [N_filters × (1+K)]

Input: 
    - Observed photometry y_obs  [N_f]     (fluxes or magnitudes)
    - Measurement uncertainties σ_obs  [N_f]
    - Design matrix B  [N_f × (1+K)]  from step 2
    - Prior on coefficient vector a = [a_0, a_1,…,a_K]  (e.g., Normal(0, τ²))

Assumption: Gaussian likelihood and Gaussian prior → Closed‑form posterior.

Steps:
3.1 Compute precision matrices:  
        Λ_y = diag(1/σ_obs²)               # data precision
        Λ_a = I/(τ²)                       # prior precision (I = identity)

3.2 Posterior precision:  
        Λ_post = Bᵀ · Λ_y · B + Λ_a
3.3 Posterior mean:  
        μ_post = Λ_post⁻¹ · (Bᵀ · Λ_y · y_obs + Λ_a · 0)
3.4 Posterior covariance:  
        Σ_post = Λ_post⁻¹

3.5 Draw M samples from N(μ_post, Σ_post):  
        a_samples[m]  for m = 1…M

Output: Posterior samples of coefficient vector a.

Input: 
    - Posterior samples a_samples  [M × (1+K)]
    - Mean spectrum μ_wave
    - PCs  [K × N_wave]

Steps:
4.1 For each sample m:
        • Reconstruct spectrum s_m = μ_wave + Σ_{k=1}^{K} a_samples[m,k] * PCs[k,:]
4.2 Aggregate reconstructions:
        • Posterior mean spectrum:  s_mean = mean(s_m over m)
        • Credible interval at each wavelength λ:  
              lower, upper = percentile(s_m[:,λ], [2.5, 97.5])
4.3 (Optional) Predictive photometry:
        • For each filter j, compute predicted flux:  
              f_pred[m,j] = μ_filter[j] + Σ_k a_samples[m,k]*PC_filter[k,j]
        • Compare to y_obs to check consistency.

Output: 
    - s_mean  (reconstructed spectrum)
    - s_lower, s_upper  (95 % credible bands)
    - Optionally predictive fluxes and residuals.

5.1 Evaluate posterior probability density of a for all objects in a catalog.
5.2 Identify objects with posterior densities below a chosen threshold.
5.3 For these outliers, optionally recompute with higher K or adjust prior to capture extreme features.
