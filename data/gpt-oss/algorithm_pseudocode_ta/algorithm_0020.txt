Input:
    S[1..N]   –  N reference TNO spectra sampled at wavelengths λ[1..L]
    K         –  desired number of principal components (e.g., 4–10)

Procedure:
    1.1   Compute the mean spectrum μ(λ) = (1/N) Σ_i S[i](λ)
    1.2   Center spectra:  S_c[i](λ) = S[i](λ) – μ(λ)
    1.3   Build data matrix X of shape (N, L):  X[i, l] = S_c[i](λ_l)
    1.4   Perform Singular Value Decomposition (SVD):
            X = U Σ Vᵀ
        →  Columns of V are orthonormal eigen‑spectra (principal components)
    1.5   Select first K columns of V → PC[1..K](λ)
    1.6   Store eigen‑values λ_k = Σ[k,k]² / (N-1)   (variance explained by each component)
Output:
    μ(λ), PC[1..K](λ), λ_k

Input:
    PC[1..K](λ)   –  Principal components (each length L)
    R_j(λ)       –  Transmission curve of filter j (j = 1..M)
    z[1..K]      –  Latent coefficient vector
Output:
    F_pred[j]    –  Predicted photometric flux in filter j

Procedure:
    2.1   For each filter j:
          Compute basis integrals
              A[j, k] = ∫ PC[k](λ) · R_j(λ) dλ    (k = 1..K)
          Compute mean flux
              μ_j   = ∫ μ(λ) · R_j(λ) dλ
          Evaluate
              F_pred[j] = μ_j + Σ_k A[j, k] · z[k]

Input:
    y[1..M]           –  Observed photometric fluxes
    σ[1..M]           –  Measurement uncertainties (assumed Gaussian)
    A[1..M, 1..K]     –  Matrix from Section 2
    Prior:  z ~ N(0, I_K)

Output:
    Posterior mean μ_z[1..K]
    Posterior covariance Σ_z[K×K]
    Sampled spectra {S_samp[t](λ)} (optional)
    Uncertainty band on the spectrum

Procedure:
    3.1   Construct data covariance C = diag(σ²)
    3.2   Compute precision matrices:
            P_data = Aᵀ · C⁻¹ · A
            P_prior = I_K
    3.3   Posterior precision P_post = P_data + P_prior
    3.4   Posterior covariance Σ_z = P_post⁻¹
    3.5   Posterior mean:
            μ_z = Σ_z · Aᵀ · C⁻¹ · y
    3.6   (Optional) Generate T samples:
            For t = 1 .. T:
                Draw z_t ~ N(μ_z, Σ_z)
                Reconstruct spectrum:
                    S_samp[t](λ) = μ(λ) + Σ_k PC[k](λ) · z_t[k]
    3.7   Compute spectral uncertainty:
            Cov_spectrum(λ) = PC(λ) · Σ_z · PC(λ)ᵀ

Input:
    Photometric catalog of N_obj objects:
        For each object i:
            y_i[1..M], σ_i[1..M]
    Pre‑computed A[1..M, 1..K] and μ(λ), PC[1..K](λ)

Procedure:
    For each object i = 1 .. N_obj:
        4.1   Call Bayesian Inference (Section 3) → μ_z_i, Σ_z_i
        4.2   Store μ_z_i, Σ_z_i
        4.3   (Optional) Reconstruct mean spectrum:
                S_mean_i(λ) = μ(λ) + Σ_k PC[k](λ) · μ_z_i[k]
        4.4   (Optional) Compute spectrum uncertainty:
                Cov_spectrum_i(λ) = PC(λ) · Σ_z_i · PC(λ)ᵀ

Input:
    Posterior samples {z_t} for an object
    Reference manifold of spectral types (e.g., grid of z values)

Procedure:
    5.1   Compute distance d_t = || z_t – z_ref || (Euclidean)
    5.2   Identify samples with d_t above a chosen percentile
    5.3   Flag these as potential outliers or rare spectral types
