Input:
    - Training spectra matrix X_train   # size N_spec × N_wave
    - Filter transmission curves {T_f}  # f = 1 … N_fil
    - New object photometry y_obs       # size N_fil × 1
    - Photometric uncertainties σ_y     # same shape as y_obs
    - Desired number of principal components k  (default k≈8)

Output:
    - Posterior samples of latent coefficients {c_m}
    - Reconstructed spectra {S_m}  (posterior predictive)
    - Credible‑interval envelope for the spectrum

--------------------------------------------------------------------
1.  PCA training
--------------------------------------------------------------------
2.  μ_X  ← mean(X_train)                       # mean spectrum (N_wave × 1)
3.  X_centered ← X_train – μ_X
4.  [U, Λ] ← eig( cov(X_centered) )            # eigenvectors (N_wave × N_wave)
5.  U_k ← first k columns of U                 # principal components (N_wave × k)
6.  Λ_k ← first k diagonal entries of Λ

--------------------------------------------------------------------
2.  Construct forward photometry model
--------------------------------------------------------------------
7.  For each filter f:
8.      R_f ← ∫ T_f(λ) * U_k(λ) dλ            # projection of PCs onto filter (k × 1)
9.  R ← stack(R_f for all f)                  # shape N_fil × k
10. μ_y ← ∫ T_f(λ) * μ_X(λ) dλ for all f     # mean photometry (N_fil × 1)

--------------------------------------------------------------------
3.  Define Bayesian model
--------------------------------------------------------------------
11. Prior on coefficients:  c ~ N(0, Λ_k)      # zero‑mean Gaussian with variance from PCs
12. Likelihood:              y_obs | c  ~ N( μ_y + R·c , diag(σ_y²) )

--------------------------------------------------------------------
4.  Posterior inference
--------------------------------------------------------------------
13. Choose sampler (e.g., Hamiltonian Monte Carlo or Gibbs):
14. Initialize c^(0) = 0
15. For iteration m = 1 … M:
16.     Sample c^(m)  from   p(c | y_obs, σ_y)   # using chosen sampler
17.     Store c^(m)

--------------------------------------------------------------------
5.  Posterior predictive spectra
--------------------------------------------------------------------
18. For each stored coefficient vector c^(m):
19.     S_m  ← μ_X + U_k · c^(m)               # full spectrum reconstruction
20.     Store S_m

--------------------------------------------------------------------
6.  Quantify uncertainties
--------------------------------------------------------------------
21. For each wavelength λ_j:
22.     Collect { S_m[j] } over all M samples
23.     Compute median, 2.5th percentile, 97.5th percentile
24.     Store as credible‑interval envelope

--------------------------------------------------------------------
7.  Return results
--------------------------------------------------------------------
25. Output {c_m}, {S_m}, credible‑interval envelope
