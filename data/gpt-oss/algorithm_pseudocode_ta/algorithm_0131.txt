Input
------
- S_train   : matrix of shape (N_s, N_λ)  – training near‑IR spectra
- T_filters : list of M filter response functions, each defined on the same λ grid
- phot      : vector of length M with measured fluxes {f_j}
- err       : vector of length M with photometric uncertainties {σ_j}

Parameters
----------
- Kmax      : maximum number of principal components to retain (e.g., 10)
- μ_prior   : prior mean of component coefficients (default = 0)
- Σ_prior   : prior covariance of component coefficients
              (default = diagonal matrix with eigenvalues of training data)

Output
------
- S_rec      : reconstructed full‑spectrum (vector of length N_λ)
- S_err_low  : lower edge of 68% credible interval for each λ
- S_err_up   : upper edge of 68% credible interval for each λ
- flag_outlier : boolean indicating whether photometry is unlikely under model

1.1  Compute mean spectrum:  μ_S = mean(S_train, axis=0)          // shape (N_λ)
1.2  Centered spectra:  X = S_train – μ_S                       // shape (N_s, N_λ)
1.3  Perform singular value decomposition:  X = U Σ Vᵀ
1.4  PCs = V[0:Kmax, :]                                      // first Kmax rows of V
1.5  Eigenvalues λ_eig = Σ[0:Kmax]² / (N_s – 1)
1.6  Set Σ_prior = diag(λ_eig)  (or user‑provided prior)

2.1  A[j,k] = ∫ PC_k(λ) * T_j(λ) dλ  /  ∫ T_j(λ) dλ      // component contribution
2.2  b[j]   = ∫ μ_S(λ) * T_j(λ) dλ  /  ∫ T_j(λ) dλ        // mean spectrum contribution

y = phot – b

3.1  Weight matrix:  W = diag(1 / err²)                      // shape (M, M)
3.2  Posterior covariance:
     Σ_post = inverse( Aᵀ W A + Σ_prior⁻¹ )                // shape (Kmax, Kmax)

3.3  Posterior mean:
     μ_post = Σ_post * ( Aᵀ W y + Σ_prior⁻¹ μ_prior )

4.1  Sample component coefficients:
     c_samples = draw N_smpl from Normal(μ_post, Σ_post)   // e.g., N_smpl = 1000
4.2  For each sample i:
     S_i(λ) = μ_S(λ) + Σ_k c_samples[i,k] * PC_k(λ)        // shape (N_λ)
4.3  Compute point estimate:
     S_rec(λ) = mean( S_i(λ) over i )

4.4  Credible interval bounds:
     S_err_low(λ) = percentile( S_i(λ), 16 )
     S_err_up(λ)  = percentile( S_i(λ), 84 )

5.1  Predictive mean fluxes:  f_pred = b + A * μ_post
5.2  Predictive variances per filter:
     var_pred = err² + diag( A * Σ_post * Aᵀ )
5.3  Log‑likelihood:
     LL = Σ_j [ -0.5 * ( (phot[j]-f_pred[j])² / var_pred[j]
                        + ln(2π*var_pred[j]) ) ]

5.4  If LL < threshold_LL (e.g., lower 1 % of expected distribution)
        flag_outlier = True
    else
        flag_outlier = False
