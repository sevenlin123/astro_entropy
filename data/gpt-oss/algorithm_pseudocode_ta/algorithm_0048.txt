Input
  S      – training spectra matrix (Nspec × Nwav)
  T_f    – filter response matrices for each filter f (Nwav × 1)
  y_obs  – observed photometry for target TNO (Nfil × 1)
  σ_obs  – observational uncertainties for each filter (Nfil × 1)
  K      – number of principal components to retain (integer)

Output
  S_rec   – reconstructed spectrum (Nwav × 1)
  ΔS      – 1‑σ uncertainty band at each wavelength (Nwav × 1)

Procedure
--------------------------------------------------------------------
1.  PCA Training
    1.1  μ_s  ← mean(S, axis=0)            // mean spectrum
    1.2  S_centered ← S – μ_s             // subtract mean
    1.3  [U, Σ, Vt] ← svd(S_centered, full_matrices=False)
          // U: eigenvectors (Nspec × Nspec), Vt: principal directions
    1.4  PCs ← Vt.T[:, :K]                // first K principal components (Nwav × K)

2.  Filter–PC Flux Matrix Construction
    // For each filter, compute expected flux of each PC and of the mean spectrum
    2.1  F_mean ← zeros(Nfil)              // mean flux per filter
    2.2  A ← zeros(Nfil, K)                // PC‑to‑filter mapping
    2.3  for p in 1..Nfil:
            R_p ← T_f[p]                   // transmission curve (vector length Nwav)
            F_mean[p] ← dot(μ_s, R_p) / sum(R_p)        // mean flux in filter p
            for k in 1..K:
                A[p,k] ← dot(PCs[:,k], R_p) / sum(R_p) // PC k flux in filter p

3.  Bayesian Linear Inference for Latent Coefficients
    // Model: y = F_mean + A·c + ε ,   ε ~ N(0, diag(σ_obs²))
    3.1  Σ_noise ← diag(σ_obs²)                     // noise covariance
    3.2  Σ_prior ← eye(K)                           // isotropic prior on c
    3.3  // Posterior covariance
           Σ_post ← inv(A.T @ inv(Σ_noise) @ A + inv(Σ_prior))
    3.4  // Posterior mean
           μ_post ← Σ_post @ A.T @ inv(Σ_noise) @ (y_obs - F_mean)
    3.5  // Sample latent coefficients
           N_samp ← 1000
           c_samples ← multivariate_normal(mean=μ_post,
                                            cov=Σ_post,
                                            size=N_samp)

4.  Spectrum Reconstruction
    4.1  S_samples ← zeros(N_samp, Nwav)
    4.2  for s in 1..N_samp:
            S_samples[s,:] ← μ_s + PCs @ c_samples[s,:].T
    4.3  S_rec ← mean(S_samples, axis=0)           // point estimate
    4.4  ΔS ← std(S_samples, axis=0)               // 1‑σ band

5.  Return (S_rec, ΔS)
--------------------------------------------------------------------
