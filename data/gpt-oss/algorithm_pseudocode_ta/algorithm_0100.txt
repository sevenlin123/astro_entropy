Inputs:
    - Training spectra set S_train = { s_i(λ) }   // i = 1 … N_train
    - Corresponding filter set F = { f_j(λ) }      // j = 1 … M_filt
    - Target photometry vector p_target = [p_1 … p_M]   // measured fluxes
    - Photometric uncertainties σ_p = [σ_1 … σ_M]

Outputs:
    - Reconstructed spectrum s_rec(λ)
    - Posterior covariance Σ_z of latent coefficients
    - Credible intervals for s_rec(λ)

Algorithm:

1. **Preprocess Training Spectra**
   1.1 Interpolate each s_i onto common wavelength grid λ_k (k = 1 … K).
   1.2 Normalize or scale spectra if required (e.g., unit mean).

2. **Principal Component Analysis (PCA)**
   2.1 Compute mean spectrum μ_s(λ) = (1/N_train) ∑_i s_i(λ).
   2.2 Center spectra: x_i(λ) = s_i(λ) – μ_s(λ).
   2.3 Form data matrix X of shape (N_train, K) with rows x_i.
   2.4 Perform eigen‑decomposition of covariance matrix C = (Xᵀ X)/(N_train–1):
          C = U Λ Uᵀ
   2.5 Select first P components (P ≈ 8–10 for reconstruction, 4–5 for taxonomy).
   2.6 Define basis matrix B (K × P) whose columns are the selected eigenvectors.
   2.7 Store prior statistics for latent coefficients:
          z_prior_mean = 0
          z_prior_cov   = diag(Λ_selected)   // variances along PCs

3. **Compute Filter Response Matrix**
   3.1 For each filter f_j(λ), compute its transmission-weighted integral over λ:
          R_jk = ∫ f_j(λ_k) dλ_k           // response at wavelength point k
   3.2 Build filter response matrix R of shape (M_filt, K).
   3.3 Project basis onto filters:
          A = R · B   // shape (M_filt, P)
   3.4 Project mean spectrum onto filters:
          μ_p = R · μ_s   // shape (M_filt)

4. **Linear Gaussian Forward Model**
   The predicted photometry for latent vector z is:
       p_pred(z) = μ_p + A · z
   Likelihood:
       p(p_target | z) ∝ exp[ –½ (p_target – μ_p – A z)ᵀ W (p_target – μ_p – A z) ]
   where W = diag( 1/σ_p² ) is the photometric weight matrix.

5. **Bayesian Inference for Latent Coefficients**
   Prior:  p(z) ∝ exp[ –½ zᵀ Σ_z⁻¹ z ]   with Σ_z = z_prior_cov
   Posterior:  p(z | p_target) ∝ p(p_target | z) · p(z)

   Since both prior and likelihood are Gaussian, the posterior is Gaussian:
       Posterior covariance:
           Σ_post = ( Aᵀ W A + Σ_z⁻¹ )⁻¹
       Posterior mean:
           z_hat = Σ_post ( Aᵀ W (p_target – μ_p) )

6. **Reconstruct Spectrum**
   6.1 s_rec(λ) = μ_s(λ) + B · z_hat
   6.2 To propagate uncertainties to the spectrum, compute the
       spectrum covariance:
           Σ_spectrum = B · Σ_post · Bᵀ
   6.3 Extract credible intervals per wavelength:
           CI_lower(k) = s_rec(λ_k) – 1.96 * sqrt( Σ_spectrum[k,k] )
           CI_upper(k) = s_rec(λ_k) + 1.96 * sqrt( Σ_spectrum[k,k] )

7. **Optional: Taxonomy Classification (if desired)**
   7.1 Use z_hat (or z samples) as feature vector for clustering or
       dimensionality reduction (e.g., t‑SNE, UMAP).
   7.2 Assign taxonomic class based on nearest‑neighbor or cluster labels
       derived from training set.

End Algorithm
