Inputs
-------
- Spectral library S = {s_i(λ)}   : Near‑IR spectra of reference TNOs
- Filter set F = {f_j(λ)}         : Transmission curves of photometric filters used
- Observation O = { (j, m_j, σ_j) } : Measured magnitudes (or fluxes) and errors per filter j
- Number of PCs K                 : Desired dimensionality of latent space (≈4–10)

Outputs
--------
- Posterior samples of latent coefficient vector c  (size K)
- Reconstructed spectra ŝ(λ) drawn from posterior
- Credible intervals for ŝ(λ) at each λ

Procedure
---------

1. **Pre‑processing of the spectral library**
   1.1. Normalise each spectrum s_i(λ) to a common reference (e.g., unit area or mean reflectance).
   1.2. Resample all spectra onto a common wavelength grid λ_grid.
   1.3. Compute the mean spectrum μ(λ) = mean_i{s_i(λ)}.
   1.4. Subtract mean: 𝑠̃_i(λ) = s_i(λ) – μ(λ).

2. **Principal Component Analysis (PCA)**
   2.1. Construct data matrix X ∈ ℝ^{N × M} where N = number of spectra, M = length of λ_grid.
        Row i = 𝑠̃_i(λ)ᵀ.
   2.2. Compute singular value decomposition: X = U Σ Vᵀ.
   2.3. Select first K columns of Vᵀ → PCs P_k(λ) (k = 1…K).
   2.4. Store projection coefficients for each reference spectrum:
        c_i = X_i · P   (X_i = row i of X, P = [P₁ … P_K]ᵀ).

3. **Filter response simulation**
   3.1. For each filter f_j(λ), compute its synthetic transmission‑weighted basis:
        Φ_jk = ∫ f_j(λ) · P_k(λ) dλ / ∫ f_j(λ) dλ     (k = 1…K)
   3.2. Compute synthetic mean magnitude in filter j:
        m̄_j = ∫ f_j(λ) · μ(λ) dλ / ∫ f_j(λ) dλ
   3.3. Build design matrix A ∈ ℝ^{J × K} where J = |F|:
        A_{jk} = Φ_jk
   3.4. Build observation vector y ∈ ℝ^J:
        y_j = m_j – m̄_j

4. **Bayesian inference in latent space**
   4.1. Prior over latent coefficients c: 
        p(c) = multivariate normal(0, Σ_prior) with Σ_prior derived from covariance of {c_i} in step 2.4.
   4.2. Likelihood given observation O:
        p(y | c) = multivariate normal(A c, Σ_obs)
        where Σ_obs is diagonal with elements σ_j².
   4.3. Posterior:
        p(c | y) ∝ p(y | c) · p(c)
   4.4. Sample from posterior using e.g. affine‑invariant MCMC (emcee):
        Initialise walkers around MAP estimate (solve least‑squares A c = y).
        Run until convergence; retain N_samp samples {c^(ℓ)}.

5. **Spectrum reconstruction**
   For each posterior sample ℓ:
       ŝ^(ℓ)(λ) = μ(λ) + Σ_{k=1}^K c_k^(ℓ) · P_k(λ)

6. **Uncertainty propagation & credible intervals**
   6.1. At each λ, collect values {ŝ^(ℓ)(λ)} over all ℓ.
   6.2. Compute percentiles (e.g., 2.5th, 50th, 97.5th) → credible interval bounds.
   6.3. Output mean spectrum = median of {ŝ^(ℓ)(λ)}.

7. **Optional: outlier detection**
   7.1. Compute posterior predictive log‑likelihood for O under each sample.
   7.2. Flag observations with extremely low predictive probability as potential outliers.

End Algorithm
