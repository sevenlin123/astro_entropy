pseudocode
Inputs
-------
S           : Matrix of N_train spectra (rows) × L_wavelengths columns
R_j(λ)      : Response curves of M photometric filters (discretized at same L wavelengths)
phot_vals   : Vector of observed magnitudes or fluxes for the target (length M)
σ_phot      : Vector of measurement uncertainties (length M)
K           : Number of principal components to retain (4–10)

Outputs
-------
s_recon     : Reconstructed full‑spectrum (length L)
cov_s       : Covariance matrix of reconstructed spectrum (L×L)
z_mean      : Posterior mean of latent coordinates (length K)
z_cov       : Posterior covariance of latent coordinates (K×K)

Procedure
---------

1. **PCA Training**
   1.1 Compute the mean spectrum μ_s  ← (1/N_train) * Σ_i S[i,:]
   1.2 Center spectra:  S_centered ← S – μ_s
   1.3 Perform singular value decomposition (SVD):
         [U, Σ, V^T] ← svd(S_centered)
   1.4 Select first K right singular vectors:
         E_K ← V^T[0:K, :]   // E_K is K×L
   1.5 Store projection matrix:  E ← transpose(E_K)   // L×K

2. **Photometric Forward Model**
   2.1 For each filter j (1..M) and each component k (1..K):
        P[j,k] ← Σ_{l=1}^{L} R_j[l] * (E[l,k])  // discrete convolution
   2.2 Compute baseline photometry from mean spectrum:
        m0[j] ← Σ_{l=1}^{L} R_j[l] * μ_s[l]

3. **Linear Gaussian Latent Variable Model**
   // Spectra:  s = μ_s + E * z + ε_s ,   ε_s ~ N(0, σ_spec^2 I)
   // Photometry:  m = m0 + P * z + ε_m ,   ε_m ~ N(0, Σ_phot)
   3.1 Define prior on latent coordinates:
        p(z) = N(0, I_K)
   3.2 Define likelihood of photometry given z:
        p(m | z) = N(m0 + P*z , Σ_phot)
        where Σ_phot = diag(σ_phot^2)

4. **Posterior Inference (Closed‑Form Gaussian)**
   4.1 Compute precision matrices:
        Λ_prior ← I_K
        Λ_lik   ← P^T * Σ_phot^{-1} * P
        Λ_post  ← Λ_prior + Λ_lik
   4.2 Compute posterior covariance:
        z_cov ← inverse(Λ_post)
   4.3 Compute posterior mean:
        z_mean ← z_cov * (P^T * Σ_phot^{-1} * (phot_vals - m0))

5. **Spectrum Reconstruction**
   5.1 Expected spectrum:
        s_recon ← μ_s + E * z_mean
   5.2 Spectrum covariance:
        cov_s ← E * z_cov * E^T

Return s_recon, cov_s, z_mean, z_cov
