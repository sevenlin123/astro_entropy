Input:
    - Seed spectra S_seed = {s_1,…,s_N}   // N ≈ 50 high‑resolution reflectance spectra
    - Filter response curves R_filt = {R_1,…,R_M}   // M ≈ 4–6 photometric bands
    - Desired number of principal components K  // e.g., K = 5 or 8
    - KDE bandwidth h
    - Noise level σ_noise  // e.g., 20% relative reflectance uncertainty
    - New photometric measurements m_new = {m_1,…,m_M} with errors σ_m

Output:
    - Posterior spectral samples {S_i}   // sampled high‑res spectra
    - Posterior taxonomic probabilities {p_T}

--------------------------------------------------------------------
STEP 1: Construct Latent Space (Prior)

1.1 Compute mean spectrum μ_S ← mean(S_seed)  // per wavelength point
1.2 Center spectra: X ← {s_j – μ_S for j=1…N}
1.3 Perform Singular Value Decomposition (SVD) on X → U Σ V^T
1.4 Select first K columns of U as principal component matrix P_K
1.5 Project each centered spectrum onto PCs:
        z_j = P_K^T · (s_j – μ_S)          // z_j ∈ ℝ^K
1.6 Store latent coefficient matrix Z = {z_j}

--------------------------------------------------------------------
STEP 2: Augment Latent Distribution (KDE)

2.1 Fit multivariate Kernel Density Estimate (KDE) to Z with bandwidth h
2.2 Draw N_aug synthetic latent vectors {z'_k} from KDE
2.3 For each z'_k:
        a) Reconstruct synthetic spectrum:
               s'_k = μ_S + P_K · z'_k
        b) Forward‑model photometry:
               For each filter f in R_filt:
                   m_f' = ∫ s'_k(λ) · R_f(λ) dλ / ∫ R_f(λ) dλ
        c) Inject Gaussian noise:
               m_f' ← m_f' + Normal(0, σ_noise · m_f')
        d) Store pair (m'_k , z'_k)

Result: Augmented training set T = {(m'_k , z'_k)} for k = 1…N_aug

--------------------------------------------------------------------
STEP 3: Train Encoder (Photometry → Latent)

3.1 Select AutoML regressor (e.g., Gradient Boosted Decision Trees)
3.2 Input features: photometric vector m'_k
    Target: latent vector z'_k
3.3 Train regressor R_enc on T
3.4 Validate R_enc on hold‑out portion of T (optional)

--------------------------------------------------------------------
STEP 4: Train Taxonomy Classifier (Optional)

4.1 Assign taxonomic label L_j to each seed spectrum s_j
4.2 Build training set C = {(z_j , L_j)}   // latent coefficients with labels
4.3 Train AutoML classifier C_cls (e.g., Random Forest)
4.4 Obtain class probability model p_T(z)

--------------------------------------------------------------------
STEP 5: Inference for New Observation

5.1 Preprocess new photometry:
        • Scale or normalize if required (consistent with training)
5.2 Predict latent vector:
        z_pred = R_enc(m_new)
5.3 Sample posterior latent distribution:
        • Option 1: draw N_post samples from predictive posterior
        • Option 2: use predictive variance to generate Gaussian jitter
5.4 For each sampled latent vector z_samp:
        a) Reconstruct high‑resolution spectrum:
               s_samp = μ_S + P_K · z_samp
        b) Store s_samp
5.5 Compile posterior spectral summary:
        • Mean spectrum = mean({s_samp})
        • Credible intervals = percentile bounds of {s_samp}
5.6 Classify taxonomy:
        p_T_pred = C_cls.predict_proba(z_pred)

Return posterior spectra and taxonomy probabilities.
