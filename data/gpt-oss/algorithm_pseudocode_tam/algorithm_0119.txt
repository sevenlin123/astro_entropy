Input
  ├─ SPECTRA_TRAIN : { s_i }  (high‑resolution reflectance spectra of N≈50 TNOs)
  ├─ FILTER_SET    : { f_j }  (effective throughput curves of chosen photometric filters)
  ├─ BAND_NOISE     : σ = 20 %   (relative reflectance uncertainty)
  └─ K_PCA          : number of principal components to keep (e.g. 5–10)

Output
  ├─ RECONSTRUCTED_SPECTRUM  : continuous spectrum per new object
  ├─ TAXONOMIC_PROBABILITIES : {P(class | photometry)}
  └─ LATENT_VECTOR            : predicted PCA coefficients

-----------------------------------------------------------------------
STEP 1 – Build Latent Prior
-----------------------------------------------------------------------

1.1  Perform Principal Component Analysis on SPECTRA_TRAIN  
      [U, Λ, V] ← PCA(SPECTRA_TRAIN, n_components = K_PCA)  
      // U: mean spectrum, V: eigenvectors, Λ: eigenvalues  

1.2  Project each training spectrum onto the PCA basis  
      for i in 1…N:
          c_i ← Vᵀ · (s_i – U)          // latent vector (size K_PCA)

1.3  Estimate continuous density of latent space using Kernel Density Estimation  
      kde_model ← KDE(c_1,…,c_N, bandwidth = 0.5)

1.4  Draw M synthetic latent vectors from the KDE (e.g. M = 10 000)  
      for k in 1…M:
          c_k_syn ← kde_model.sample()
          // store synthetic latent vectors

1.5  Reconstruct synthetic spectra from sampled latent vectors  
      for k in 1…M:
          s_k_syn ← U + V · c_k_syn       // inverse PCA

-----------------------------------------------------------------------
STEP 2 – Generate Synthetic Photometry
-----------------------------------------------------------------------

2.1  For each synthetic spectrum s_k_syn compute noiseless band reflectances  
      for each filter f_j in FILTER_SET:
          R_kj_noisy ← ∫ s_k_syn(λ) · f_j(λ) dλ / ∫ s_⊙(λ) · f_j(λ) dλ  
          // s_⊙ is solar spectrum (removed by division)

2.2  Add Gaussian noise with relative standard deviation σ  
      R_kj ← R_kj_noisy × (1 + N(0, σ))  

2.3  Assemble training data pairs  
      X_train ← {R_kj}   // matrix of shape (M × J)  
      Y_train ← {c_k_syn}  // matrix of shape (M × K_PCA)

-----------------------------------------------------------------------
STEP 3 – Train Encoder (Photometry → Latent)
-----------------------------------------------------------------------

3.1  Use AutoML framework (e.g. AutoGluon) to fit a regression model  
      encoder ← AutoML_Regression(X_train → Y_train)  
      // Ensemble of Gradient‑Boosted Trees & Neural Nets, tuned automatically

-----------------------------------------------------------------------
STEP 4 – Train Classifier (Latent → Taxonomy)
-----------------------------------------------------------------------

4.1  Label each training spectrum with its taxonomy class  
      LABEL_i ← class(s_i)      // e.g. H₂O, CO₂, Organic, Methanol

4.2  Use latent vectors of real spectra (c_i) as features  
      X_cls ← {c_i}  
      y_cls ← {LABEL_i}

4.3  Train a probabilistic classifier with AutoML  
      classifier ← AutoML_Classification(X_cls → y_cls)  
      // Outputs probability distribution over classes

-----------------------------------------------------------------------
STEP 5 – Inference for a New Object
-----------------------------------------------------------------------

5.1  Observe sparse photometry M_obs in the FILTER_SET  
      R_obs ← {r_j}   // measured reflectances (possibly noisy)

5.2  Predict latent coefficients with the encoder  
      c_pred ← encoder.predict(R_obs)

5.3  Compute taxonomic probabilities  
      P_class ← classifier.predict_proba(c_pred)

5.4  Reconstruct high‑resolution spectrum via inverse PCA  
      s_recon ← U + V · c_pred

-----------------------------------------------------------------------
Return Results
-----------------------------------------------------------------------

Return s_recon, P_class, c_pred
