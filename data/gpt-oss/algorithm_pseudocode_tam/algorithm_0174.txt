pseudocode
INPUT
    S_raw[1..N_spec][1..N_wave]        // Reference spectra (reflectance)
    T_ref[1..N_spec]                  // Taxonomic class labels for reference spectra
    W_eff[1..N_filter][1..N_wave]     // Effective throughput curves of photometric filters
    R_phot[1..N_obj][1..N_filter]     // Sparse photometry of new objects
    N_lat                          // Desired number of PCA components (e.g., 5–10)
    h_kde                          // KDE bandwidth (e.g., 0.5)
    N_synth = 5000                  // Number of synthetic latent samples
    sigma_phot = 0.20               // Relative photometric noise (20 %)

OUTPUT
    S_rec[1..N_obj][1..N_wave]          // Reconstructed spectra
    C_prob[1..N_obj][1..N_tax]           // Taxonomy probability distribution

--------------------------------------------------------------------
1. PREPARE LATEENT SPACE (Prior)

   1.1 Standardise spectra:
       For each i in 1..N_spec:
           μ_i = mean(S_raw[i])
           σ_i = std(S_raw[i])
           S_std[i] = (S_raw[i] - μ_i) / σ_i

   1.2 Compute PCA on S_std:
       [U, Λ, V] = PCA(S_std, N_lat)
       // U: loadings (principal components), V: coefficients matrix

   1.3 Store mean vector M = mean(S_raw) and scaling vector S = std(S_raw)

   1.4 Extract latent coefficients:
       For each i:
           z_true[i] = V[i, 1:N_lat]

   1.5 Perform Kernel Density Estimation in latent space:
       KDE_model = FitKDE(z_true, bandwidth = h_kde)

   1.6 Generate synthetic latent samples:
       For s in 1..N_synth:
           z_synth[s] = Sample(KDE_model)
           // Append to z_true to form augmented training set

   1.7 For each synthetic latent sample, reconstruct synthetic spectrum:
       For s in 1..N_synth:
           S_synth[s] = U * z_synth[s] + M
           // Rescale back: S_synth[s] = S_synth[s] * S + M

--------------------------------------------------------------------
2. GENERATE SYNTHETIC PHOTOMETRY (Likelihood)

   2.1 For each synthetic spectrum j in 1..N_synth:
           For each filter f in 1..N_filter:
               // Convolution with filter throughput
               m_clean[j,f] = ∫ S_synth[j](λ) * W_eff[f](λ) dλ
               // Normalise if necessary

   2.2 Inject Gaussian noise:
           For each j,f:
               m_noisy[j,f] = m_clean[j,f] * (1 + Normal(0, sigma_phot))

   2.3 Build training data pairs:
           X_train = { m_noisy[j,:] }          // Photometry vectors
           Y_train = { z_synth[j,:] }          // Corresponding latent coeffs
           L_train = { T_ref[j] }             // Class labels for subset that match real spectra
           // Note: For synthetic spectra, labels may be assigned by nearest real spectrum

--------------------------------------------------------------------
3. TRAIN REGRESSOR (Encoder) AND CLASSIFIER

   3.1 Train photometry‑to‑latent regressor:
           ModelReg = AutoML_Regress(X_train → Y_train)
           // Example: Gradient Boosted Decision Trees, Neural Network, etc.

   3.2 Train taxonomy classifier on latent space:
           ModelCls = AutoML_Classifier(L_train → Y_train)
           // Or train separate classifier on real latent vectors only

--------------------------------------------------------------------
4. INFERENCE ON NEW OBJECTS

   For each object k in 1..N_obj:

       4.1 Predict latent distribution:
           z_pred_mean, z_pred_cov = ModelReg.PredictDistribution(R_phot[k,:])
           // Optionally obtain N_samples draws from predictive distribution

       4.2 Reconstruct spectrum (posterior mean):
           S_rec[k] = U * z_pred_mean + M
           S_rec[k] = S_rec[k] * S + M          // rescale to original units

       4.3 Estimate taxonomy probabilities:
           C_prob[k] = ModelCls.PredictProbability(z_pred_mean)

--------------------------------------------------------------------
5. OPTIONAL POSTERIOR SAMPLING (for uncertainty)

   For each object k:
       For n in 1..N_post_samples:
           z_sample[n] ~ ModelReg.PredictDistribution(R_phot[k,:])
           S_sample[n] = U * z_sample[n] + M
           S_sample[n] = S_sample[n] * S + M
       Compute statistics (median, CI) over {S_sample[n]}

--------------------------------------------------------------------
END
