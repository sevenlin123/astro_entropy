Input:
    - Reference high‑resolution TNO spectra {S_ref_i}, i = 1…N_seed (≈50)
    - Desired number of principal components K (typically 5–10)

Steps:
    1.1 Pre‑process spectra (e.g., normalize, remove outliers).
    1.2 Compute Principal Component Analysis (PCA):
        - Center spectra → X_centered
        - Perform SVD or eigen‑decomposition → eigenvectors U_K, eigenvalues Λ_K
        - Project spectra onto PCs → latent vectors z_i = U_Kᵀ · X_centered_i
    1.3 Estimate density in latent space:
        - Use Kernel Density Estimation (KDE) with bandwidth h ≈ 0.5
        - Obtain continuous probability density p(z)
    1.4 Generate synthetic latent samples:
        - Draw M samples z_aug_j ∼ p(z)  (M ≫ N_seed, e.g., 5000)
        - Store augmented set Z_aug = {z_aug_j}

Input:
    - Augmented latent set Z_aug
    - PCA eigenvectors U_K, mean spectrum μ_S
    - Instrument filter curves {T_f}, f = 1…F (e.g., JWST NIRCam)
    - Relative photometric noise σ_rel (default 0.20)

Steps:
    2.1 Decode latent samples to spectra:
        - For each z_aug_j:
            • Reconstruct spectrum: S_j = μ_S + U_K · z_aug_j
    2.2 Convolve spectra with filter curves:
        - For each filter f:
            • Compute model photometric flux: m_f_j = ∫ S_j(λ)·T_f(λ)dλ / ∫ T_f(λ)dλ
    2.3 Add Gaussian noise:
        - m_f_j ← m_f_j + Normal(0, σ_rel·m_f_j)
    2.4 Assemble training pairs:
        - Features: photometry vector m_j = [m_1_j … m_F_j]
        - Targets: latent vector z_aug_j

Input:
    - Training pairs {(m_j, z_aug_j)} from Step 2
    - Choice of AutoML regressor (e.g., AutoGluon with Gradient‑Boosted Trees)

Steps:
    3.1 Configure AutoML training pipeline:
        - Define input columns = photometry bands
        - Define target columns = latent coefficients (K values)
        - Set hyper‑parameter search space (learning rate, tree depth, etc.)
        - Enable ensembling and cross‑validation internally
    3.2 Fit model to training data:
        - Model_Encoder = AutoML.fit(features=m, targets=z)
    3.3 Save the trained encoder for inference.

Input:
    - Latent vectors z_i from Step 1.2 (seed spectra only)
    - Corresponding taxonomic labels L_i

Steps:
    4.1 Prepare training data:
        - Features = z_i (K columns)
        - Target = L_i
    4.2 Configure AutoML classifier:
        - Options: Random Forest, Gradient‑Boosted Trees, Neural Nets, etc.
        - Cross‑validation, calibration included
    4.3 Fit classifier:
        - Classifier = AutoML.fit(features=z, target=L)
    4.4 Save classifier for inference.

Input:
    - New observed photometry vector m_new = [m_1 … m_F]
    - Trained encoder Model_Encoder
    - PCA eigenvectors U_K, mean spectrum μ_S

Steps:
    5.1 Predict latent coefficients:
        - z_pred = Model_Encoder.predict(m_new)   // returns K‑dimensional vector
    5.2 Optionally sample posterior:
        - If probabilistic encoder available, draw multiple samples {z_k}
        - Compute mean and credible intervals of reconstructed spectra
    5.3 Decode to high‑resolution spectrum:
        - S_rec = μ_S + U_K · z_pred
    5.4 Output:
        - Reconstructed spectrum S_rec(λ)
        - Uncertainty estimates if multiple draws were performed

Input:
    - Predicted latent coefficients z_pred (or sample set {z_k})
    - Trained classifier Classifier

Steps:
    6.1 Predict taxonomic probabilities:
        - P(L | z_pred) = Classifier.predict_proba(z_pred)
    6.2 Return probability vector over classes (H₂O, CO₂, Organic, Methanol, etc.).
