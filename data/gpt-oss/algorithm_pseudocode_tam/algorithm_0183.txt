INPUT: 
   - Reference spectra {S_j(λ)}   j = 1 … N   (high‑resolution reflectance)
   - Filter set {F_k(λ)}           k = 1 … K_f   (effective throughput curves)
   - Hyper‑parameters:  
       * K_pc         : number of principal components (e.g. 5–10)  
       * h_KDE        : KDE bandwidth (≈0.5)  
       * M_synth      : number of synthetic latent samples (≈10⁴)  
       * σ_phot_frac  : photometric noise fraction (0.20)

STEP 1 – Mean subtraction and PCA  
----------------------------------
1.1  Compute mean spectrum μ(λ)  ←  (1/N) Σ_j S_j(λ)
1.2  Center spectra:  Ŝ_j(λ) ← S_j(λ) – μ(λ)
1.3  Perform PCA on {Ŝ_j(λ)} → obtain K_pc orthonormal eigenvectors {u_i(λ)}  i=1…K_pc
1.4  Project each centered spectrum onto PCs:  
     c_j(i) ← ⟨Ŝ_j , u_i⟩    (inner product over λ)
     → latent matrix C_true ∈ ℝ^{N×K_pc}

STEP 2 – Kernel Density Estimation (KDE) in latent space  
--------------------------------------------------------
2.1  Fit a multivariate KDE to C_true with bandwidth h_KDE  
     pdf(c)  ←  KDE(C_true, h_KDE)
2.2  Sample M_synth latent vectors {c*_m} from pdf(c)

STEP 3 – Synthetic spectra generation  
-------------------------------------
3.1  For each sampled vector c*_m:
        S*_m(λ) ← μ(λ) + Σ_{i=1}^{K_pc} c*_m(i) · u_i(λ)

STEP 4 – Forward photometry (with noise)  
---------------------------------------
4.1  For each synthetic spectrum S*_m(λ):
        For each filter k:
            m*_m(k) ←  [∫ S*_m(λ)·F_k(λ) dλ ] / [∫ F_k(λ) dλ]
        Add Gaussian noise:
            m*_m(k) ← m*_m(k) · (1 + 𝒩(0, σ_phot_frac²))

STEP 5 – Prepare training data for regressor and classifier  
----------------------------------------------------------
5.1  Training set for regressor R:  {(m*_m,  c*_m)}  (m*_m ∈ ℝ^{K_f}, c*_m ∈ ℝ^{K_pc})
5.2  Training set for classifier C:  {(c*_m,  label_j)}  
        where label_j is the taxonomic class of the *nearest* real spectrum
        (obtained by Euclidean distance between c*_m and C_true)

STEP 6 – Train AutoML models  
----------------------------
6.1  Train regressor R to map photometry → latent coefficients  
      Input dimension = K_f , Output dimension = K_pc
6.2  Train classifier C to map latent coefficients → class probabilities  
      Input dimension = K_pc , Output = probability vector over classes

OUTPUT:  Trained regressor R, classifier C, PCA basis {u_i}, mean μ

INPUT:  
   - New observed photometry vector m_obs ∈ ℝ^{K_f}
   - Trained components: R, C, {u_i}, μ

STEP 1 – Predict latent coefficients  
------------------------------------
1.1  Use regressor R to obtain predicted latent vector:  
        c_pred  ←  R(m_obs)          // point estimate (or posterior samples if available)

STEP 2 – Generate reconstructed spectrum  
-----------------------------------------
2.1  Reconstruct spectrum in spectral domain:  
        S_rec(λ)  ←  μ(λ) + Σ_{i=1}^{K_pc} c_pred(i) · u_i(λ)

STEP 3 – Taxonomic classification  
---------------------------------
3.1  Compute class probability vector:  
        p_cls  ←  C(c_pred)

OPTIONAL STEP – Uncertainty quantification  
------------------------------------------
4.1  If R provides predictive variance or a sampling mechanism:
        * Draw N_samples latent vectors {c^(s)} from the posterior of R
        * For each c^(s), reconstruct S^(s)(λ) as in Step 2
        * The collection {S^(s)} yields a credible interval for every λ
        * Likewise, average the class probabilities over the samples.

OUTPUT:  
   - Reconstructed spectrum S_rec(λ)  
   - Taxonomic class probabilities p_cls  
   - (Optional) Credible intervals for spectrum and class
