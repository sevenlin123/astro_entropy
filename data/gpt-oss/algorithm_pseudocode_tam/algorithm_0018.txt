INPUT:
    - Reference spectra S_ref = {s_i | i = 1…N}   // N ≈ 50 high‑res spectra
    - Filter response curves {T_f | f = 1…F}      // e.g. JWST NIRCam filters
    - Photometric observations m_new            // sparse measurements (size ≤ F)

OUTPUT:
    - Reconstructed spectrum s_hat(λ)
    - Uncertainty envelope σ_s(λ)
    - Taxonomic probability vector p_tax
--------------------------------------------------------------------
STEP 1 : Pre‑process Reference Spectra
    1.1  For each spectrum s_i:
            • Normalize to unit mean reflectance over chosen λ range.
            • Interpolate to common wavelength grid Λ = {λ_1 … λ_M}.
    1.2  Stack spectra into matrix X ∈ ℝ^(N×M).
    1.3  Compute PCA on X:
            • Center X → X_centered = X – μ_x  (μ_x: mean spectrum).
            • Eigen‑decompose covariance → eigenvectors V_k (k = 1…K),
              eigenvalues λ_k.
            • Choose K = 5  (captures >90 % variance).
    1.4  Store:
            • Mean spectrum μ_x
            • Basis matrix B = V_[1:K]      // M × K
            • Coefficient matrix C_real = X_centered * B   // N × K

--------------------------------------------------------------------
STEP 2 : Build Prior in Latent Space
    2.1  Estimate density p(c) over C_real using Kernel Density Estimator (KDE):
            • Bandwidth h ≈ 0.5  (tuned by cross‑validation on C_real).
    2.2  Sample synthetic latent vectors {c_j} from KDE:
            • Number of samples N_syn = 10,000.
    2.3  For each c_j:
            • Reconstruct synthetic spectrum s_j = μ_x + B * c_j
            • Store (c_j , s_j)

--------------------------------------------------------------------
STEP 3 : Generate Synthetic Photometry (Training Data)
    3.1  For each synthetic spectrum s_j:
            • For each filter f:
                – Compute model flux:
                      F_f = ∫ s_j(λ) * T_f(λ) dλ / ∫ T_f(λ) dλ
            • Assemble vector m_j = {F_f | f = 1…F}.
            • Add Gaussian noise:
                  m_j_noisy = m_j + 𝒩(0, 0.2*m_j)   // 20 % relative std
            • Record training pair (m_j_noisy , c_j).

--------------------------------------------------------------------
STEP 4 : Train AutoML Regressor (Encoder)
    4.1  Define feature matrix X_phot = {m_j_noisy} (N_syn × F).
    4.2  Define target matrix Y_lat  = {c_j}      (N_syn × K).
    4.3  Use AutoML framework (e.g., AutoGluon) to train ensemble regressor R:
            • Hyperparameters automatically tuned.
            • Objective: minimize mean squared error on Y_lat.
    4.4  Save trained regressor R.

--------------------------------------------------------------------
STEP 5 : Train Taxonomy Classifier
    5.1  Label each synthetic spectrum s_j with its dominant class
           (derived from nearest real spectrum in C_real).
    5.2  Train classifier C_cls (AutoML) on (Y_lat , labels).
    5.3  Save trained classifier C_cls.

--------------------------------------------------------------------
STEP 6 : Forward Inference on New Observation
    6.1  Input m_new (size ≤ F).  
    6.2  Pass m_new through encoder R to obtain latent prediction:
            c_pred = R.predict(m_new)          // vector K
    6.3  (Optional) Estimate uncertainty in c_pred via model‑based
            variance or Monte Carlo dropout → σ_c.
    6.4  Decode spectrum:
            s_hat = μ_x + B * c_pred
    6.5  (Optional) Propagate σ_c through inverse PCA to get σ_s(λ):
            σ_s = B * diag(σ_c) * Bᵀ   // approximate linear propagation
    6.6  Classify taxonomy:
            p_tax = C_cls.predict_proba(c_pred)
--------------------------------------------------------------------
RETURN: s_hat, σ_s, p_tax
