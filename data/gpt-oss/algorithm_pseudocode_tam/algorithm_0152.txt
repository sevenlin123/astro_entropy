INPUT:   High‑resolution reflectance spectra S_i(λ), i = 1…N_seed (≈ 51)
OUTPUT:  Normalized spectra, wavelength grid λ_grid

FOR each spectrum S_i:
    1.1 Interpolate to common λ_grid
    1.2 Divide by solar spectrum to obtain reflectance R_i(λ)
    1.3 Store R_i
END FOR

INPUT:  Normalized spectra {R_i(λ)}
OUTPUT: PCA basis V_k(λ), k = 1…K (chosen K ≈ 8–10)

2.1 Compute mean spectrum μ(λ) = mean_i R_i(λ)
2.2 Subtract mean: X_i = R_i – μ
2.3 Perform Singular Value Decomposition (SVD) on matrix [X_1 … X_N]
      → Principal components V_k(λ) and singular values σ_k
2.4 Retain first K components (explained variance ≥ 99%)

FOR each spectrum R_i:
    α_i = V^T * (R_i – μ)          # K‑dimensional coefficient vector
END FOR

PARAMETER: Bandwidth h (≈ 0.5)
FUNCTION KDE(α) → p(α)

# Generate synthetic latent samples:
N_syn = 5000
FOR j = 1…N_syn:
    Draw random α_j from KDE(α)
    Store α_j
END FOR

FOR each synthetic α_j:
    R_syn = μ + Σ_k α_j[k] * V_k
    Store R_syn
END FOR

INPUT:  Synthetic spectra {R_syn(λ)}, filter transmission curves {T_f(λ)},
        Photometric uncertainty σ_rel (≈ 20%)
OUTPUT: Synthetic photometry vectors m_syn[f]

FOR each R_syn:
    FOR each filter f:
        3.1 Compute noiseless reflectance in filter:
            R_f = ∫ R_syn(λ) * T_f(λ) dλ / ∫ T_f(λ) dλ
        3.2 Add Gaussian noise:
            m_f = R_f + N(0, σ_rel * R_f)
    END FOR
    Store m_syn
END FOR

TRAINING SET: { (m_syn, α_syn) }

Use AutoML framework (e.g., AutoGluon) to search over ensemble models
(including Gradient‑Boosted Trees, Neural Networks).
Select best model M_enc according to cross‑validated RMSE on latent space.

LABELS:  {Water, CO2, Organics, Methanol} derived from seed spectra
TRAINING SET: { (α_i, label_i) }  # α_i from real spectra

Use AutoML to train classifier M_cls (ensemble of decision trees, etc.).
Output probability vector P(label | α).

INPUT:  Observed photometry vector m_obs[f]
OUTPUT: Posterior mean spectrum Ŝ(λ), covariance C(λ), classification probabilities P

# 5.1 Encode photometry to latent space
α̂ = M_enc.predict(m_obs)                # Mean latent vector
σ_α = M_enc.predict_uncertainty(m_obs)   # Optional: estimate variance

# 5.2 Decode to spectrum
Ŝ = μ + Σ_k α̂[k] * V_k

# 5.3 Propagate uncertainty (optional)
C = V * diag(σ_α) * V^T

# 5.4 Classify
P = M_cls.predict_proba(α̂)

RETURN Ŝ(λ), C(λ), P
