Input:
    - SeedSpectra   : {S_i(λ)}  i = 1 … N  (high‑resolution reflectance spectra)
    - FilterCurves  : {T_k(λ)}  k = 1 … K  (instrument throughput curves)
    - Photometry    : {m_j}  j = 1 … M  (observed magnitudes/reflectances of a new target)
Parameters:
    - PCA_components     : Kp   (number of principal components to retain, e.g. 8–10)
    - KDE_bandwidth      : h    (e.g. 0.5)
    - Noise_level        : σ_n  (relative photometric noise, e.g. 20 %)
    - AutoML_settings    : (defaults for regressor and classifier)

Output:
    - ReconstructedSpectrum : R(λ)  (high‑resolution spectrum)
    - TaxonomyProbabilities : P(T | m)  (probabilities over spectral classes)
    - PosteriorSamples      : {θ^(s)}  (optional, latent coefficient samples)

--------------------------------------------------------------------
Step 1 – Build Latent Manifold (Prior)
--------------------------------------------------------------------
1.1 Compute Mean Spectrum:
        μ(λ) ← (1/N) Σ_i S_i(λ)

1.2 Center Spectra:
        S'_i(λ) ← S_i(λ) – μ(λ)

1.3 Perform PCA on {S'_i}:
        • Construct covariance matrix C = (1/(N-1)) Σ_i S'_i S'_i^T
        • Eigen-decompose: C = V Λ V^T
        • Select top Kp eigenvectors: V_p = [v_1 … v_Kp]
        • Store eigenvalues Λ_p

1.4 Project seed spectra onto PCA space:
        α_i = V_p^T * S'_i      // α_i ∈ ℝ^{Kp}

--------------------------------------------------------------------
Step 2 – Augment Latent Distribution (KDE)
--------------------------------------------------------------------
2.1 Fit multivariate KDE to {α_i} with bandwidth h:
        p_KDE(α) ← KDE({α_i}, h)

2.2 Sample synthetic latent vectors:
        For s = 1 … N_aug:
              α_s ← DrawRandomSample(p_KDE)

--------------------------------------------------------------------
Step 3 – Generate Synthetic Photometry (Likelihood)
--------------------------------------------------------------------
For each sampled latent vector α_s:
    3.1 Decode to spectrum:
          S_s(λ) = μ(λ) + V_p * α_s

    3.2 Forward‑model photometry:
          For each filter k:
                m_s,k = ⟨S_s(λ), T_k(λ)⟩ / ⟨S_⊙(λ), T_k(λ)⟩   // reflectance in band k
          // ⟨·,·⟩ denotes integral over λ

    3.3 Inject Gaussian noise:
          For each band k:
                m_s,k ← m_s,k + Normal(0, σ_n * m_s,k)

    3.4 Store pair (m_s, α_s)

Result: TrainingSet = {(m_s, α_s)}_{s=1}^{N_aug}

--------------------------------------------------------------------
Step 4 – Train AutoML Regressor (Encoder)
--------------------------------------------------------------------
4.1 Input: Photometry vectors {m_s}
     Output: Latent vectors {α_s}
4.2 AutoMLRegressor ← AutoMLTrain(TrainingSet, AutoML_settings)
     // Uses ensemble of GBDTs, NN, etc.; returns fitted model

--------------------------------------------------------------------
Step 5 – Train Taxonomy Classifier
--------------------------------------------------------------------
5.1 Label seed spectra with class labels L_i (e.g. H2O, CO2, Organic, Methanol)
5.2 Project labeled spectra onto PCA space: {α_i, L_i}
5.3 Train AutoMLClassifier on {α_i, L_i}:
        AutoMLClassifier ← AutoMLTrain({α_i, L_i}, AutoML_settings)

--------------------------------------------------------------------
Step 6 – Inference on New Observation
--------------------------------------------------------------------
6.1 Preprocess Photometry:
        m_new ← Normalize(m_j)   // match scaling used during training

6.2 Predict Latent Coefficients:
        α_hat = AutoMLRegressor.predict(m_new)   // point estimate
        Optionally, obtain posterior samples by perturbing m_new with Gaussian noise:
            For t = 1 … N_post:
                m_t = m_new + Normal(0, σ_n * m_new)
                α_t = AutoMLRegressor.predict(m_t)
            PosteriorSamples = {α_t}

6.3 Decode to Spectrum:
        S_hat(λ) = μ(λ) + V_p * α_hat
        ReconstructedSpectrum = S_hat(λ)

6.4 Classify Taxonomy:
        P_classes = AutoMLClassifier.predict_proba(α_hat)

--------------------------------------------------------------------
Return:
    - ReconstructedSpectrum
    - TaxonomyProbabilities = P_classes
    - (Optional) PosteriorSamples of latent vectors
