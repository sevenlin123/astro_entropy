Input:  
    - Reference spectra set R = {S_i | i = 1..N_ref}   // N_ref ≈ 50 TNO spectra  
    - Filter response curves F = {f_j | j = 1..M}      // e.g., JWST NIRCam filters  
    - Desired number of principal components K (e.g., 5–10)  
    - KDE bandwidth h (≈ 0.5)  

Procedure:
1.1 Standardize spectra:
        For each S_i, normalize by dividing by its average reflectance or by the solar spectrum.

1.2 Construct data matrix X ∈ ℝ^(N_ref × L) where L = number of wavelength points per spectrum.

1.3 Perform Principal Component Analysis (PCA):
        Compute mean spectrum μ_S = mean(X, axis=0).
        Center X_c = X – μ_S.
        Compute covariance C = (X_cᵀ X_c) / (N_ref – 1).
        Eigen-decompose C → eigenvalues λ_k, eigenvectors v_k.
        Select first K eigenvectors V_K = [v_1 … v_K].
        Project each spectrum to latent space:
            z_i = V_Kᵀ (S_i – μ_S)     // z_i ∈ ℝ^K

1.4 Fit Kernel Density Estimate (KDE) on latent vectors {z_i}:
        Use Gaussian kernel with bandwidth h to obtain density p(z).

1.5 Generate synthetic latent samples:
        Sample N_syn ≫ N_ref latent vectors {z'_k} from p(z) (e.g., N_syn = 5000).

1.6 Decode synthetic spectra:
        For each z'_k:
            S'_k = μ_S + V_K z'_k      // reconstruct high‑resolution spectrum

1.7 Forward‑model synthetic photometry:
        For each S'_k:
            For each filter f_j:
                m_j = ∫ S'_k(λ) * f_j(λ) dλ   // compute reflectance in filter
            Assemble photometry vector m_k = [m_1 … m_M].

1.8 Add Gaussian noise to photometry:
        For each m_j in m_k:
            σ_j = 0.2 * m_j                    // 20 % relative uncertainty
            m_j_noisy = m_j + Normal(0, σ_j)
        Store noisy photometry vector 𝑚̃_k.

1.9 Prepare training dataset:
        Inputs X_train = {𝑚̃_k}              // M‑dimensional noisy photometry
        Targets Y_latent = {z'_k}           // K‑dimensional latent coefficients
        Targets Y_classifier = taxonomy labels associated with z'_k
            // assign label of nearest real spectrum or interpolate if desired

2.1 Train Encoder (photometry → latent coefficients):
        Use AutoML (e.g., AutoGluon) to learn mapping f_enc:
            f_enc : ℝ^M → ℝ^K
        Loss: Mean‑Squared Error between f_enc(𝑚̃_k) and z'_k.
        Output: Trained encoder model Enc.

2.2 Train Classifier (latent → taxonomy):
        Use AutoML to learn mapping f_cls:
            f_cls : ℝ^K → probability vector over taxonomic classes.
        Loss: Cross‑Entropy between f_cls(z'_k) and Y_classifier.
        Output: Trained classifier model Cls.

Input: Observed photometry vector m_obs = [m_1 … m_M]  // measured reflectances

Procedure:
3.1 Preprocess m_obs:
        Optionally rescale or normalize to match training distribution.

3.2 Predict latent coefficients:
        z_pred = Enc(m_obs)

3.3 Reconstruct full spectrum:
        S_rec = μ_S + V_K z_pred          // high‑resolution reflectance

3.4 Predict taxonomy probabilities:
        P_tax = Cls(z_pred)               // vector of class probabilities

Output:
        - Reconstructed spectrum S_rec (length L)
        - Taxonomy probability vector P_tax

4.1 Compute derived spectral metrics:
        - Spectral slope over specified wavelength ranges.
        - Absorption band depths by comparing S_rec to continuum.

4.2 Generate uncertainty estimates:
        - Draw multiple latent samples from posterior p(z | m_obs) using
          e.g., Monte‑Carlo dropout or ensemble predictions from Enc.
        - Reconstruct spectra for each sample to obtain prediction variance.
