Input:
    S_ref[1..N]        – Reference spectra (high‑resolution reflectance arrays)
    λ_ref[1..M]        – Wavelength grid of the reference spectra
    λ_phot[1..L]       – Wavelength centers of the photometric bands
    T_eff[1..L]        – Effective filter transmission curves
    n_components K     – Desired dimensionality of latent space (e.g., 5–10)
    h_kde               – Bandwidth for kernel density estimation
    n_aug              – Number of synthetic latent samples to generate (e.g., 5000)
    n_noise_samples   – Number of noisy photometric realizations per synthetic spectrum
    σ_rel = 0.20        – Relative reflectance noise level (20 %)

Output:
    For each new observation m[1..L]:
        * Posterior samples of latent coefficients z[1..K]
        * Reconstructed spectra S_recon[1..M] (mean and credible intervals)
        * Taxonomic probability vector P_type[1..C]

--------------------------------------------------------------------
1.  PRINCIPAL COMPONENT ANALYSIS (PCA)
--------------------------------------------------------------------
1.1  Center the reference spectra:
        μ_S = mean(S_ref across N)
        S_centered[i] = S_ref[i] – μ_S          for i = 1…N

1.2  Compute covariance matrix C = (1/(N-1)) * (S_centered^T · S_centered)

1.3  Perform eigendecomposition of C:
        [eigvecs, eigvals] = eig(C)
        Sort eigvals descending; keep first K eigenvectors:
            V_pca = eigvecs[:, 1:K]             // shape (M × K)

1.4  Project each centered spectrum onto the PCA basis:
        Z_real[j] = V_pca^T · S_centered[j]    // shape (N × K)

--------------------------------------------------------------------
2.  DENSITY ESTIMATION AND DATA AUGMENTATION
--------------------------------------------------------------------
2.1  Fit a multivariate Kernel Density Estimator (KDE) to the real latent
        coordinates {Z_real[j]} using bandwidth h_kde.

2.2  Sample n_aug latent vectors from the KDE:
        For t = 1…n_aug:
            z_t ~ KDE
            Store z_t in list Z_aug[t]

2.3  For each z_t, reconstruct a synthetic spectrum:
        s_t = μ_S + V_pca · z_t                // shape (M)

--------------------------------------------------------------------
3.  SYNTHETIC PHOTOMETRY GENERATION
--------------------------------------------------------------------
3.1  For each synthetic spectrum s_t:
        For l = 1…L:
            m_t[l] = ∫ s_t(λ) · T_eff[l](λ) dλ / ∫ T_eff[l](λ) dλ
            // Reflectance weighted by filter throughput

3.2  Add Gaussian noise to each m_t[l]:
        For n = 1…n_noise_samples:
            m_t_n[l] = m_t[l] + Normal(0, σ_rel * m_t[l])
            Append (m_t_n, z_t) to training dataset D

--------------------------------------------------------------------
4.  TRAINING PHASE
--------------------------------------------------------------------
4.1  Prepare training data D:
        X = {m_t_n[1..L]}           // Photometric vectors
        Y = {z_t}                   // Corresponding latent coefficients

4.2  Train an AutoML regressor R (ensemble of GBDT + NN):
        R.fit(X, Y)                 // Maps photometry → latent vector

4.3  Train a separate AutoML classifier C on real latent vectors:
        Input: Z_real[1..N]
        Labels: taxonomy class of each reference spectrum
        C.fit(Z_real, labels)

--------------------------------------------------------------------
5.  INFERENCE (FOR NEW OBSERVATIONS)
--------------------------------------------------------------------
For each new photometric observation m_new[1..L]:

5.1  Predict latent coefficient distribution:
        z_pred_mean, z_pred_cov = R.predict_with_uncertainty(m_new)
        // If R returns deterministic vector, sample z_pred ~ N(z_pred_mean,
        //                                 z_pred_cov) or use Monte Carlo dropout.

5.2  Generate N_posterior samples of latent vector:
        For k = 1…N_posterior:
            z_k = sample_from(z_pred_mean, z_pred_cov)
            S_k   = μ_S + V_pca · z_k          // Reconstructed spectrum
            Store S_k

5.3  Compute spectral statistics:
        S_mean      = mean(S_k over k)
        CredibleInt = percentile(S_k, [2.5%, 97.5%])   // 95 % CI

5.4  Taxonomic probabilities:
        P_type = C.predict_proba(mean(z_k over k))
        // Optionally, feed each z_k to C and average probabilities.

5.5  Return:
        • Posterior samples S_k
        • Mean spectrum S_mean and credible interval
        • Taxonomy probability vector P_type

--------------------------------------------------------------------
6.  OPTIONAL: OUTLIER DETECTION
--------------------------------------------------------------------
6.1  Compute Mahalanobis distance of z_pred_mean to KDE density:
        d = sqrt( (z_pred_mean - μ_KDE)^T · Σ_KDE^{-1} · (z_pred_mean - μ_KDE) )

6.2  Flag observation as outlier if d > threshold (e.g., 3σ)

--------------------------------------------------------------------
End of Algorithm
