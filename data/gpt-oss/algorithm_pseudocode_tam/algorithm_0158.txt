INPUT:
    S_spec   : list of N_ref spectral vectors (λ_i, R_i)  [seed spectra]
    F_filter : list of M filter transmission curves {T_j(λ)}   [JWST NIRCam or user set]
    K_lat    : number of principal components to retain            (e.g., 5–10)
    h_kde    : KDE bandwidth (e.g., 0.5)
    B        : number of synthetic latent samples per seed spectrum (e.g., 200)
    σ_noise  : relative photometric noise level (e.g., 0.20 for 20%)
    N_pred   : number of test photometry vectors to reconstruct

OUTPUT:
    For each new photometry vector m:
        - Posterior mean spectrum Ŝ(λ)
        - Posterior covariance (optional)
        - Taxonomy probability vector p_type

1.1   Pre‑process seed spectra:
      • Resample all S_spec onto common wavelength grid λ_grid
      • Normalize (e.g., divide by mean reflectance)

1.2   Compute mean spectrum μ_S = mean(S_spec)

1.3   Center spectra:  X = {S_spec - μ_S}

1.4   Perform Singular Value Decomposition (SVD):
      U, Σ, V^T = svd(X, full_matrices=False)

1.5   Select first K_lat columns of U * Σ  →  PC_basis (K_lat × N_wavelength)
      (These are the principal component eigenvectors.)

1.6   Project each centered spectrum onto PCs:
      For each s ∈ S_spec:
          coeff(s) = PC_basis · (s - μ_S)^T   →  vector of length K_lat

1.7   Store matrix C = [coeff(s_1), … , coeff(s_N)]  (size K_lat × N_ref)

1.8   Estimate continuous latent density:
      • Use kernel density estimator (Gaussian kernels) on rows of C
      • Bandwidth parameter h = h_kde
      (Store KDE model for sampling.)

2.1   For i = 1 … N_ref:                // seed spectra
      For b = 1 … B:                    // synthetic samples per seed
          • Sample latent vector z_b ~ KDE(C[:,i])      // KDE conditional on seed i
          • Reconstruct synthetic spectrum:
                S_syn = μ_S + PC_basis^T · z_b
          • Forward‑model photometry:
                For each filter j:
                    m_j = ∫ S_syn(λ) * T_j(λ) dλ / ∫ T_j(λ) dλ
          • Inject Gaussian noise:
                m_j_noisy = m_j * (1 + Normal(0, σ_noise))
          • Store tuple (m_noisy, z_b, label_i)
      End
   End

Result: Training database D = {(m_noisy, z_true, label)}

3.1   Extract feature matrix X_reg = {m_noisy}   (size N_tr × M)
       Target matrix Y_reg = {z_true}            (size N_tr × K_lat)

3.2   Initialize AutoML regressor (e.g., AutoGluon Tabular):
        AutoML_Regressor = AutoMLRegressor(
                            models=[GBDT, RandomForest, NeuralNet],
                            search_strategy='grid',
                            metric='rmse')

3.3   Fit:
        AutoML_Regressor.fit(X_reg, Y_reg)

4.1   Extract feature matrix X_cls = {z_true}   (size N_tr × K_lat)
       Labels y_cls = {label_i}                 (categorical)

4.2   Initialize AutoML classifier (e.g., AutoGluon Tabular):
        AutoML_Classifier = AutoMLClassifier(
                               models=[GBDT, RandomForest, NeuralNet],
                               search_strategy='grid',
                               metric='accuracy')

4.3   Fit:
        AutoML_Classifier.fit(X_cls, y_cls)

FUNCTION ReconstructSpectrum(m_obs):

    # 5.1   Encode photometry → latent coordinates
    z_pred = AutoML_Regressor.predict(m_obs)        # vector of length K_lat

    # 5.2   Decode to full spectrum
    S_hat = μ_S + PC_basis^T · z_pred                # vector of length N_wavelength

    # 5.3   Taxonomy prediction
    p_type = AutoML_Classifier.predict_proba(z_pred)   # probabilities over classes

    RETURN S_hat, p_type
END

FOR each photometry vector m_k in test set (k = 1 … N_pred):
    S_k, P_k = ReconstructSpectrum(m_k)
    STORE S_k, P_k
END
