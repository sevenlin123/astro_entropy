Input:
    - Reference spectra S_ref[1..N_ref][1..L]   // L wavelength bins
    - Filter response curves R_filt[1..F][1..L]   // F filters
    - Bandwidth h_KDE (e.g., 0.5)
    - Desired number of PCA components K (e.g., 8–10)
    - Number of synthetic samples M  (e.g., 10 000)
    - Noise level σ_noise (e.g., 0.20)

Output:
    - Trained encoder E  (photometry → latent coefficients)
    - Trained classifier C  (latent → taxonomy probabilities)
    - Function Reconstruct(m_phot) → S_recon[L]
    - Function Classify(m_phot)  → {P_H2O, P_CO2, P_Org, P_Meth}

Procedure:

1. **Pre‑processing**
   1.1. Normalize each reference spectrum S_ref[i] (e.g., divide by solar spectrum).
   1.2. Optional: interpolate spectra to common wavelength grid if needed.

2. **Principal Component Analysis (PCA)**
   2.1. Stack spectra into matrix X[N_ref × L].
   2.2. Center X by subtracting column means μ_X.
   2.3. Compute covariance Σ = (Xᵀ X) / (N_ref – 1).
   2.4. Perform eigendecomposition Σ = U Λ Uᵀ.
   2.5. Select first K eigenvectors U_K.
   2.6. Project spectra to latent space: Z_real = X_centered · U_K   // size N_ref × K
   2.7. Store inverse transform matrix U_Kᵀ and mean μ_X.

3. **Latent‑space Augmentation (KDE)**
   3.1. Estimate density p(Z) using multivariate KDE with bandwidth h_KDE on Z_real.
   3.2. Sample M synthetic latent vectors: Z_syn[1..M][1..K] ~ KDE(Z_real).

4. **Synthetic Spectra Generation**
   4.1. For each z in Z_syn:
          S_syn = μ_X + z · U_Kᵀ          // inverse PCA → full spectrum
          Store S_syn.
   4.2. Optionally append real spectra: Z_all = concat(Z_real, Z_syn),
       S_all = concat(S_ref, S_syn).

5. **Synthetic Photometry Simulation**
   5.1. For each spectrum S in S_all:
          For each filter f:
              m_f = ∫ S(λ) * R_filt[f](λ) dλ   // numerical integration
          Collect vector m = [m_1 … m_F].
   5.2. Add Gaussian noise:
          For each m_f: m_f ← m_f + N(0, σ_noise² * m_f²).
   5.3. Store pairs (m, z) where z is latent coefficients for that spectrum.

6. **Encoder Training**
   6.1. Split dataset (m, z) into training/validation (e.g., 80/20).
   6.2. Use AutoML (e.g., AutoGluon) to build an ensemble regressor:
          Input: photometry vector m (length F)
          Output: latent vector z (length K)
   6.3. Train until convergence; store model E.

7. **Classifier Training**
   7.1. Label each reference spectrum with taxonomy class c ∈ {H₂O, CO₂, Org, Meth}.
   7.2. Associate each latent vector z with its class label.
   7.3. Train AutoML classifier:
          Input: latent vector z
          Output: probability distribution over classes.
   7.4. Store model C.

8. **Inference Functions**
   Function Reconstruct(m_phot):
        8.1. Predict latent coefficients: ẑ = E.predict(m_phot).
        8.2. Reconstruct spectrum: Ŝ = μ_X + ẑ · U_Kᵀ.
        8.3. Return Ŝ.

   Function Classify(m_phot):
        8.4. Predict latent coefficients: ẑ = E.predict(m_phot).
        8.5. Predict taxonomy probabilities: P = C.predict(ẑ).
        8.6. Return P.

9. **Usage Example**
   For new object with photometry m_new:
        S_rec = Reconstruct(m_new)
        P_tax = Classify(m_new)
