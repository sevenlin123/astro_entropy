INPUT  
    S_real[1…N]          # High‑resolution spectra of N reference TNOs  
    F[1…M]               # Transmission curves of M photometric filters  
    K_pca                 # Desired number of principal components (≈4–10)  
    h_kde                  # Bandwidth for KDE augmentation  

OUTPUT  
    PCA_model              # Mean spectrum μ, eigenvectors V[1…K]  
    KDE_model              # Density estimator over latent space  
    Encoder_model          # Regression model: photometry → latent vector  
    Classifier_model       # Latent‑space classifier: latent → taxonomy probs

1.1.1  Center each spectrum:  S_centered[i] = S_real[i] – mean(S_real)
1.1.2  Build covariance matrix C = (S_centered)^T · S_centered / (N-1)
1.1.3  Eigen‑decompose C → eigenvalues λ[1…K], eigenvectors v[1…K]
1.1.4  Form PCA_model = {μ = mean(S_real), V = [v[1],…,v[K]]}

For each i in 1…N:
      a_i = V^T · (S_real[i] – μ)        # Projection → latent coefficient vector (size K)
Store latent set A = {a_1,…,a_N}

1.3.1  Fit a multivariate KDE to A with bandwidth h_kde → KDE_model
1.3.2  Sample M_synth latent vectors {z_j} ~ KDE_model   (M_synth ≫ N, e.g., 5000)

For each synthetic latent vector z_j:
      1.4.1  Reconstruct spectrum:  S_hat[j] = μ + V · z_j
      1.4.2  For each filter m in 1…M:
                Compute ideal photometric flux f_m = ∫ S_hat[j] · F[m] dλ
      1.4.3  Add Gaussian noise:  f_m_noisy = f_m × (1 + ε_m),
                where ε_m ~ Normal(0, 0.20)          # 20 % relative uncertainty
      1.4.4  Store training pair: (photometry vector p_j = [f_1_noisy,…,f_M_noisy],
                                   latent target z_j)

Use an AutoML regression framework (e.g., AutoGluon) to fit:
    Encoder_model = argmin_{model} Σ_j ||Encoder_model(p_j) – z_j||²

Label each real spectrum S_real[i] with its known taxonomic class c_i.
Project labeled spectra to latent space: a_i (computed in 1.2).
Fit a classification AutoML model on {(a_i , c_i)} to obtain:
    Classifier_model = argmin_{model} ClassificationLoss

INPUT  
    p_new[1…M]          # Observed noisy photometry of a new TNO  
    PCA_model, KDE_model, Encoder_model, Classifier_model
OUTPUT  
    S_recon[1…L]         # Reconstructed high‑resolution spectrum (L wavelengths)  
    Cov_S_recon[1…L][1…L]  # Optional covariance matrix of reconstruction  
    Taxonomy_probs[C]     # Probability distribution over taxonomic classes

z_pred = Encoder_model(p_new)          # Point estimate in latent space

Sample N_latent samples {z_k} from a Gaussian centered at z_pred
    with covariance estimated from encoder uncertainty

For each sampled z_k:
      S_k = μ + V · z_k                      # Inverse PCA transform
Aggregate samples to obtain:
      S_recon = mean_k(S_k)                 # Point estimate
      Cov_S_recon = covariance_k(S_k)      # Posterior covariance

Taxonomy_probs = Classifier_model(z_pred)   # Softmax or probabilistic output

Return S_recon, Cov_S_recon, Taxonomy_probs
