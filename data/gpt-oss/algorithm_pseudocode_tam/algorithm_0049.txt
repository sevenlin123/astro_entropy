INPUT:  
    - ObservedSpectra = {S_i(λ)} , i = 1 … N_obs   // N_obs ≈ 51 spectra
    - FilterCurves = {T_k(λ)} , k = 1 … N_filt      // JWST NIRCam filters

PARAMETERS:  
    - K_pca            // number of principal components (≈ 5–10)
    - h_kde            // KDE bandwidth (≈ 0.5)
    - N_aug            // number of augmented latent samples (≈ 5 000)
    - σ_phot          // photometric noise std. (≈ 20 % of reflectance)

STEPS:
1.1  Normalize each spectrum S_i(λ) to unit mean reflectance.
1.2  Build matrix X ∈ ℝ^{N_obs × M} where M = number of wavelength bins.
1.3  Perform PCA on X → eigenvectors V_j(λ), j = 1…K_pca, and coefficients C_i ∈ ℝ^{K_pca}.
1.4  Compute KDE over {C_i} with bandwidth h_kde → density p(C).
1.5  Sample N_aug latent vectors {C̃_s} from p(C)  // synthetic latent samples
1.6  For each sampled C̃_s:
        1.6.1  Reconstruct synthetic spectrum S̃_s(λ) = μ_X + Σ_{j=1}^{K_pca} C̃_s[j] * V_j(λ)
        1.6.2  Compute synthetic photometry:
                m̃_s[k] = ∫ S̃_s(λ) * T_k(λ) dλ  for all k
        1.6.3  Add Gaussian noise: 
                m̃_s_noisy[k] = m̃_s[k] * (1 + Normal(0, σ_phot))
        1.6.4  Store pair (m̃_s_noisy, C̃_s)

INPUT:  
    - TrainingPairs = {(m̃_s_noisy, C̃_s)} from Step 1.6
    - AutoMLFramework (e.g., AutoGluon)

STEPS:
2.1  Define feature set = m̃_s_noisy (length N_filt).
2.2  Define target set = C̃_s (length K_pca).
2.3  Use AutoML to search/ensemble models that minimize
        mean squared error (MSE) between predicted and true coefficients.
2.4  Select best performing regressor R_enc.

INPUT:  
    - LatentCoefficients = {C_i} from Step 1.3
    - Labels = {ℓ_i} where ℓ_i ∈ {H2O, CO2, Organics, Methanol}

STEPS:
3.1  Use AutoML to train multi‑class classifier C_cls on (C_i, ℓ_i).
3.2  Validate classifier on cross‑validation folds.

INPUT:  
    - ObservedPhotometry = {m_k} (k = 1 … N_filt)
    - Trained regressor R_enc
    - Trained classifier C_cls
    - PCA basis V_j(λ), mean spectrum μ_X

STEPS:
4.1  Predict latent coefficients:
        Ĉ = R_enc.predict(m_k)
4.2  Reconstruct spectrum:
        Ŝ(λ) = μ_X + Σ_{j=1}^{K_pca} Ĉ[j] * V_j(λ)
4.3  Compute taxonomy probabilities:
        p(ℓ | Ĉ) = C_cls.predict_proba(Ĉ)
4.4  Output:
        - Reconstructed spectrum Ŝ(λ)
        - Posterior class probabilities p(ℓ | Ĉ)

INPUT:  
    - Trained regressor R_enc (with probabilistic outputs if available)
    - ObservedPhotometry = {m_k}
    - Number of samples N_samp

STEPS:
5.1  For n = 1 … N_samp:
        5.1.1  Sample latent vector Ĉ_n from predictive distribution of R_enc
        5.1.2  Reconstruct spectrum Ŝ_n(λ) as in 4.2
        5.1.3  Classify Ĉ_n → p_n(ℓ)
5.2  Aggregate samples to estimate:
        - Credible intervals on Ŝ(λ)
        - Empirical class probability distribution
