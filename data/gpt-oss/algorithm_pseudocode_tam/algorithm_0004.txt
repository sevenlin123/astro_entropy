pseudo
1.1 Load reference spectra S[1…N]   // each of length M
1.2 Compute mean spectrum μS = mean(S)
1.3 Center spectra: S_centered[i] = S[i] – μS

1.4 Perform PCA on {S_centered}
      → obtain eigenbasis P (M × K)   // columns are PCs
      → project spectra: C[i] = Pᵀ · S_centered[i]   // C is N × K

1.5 Fit Kernel Density Estimate (KDE) on latent points C  
      KDE_params = KDE(C, bandwidth = h)

1.6 Sample synthetic latent vectors  
      C_synth[1…N_synth] = KDE_sample(KDE_params)

1.7 Reconstruct synthetic spectra  
      for each k in 1…N_synth:
          S_synth[k] = μS + P · C_synth[k]

1.8 Compute synthetic photometry for each synthetic spectrum  
      for each filter f in 1…F:
          m_synth[k, f] = ∫ S_synth[k]·T_f / ∫ T_f          // reflectance
      // add Gaussian noise (20 % relative uncertainty)
      σ_noise = 0.2 * m_synth
      m_synth_noisy = m_synth + Normal(0, σ_noise)

1.9 Assemble training data  
      X_train = m_synth_noisy       // F‑dimensional photometry
      Y_train = C_synth             // K‑dimensional latent coeffs
      // (Optional) Store true taxonomic label for each C[i] from reference set

1.10 Train AutoML regressor R on (X_train, Y_train)
      R = AutoML_Train(X_train, Y_train)

1.11 Train AutoML classifier C on latent coefficients and labels
      // Labels come from reference spectra (water, CO₂, organics, methanol)
      C = AutoML_Train(C_latent = C, labels = L)

pseudo
INPUT: photometric measurements m_obs[1…F]  // observed reflectance in each filter
OUTPUT: reconstructed spectrum s_rec[1…M]
        taxonomic probability vector p_tax[1…T]   // T = number of classes

2.1 Predict latent coefficients
      c_pred = R.predict(m_obs)        // returns K‑dim vector

2.2 Reconstruct spectrum
      s_rec = μS + P · c_pred          // length M

2.3 Classify taxonomy
      p_tax = C.predict_proba(c_pred)  // probability for each class

RETURN (s_rec, p_tax)
