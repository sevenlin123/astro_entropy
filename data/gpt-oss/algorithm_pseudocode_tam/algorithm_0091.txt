INPUT:
    - SeedSpectra          : array of N_seed reflectance spectra (high‑res wavelengths)
    - FilterThroughputs    : list of M filter transmission curves
    - BandNoiseFraction    : relative photometric noise level (e.g., 0.20)
    - KDEBandwidth         : kernel width for latent density (e.g., 0.5)
    - NumSyntheticSamples  : number of samples drawn from KDE (e.g., 10,000)

OUTPUT:
    - ReconstructedSpectrum   : high‑resolution reflectance spectrum
    - SpectrumUncertainty     : per‑wavelength confidence interval
    - TaxonomyProbabilities   : probability vector over classes {Water, CO2, Organics, Methanol}

--------------------------------------------------------------------
# 1. DEFINE PRIOR – TRAIN PCA ON SEED SPECTRA
--------------------------------------------------------------------
1.1 Compute mean spectrum μ_spec = mean(SeedSpectra)
1.2 Center spectra: X_centered = SeedSpectra – μ_spec
1.3 Perform Singular Value Decomposition: X_centered = U Σ Vᵀ
1.4 Select first K PCs (columns of V): PCs = V[:, 0:K]
1.5 Project seed spectra onto PCs: LatentSeed = X_centered · PCs      # size N_seed × K

--------------------------------------------------------------------
# 2. AUGMENT PRIOR – SAMPLE FROM KDE IN LATENT SPACE
--------------------------------------------------------------------
2.1 Estimate probability density p(z) via KDE on LatentSeed with bandwidth KDEBandwidth
2.2 Draw N_synthetic latent vectors: LatentAug = KDE.sample(N_synthetic)
2.3 For each z ∈ LatentAug:
        a) Reconstruct synthetic spectrum: Spec_syn = μ_spec + PCs · zᵀ
        b) Store Spec_syn and its latent vector z

--------------------------------------------------------------------
# 3. BUILD TRAINING DATABASE OF PHOTOMETRY ↔ LATENT COEFFICIENTS
--------------------------------------------------------------------
3.1 For each synthetic spectrum Spec_syn:
        a) Compute noiseless photometry:
              Phot_noiseless = Convolve(Spec_syn, FilterThroughputs)
        b) Inject Gaussian noise:
              Phot_noisy = Phot_noiseless * (1 + Normal(0, BandNoiseFraction))
        c) Append (Phot_noisy, Latent vector z) to TrainingSet
--------------------------------------------------------------------
# 4. TRAIN AUTOMATED REGRESSOR (Encoder)
--------------------------------------------------------------------
4.1 Use AutoML framework (e.g., AutoGluon) to fit a model:
        Regressor = AutoML.fit(
            X = [Phot_noisy],
            y = [Latent vector z],
            task='regression',
            hyperparams=AutoTuned
        )
4.2 OPTIONAL: Store predictive variance/ensemble outputs for uncertainty

--------------------------------------------------------------------
# 5. TRAIN TAXONOMY CLASSIFIER (in latent space)
--------------------------------------------------------------------
5.1 Assign taxonomic label ℓ_i to each seed spectrum (from external catalog)
5.2 Fit classifier on latent vectors of seed spectra:
        Classifier = AutoML.fit(
            X = LatentSeed,
            y = Labels,
            task='classification',
            hyperparams=AutoTuned
        )

--------------------------------------------------------------------
# 6. INFERENCE FOR NEW OBJECT
--------------------------------------------------------------------
Input: PhotometryObs  (size M)

6.1 Predict latent coefficients:
        LatentPred, LatentVar = Regressor.predict(PhotometryObs)
        # If ensemble, aggregate means and variances

6.2 Reconstruct high‑resolution spectrum:
        Spec_rec = μ_spec + PCs · LatentPredᵀ
        # Propagate LatentVar to obtain SpectrumUncertainty via Jacobian:
        # SpectrumUncertainty ≈ PCs · sqrt(LatentVar)ᵀ

6.3 Classify taxonomy:
        TaxProb = Classifier.predict_proba(LatentPred)

RETURN (Spec_rec, SpectrumUncertainty, TaxProb)
