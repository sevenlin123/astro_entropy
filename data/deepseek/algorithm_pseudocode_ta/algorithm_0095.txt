**Algorithm: Probabilistic Spectral Reconstruction via Latent Space Bayesian Inference**

1. **Initialize Training Data**
   - Input a collection of near-infrared spectra for trans-Neptunian objects.

2. **Principal Component Analysis (PCA) Training**
   - Perform PCA on the training spectra to derive principal components.
   - Extract eigenvectors and eigenvalues representing the spectral manifold.

3. **Define Prior Distributions**
   - Set up prior probabilities for each object's position in the latent PCA space.

4. **For Each Test Spectrum**
   - a. Project sparse photometric data into the latent PCA space.
   - b. Perform Bayesian inference using the PCA basis to estimate the most probable latent parameters.
   - c. Propagate uncertainties from photometric measurements through the PCA model.
   - d. Reconstruct the full spectral shape by mapping latent estimates back to the spectral domain.
   - e. Compute empirical credible intervals for the reconstructed spectra.

5. **Output**
   - For each test object, produce the reconstructed spectrum and associated uncertainties.

This algorithm encapsulates the core steps of spectral reconstruction using a probabilistic latent-space framework, combining PCA and Bayesian inference.
