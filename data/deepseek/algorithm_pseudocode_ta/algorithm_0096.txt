**Algorithm for Spectral Reconstruction of TNOs**

**Training Phase:**
1. **Input**: Set of training spectra `S` with dimensions `[N_spectra, N_wavelengths]`.
2. **Log Transformation**: Apply logarithm to each spectrum to capture multiplicative variations.
3. **Center Data**: Subtract the mean spectrum from the log-transformed data.
4. **Compute Covariance Matrix**: Calculate the covariance matrix `C` of the centered data.
5. **PCA Decomposition**: Diagonalize `C` to obtain eigenspectra `V` and eigenvalues `D`.
6. **Select Top K Eigenspectra**: Choose top `K` eigenspectra based on explained variance.

**Precompute Forward Model Matrix:**
1. **Initialize**: For each filter `j`, compute the integral of each eigenspectrum with the filter response to create matrix `F` where `F[j,k]` is the integral result.

**Testing Phase (for each test object):**
1. **Read Photometric Data**: Convert photometric measurements into flux vector `Y`.
2. **Bayesian Inference**:
   - Set up the system `Y = F * a + noise`.
   - Define prior and likelihood distributions.
   - Solve for the posterior mode of `a` using matrix inversion.
3. **Reconstruct Log Spectrum**: Combine the mean log spectrum with estimated `a` coefficients.
4. **Exponentiate**: Convert the log spectrum back to the original space.
5. **Output**: Reconstructed spectrum with uncertainties.

**Code Structure (Pseudocode):**

```python
# Training Phase

def train_pca(spectra):
    # Input: [N_spectra, N_wavelengths]
    # Output: top_k_eigenspectra, F_matrix
    # Log transform
    log_spectra = np.log(spectra + 1e-10)
    # Center data
    centered = log_spectra - np.mean(log_spectra, axis=0)
    # Compute covariance matrix
    cov = np.cov(centered, rowvar=False)
    # Diagonalize
    eig_val, eig_vec = np.linalg.eigh(cov)
    # Sort
    idx = eig_val.argsort()[::-1]
    eig_val = eig_val[idx]
    eig_vec = eig_vec[:, idx]
    # Select top K
    K = determine_k(eig_val)
    top_k_eigenspectra = eig_vec[:, :K]
    # Precompute F_matrix
    F_matrix = precompute_F(top_k_eigenspectra, filters)
    return top_k_eigenspectra, F_matrix

def precompute_F(eigenspectra, filters):
    F = []
    for filter in filters:
        F_row = [np.trapz(eigenspectra[:, k] * filter.response, filter.wavelengths) for k in range(eigenspectra.shape[1])]
        F.append(F_row)
    return np.array(F)

# Testing Phase

def reconstruct_spectrum(test_photometry, F_matrix, top_k_eigenspectra, sigma_prior, sigma_obs):
    # Convert photometry to flux vector Y
    Y = convert_to_flux(test_photometry)
    # Bayesian Inference
    F = F_matrix
    # Solve for a_post
    inv_matrix = np.linalg.inv(np.dot(F.T, F) * sigma_prior**2 + np.eye(F.shape[1]) * sigma_obs**2)
    a_post = np.dot(inv_matrix, np.dot(F.T, Y) * sigma_prior**2) / sigma_obs**2
    # Reconstruct log spectrum
    mu = np.mean(log_spectra, axis=0)
    recon_log = mu + np.dot(a_post, top_k_eigenspectra)
    # Exponentiate to get original spectrum
    recon_spectrum = np.exp(recon_log)
    return recon_spectrum

# Example usage

training_spectra = read_training_data()
top_k_eigenspectra, F_matrix = train_pca(training_spectra)

test_photometry = read_test_photometry()
recon_spectrum = reconstruct_spectrum(test_photometry, F_matrix, top_k_eigenspectra, sigma_prior, sigma_obs)
```
