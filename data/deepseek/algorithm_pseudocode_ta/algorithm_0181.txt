**Algorithm: Probabilistic Spectral Reconstruction**

**Input:**
- `TrainingSpectra`: Array of normalized and centered near-IR spectra.
- `PhotometricData`: Array of structures, each containing:
  - `ObjectID`
  - `Filters`
  - `Fluxes`
  - `FluxUncertainties`

**Output:**
- `ReconstructedSpectra`: Array of structures, each containing:
  - `ObjectID`
  - `WavelengthGrid`
  - `Spectrum`
  - `SpectrumUncertainty`

**Process:**

1. **Preprocess Training Spectra:**
   - For each spectrum in `TrainingSpectra`:
     1.1 Subtract the mean flux across all spectra to center.
     1.2 Normalize by dividing each flux by the spectrum's mean.
   - Perform PCA on the processed `TrainingSpectra`.
   - Retain `k` principal components based on explained variance (e.g., `k=4-5` or `8-10`).

2. **For each TNO in `PhotometricData`:**
   - Extract `ObjectID`, `Filters`, `Fluxes`, `FluxUncertainties`.
   - For each filter in `Filters`:
     2.1 Compute the filter's transmission curve.
     2.2 Project the transmission curve onto each PCA component to get filter responses.
   - Set up Bayesian model:
     2.3 Model observed flux as a combination of PCA components' contributions through the filter.
     2.4 Include flux uncertainties as observation noise.
     2.5 Define prior distributions for PCA coefficients.
   - Perform Bayesian inference (e.g., MCMC) to estimate PCA coefficients.
   - From posterior samples, compute mean and variance for each PCA coefficient.
   - Reconstruct `Spectrum` using the top `k` PCA eigenvectors multiplied by their coefficients.
   - Propagate uncertainties to calculate `SpectrumUncertainty`.

**End Process.**

**Output:** `ReconstructedSpectra`
