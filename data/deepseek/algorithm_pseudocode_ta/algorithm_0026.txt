```
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    Training spectra S_train
    Observed photometric data D_obs (magnitudes and uncertainties)
    Filter responses R (transmission curves)

Output:
    Reconstructed spectra S_recon and uncertainties U

Steps:

1. Precompute PCA Basis:
    a. Perform PCA on S_train to extract principal components (PCs).
    b. Determine the optimal number of PCs using cross-validation to ensure good reconstruction from photometric data.

2. Bayesian Inference Setup:
    a. For each filter, define the transmission function T(wavelength, filter) to compute observed magnitudes from a spectrum.

3. For each Object:
    a. Extract observed photometric magnitudes m_obs and uncertainties sigma from D_obs.
    b. Convert m_obs into fluxes if necessary, using filter responses R.
    c. Define the forward model function F(w) = integral(T(wavelength, filter) * S(w) d wavelength), where S(w) is the spectrum parameterized by weights w.
    d. Set up the prior distribution over weights w, such as w ~ MultivariateNormal(0, I).
    e. Compute the likelihood function L(w) = Normal(m_obs; F(w), sigma²).
    f. Use MCMC sampling to draw posterior samples of w given m_obs and sigma.
    g. Reconstruct the spectrum for each weight sample: S_sample = PC_inverse(w_sample).
    h. Aggregate S_samples to get S_recon and calculate uncertainties U as the standard deviation or percentile range of S_samples.

4. Output:
    a. Return the mean spectrum S_recon and quantile-based uncertainties U.

Return S_recon, U
```
