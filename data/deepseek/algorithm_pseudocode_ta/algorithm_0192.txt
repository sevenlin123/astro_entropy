```pseudocode
Algorithm CoreSpectralReconstruction:
    Input: Raw photometric data, parameters
    Output: Reconstructed spectra, uncertainties

    1. DataPreprocessing(RawData) -> NormalizedData
        a. Collect photometric data from various sources
        b. Normalize measurements to account for observation variations

    2. PCADimensionalityReduction(NormalizedData) -> PCAComponents, ExplainedVariance
        a. Apply PCA to normalized spectral data
        b. Determine optimal number of principal components based on explained variance

    3. BayesianInference(PCAComponents, NormalizedData) -> PosteriorSamples, Uncertainties
        a. Set up probabilistic model using PCA coefficients
        b. Define prior distribution based on training data
        c. Use MCMC to sample posterior distribution of PCA coefficients

    4. UncertaintyPropagation(PosteriorSamples, photometric_uncertainties) -> ReconstructedSpectra, Uncertainties
        a. Propagate photometric uncertainties through PCA model to quantify uncertainties in reconstructed spectra

    5. Output ReconstructedSpectra, Uncertainties
```
