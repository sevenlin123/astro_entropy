**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Read Reference Spectra**: Load the dataset of near-infrared spectra of trans-Neptunian objects.

2. **PCA Analysis**:
   - **Center Spectra**: Remove the mean from each spectrum.
   - **Compute Covariance Matrix**: Calculate the covariance matrix of the centered spectra.
   - **Diagonalization**: Diagonalize the covariance matrix to obtain principal components (eigenvectors) and variances (eigenvalues).
   - **Sort Components**: Arrange components in descending order of variance.

3. **Select Principal Components**: Choose the top 4-5 or 8-10 components based on the desired fidelity level.

4. **Project Spectra**: Express each reference spectrum as a linear combination of the selected principal components to obtain coefficients (scores).

5. **Precompute Forward Model**:
   - **Filter Sensitivity**: For each NIRCam filter (e.g., F090W), compute the transmission function.
   - **Sensitivity Matrix**: For each component, calculate its sensitivity to each filter by integrating the eigenspectrum with the filter's transmission curve. Construct matrix F where F_ij represents filter sensitivity to component j.

6. **Convert Photometry to Flux** (if necessary):
   - Convert observed photometric magnitudes to fluxes using the instrument's zero-point.

7. **Bayesian Inference Setup**:
   - **Prior**: Assume Gaussian priors on coefficients with mean 0.
   - **Likelihood**: Define a Gaussian likelihood with mean as F * c and variance as photometric measurement error.

8. **Markov Chain Monte Carlo (MCMC)**:
   - Initialize MCMC with starting guesses for coefficients.
   - For each iteration:
     - Propose new coefficients.
     - Compute predicted flux using F * proposed coefficients.
     - Calculate log posterior probability.
     - Accept or reject based on Metropolis-Hastings criterion.
   - Post-burn-in, collect posterior samples.

9. **Reconstruct Spectra**:
   - For each posterior sample of coefficients, compute the spectrum as sum(c_j * eigenspectrum_j).

10. **Calculate Uncertainties**:
    - For each wavelength, compute the standard deviation across all posterior-reconstructed spectra to determine uncertainties.

11. **Output**:
    - Provide the mean reconstructed spectrum and its uncertainties.

---

This algorithm systematically transforms sparse photometric data into full spectra by leveraging PCA and Bayesian inference, enabling robust taxonomic classification and outlier detection of trans-Neptunian objects.
