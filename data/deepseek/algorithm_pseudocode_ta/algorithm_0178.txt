**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Input Data**: 
   - Photometric measurements for trans-Neptunian objects (TNOs).
   - Training set of near-infrared (near-IR) spectra.

2. **Principal Component Analysis (PCA)**:
   - Compute PCA on the training set of near-IR spectra.
   - Select the appropriate number of principal components (e.g., 4-5 for taxonomic classification, 8-10 for higher reconstruction fidelity).

3. **Spectral Manifold Model**:
   - Construct a probabilistic model representing the spectral manifold in the PCA space.

4. **Bayesian Inference**:
   - For each TNO, utilize its photometric data to perform Bayesian inference on the PCA coefficients.
   - Account for measurement uncertainties during the inference process.

5. **Spectral Reconstruction**:
   - Reconstruct the full spectrum by mapping the inferred PCA coefficients back into the original spectral space.

6. **Uncertainty Propagation**:
   - Propagate the uncertainties from the Bayesian inference through the reconstruction process to assess the reliability of the reconstructed spectra.

7. **Output**:
   - Reconstructed spectra along with associated uncertainties.
   - Quantitative measure of spectral information content for each object.

**End Algorithm**
