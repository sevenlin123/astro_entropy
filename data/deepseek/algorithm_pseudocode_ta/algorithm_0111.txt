The core computational algorithm for the probabilistic spectral reconstruction framework is outlined below:

1. **Preprocessing**:
   - Normalize and align all near-infrared spectral datasets.
   - Fill gaps or remove outliers in individual spectra.

2. **Dimensionality Reduction**:
   - Perform Principal Component Analysis (PCA) on the preprocessed spectral data.
   - Retain the top K principal components, where K is chosen to capture the necessary variability (e.g., 4-5 for classification, up to 8-10 for high-fidelity reconstruction).

3. **Probabilistic Model Setup**:
   - Represent each TNO's spectrum in the latent principal component space.
   - Model the observed photometric magnitudes as a linear combination of the principal components.
   - Incorporate measurement uncertainties in the photometric data.

4. **Bayesian Inference**:
   - Use MCMC methods (e.g., Metropolis-Hastings or Hamiltonian Monte Carlo) to sample the posterior distributions of the latent variables.
   - The likelihood function considers the photometric measurements and their uncertainties, modeled as Gaussian.

5. **Spectral Reconstruction**:
   - Project the posterior samples of the latent variables back into the original spectral space using the PCA loadings.
   - Combine these projections to obtain the reconstructed spectra.

6. **Uncertainty Propagation**:
   - Calculate the uncertainties on the reconstructed spectra by quantifying the variance in the posterior samples of the latent variables.

7. **Output**:
   - Obtain the reconstructed spectra along with their uncertainties for each TNO.

```pseudocode
Algorithm: Probabilistic Spectral Reconstruction

Input:
- Spectral dataset: N samples × M wavelengths
- Observed photometric magnitudes: N samples × P bands
- Measurement uncertainties: N samples × P bands

Output:
- Reconstructed spectra: N samples × M wavelengths
- Uncertainties on reconstructed spectra: N samples × M wavelengths

Steps:

1. Preprocessing:
   - Normalize and align all spectra to a common wavelength grid.
   - Handle missing data points or outliers by interpolation or removal.

2. Dimensionality Reduction:
   - Compute PCA on the aligned spectral dataset.
   - Select top K principal components based on explained variance.

3. Probabilistic Model:
   - For each TNO, represent its spectrum as a linear combination of the top K principal components.
   - Define the photometric measurements as Y = Xβ + ε, where β are the latent variables, and ε ~ N(0, σ²).

4. Bayesian Inference:
   - Set up the likelihood function: p(Y | β) = Normal(Y | Xβ, σ²).
   - Define the prior distributions for the latent variables β.
   - Use MCMC to sample the posterior distribution p(β | Y).

5. Spectral Reconstruction:
   - For each MCMC sample of β, project onto the original spectral space using PCA.
   - Reconstruct the spectrum as Y_recon = Xβ.

6. Uncertainty Propagation:
   - Compute the variance of the MCMC samples of β.
   - Propagate this variance through the PCA projection to obtain uncertainties on Y_recon.

7. Output Results:
   - For each TNO, output the mean reconstructed spectrum and associated uncertainties.

End
```
