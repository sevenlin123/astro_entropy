**Algorithm: Probabilistic Spectral Reconstruction Framework**

**Step 1: Principal Component Decomposition (PCA)**
- **Input**: Training spectra (X)
- **Compute**: PCA basis vectors (U) and scores (P)
- **Output**: PCA basis (U), scores (P)

**Step 2: Photometric Flux Projection**
- **Input**: Observed flux measurements (F_obs), reference spectra (X), PCA basis (U)
- **Compute**: Uncertainty-covarianced scores (P)
- **Output**: Scores with uncertainties (P)

**Step 3: Bayesian Inference for PCA Scores**
- **Input**: Observed fluxes (F_obs), reference PCA (U, P), photometric uncertainties (σ_F)
- **Compute**: Posterior mean scores (P_post), covariance matrix (Σ_P)
- **Output**: Posterior scores (P_post), posterior covariance (Σ_P)

**Step 4: Spectrum Reconstruction**
- **Input**: Posterior mean scores (P_post), PCA basis (U)
- **Compute**: Reconstructed spectrum (X_recon), uncertainty (σ_X)
- **Output**: Reconstructed spectrum (X_recon), uncertainty (σ_X)

**Step 5: Spectral Class Probability Calculation**
- **Input**: Posterior distributions (P_post, Σ_P), spectral class definitions
- **Compute**: Class probabilities (C_p)
- **Output**: Class probabilities (C_p)

**Step 6: Outlier Detection via Posterior Predictive Distribution**
- **Input**: Reconstructed spectra (X_recon, σ_X), reference spectral classes (C_ref)
- **Compute**: Outlier scores (O)
- **Output**: Outlier scores (O)

**Step 7: Optimal Survey Configuration Selection**
- **Input**: Reference spectral classes (C_ref), filter transmission curves (Filt)
- **Compute**: Information content evaluation for each filter setup
- **Output**: Filter configuration ranking (Rank_Filt)

**End Algorithm**
