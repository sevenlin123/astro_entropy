**Algorithm: Probabilistic Spectral Reconstruction**

1. **Train Principal Component Analyzer (PCA)**
   - Input: Set of known TNO near-IR spectra
   - Output: Trained PCA model with principal components

2. **Project Photometric Data into PCA Space**
   - For each TNO:
     - Input: Photometric measurements
     - Output: Projection onto PCA latent space

3. **Perform Bayesian Inference in PCA Space**
   - Define prior distribution over latent variables
   - Calculate likelihood based on photometric uncertainties
   - Update posterior distribution using Bayesian inference

4. **Reconstruct Full Spectra**
   - Using posterior mean of latent variables
   - Apply inverse PCA transformation to obtain reconstructed spectrum

5. **Propagate Measurement Uncertainties**
   - Compute uncertainties in reconstructed spectra using posterior variances

6. **Probabilistic Spectral Classification**
   - Calculate distances between latent representations
   - Classify into spectral types based on proximity

**End Algorithm**
