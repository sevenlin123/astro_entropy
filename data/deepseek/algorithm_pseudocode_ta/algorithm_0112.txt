**Algorithm for Probabilistic Spectral Reconstruction of Trans-Neptunian Objects from Sparse Photometry**

1. **Training of Dimensionality-Reduction Model (PCA):**
   - Input: Set of near-infrared (near-IR) spectra.
   - Output: Principal Component Analysis (PCA) model with a predefined number of principal components (PCs).

2. **Bayesian Inference in Reduced Latent Space:**
   - Input: Photometric measurements and PCA model.
   - Perform Bayesian inference using the PCA model to reconstruct full spectra.
   - Propagate measurement uncertainties through the reconstruction process.

3. **Determine Optimal Number of Principal Components via LOOCV:**
   - Input: PCA model and dataset.
   - Apply leave-one-out cross-validation (LOOCV) to evaluate the performance of different numbers of PCs.
   - Select the optimal number of PCs (approximately 4-5 for classification, 8-10 for high-fidelity reconstruction).

4. **Reconstruct Spectra and Calibrate Uncertainties:**
   - Using the optimal PCA model, reconstruct full spectra from photometric data.
   - Calculate credible intervals to assess the uncertainty calibration.

5. **Analyze Posterior Probabilities for Outlier Detection:**
   - Compute posterior probabilities of spectral models.
   - Identify rare spectral types by detecting low-probability intermediate models.

6. **Quantify Information Content of Photometric Bands:**
   - Evaluate the information content of each photometric band using the framework.
   - Determine optimally informative configurations for future observations.

**End Algorithm**
