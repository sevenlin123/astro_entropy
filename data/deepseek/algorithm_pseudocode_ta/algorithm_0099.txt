```plaintext
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Initialize PCA Model:
    a. Read reference spectra.
    b. Compute the mean spectrum (S_mean).
    c. Center the reference spectra by subtracting S_mean.
    d. Compute the covariance matrix of the centered spectra.
    e. Perform PCA on the covariance matrix to obtain eigenvectors (V).

2. For each target object:
    a. Read photometric data.
    b. Parameterize the spectrum as S = S_mean + V * a, where 'a' are the latent variables.
    c. Perform Bayesian inference to estimate 'a' given photometric data.
    d. Reconstruct the spectrum using the estimated coefficients: S_recon = S_mean + V * a.
    e. Compute uncertainties by transforming the posterior covariance of 'a' through V.

3. Output:
    a. Reconstructed spectra and uncertainties for each object.
```

This algorithm outlines the core steps for reconstructing spectra from sparse photometry using a probabilistic latent-space framework based on PCA and Bayesian inference.
