**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

**Step 1: Train Principal Component Analysis (PCA) Model**

1. Input: Collection of near-infrared (near-IR) spectra of trans-Neptunian objects (TNOs).
2. Compute the mean spectrum across all objects.
3. Subtract the mean spectrum from each input spectrum to center the data.
4. Perform eigenvalue decomposition on the centered data covariance matrix to obtain principal component (PC) eigenvectors and eigenvalues.
5. Select the top K principal components (K ≈ 4-5 for taxonomic classification; up to 8-10 for improved reconstruction).

**Step 2: Project Photometric Data into Latent Space**

1. Input: Sparse photometric measurements of a TNO.
2. Convert photometric data into flux values within the near-IR range.
3. Project the photometric fluxes onto the pre-trained PCA eigenvectors to obtain latent-space coordinates.

**Step 3: Bayesian Inference in Reduced Space**

1. Define prior distributions for the latent-space parameters based on the PCA model.
2. Define the likelihood function using the projected photometric data and the PCA model.
3. Use Bayesian inference (e.g., Markov Chain Monte Carlo or variational methods) to estimate the posterior distribution of the latent parameters, accounting for measurement uncertainties.
4. Obtain the posterior mean and variance-covariance matrix for the latent parameters.

**Step 4: Reconstruct Full Spectra**

1. Multiply the posterior mean latent parameters by the PCA eigenvectors to reconstruct the full spectrum.
2. Propagate the uncertainties from the posterior covariance matrix through the linear transformation to estimate the uncertainty in the reconstructed spectrum.

**Output:**
- Reconstructed full near-IR spectrum for the TNO.
- Associated uncertainty estimates across wavelengths.

```pseudocode
// Step 1: Train PCA Model
function trainPCA(spectra):
    meanSpectrum = mean(spectra)
    centeredData = spectra - meanSpectrum
    covarianceMatrix = centeredData' * centeredData / n
    [eigenvalues, eigenvectors] = eigenvalueDecomposition(covarianceMatrix)
    select top K eigenvectors and eigenvalues
    return PCAModel(eigenvectors, eigenvalues)

// Step 2: Project Photometry into Latent Space
function projectPhotometry(photometry, PCAModel):
    fluxValues = convertPhotometryToFlux(photometry)
    latentCoordinates = PCAModel.eigenvectors * fluxValues
    return latentCoordinates

// Step 3: Bayesian Inference
function bayesianInference(latentCoordinates, PCAModel):
    definePriorDistributions()
    defineLikelihood(latentCoordinates, PCAModel)
    performBayesianInference(posterior_sampler)
    posteriorMean = mean(posterior_sampler)
    posteriorCovariance = covariance(posterior_sampler)
    return (posteriorMean, posteriorCovariance)

// Step 4: Spectrum Reconstruction
function reconstructSpectrum(posteriorMean, posteriorCovariance, PCAModel):
    reconstructedSpectrum = PCAModel.eigenvectors * posteriorMean + meanSpectrum
    spectrumUncertainty = sqrt(PCAModel.eigenvectors * posteriorCovariance * PCAModel.eigenvectors')
    return (reconstructedSpectrum, spectrumUncertainty)
```
