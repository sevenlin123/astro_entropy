```
algorithm Probabilistic Spectral Reconstruction from Sparse Photometry
    input: Near-infrared spectra of trans-Neptunian objects
    output: Reconstructed spectra with credible intervals and optimized survey filters

    begin
        // Step 1: Data Preprocessing
        Load training dataset of near-IR spectra
        Extract photometric measurements from each spectrum
        Standardize and normalize the data
        
        // Step 2: Principal Component Analysis (PCA)
        Perform PCA on standardized spectra
        Identify dominant principal components (e.g., 4-5 for taxonomic classification)
        
        // Step 3: Build Probabilistic Model in Latent Space
        Initialize Bayesian model with latent variables representing PCA components
        Propagate measurement uncertainties from photometric data into latent space
        Perform Bayesian inference to estimate latent variables
        
        // Step 4: Reconstruct Original Spectra
        Map estimated latent variables back to spectral space
        Generate full reconstructed spectra
        Calculate credible intervals for each reconstructed spectrum
        
        // Step 5: Outlier Detection
        Compute posterior probabilities of spectral classifications
        Identify objects with low posterior probabilities
        Apply threshold to detect outliers and peculiar cases
        
        // Step 6: Optimize Future Surveys
        Evaluate information content of near-IR filters
        Select optimal filter combinations (e.g., F090W, F115W)
        Generate recommendations for JWST/NIRCam observations
    end
```
