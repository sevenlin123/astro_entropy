**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

**Step 1: Preprocessing**
   - **1a**: Gather reference spectra of trans-Neptunian objects.
   - **1b**: Apply Principal Component Analysis (PCA) to the reference spectra to derive principal components.
   - **1c**: Select the number of significant principal components based on cumulative explained variance (e.g., 95%).

**Step 2: Forward Modeling for Each Object**
   - **2a**: Acquire sparse photometric data (e.g., magnitudes in specific filters).
   - **2b**: Relate photometric fluxes to the spectrum using the instrument and filter response model.

**Step 3: Bayesian Inference**
   - **3a**: Define the likelihood function connecting photometric data to the spectrum.
   - **3b**: Use precomputed principal components as priors.
   - **3c**: Perform Markov Chain Monte Carlo (MCMC) sampling to determine posterior distributions of the principal components.

**Step 4: Spectrum Reconstruction**
   - **4a**: Map the posterior samples of the principal components back to the original spectral space.
   - **4b**: Calculate uncertainties using posterior covariance of the principal components and the transformation matrix.

**Step 5: Output**
   - **5a**: Output the reconstructed spectrum.
   - **5b**: Output uncertainty estimates for each wavelength.

This algorithm effectively reconstructs the spectrum from sparse photometric data using a Bayesian framework in the reduced PCA space.
