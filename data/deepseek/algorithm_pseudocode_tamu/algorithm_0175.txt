```pseudocode
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Photometric measurements (sparse) of a TNO
    - Pre-trained Principal Component Analysis (PCA) model
    - Synthetic photometric training data generated via forward modeling

Output:
    - Reconstructed high-resolution spectrum
    - Probabilistic constraints on spectral features
    - Taxonomic classification probabilities

1. **Dimensionality Reduction via PCA**:
    a. Project input photometry into the PCA latent space using pre-trained components.
    b. Obtain latent coefficients through regression.

2. **Forward Modeling**:
    a. Simulate photometric measurements from the latent coefficients using the NIRCam filter response curves.
    b. Inject Gaussian noise with 20% relative uncertainty.

3. **Synthetic Data Generation**:
    a. Use Kernel Density Estimation (KDE) to smooth the latent space manifold.
    b. Generate synthetic training data by sampling from the KDE.

4. **Regression Training**:
    a. Train an ensemble of gradient-boosted decision trees (AutoML) to map photometry to latent coefficients.
    b. Validate using leave-one-out cross-validation.

5. **Reconstruction**:
    a. Transform predicted latent coefficients back into full spectrum using inverse PCA.
    b. Sample posterior distributions using Gaussian Copula to preserve physical correlations.

6. **Uncertainty Quantification**:
    a. Calculate RMSE and PCC between reconstructed and true spectra.
    b. Assess credible interval coverage for uncertainty calibration.

7. **Taxonomic Classification**:
    a. Classify the latent coefficients using a pre-trained classifier.
    b. Output posterior probabilities for each taxonomic class.

8. **Outlier Detection**:
    a. Identify objects with posterior probabilities significantly below thresholds.
    b. Flag for spectroscopic follow-up if anomalies detected.

End Algorithm
```
