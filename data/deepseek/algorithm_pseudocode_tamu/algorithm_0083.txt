### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Principal Component Analysis (PCA) Initialization**:
   - Train PCA on a reference set of near-infrared spectra of TNOs.
   - Determine the optimal number of principal components (PCs) through validation (e.g., LOOCV).
   
2. **Latent Space Definition**:
   - Project the reference spectra onto the PCA basis to obtain latent coefficients.
   - Construct a prior probability distribution over the latent space using Kernel Density Estimation (KDE) with a Gaussian kernel.
   
3. **Synthetic Data Augmentation**:
   - Generate synthetic latent vectors from the prior distribution to augment the training data.
   - Forward-model these synthetic latent vectors to produce mock photometric observations using the instrument's filter responses (e.g., JWST/NIRCam).
   
4. **Training the Encoder (AutoMLRegressor)**:
   - Use the augmented training data (synthetic + real) to train an ensemble of gradient-boosted decision trees.
   - The model maps sparse photometric observations to latent space coordinates.
   
5. **Forward Inference**:
   - For new photometric observations:
     - Predict latent coefficients using the trained encoder.
     - Apply the inverse PCA transform to reconstruct the full spectrum.
   
6. **Uncertainty Quantification**:
   - Sample the joint posterior of latent coefficients using a Gaussian Copula framework.
   - Propagate uncertainties through the inverse PCA transform to generate confidence intervals for the reconstructed spectrum.
   
7. **Taxonomic Classification**:
   - Train a separate classifier on the latent space to predict taxonomic categories (e.g., H₂O, CO₂, Organic, Methanol).
   - Provide probabilistic taxonomic assignments for each object.
   
8. **Survey Optimization**:
   - Evaluate the information content of different filter configurations.
   - Identify the minimal set of filters that maximizes spectral reconstruction fidelity.
   
9. **Outlier Detection**:
   - Calculate the probability of each object belonging to the learned latent manifold.
   - Flag objects with significantly low probabilities as potential outliers.
