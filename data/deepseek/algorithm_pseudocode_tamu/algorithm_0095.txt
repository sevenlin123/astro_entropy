Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- Training Spectra: Set of reference TNO near-IR spectra (N = 51)
- Photometric Observations: Sparse multi-band photometry for target TNO
- Filter Throughputs: NIRCam filter response functions
- Photometric Uncertainty: 20% relative uncertainty

Output:
- Reconstructed Spectrum: High-resolution spectral estimate
- Credible Intervals: Uncertainty bounds on reconstructed spectrum
- Taxonomic Classification: Probabilistic assignment to spectral types

Steps:

1. **Principal Component Analysis (PCA):**
   a. Train PCA on the reference spectra to obtain eigencomponents.
   b. Project reference spectra onto PCA basis to get latent coefficients.

2. **Data Augmentation via Kernel Density Estimation (KDE):**
   a. Fit non-parametric KDE to latent coefficients of reference spectra.
   b. Generate synthetic latent vectors to augment training data.
   c. Ensure smooth manifold in latent space.

3. **Forward Modeling:**
   a. Simulate photometric observations for each augmented spectrum.
   b. Convolve spectra with NIRCam filter responses.
   c. Add Gaussian noise (20% relative) to simulate realistic photometry.

4. **Automated Machine Learning (AutoML) Training:**
   a. Train an ensemble regressor (e.g., XGBoost) to map photometry to latent coefficients.
   b. Use augmented synthetic data for training.

5. **Inverse PCA Transformation:**
   a. Apply trained regressor to target photometry to predict latent coefficients.
   b. Project latent coefficients back to full spectral space using inverse PCA.

6. **Uncertainty Quantification:**
   a. Sample from joint posterior distribution of latent coefficients using Gaussian Copula.
   b. Propagate uncertainties through inverse PCA to generate credible intervals.

7. **Taxonomic Classification:**
   a. Apply trained classifier to latent coefficients to obtain probability distribution over spectral types.

8. **Validation (LOOCV):**
   a. Remove one reference spectrum and retrain models.
   b. Assess reconstruction fidelity using RMSE and credible interval coverage.
   c. Repeat for all reference spectra.

End
