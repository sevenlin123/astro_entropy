Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input: Sparse photometric observations of a TNO
Output: Reconstructed spectrum with uncertainty quantification

1. Initialize Principal Component Analysis (PCA) basis:
   a. Train PCA on a reference dataset of 51 TNO spectra.
   b. Determine the number of principal components (K) based on reconstruction fidelity (e.g., 4-5 for classification, 8-10 for high fidelity).
   
2. Generate synthetic training data:
   a. Project real seed spectra onto the PCA basis to obtain latent coefficients.
   b. Perform Kernel Density Estimation (KDE) on the latent coefficients to create a continuous manifold.
   c. Augment the training set with synthetic spectra by sampling from the KDE model.
   
3. Train the AutoML regressor:
   a. Use the synthetic training data to train an ensemble of gradient-boosted decision trees.
   b. The regressor maps sparse photometry to latent coefficients.
   
4. Forward modeling:
   a. Simulate photometric observations for each synthetic spectrum by convolving with the instrument response functions (e.g., JWST/NIRCam filters).
   b. Inject Gaussian noise (20% relative reflectance uncertainty) into the synthetic photometry.
   
5. Bayesian inference:
   a. For new photometric observations, predict latent coefficients using the trained regressor.
   b. Apply inverse PCA transform to reconstruct the full spectrum.
   c. Quantify uncertainties by sampling from the joint posterior of latent coefficients using Gaussian Copula framework.
   
6. Output:
   a. Return the reconstructed spectrum.
   b. Provide uncertainty intervals and classification probabilities for taxonomic types.
