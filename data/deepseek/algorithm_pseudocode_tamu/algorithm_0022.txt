```pseudocode
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Input Preparation**:
   - Obtain sparse photometric observations for a set of trans-Neptunian objects (TNOs).
   - Define the target spectral bands and photometric filters.

2. **Principal Component Analysis (PCA)**:
   - Train PCA on a reference set of near-infrared spectra of TNOs to obtain principal components (PCs) and corresponding eigenvectors.
   - Project reference spectra onto the PCA space to derive latent coefficients (principal component scores).

3. **Data Augmentation with Kernel Density Estimation (KDE)**:
   - Use KDE on the latent coefficients to create a smooth probability distribution, generating synthetic latent vectors.
   - Ensure the latent manifold captures the continuous spectral variations of TNOs.

4. **Forward Modeling and Synthetic Photometry**:
   - Simulate photometric observations for each synthetic spectrum by convolving with instrumental response (e.g., JWST/NIRCam filters).
   - Inject Gaussian noise (relative uncertainty ~20%) into synthetic photometry to mimic real-world observational uncertainties.

5. **Training the AutoML Regressor**:
   - Use the synthetic photometry and corresponding latent coefficients to train an ensemble of gradient-boosted decision trees.
   - The regressor learns the mapping from photometric inputs to latent space coefficients.

6. **Leave-One-Out Cross-Validation (LOOCV)**:
   - For each held-out object, remove its spectrum from the training set.
   - Generate synthetic latent vectors using the remaining data and evaluate reconstruction accuracy and uncertainty calibration.

7. **Spectral Reconstruction**:
   - For new photometric observations, use the trained regressor to predict latent coefficients.
   - Apply inverse PCA transformation to reconstruct the full spectrum.
   - Sample the joint posterior distribution of latent coefficients using a Gaussian Copula to generate ensembles and quantify uncertainties.

8. **Taxonomic Classification**:
   - Project the predicted latent coefficients into a pre-trained classifier.
   - Determine the probability distribution over spectral types (e.g., H₂O, CO₂, Organics, Methanol).

9. **Output**:
   - Provide reconstructed spectrum, associated uncertainties, and taxonomic classification probabilities.

End Algorithm
```
