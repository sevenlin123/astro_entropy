### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Input**:
   - Observed sparse photometric measurements $\mathbf{m}$.
   - Training set of reference TNO spectra $S_{\text{train}}$.

2. **Preprocessing**:
   - **Principal Component Analysis (PCA)**:
     - Train PCA on $S_{\text{train}}$ to obtain eigenvectors $\mathbf{v}_k$ and eigenvalues $\lambda_k$.
     - Project $S_{\text{train}}$ onto the PCA basis to get latent coefficients $\mathbf{z}_{\text{train}}$.
   - **Kernel Density Estimation (KDE)**:
     - Compute the probability density function (PDF) of $\mathbf{z}_{\text{train}}$ using KDE with Gaussian kernels.
     - Determine optimal bandwidth $h$ through cross-validation.

3. **Forward Modeling**:
   - Simulate synthetic photometry for each augmented spectrum by convolving with instrument filter curves (e.g., JWST/NIRCam).
   - Inject Gaussian noise with relative uncertainty (e.g., 20%) into the synthetic photometry.

4. **Training**:
   - **Data Augmentation**:
     - Sample synthetic latent vectors $\mathbf{z}_{\text{syn}}$ from the KDE-defined prior.
     - Forward model $\mathbf{z}_{\text{syn}}$ to generate synthetic photometry $\mathbf{m}_{\text{syn}}$.
   - **Regressor Training**:
     - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map $\mathbf{m}_{\text{obs}}$ to $\mathbf{z}$.
   - **Classifier Training**:
     - Train a secondary AutoML classifier to predict taxonomic labels from $\mathbf{z}$.

5. **Inference**:
   - **Predict Latent Coefficients**:
     - Use the trained regressor to predict $\hat{\mathbf{z}}$ given $\mathbf{m}$.
   - **Reconstruct Spectrum**:
     - Apply inverse PCA transform: $\hat{S} = \sum_{k=1}^{K} \hat{z}_k \mathbf{v}_k$.
   - **Sample Posterior**:
     - Draw multiple samples from the posterior distribution of $\hat{\mathbf{z}}$ using Gaussian Copula.
     - For each sample, compute $\hat{S}_i$ and aggregate to form credible intervals.

6. **Output**:
   - Reconstructed spectrum $\hat{S}$ with uncertainty intervals.
   - Probabilistic taxonomic classification.

7. **Validation**:
   - Perform leave-one-out cross-validation (LOOCV) to assess reconstruction accuracy and credible interval coverage.

This algorithm provides a statistically rigorous framework for reconstructing high-resolution spectra from sparse photometric data, enabling detailed analysis of TNO surface compositions.
