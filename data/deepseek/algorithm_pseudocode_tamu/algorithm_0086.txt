### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

```plaintext
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry
Input: Sparse photometric measurements m of a Trans-Neptunian Object
Output: Reconstructed spectrum S with uncertainty quantification

1. **Precompute Principal Components (PCs):**
   - Train PCA on a reference sample of TNO spectra (N = 51).
   - Determine the number of principal components K (e.g., K = 8–10) based on reconstruction fidelity and cross-validation.

2. **Forward Modeling:**
   - Simulate photometric fluxes for each PCA-compressed spectrum by convolving with NIRCam filter transmission curves.

3. **Training AutoML Regressor (Encoder):**
   - Use the simulated photometric data and corresponding PCA coefficients to train an ensemble regressor (e.g., XGBoost).
   - The regressor maps sparse photometry m to latent PCA coefficients z.

4. **KDE Augmentation:**
   - Construct a continuous latent manifold using Kernel Density Estimation (KDE) on the PCA coefficients.
   - Bandwidth h is empirically determined (e.g., h ≈ 0.5) to balance manifold smoothness and fidelity.

5. **Reconstruction Pipeline:**
   a. **Latent Space Inference:**
      - Pass observed photometry m through the trained regressor to obtain posterior distribution over latent coefficients z.
   b. **Inverse PCA Transform:**
      - Project the predicted z through the inverse PCA transformation to reconstruct the full spectrum S.
   c. **Uncertainty Quantification:**
      - Sample the joint posterior of z using a Gaussian Copula to generate an ensemble of possible spectra.
      - Compute credible intervals (e.g., 95%) for the reconstructed spectrum.

6. **Taxonomic Classification (Optional):**
   a. **Latent Space Projection:**
      - Project the predicted z into a taxonomic classifier trained on the labeled PCA coefficients.
   b. **Output Probabilities:**
      - Return probabilities for each taxonomic class (e.g., H₂O, CO₂, Organic, Methanol).

7. **Validation Metrics:**
   a. **Root Mean Square Error (RMSE):** Compare reconstructed S with reference spectrum.
   b. **Correlation Coefficient (CC):** Measure similarity between S and reference.
   c. **Credibility Interval Coverage:** Verify 95% intervals contain true spectrum.

8. **Filter Optimization (Optional):**
   a. **Mutual Information Calculation:** Assess information content of each NIRCam filter.
   b. **Optimal Filter Selection:** Identify filter combinations maximizing mutual information with latent space.

9. **Outlier Detection (Optional):**
   a. **High Entropy Detection:** Identify objects with posterior distributions indicating unusual spectral types.
   b. **Manifold Deviation:** Flag objects with low posterior density in the learned manifold.

End of Algorithm
```
