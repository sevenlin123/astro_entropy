Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Observed photometric fluxes m
    - Training set of reference spectra S_train
    - PCA basis derived from S_train
    - NIRCam filter transmission curves

Output:
    - Reconstructed spectrum S_recon
    - Taxonomic classification probabilities
    - Uncertainty estimates

Steps:

1. Initialize PCA:
    a. Compute PCA on S_train to obtain principal components (PCs).
    b. Determine optimal number of PCs (K) via LOOCV.

2. Construct Latent Space:
    a. Project S_train onto PCs to get latent coefficients z_train.
    b. Apply Kernel Density Estimation (KDE) on z_train to define prior distribution.

3. Generate Synthetic Training Data:
    a. Sample synthetic latent vectors from KDE.
    b. Forward model synthetic spectra through NIRCam filters to simulate photometry.

4. Train AutoML Regressor:
    a. Use paired synthetic photometry and latent coefficients to train model.
    b. Inject Gaussian noise (20% relative uncertainty) into synthetic photometry.
    c. Optimize hyperparameters using AutoML framework.

5. Forward Inference:
    a. For new photometry m:
        i. Predict latent coefficients z_hat = AutoMLRegressor(m)
        ii. Decode z_hat through inverse PCA to reconstruct spectrum S_recon.
        iii. Calculate confidence intervals using Gaussian Copula sampling.

6. Taxonomic Classification:
    a. Classify z_hat into taxonomic groups using pre-trained classifier.
    b. Output probability distribution over spectral types.

7. Outlier Detection (optional):
    a. Compute distance of z_hat from KDE density.
    b. Flag as outlier if density falls below threshold.

8. Performance Metrics (during LOOCV):
    a. Compute Mean Absolute Error (MAE), Correlation Coefficient (r), and Credible Interval Coverage for each test spectrum.

End Algorithm
