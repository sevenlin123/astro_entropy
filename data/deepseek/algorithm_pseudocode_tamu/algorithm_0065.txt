Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- Photometric observations (m)
- Training spectral dataset (S_train)
- Principal Component Analysis (PCA) model parameters

Output:
- Reconstructed spectrum (S_recon)
- Posterior distribution of spectral coefficients

Steps:

1. **Precompute PCA Basis**:
   - Train PCA on S_train to obtain principal components (PCs) and loadings.
   - Determine optimal number of PCs (K) via cross-validation.

2. **Data Augmentation**:
   - Generate synthetic spectral coefficients using Kernel Density Estimation (KDE) on PCA-compressed training data.
   - Forward model synthetic spectra through the instrument's filter response functions to simulate photometric observations.

3. **Training Phase**:
   - Use AutoML regressor (e.g., Gradient Boosted Decision Trees) to learn mapping from photometric observations to PCA coefficients.
   - Augment training data with synthetic photometry and corresponding PCA coefficients.

4. **Inference Phase**:
   - Encode observed photometric data (m) through trained AutoML regressor to obtain predicted PCA coefficients (β).
   - Apply inverse PCA transformation to β to reconstruct full spectrum S_recon = β * PCs + mean_spectrum.

5. **Uncertainty Quantification**:
   - Sample posterior distribution of β using Gaussian Copula framework, accounting for latent space correlations.
   - Propagate uncertainties through inverse PCA to obtain credible intervals for S_recon.

6. **Classification (Optional)**:
   - Classify spectrum into taxonomic groups by projecting β into trained classifier.
   - Output probability distribution over spectral types.

End.
