### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

**Input**:  
- `obs_photometry`: Observed sparse photometric measurements (e.g., magnitudes or fluxes) for a TNO.  
- `training_spectra`: Reference near-IR spectra from a curated training set (e.g., DiSCo-TNO sample).  
- `n_components`: Number of principal components (K) selected for the latent space (e.g., 8–10 for high fidelity).  

**Output**:  
- `reconstructed_spectrum`: High-resolution spectral reconstruction in the near-IR.  
- `credible_intervals`: Calibrated uncertainty estimates for the reconstructed spectrum.  
- `taxonomy_probabilities`: Probabilities of belonging to predefined spectral taxonomic classes (e.g., H₂O, CO₂, Organics).  

---

#### **Step 1: Training Phase**

1. **Principal Component Analysis (PCA)**:  
   - Perform PCA on `training_spectra` to reduce the spectral dimensionality.  
   - Extract the first `n_components` principal components (latent space basis).  

2. **Kernel Density Estimation (KDE)**:  
   - Project the training spectra onto the PCA latent space.  
   - Fit a Gaussian KDE to the latent coordinates to model the prior probability distribution.  

3. **Synthetic Data Generation**:  
   - Sample synthetic latent vectors from the KDE to augment the training set.  
   - Forward-model these synthetic spectra through the NIRCam filter set to generate mock photometry.  
   - Inject Gaussian noise (e.g., 20% relative uncertainty) into the synthetic photometry to simulate real-world observational noise.  

4. **Training the AutoML Regressor**:  
   - Use the AutoML framework (e.g., AutoGluon) to train a regressor (e.g., ensemble of gradient-boosted trees).  
   - Input features: Mock photometry.  
   - Target: Corresponding synthetic latent coefficients.  

5. **Training the Taxonomy Classifier**:  
   - Train a secondary AutoML classifier on the PCA latent space.  
   - Input features: Latent coefficients.  
   - Targets: Taxonomic labels (e.g., H₂O, CO₂, Organics).  

---

#### **Step 2: Inference Phase**

1. **Predict Latent Coefficients**:  
   - Pass the observed `obs_photometry` through the trained AutoML regressor.  
   - Obtain predicted latent coefficients (posterior distribution).  

2. **Sampling the Posterior**:  
   - Use a Gaussian Copula to sample the joint posterior distribution of the latent coefficients.  
   - Ensure the sampling respects the physical dependencies in the latent space.  

3. **Reconstruct Spectra**:  
   - Apply the inverse PCA transform to the sampled latent coefficients to obtain full-resolution spectra.  

4. **Calculate Credible Intervals**:  
   - Compute empirical credible intervals (e.g., 95%) across the wavelength domain using the ensemble of reconstructed spectra.  

5. **Classify Taxonomy**:  
   - Project the predicted latent coefficients into the taxonomy classifier.  
   - Obtain probabilities for each taxonomic class.  

6. **Output Results**:  
   - Return the reconstructed spectrum, credible intervals, and taxonomic probabilities.
