Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Preprocessing**
   - **Input:** Set of reference TNO spectra
   - **Output:** Latent manifold defined by PCA components
   - **Steps:**
     a. Perform Principal Component Analysis (PCA) on the reference spectra to extract principal components.
     b. Determine the optimal number of PCA components (K) using LOOCV and nRMSE metric.
   
2. **Training the Latent Space Model**
   - **Input:** PCA components, reference spectra
   - **Output:** Augmented latent manifold for model regularization
   - **Steps:**
     a. Project reference spectra onto the PCA components to obtain latent coefficients.
     b. Apply Kernel Density Estimation (KDE) with Gaussian kernel to smooth the latent space, creating a continuous probability distribution.
     c. Augment the training set by sampling synthetic latent vectors from the KDE-defined manifold.
   
3. **Forward Modeling**
   - **Input:** Synthetic latent vectors
   - **Output:** Simulated photometry with noise
   - **Steps:**
     a. Forward simulate the synthetic spectra through the target instrument's filter transmission curves (e.g., JWST/NIRCam).
     b. Inject Gaussian noise (20% relative reflectance uncertainty) into the simulated photometry to mimic real-world observations.
   
4. **Training the AutoML Regressor**
   - **Input:** Noisy synthetic photometry and latent coefficients
   - **Output:** Trained regressor mapping photometry to latent space
   - **Steps:**
     a. Use AutoML (e.g., XGBoost) to train a regressor on the synthetic photometry, predicting latent coefficients.
     b. Optimize hyperparameters and validate using separate training and validation sets.
   
5. **LOOCV Validation**
   - **Input:** Real photometric observations
   - **Output:** Reconstructed spectra and classification probabilities
   - **Steps:**
     a. For each object:
        i. Remove the object from the training set.
        ii. Rebuild the latent manifold and synthetic photometry without the object.
        iii. Retrain the AutoML regressor and classifier.
        iv. Predict latent coefficients using the object's real photometry.
        v. Apply inverse PCA transform to reconstruct the full spectrum.
        vi. Evaluate reconstruction accuracy using nRMSE and credible interval coverage.
     b. Assess taxonomic classification accuracy using the latent-space classifier.
   
6. **Survey Optimization and Outlier Detection**
   - **Input:** Filter configurations and photometric data
   - **Output:** Optimized filter sets and identified outliers
   - **Steps:**
     a. Analyze feature importance from the AutoML regressor to identify informative photometric bands.
     b. Determine optimal filter combinations that maximize spectral reconstruction fidelity.
     c. Flag objects with photometric constraints inconsistent with known spectral classes as outliers.
