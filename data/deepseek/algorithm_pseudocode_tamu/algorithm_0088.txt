### Algorithm: Probabilistic Spectral Reconstruction Framework

#### Input:
- **Photometric Observations**: Sparse multi-band photometric measurements (e.g., F090W, F115W, F410M, F460M) of a trans-Neptunian object.
- **Training Spectra**: Reference near-infrared spectra of TNOs (DiSCo-TNO sample).
- **Filter Set**: Specifications of the photometric filters used for observation.

#### Output:
- **Reconstructed Spectrum**: High-resolution near-infrared spectrum estimated from photometric data.
- **Taxonomic Classification**: Probabilistic assignment to spectral types (e.g., H₂O, CO₂, Organic, Methanol).
- **Uncertainty Quantification**: Credible intervals for the reconstructed spectrum.

#### Steps:

1. **Preprocessing**:
   - Normalize photometric observations and convert to reflectance units.
   - Extract principal components (PCs) from the training spectra using PCA.
     - Compute eigenvectors and eigenvalues.
     - Select top K PCs (e.g., K=10) based on explained variance and cross-validation.

2. **Latent Manifold Construction**:
   - Project training spectra onto the selected PCs to obtain latent coefficients.
   - Perform kernel density estimation (KDE) on latent coefficients to create a smooth probability distribution.
   - Augment training data by sampling synthetic latent vectors from the KDE.

3. **Forward Modeling**:
   - Simulate photometric observations for each synthetic spectrum by convolving with filter transmission curves.
   - Add Gaussian noise (relative uncertainty ~20%) to simulate realistic photometric uncertainties.

4. **Model Training**:
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to latent coefficients.
   - Use synthetic and augmented data for training to avoid overfitting.
   - Validate using leave-one-out cross-validation.

5. **Spectral Reconstruction**:
   - For new photometric observations, predict latent coefficients using the trained regressor.
   - Apply inverse PCA transform to reconstruct the full spectrum.
   - Sample from the posterior distribution of latent coefficients using a Gaussian Copula to quantify uncertainties.

6. **Classification**:
   - Project latent coefficients onto a taxonomic classifier trained on the labeled training spectra.
   - Assign probabilities to spectral types based on the predicted latent space.

7. **Output Generation**:
   - Combine reconstructed spectrum, classification probabilities, and credible intervals for interpretation.

#### Pseudocode:

```python
def spectral_reconstruction(photometry, training_spectra, filters):
    # Step 1: Preprocessing
    normalize_photometry(photometry)
    
    # Step 2: Latent Manifold Construction
    pcs = compute_pca(training_spectra)
    latent_coefficients = project_to_pca(training_spectra, pcs)
    kde = fit_kde(latent_coefficients)
    
    # Step 3: Forward Modeling
    synthetic_photometry = forward_model(synthetic_spectra, filters)
    add_noise(synthetic_photometry, noise_level=0.2)
    
    # Step 4: Model Training
    regressor = train_automlRegressor(synthetic_photometry, latent_coefficients)
    validate_model(regressor, training_data)
    
    # Step 5: Spectral Reconstruction
    predicted_latents = regressor.predict(photometry)
    reconstructed_spectrum = inverse_pca(predicted_latents, pcs)
    sample_posterior(reconstructed_spectrum, kde)
    
    # Step 6: Classification
    taxonomic_probabilities = classify_latent(predicted_latents, training_labels)
    
    # Step 7: Output Generation
    output_results(reconstructed_spectrum, taxonomic_probabilities,credible_intervals)
```
