Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Photometric measurements (m)
    - Training set of reference spectra (S_train)
    - Principal Component Analysis (PCA) basis (U, S, V)
    - Synthetic photometry generated from forward modeling
    - Gaussian Copula for posterior sampling

Output:
    - Reconstructed spectrum (S_hat)
    - Confidence intervals for spectral features
    - Taxonomic classification probabilities

Steps:

1. Initialize PCA Model:
    a. Perform PCA on S_train to obtain principal components (PCs).
    b. Determine the number of PCs (K) that capture dominant spectral variability (4-5 PCs for classification, 8-10 for high fidelity).

2. Prepare Training Data:
    a. Project S_train onto PCA basis to get latent coefficients (z_train).
    b. Generate synthetic spectra using Kernel Density Estimation (KDE) on z_train to create a continuous latent manifold.
    c. Forward model synthetic spectra through NIRCam filters to produce synthetic photometry with added 20% Gaussian noise.

3. Train AutoML Regressor:
    a. Use AutoGluon to train an ensemble model (e.g., XGBoost) mapping noisy photometry to latent coefficients.
    b. Augment training data with synthetic photometry and corresponding latent coefficients.

4. Latent Space Inference:
    a. For new photometric observations (m_test):
        i. Predict latent coefficients (z_hat) using the trained AutoML regressor.
        ii. Sample from the joint posterior distribution of z_hat using Gaussian Copula to account for dependencies.

5. Spectral Reconstruction:
    a. Apply inverse PCA transform to z_hat to reconstruct the full spectrum S_hat.
    b. Calculate confidence intervals by aggregating multiple S_hat samples.

6. Taxonomic Classification:
    a. Project z_hat into the taxonomic classifier trained on labeled PCA coefficients.
    b. Output probabilities for each taxonomic class (e.g., H2O, CO2, Organic, Methanol).

7. Validate and Optimize:
    a. Perform LOOCV to assess reconstruction fidelity (RMSE) and uncertainty coverage (~95% empirical coverage).
    b. Evaluate classification accuracy (precision, recall, F1-score) on held-out data.
    c. Use mutual information to identify optimal photometric filter configurations.

End.
