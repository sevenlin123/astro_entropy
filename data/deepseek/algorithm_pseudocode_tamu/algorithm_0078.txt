### Algorithm: Probabilistic Spectral Reconstruction Framework

#### Input:
- `photometry`: Sparse photometric measurements of a trans-Neptunian object.
- `reference_spectra`: Training set of near-infrared spectra.
- `filter_curves`: Filter transmission curves for the photometric bands.

#### Output:
- `reconstructed_spectrum`: Full spectral energy distribution.
- `credible_intervals`: Uncertainty bounds at 1σ and 2σ levels.
- `taxonomy_prediction`: Probabilistic taxonomic classification.

#### Steps:

1. **Principal Component Analysis (PCA):**
   - Compute PCA on `reference_spectra` to obtain principal components (PCs).
   - Select the number of PCs (K) based on validation (4–5 for classification, 8–10 for fidelity).

2. **Density Estimation:**
   - Project `reference_spectra` onto the PCA latent space.
   - Use Kernel Density Estimation (KDE) to estimate the probability density of latent coefficients.

3. **Synthetic Data Augmentation:**
   - Generate synthetic latent vectors using the estimated KDE.
   - Forward model these synthetic spectra through the photometric filter curves to produce synthetic photometry.

4. **Model Training:**
   - Train an automated machine learning regressor (e.g., AutoGluon) to map sparse photometry to latent coefficients.
   - Inject Gaussian noise (20% relative reflectance) into synthetic photometry for robust training.

5. **Inference Pipeline:**
   - **Encoding:** Pass `photometry` through the trained regressor to predict latent coefficients.
   - **Decoding:** Apply inverse PCA transform to reconstruct the full spectrum.
   - **Uncertainty Sampling:** Use Gaussian Copula to sample the posterior of latent coefficients, generating credible intervals.

6. **Taxonomy Classification:**
   - Train a classifier on the PCA latent space to predict taxonomic categories.
   - Predict taxonomy probabilities from encoded photometry.

7. **Output Generation:**
   - Combine reconstructed spectrum, credible intervals, and taxonomy prediction.

#### Pseudocode:

```pseudocode
function probabilistic_spectral_reconstruction(photometry, reference_spectra, filter_curves):
    1. Perform PCA on reference_spectra to obtain principal components (PCs).
    2. Determine optimal number of PCs (K) through validation.
    3. Project reference_spectra onto latent PCA space.
    4. Estimate latent density using KDE.
    5. Generate synthetic latent vectors and forward model to synthetic_photometry.
    6. Train regressor on (synthetic_photometry, latent_coefficients) with added noise.
    7. Predict latent_coefficients_hat from photometry using trained regressor.
    8. Decode latent_coefficients_hat into reconstructed_spectrum via inverse PCA.
    9. Sample posterior using Gaussian Copula to get credible_intervals.
    10. Classify taxonomy using latent manifold classifier.
    11. Return reconstructed_spectrum, credible_intervals, taxonomy_prediction.
```

This algorithm outlines the core computational steps for reconstructing spectra from sparse photometry using a probabilistic latent-space framework.
