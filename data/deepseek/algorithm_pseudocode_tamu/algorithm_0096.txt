### Pseudocode Algorithm for Probabilistic Spectral Reconstruction from Sparse Photometry

```python
Algorithm ProbabilisticSpectralReconstruction

Inputs:
    - Training Spectra: Set of reference TNO spectra (S)
    - Photometric Observations: Sparse multi-band photometry measurements (m)
    - Number of Principal Components (K)

Outputs:
    - Reconstructed Spectra: Full-resolution spectral estimates (S_reconstructed)
    - Uncertainty Quantification: Credible intervals for the reconstructed spectra
    - Taxonomic Classification: Probabilistic assignment of spectral types

Steps:

1. **Preprocessing**:
    1. Normalize and mask bad/saturated data in training spectra.
    2. Extract spectral features and prepare data for PCA.

2. **Dimensionality Reduction (PCA)**:
    1. Perform PCA on training spectra to obtain principal component coefficients (PC).
    2. Determine the optimal number of principal components (K) based on explained variance or cross-validation.

3. **Prior Augmentation (Kernel Density Estimation)**:
    1. Project training spectra onto the PCA latent space.
    2. Apply Kernel Density Estimation (KDE) with a Gaussian kernel to construct a smooth prior distribution over the latent space.
    3. Validate the bandwidth (h) to ensure proper smoothing without overfitting.

4. **Synthetic Data Generation**:
    1. Forward model the augmented latent spectra through the NIRCam filter set to generate synthetic photometry.
    2. Inject Gaussian noise (e.g., 20%) into synthetic photometry to simulate real observational uncertainties.

5. **Training the AutoML Regressor**:
    1. Use the synthetic photometry and corresponding latent coefficients as training data.
    2. Train an ensemble of Gradient Boosted Decision Trees (e.g., XGBoost) to map photometric inputs to latent coefficients.
    3. Optimize hyperparameters automatically using the AutoGluon framework.

6. **Leave-One-Out Cross-Validation (LOOCV)**:
    1. For each held-out spectrum:
        a. Remove the spectrum from the training set.
        b. Reconstruct its latent coefficients using the trained regressor.
        c. Project back to full spectral space using inverse PCA.
        d. Compute reconstruction error and uncertainty coverage.
    2. Aggregate performance metrics across all LOOCV iterations.

7. **Uncertainty Calibration**:
    1. Sample the joint posterior of latent coefficients using Gaussian Copula.
    2. Ensure credible intervals (e.g., 95%) contain the true spectrum.

8. **Taxonomic Classification**:
    1. Train a secondary classifier on the latent coefficients to predict taxonomic classes (e.g., H₂O, CO₂, Organic, Methanol).
    2. Assign probabilistic labels to new observations based on latent space predictions.

9. **Reconstruction Pipeline**:
    1. For new photometric observations:
        a. Predict latent coefficients using the trained regressor.
        b. Project to full spectral space via inverse PCA.
        c. Generate uncertainty estimates using posterior sampling.
        d. Classify taxonomic type using the latent classifier.

10. **Applications**:
    1. **Survey Optimization**:
        a. Evaluate different NIRCam filter combinations for information content.
        b. Identify optimal filter sets based on reconstruction fidelity.
    2. **Outlier Detection**:
        a. Analyze posterior probabilities in the latent space.
        b. Flag objects with low probability assignments for follow-up.

End of Algorithm
```

This algorithm outlines the core computational steps for the probabilistic spectral reconstruction framework, focusing on the Bayesian inference, dimensionality reduction, and machine learning components described in the paper.
