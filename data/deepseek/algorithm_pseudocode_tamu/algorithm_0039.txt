```pseudocode
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Initialize Parameters**
   - Input: Set of reference TNO spectra, sparse photometric measurements
   - Output: Reconstructed high-resolution spectrum, taxonomic classification
   - Hyperparameters: Number of principal components (K), bandwidth (h)

2. **Training Phase**
   a. **Principal Component Analysis (PCA)**
      - Decompose reference spectra into principal components.
      - Determine K dominant components capturing spectral variability.

   b. **Density Estimation**
      - Apply Kernel Density Estimation (KDE) with Gaussian kernel and bandwidth h.
      - Construct latent manifold representing probable spectral variations.

   c. **Synthetic Data Generation**
      - Generate synthetic spectra by sampling latent manifold.
      - Convert synthetic spectra to photometric measurements using forward modeling.
      - Add noise (relative uncertainty of 20%) to synthetic photometry.

   d. **Model Training**
      - Train AutoML regressor (ensemble of gradient-boosted trees) to map photometry to latent coefficients.

3. **Forward Inference**
   a. **Photometry to Latent Space**
      - Use trained regressor to predict latent coefficients from input photometry.

   b. **Reconstruct Spectrum**
      - Apply inverse PCA transformation to latent coefficients to obtain full spectrum.

   c. **Uncertainty Quantification**
      - Sample Gaussian Copula to generate ensemble of spectral realizations.
      - Compute credible intervals for reconstructed features.

   d. **Taxonomic Classification**
      - Project latent coefficients into pre-trained classifier.
      - Determine probability distribution over spectral types.

4. **Performance Evaluation (LOOCV)**
   a. **Iterate Over Test Cases**
      - For each test case, remove from training set, retrain models.
      - Generate synthetic photometry for test case and evaluate reconstruction.

   b. **Compute Metrics**
      - Calculate Root Mean Squared Error (RMSE) between predicted and true spectra.
      - Assess empirical credible interval coverage.

5. **Application**
   a. **Survey Optimization**
      - Analyze filter configurations using Fisher Information Matrix.
      - Identify optimal JWST/NIRCam filters for TNO observations.

   b. **Outlier Detection**
      - Identify objects with low probability in typical spectral clusters.
      - Reconstruct rare spectral types (e.g., peculiar Neptune Trojans).

6. **Output**
   - Provide reconstructed spectrum, taxonomic probabilities, and uncertainty estimates.
```
