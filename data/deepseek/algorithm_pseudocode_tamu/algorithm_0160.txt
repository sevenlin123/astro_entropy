### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

#### Inputs:
- **Photometric Data**: Sparse photometric measurements (fluxes) in specified filters.
- **Reference Spectra**: A training set of known high-resolution near-IR spectra.
- **Filter Curves**: Throughput or transmission curves of the photometric filters used.

#### Parameters:
- **Number of Principal Components (K)**: Typically 8–10 for high fidelity.
- **Observational Uncertainty**: Assumed relative uncertainty (e.g., 20%).

#### Steps:

1. **Training Phase**:
   1. **Principal Component Analysis (PCA)**:
      - Compute PCA on the reference spectra to extract principal components (eigenvectors and eigenvalues).
      - Determine the number of principal components (K) that capture the essential spectral variability (LOOCV optimized).
   2. **Density Estimation**:
      - Use Kernel Density Estimation (KDE) on the PCA scores of the reference spectra to model the latent space prior.
   3. **Synthetic Data Generation**:
      - Generate synthetic latent vectors using the KDE model.
      - Forward-model these latent vectors through the inverse PCA transform to generate synthetic spectra.
      - Convolve synthetic spectra with filter curves and add noise (based on assumed uncertainty) to create synthetic photometric data.
   4. **Model Training**:
      - Train an AutoML regressor (ensemble of gradient-boosted decision trees) to map synthetic photometric data to latent PCA coefficients.

2. **Inference Phase**:
   1. **Photometric Input**:
      - Normalize input photometric data relative to a reference spectrum (e.g., solar spectrum).
   2. **Forward Modeling**:
      - Convert normalized photometric data into reflectance values.
   3. **Regressor Prediction**:
      - Use the trained AutoML regressor to predict latent PCA coefficients from the photometric data.
   4. **Spectral Reconstruction**:
      - Apply the inverse PCA transform to the predicted latent coefficients to obtain a reconstructed spectrum.
   5. **Uncertainty Quantification**:
      - Sample the joint posterior distribution of latent coefficients using Gaussian Copula.
      - Propagate uncertainties through the inverse PCA transform to generate confidence intervals for the reconstructed spectrum.

3. **Classification**:
   1. **Latent Space Projection**:
      - Project the predicted latent coefficients into the pre-trained taxonomic classifier.
   2. **Probability Estimation**:
      - Obtain probability distribution over taxonomic classes (e.g., H₂O, CO₂, Organics, Methanol).

#### Outputs:
- **Reconstructed Spectrum**: Full near-IR spectrum interpolated from sparse photometry.
- **Confidence Intervals**: Statistical uncertainties on the reconstructed spectrum.
- **Taxonomic Classification**: Probabilistic assignment to spectral types.

#### Notes:
- The algorithm assumes a Bayesian framework, with the prior defined by PCA and KDE on reference spectra.
- Uncertainties are propagated through the model, ensuring physically consistent and statistically rigorous reconstructions.
- Synthetic data augmentation ensures robust training even with limited reference spectra.
