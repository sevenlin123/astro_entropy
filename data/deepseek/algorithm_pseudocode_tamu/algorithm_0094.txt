**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

**1. Model Training:**
   - **Input:** Reference spectra dataset, photometric filter definitions.
   - **Output:** Trained PCA model, trained AutoML regressor, latent manifold.

   **Steps:**
   
   **1.1. Principal Component Analysis (PCA):**
      - **Objective:** Reduce spectral dimensionality to form a low-dimensional latent space.
      - **Process:**
         - Normalize the reference spectra.
         - Compute PCA on the normalized spectra to obtain principal components (eigenvectors) and scores (latent coefficients).
         - Retain K principal components, where K is determined based on explained variance or LOOCV performance.

   **1.2. Synthetic Data Generation using Kernel Density Estimation (KDE):**
      - **Objective:** Augment the training data to create a smooth latent manifold.
      - **Process:**
         - Project the reference spectra onto the PCA latent space to obtain initial latent coefficients.
         - Fit a Gaussian KDE to these latent coefficients to estimate the probability density in the latent space.
         - Sample synthetic latent vectors from the KDE to create additional training data points, ensuring a continuous manifold.

   **1.3. Training the AutoML Regressor:**
      - **Objective:** Learn the mapping from sparse photometry to latent coefficients.
      - **Process:**
         - For each reference spectrum:
             - Generate synthetic photometry by forward modeling through the target instrument's filters (e.g., JWST NIRCam).
             - Add Gaussian noise (relative uncertainty, e.g., 20%) to simulate observational uncertainties.
         - Combine the original and synthetic photometric data with their corresponding latent coefficients.
         - Train an ensemble of gradient-boosted decision trees (AutoML) to regress photometric inputs to latent coefficients.
         - Optimize hyperparameters (e.g., number of trees, learning rate) using nested cross-validation.

**2. Spectral Reconstruction:**
   - **Input:** Observed photometric measurements.
   - **Output:** Reconstructed spectrum with credible intervals.

   **Steps:**
   
   **2.1. Photometric Forward Modeling:**
      - **Objective:** Convert observed photometry into expected reflectance in each filter.
      - **Process:**
         - For each photometric band, compute the reflectance using the observed magnitudes and the instrument's response curves.

   **2.2. AutoML Regression:**
      - **Objective:** Predict latent coefficients given the observed photometry.
      - **Process:**
         - Pass the forward-modeled photometry through the trained AutoML regressor to obtain predicted latent coefficients.

   **2.3. Inverse PCA Transformation:**
      - **Objective:** Reconstruct the full spectrum from latent coefficients.
      - **Process:**
         - Apply the inverse transformation using the PCA eigenvectors and the predicted latent coefficients to reconstruct the high-dimensional spectrum.

   **2.4. Posterior Sampling and Credible Intervals:**
      - **Objective:** Quantify uncertainties in the reconstructed spectrum.
      - **Process:**
         - Sample the joint posterior distribution of the latent coefficients using a Gaussian Copula, considering their marginal distributions and correlations.
         - For each sample, apply the inverse PCA to obtain a spectrum realization.
         - Calculate empirical credible intervals (e.g., 95%) across all wavelength points.

**3. Taxonomic Classification:**
   - **Input:** Reconstructed latent coefficients.
   - **Output:** Probabilistic taxonomic classification.

   **Steps:**
   
   **3.1. Latent Space Classification:**
      - **Objective:** Determine the taxonomic group of the object.
      - **Process:**
         - Use a pre-trained classifier (trained on the latent space of reference spectra) to predict the probability distribution over taxonomic classes (e.g., Water-type, CO₂-type, Organics-type).
         - Classify the object based on the highest probability or other criteria.

**Note:** The above algorithm assumes pre-computed PCA, synthetic data, and trained models. The actual implementation would include validation steps, such as LOOCV, to ensure model reliability and performance.
