### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

**Objective:**  
Reconstruct high-resolution spectra and classify taxonomic types of trans-Neptunian objects (TNOs) from sparse photometric measurements using a Bayesian framework.

**Steps:**

1. **Training Phase:**
   - **Data Preparation:**
     - Obtain a reference set of near-IR spectra for TNOs (e.g., 51 spectra).
     - Exclude rare spectral types and outliers to focus on dominant classes.
   - **Principal Component Analysis (PCA):**
     - Apply PCA to the reference spectra to reduce dimensionality.
     - Determine the number of principal components (e.g., 4–5 for classification, 8–10 for improved fidelity).
     - Construct a latent space using the PCA basis.
   - **Density Estimation:**
     - Use Kernel Density Estimation (KDE) to create a continuous probability distribution over the latent space.
     - Augment the training data with synthetic spectra to fill gaps in the latent manifold.
   - **Forward Modeling:**
     - Simulate photometric observations by convolving spectra with filter responses (e.g., JWST/NIRCam).
     - Inject Gaussian noise (e.g., 20% relative uncertainty) to simulate realistic photometric uncertainties.
   - **Model Training:**
     - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to latent coefficients.
     - Train a secondary classifier to predict taxonomic types from latent coefficients.

2. **Inference Phase:**
   - **Input Processing:**
     - Accept new photometric observations as input.
   - **Regression:**
     - Use the trained AutoML regressor to predict latent coefficients given the photometry.
   - **Posterior Sampling:**
     - Sample the joint posterior distribution of latent coefficients using a Gaussian Copula to preserve physical dependencies.
   - **Spectrum Reconstruction:**
     - Apply the inverse PCA transform to the latent coefficients to reconstruct the full spectrum.
   - **Uncertainty Quantification:**
     - Generate an ensemble of reconstructions to compute credible intervals.
   - **Classification:**
     - Classify the object into taxonomic groups (e.g., Water, CO₂, Organic, Methanol) using the latent space classifier.

3. **Validation and Applications:**
   - Perform leave-one-out cross-validation (LOOCV) to assess reconstruction accuracy and credible interval coverage.
   - Use the framework for survey optimization by identifying optimal filter combinations.
   - Detect spectral outliers and rare types by analyzing posterior probabilities.

**Output:**
- Reconstructed spectrum with uncertainties.
- Probabilistic taxonomic classification.
- Information content analysis for survey planning.
