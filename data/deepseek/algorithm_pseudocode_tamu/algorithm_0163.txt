Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- Observed photometric measurements m (sparse multi-band observations)
- Training set of reference spectra S_train
- Filter response functions for the photometric bands
- Uncertainty estimates for the photometric measurements

Output:
- Reconstructed spectrum S_recon
- Classification probabilities for taxonomic types
- Uncertainty intervals for the reconstructed spectrum

Steps:

1. **Preprocessing and Initialization**
   a. Normalize the observed photometric measurements m.
   b. Extract wavelength grid and corresponding filter transmission curves.
   c. Define the number of principal components K (based on LOOCV validation).

2. **Training Phase**
   a. Perform Principal Component Analysis (PCA) on S_train to obtain:
      - PCA basis vectors (principal components)
      - Corresponding eigenvalues
      - Mean spectrum μ
   b. Project the reference spectra onto the PCA basis to get latent coefficients z_train.
   c. Augment the latent space using Kernel Density Estimation (KDE) to generate synthetic training data z_mock.
   d. Train an Automated Machine Learning (AutoML) regressor (ensemble of gradient-boosted trees) to map photometric inputs to latent coefficients:
      - Input: normalized photometric measurements
      - Output: latent coefficients z
      - Training data: z_train and z_mock
   e. Train a secondary classifier on the latent space to predict taxonomic classes.

3. **Forward Modeling and Simulation-Based Inference**
   a. For each spectrum in the training set, generate synthetic photometry by convolving with filter responses and adding 20% relative Gaussian noise.
   b. Use the synthetic photometry to validate the likelihood mapping.

4. **Inference Phase**
   a. For the observed photometry m:
      i. Normalize m.
      ii. Pass m through the trained AutoML regressor to obtain posterior distribution over latent coefficients z_post.
      iii. Sample from z_post using Gaussian Copula to respect dependencies.
   b. Apply inverse PCA transform to z_post to reconstruct the spectrum S_recon:
      S_recon = μ + Σ(z_post * PCA_basis)
   c. Compute confidence intervals for S_recon.
   d. Classify S_recon using the latent space classifier.

5. **Uncertainty Quantification**
   a. Propagate photometric uncertainties through the reconstruction process.
   b. Calculate empirical credible intervals for the reconstructed spectrum.

6. **Post-Processing**
   a. Generate visualizations of the reconstructed spectrum and classification results (omitted per instructions).
   b. Store results for evaluation metrics (LOOCV, etc.).

End
