**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

**Input:**  
- Observed photometric measurements $\mathbf{m} \in \mathbb{R}^d$ (sparse multiband photometry)
- Training set of reference spectra $\mathcal{S}_{\text{train}} = \{S_i\}_{i=1}^{N}$ (where $N=51$ for TNOs)
- NIRCam filter transmission curves and uncertainties

**Output:**  
- Reconstructed spectrum $\hat{S} \in \mathbb{R}^w$ (continuous reflectance spectrum)
- Latent coefficients $\mathbf{z} \in \mathbb{R}^k$ (principal component decomposition)
- Taxonomic classification probabilities

**Steps:**

1. **Preprocessing:**
   - Perform **Principal Component Analysis (PCA)** on $\mathcal{S}_{\text{train}}$ to derive principal components (PCs) $\{u_j\}_{j=1}^k$.
   - Select $k \in \{4,5\}$ for taxonomic classification, $k \in \{8,10\}$ for improved reconstruction fidelity.

2. **Data Augmentation:**
   - Apply **Kernel Density Estimation (KDE)** with Gaussian kernel on the latent space of PCs to generate synthetic spectra.
   - Ensure bandwidth $h \sim 0.5$ for smooth manifold without over-smoothing.

3. **Forward Modeling:**
   - Simulate photometric measurements $\mathbf{m}_{\text{mock}}$ for each augmented spectrum by convolving with NIRCam filter responses.
   - Inject Gaussian noise with 20% relative uncertainty to $\mathbf{m}_{\text{mock}}$.

4. **Training Phase:**
   - Construct training database pairing $\mathbf{m}_{\text{mock}}$ with corresponding latent coefficients $\mathbf{z}$.
   - Train an **Automated Machine Learning (AutoML)** regressor (e.g., Gradient Boosted Decision Trees) to map $\mathbf{m}$ to $\mathbf{z}$.
   - Simultaneously train a taxonomic classifier on the latent space.

5. **Inference Phase:**
   - For new photometric measurements $\mathbf{m}$:
     a. Predict latent coefficients $\hat{\mathbf{z}}$ using the trained regressor.
     b. Project $\hat{\mathbf{z}}$ through inverse PCA to reconstruct $\hat{S}$.

6. **Uncertainty Quantification:**
   - Sample from the joint posterior distribution of $\hat{\mathbf{z}}$ using a Gaussian Copula to generate an ensemble of reconstructions.
   - Compute empirical credible intervals for $\hat{S}$.

7. **Taxonomic Classification:**
   - Classify $\hat{\mathbf{z}}$ into predefined spectral types (e.g., Water, CO$_2$, Organics) using the trained classifier.

8. **Validation (LOOCV):**
   - Remove one spectrum from $\mathcal{S}_{\text{train}}$, retrain models, and reconstruct the removed spectrum.
   - Assess RMSE, coverage, classification accuracy, and outlier detection rates.

**End of Algorithm**
