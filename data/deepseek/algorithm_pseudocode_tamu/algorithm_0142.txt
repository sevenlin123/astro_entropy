### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Input Data**:
   - Observed photometric measurements **m** for a trans-Neptunian object (TNO).
   - Training dataset **D** containing reference spectra and their corresponding photometric measurements.

2. **Preprocessing**:
   - Perform **Principal Component Analysis (PCA)** on the training spectra to obtain principal components **PC₁, PC₂, ..., PC_K**.
   - Select the number of principal components **K** based on cross-validation (e.g., 4-5 for classification, 8-10 for high-fidelity reconstruction).

3. **Training Phase**:
   - Construct a **synthetic latent manifold** using **Kernel Density Estimation (KDE)** on the PCA coefficients of the training spectra.
   - Generate **synthetic photometry** by forward modeling the synthetic spectra through the JWST/NIRCam filter system, including Gaussian noise (e.g., 20% relative uncertainty).

4. **Model Training**:
   - Train an **Automated Machine Learning (AutoML)** regressor (e.g., Gradient Boosted Decision Trees) to map photometric measurements **m** to PCA coefficients **z**.
   - Simultaneously train a taxonomic classifier to predict spectral types (e.g., H₂O, CO₂, Organic) using the PCA coefficients.

5. **Inference Phase**:
   - Use the trained regressor to predict the PCA coefficients **ẑ** given the observed photometry **m**.
   - Apply the inverse PCA transformation to reconstruct the full spectrum **Ŝ** from **ẑ**.
   - Sample the joint posterior distribution of **ẑ** using a **Gaussian Copula** to quantify uncertainties in the reconstructed spectrum.

6. **Output**:
   - Reconstructed spectrum **Ŝ** with associated uncertainties.
   - Probabilistic taxonomic classification of the object.

### Pseudocode:

```pseudocode
function probabilistic_spectral_reconstruction(m, D):
    # Step 1: Preprocess Training Data
    spectra, _ = extract_reference_spectra(D)
    pc_basis = perform_pca(spectra)
    
    # Step 2: Construct Synthetic Manifold
    z_real = project_spectra(pc_basis, spectra)
    z_synthetic = generate_synthetic_latents(z_real, h=0.5)
    
    # Step 3: Forward Model Photometry
    m_synthetic = forward_model(z_synthetic, instrument='JWST/NIRCam', noise_level=0.2)
    
    # Step 4: Train AutoML Regressor and Classifier
    regressor = train_automl_regressor(m_synthetic, z_synthetic)
    classifier = train_automl_classifier(z_synthetic, spectral_types)
    
    # Step 5: Process Observed Photometry
    z_hat = regressor.predict(m)
    S_reconstructed = inverse_pca_transform(pc_basis, z_hat)
    
    # Step 6: Quantify Uncertainties
    z_samples = sample_posterior(z_hat, correlation_matrix)
    S_samples = [inverse_pca_transform(pc_basis, z) for z in z_samples]
    
    # Step 7: Classify Taxonomic Type
    taxonomic_prediction = classifier.predict(z_hat)
    
    return S_reconstructed, S_samples, taxonomic_prediction
```

### Explanation:

- **Step 1**: The training spectra are decomposed into principal components to form a low-dimensional latent space.
- **Step 2**: A synthetic latent manifold is created to augment the training data, enabling smoother interpolation between reference spectra.
- **Step 3**: Synthetic photometry is generated by simulating observations of the synthetic spectra, introducing realistic noise levels.
- **Step 4**: Machine learning models are trained to map photometric inputs to latent space coordinates and to classify spectral types.
- **Step 5**: Given observed photometry, the trained models predict the latent space coordinates and reconstruct the full spectrum.
- **Step 6**: Uncertainties in the reconstructed spectrum are estimated using a Gaussian Copula to maintain physical correlations.
- **Step 7**: The taxonomic classification provides a probabilistic assignment of spectral types based on the latent coordinates.

This algorithm bridges the gap between sparse photometric data and detailed spectral reconstruction, enabling probabilistic characterization of TNO surface compositions.
