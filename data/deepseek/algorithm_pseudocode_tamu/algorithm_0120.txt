### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

#### 1. **Preprocessing and Initialization**
   - **Input**: Observed photometric measurements (sparse) for a TNO.
   - **Training Data**: A sample of near-IR spectra (reference spectra) used for model training.
   - **Dimensionality Reduction**: Apply Principal Component Analysis (PCA) on the reference spectra to obtain a set of principal components (PCs).

#### 2. **Latent Space Definition**
   - **Objective**: Define a low-dimensional manifold (latent space) representing the spectral variability of TNOs.
   - **Steps**:
     1. Project the reference spectra onto the PCA basis to get latent coefficients.
     2. Use Kernel Density Estimation (KDE) to model the probability distribution of these latent coefficients.
     3. Generate synthetic latent vectors to augment the training data, ensuring a smooth and continuous manifold.

#### 3. **Forward Modeling and Training**
   - **Objective**: Train a machine learning model to map sparse photometry to latent space.
   - **Steps**:
     1. For each synthetic latent vector, forward model the spectrum through the NIRCam filter set to generate synthetic photometry.
     2. Inject Gaussian noise (20% relative uncertainty) into the synthetic photometry to simulate real-world observational uncertainties.
     3. Train an ensemble of Gradient Boosted Decision Trees (GBDTs) using AutoML to regress from noisy photometry to latent coefficients.
     4. Validate the model using Leave-One-Out Cross-Validation (LOOCV) on the reference spectra.

#### 4. **Reconstruction and Uncertainty Quantification**
   - **Objective**: Reconstruct the full spectrum and quantify uncertainties from sparse photometry.
   - **Steps**:
     1. For a new photometric observation:
        - Use the trained GBDT model to predict the latent coefficients.
        - Apply the inverse PCA transform to reconstruct the full spectrum.
     2. Sample the joint posterior distribution of latent coefficients using a Gaussian Copula framework to generate an ensemble of possible spectra.
     3. Calculate confidence intervals for the reconstructed spectrum based on the ensemble.

#### 5. **Classification**
   - **Objective**: Classify the spectral type of the TNO.
   - **Steps**:
     1. Use a trained classifier (ensemble of GBDTs) on the predicted latent coefficients to obtain posterior probabilities over taxonomic categories (e.g., H₂O, CO₂, Organics, Methanol).
     2. Return the most probable spectral type along with confidence scores.

#### 6. **Output**
   - **Deliverables**:
     - Reconstructed spectrum with confidence intervals.
     - Probabilistic classification of the spectral type.
     - Diagnostics on the plausibility of the reconstruction (e.g., RMSE, coverage statistics).

### Pseudocode Representation

```pseudocode
Algorithm ProbabilisticSpectralReconstruction(photometry):
    // Preprocessing
    reference_spectra = LoadReferenceSpectra()
    pca = PerformPCA(reference_spectra)
    
    // Training Phase
    latent_coeffs = PCA.transform(reference_spectra)
    kde = FitKDE(latent_coeffs)
    
    // Data Augmentation
    synthetic_latents = SampleKDE(kde, num_samples=Thousands)
    synthetic_photometry = ForwardModel(synthetic_latents, nircam_filters)
    
    // Add Noise
    noisy_photometry = AddGaussianNoise(synthetic_photometry, sigma=0.2)
    
    // Train Model
    regressor = AutoMLRegressor()
    regressor.train(noisy_photometry, synthetic_latents)
    
    // Validation
    loocv_score = LeaveOneOutCrossValidation(regressor, reference_spectra)
    
    // Reconstruct Spectrum
    predicted_latents = regressor.predict(photometry)
    reconstructed_spectrum = PCA.inverse_transform(predicted_latents)
    
    // Uncertainty Sampling
    posterior_samples = SampleGaussianCopula(predicted_latents)
    confidence_intervals = ComputeIntervals(reconstructed_spectrum, posterior_samples)
    
    // Classification
    taxonomic_posteriors = Classifier.predict(posterior_samples)
    dominant_class = FindDominantClass(taxonomic_posteriors)
    
    // Output
    return reconstructed_spectrum, confidence_intervals, dominant_class
```

### Explanation
This algorithm systematically transforms sparse photometric data into a full spectral reconstruction leveraging PCA and machine learning. It ensures robustness by propagating uncertainties through a probabilistic framework and provides interpretable outputs for taxonomic classification.
