```pseudocode
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Training Spectra: Set of reference TNO spectra (S_train)
    - Photometric Filters: List of NIRCam filters (F)
    - Photometric Observations: Sparse photometric measurements (m_obs)
    - Number of Principal Components (K)

Output:
    - Reconstructed Spectrum (S_recon)
    - Uncertainty Quantification (ECI)
    - Taxonomic Classification (Class)

Steps:

1. **Principal Component Analysis (PCA):**
    a. Train PCA on S_train to extract top K principal components (PCs).
    b. Compute latent coefficients (z) for S_train.

2. **Density Estimation:**
    a. Apply Kernel Density Estimation (KDE) on latent coefficients (z) to form a continuous prior distribution over the latent space.

3. **Forward Modeling:**
    a. For each spectrum in training set:
        i. Convolve spectrum with each NIRCam filter's throughput curve to simulate photometric response.
        ii. Add Gaussian noise with relative reflectance uncertainty (e.g., 20%) to simulate observational noise.
    b. Create a training database of noisy photometry (m_sim) paired with latent coefficients (z).

4. **AutoML Regression Training:**
    a. Train an ensemble regressor (e.g., Gradient Boosted Decision Trees) to map photometric inputs (m_sim) to latent coefficients (z_pred).

5. **Inverse PCA Transformation:**
    a. Define inverse transformation using top K PCs to reconstruct full spectrum from latent coefficients.

6. **Reconstruction Pipeline:**
    a. For new photometric observations (m_obs):
        i. Use trained regressor to predict latent coefficients (z_pred).
        ii. Sample from joint posterior distribution of z_pred using Gaussian Copula to account for dependencies.
        iii. Apply inverse PCA to obtain reconstructed spectrum (S_recon) for each sample.

7. **Uncertainty Quantification:**
    a. Calculate empirical credible intervals (ECIs) for S_recon based on posterior samples.

8. **Taxonomic Classification:**
    a. Train a separate classifier on latent coefficients to predict taxonomic class (e.g., H2O, CO2, Organic).
    b. Output probability distribution over spectral types for each observation.

9. **Validation:**
    a. Perform Leave-One-Out Cross-Validation (LOOCV) to assess RMSE and ECI coverage.
    b. Evaluate taxonomic classification accuracy.

End
```
