### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

#### Step 1: Preprocessing and PCA Training
1. **Input Data**: Obtain a training set of reference TNO spectra.
2. **PCA Application**:
   - Compute Principal Component Analysis (PCA) on the reference spectra to derive principal components (eigenvectors) and latent coefficients (scores).
   - Select the number of principal components (K) based on explained variance or cross-validation results (e.g., 4-5 for classification, 8-10 for high-fidelity reconstruction).

#### Step 2: Latent Space Augmentation
1. **Density Estimation**:
   - Use Kernel Density Estimation (KDE) with a Gaussian kernel to estimate the probability density of the latent coefficients.
   - Bandwidth (h) is set to 0.5 to balance smoothing and fidelity.

#### Step 3: Synthetic Data Generation
1. **Forward Modeling**:
   - For each synthetic latent vector, generate a full spectrum by applying the inverse PCA transform.
   - Simulate photometric observations by convolving the generated spectra with the filter responses of the target instrument (e.g., JWST/NIRCam).
   - Inject Gaussian noise with a relative uncertainty of 20% into the synthetic photometry.

#### Step 4: Training the AutoML Regressor
1. **Training Data Preparation**:
   - Combine real seed spectra and synthetic data.
   - Exclude the held-out spectrum during each LOOCV iteration.
2. **Model Training**:
   - Train an ensemble of gradient-boosted decision trees (e.g., XGBoost) to map sparse photometry to latent coefficients.

#### Step 5: Inference and Reconstruction
1. **Latent Space Prediction**:
   - For new photometric observations, predict the corresponding latent coefficients using the trained AutoML regressor.
2. **Spectrum Reconstruction**:
   - Apply the inverse PCA transform to the predicted latent coefficients to obtain the full spectrum.
3. **Uncertainty Quantification**:
   - Sample the joint posterior distribution of latent coefficients using a Gaussian Copula to generate confidence intervals for the reconstructed spectrum.

#### Step 6: Taxonomic Classification
1. **Latent Space Projection**:
   - Project the predicted latent coefficients onto a pre-trained classifier.
2. **Classification Output**:
   - Assign probability distributions over taxonomic categories (e.g., H₂O, CO₂, Organic, Methanol).

#### Step 7: Performance Evaluation
1. **Reconstruction Accuracy**:
   - Compute relative RMSE within each photometric band.
2. **Credible Interval Coverage**:
   - Check if 95% credible intervals contain the true spectrum at least 95% of the time.
3. **Classification Metrics**:
   - Evaluate true positive and false positive rates for taxonomic assignments.

#### Step 8: Applications
1. **Survey Optimization**:
   - Identify filter configurations that maximize information content by evaluating mutual information with the latent space.
2. **Outlier Detection**:
   - Flag objects with posterior projections inconsistent with the learned manifold for follow-up spectroscopy.

### Final Algorithm Description

The algorithm begins by training a PCA model on reference spectra to capture spectral variability in a low-dimensional latent space. Synthetic data augmentation is performed using KDE to create a smooth manifold. Sparse photometry is mapped to latent coefficients via an AutoML regressor, which is then inverted to reconstruct full spectra. Uncertainty quantification and taxonomic classification are achieved through posterior sampling and latent space projection. The framework evaluates reconstruction accuracy, uncertainty calibration, and classification performance, enabling survey optimization and outlier detection.
