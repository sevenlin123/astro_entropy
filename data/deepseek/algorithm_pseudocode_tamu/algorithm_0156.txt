### Algorithm: Probabilistic Spectral Reconstruction Framework

```plaintext
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Training Spectra: Set of reference near-IR spectra (S_train)
    - Photometric Observations: Sparse multi-band photometry (m_test)
    - PCA Basis: Principal Component Analysis (PCA) derived from S_train
    - Filters: Effective spectral response functions (e.g., JWST/NIRCam filters)

Output:
    - Reconstructed Full Spectra: High-resolution spectral estimates (S_recon)
    - Taxonomic Classifications: Probabilistic assignments of spectral types
    - Uncertainty Quantification: Credible intervals for reconstructed features

Steps:

1. **Principal Component Analysis (PCA):**
    a. Train PCA on S_train to derive principal components (PCs) and corresponding loadings.
    b. Project S_train onto the PCA basis to obtain latent coefficients (z_train).

2. **Data Augmentation with Kernel Density Estimation (KDE):**
    a. Construct a continuous latent manifold using KDE on z_train with a Gaussian kernel.
    b. Bandwidth (h) optimized empirically to balance smoothing and fidelity (h ≈ 0.5).

3. **Synthetic Photometry Generation:**
    a. Forward model augmented spectra through target instrument filters to simulate photometry.
    b. Inject Gaussian noise with relative uncertainty (σ ≈ 20%) into synthetic photometry.

4. **Automated Machine Learning (AutoML) Training:**
    a. Train an ensemble regressor (e.g., XGBoost) to map sparse photometry to latent coefficients.
    b. Simultaneously train a taxonomic classifier on the latent manifold using labels from S_train.

5. **Forward Inference Pipeline:**
    a. For each test observation m_test:
        i. Use trained regressor to predict posterior distribution of latent coefficients (z_posterior).
        ii. Sample from z_posterior using Gaussian Copula to preserve manifold correlations.
        iii. Apply inverse PCA transform to generate S_recon.
        iv. Classify spectral type using latent space classifier.

6. **Uncertainty Quantification:**
    a. Propagate photometric uncertainties through the PCA transformation.
    b. Generate ensembles of S_recon to construct credible intervals.

7. **Outlier Detection:**
    a. Assess posterior probabilities in latent space.
    b. Flag observations with low-probability states for follow-up spectroscopy.

End
```

### Explanation

The algorithm systematically reduces the dimensionality of spectral data using PCA, enabling reconstruction from sparse photometry. It employs KDE to smooth the latent manifold, stabilizing the regression training. Synthetic photometry generated from the manifold mimics real observations, allowing robust model training. The AutoML regressor predicts latent coefficients, which are transformed back to full spectra. Uncertainty quantification and outlier detection enhance the reliability and utility of the reconstructed spectra for taxonomic studies and survey optimization.
