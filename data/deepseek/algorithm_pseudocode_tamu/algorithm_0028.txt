**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Preparation**
   - Obtain sparse photometric measurements for a trans-Neptunian object (TNO).
   - Define the target spectral bands for reconstruction.

2. **Principal Component Analysis (PCA) Initialization**
   - Train PCA on a reference dataset of TNO spectra.
   - Determine the optimal number of principal components (K) based on reconstruction fidelity and cross-validation results.

3. **Kernel Density Estimation (KDE) Augmentation**
   - Project the reference spectra onto the PCA latent space.
   - Use KDE to generate synthetic latent vectors, creating a smooth manifold that approximates the spectral distribution of the reference data.

4. **AutoML Regressor Training**
   - Train an automated machine learning regressor (e.g., gradient-boosted decision trees) to map sparse photometric inputs to PCA latent coefficients.
   - Augment training data with synthetic samples generated from the KDE manifold to improve model generalization.

5. **Forward Modeling**
   - Simulate photometric observations by convolving PCA-derived spectra with filter response functions.
   - Inject Gaussian noise (e.g., 20% relative uncertainty) to account for observational errors.

6. **Simulation-Based Inference**
   - Construct an implicit likelihood function using the forward-simulated photometry and their uncertainties.
   - Perform training and validation using the synthetic and real datasets.

7. **Reconstruction Process**
   - For new photometric data:
     - Predict latent coefficients using the trained AutoML regressor.
     - Apply inverse PCA transformation to reconstruct the full spectrum.
     - Sample from the posterior distribution of latent variables using a Gaussian Copula to quantify uncertainties.

8. **Taxonomy Classification**
   - Classify the reconstructed spectrum into predefined taxonomic categories (e.g., Water-type, CO₂-type, Organics-type) by evaluating the latent coefficients against trained classification models.

9. **Validation and Uncertainty Quantification**
   - Assess reconstruction accuracy using metrics like RMSE, credible interval coverage, and feature-specific RMSE.
   - Evaluate taxonomic classification performance using F1-score, precision, recall, and calibration metrics.

10. **Outlier Detection**
    - Compute anomaly scores based on photometric residuals and posterior probabilities.
    - Flag objects with scores exceeding thresholds for further investigation.

11. **Survey Optimization**
    - Identify optimal photometric filter combinations by maximizing mutual information between filters and spectral features.
    - Determine the most informative filter sets for maximizing reconstruction fidelity and taxonomic distinction.

**Output:** Reconstructed high-resolution spectrum, taxonomic classification, uncertainty estimates, and outlier detection results.
