**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Data Preprocessing**
   - Input: Observed sparse photometric measurements of TNOs.
   - Output: Normalized photometric data for training.

2. **Principal Component Analysis (PCA)**
   - Train PCA model using reference TNO spectra.
   - Obtain principal component (PC) coefficients for the training spectra.

3. **Data Augmentation with Kernel Density Estimation (KDE)**
   - Project training spectra onto PCA space.
   - Generate synthetic latent vectors using Gaussian KDE.
   - Ensure smooth, continuous prior distribution in latent space.

4. **Forward Modeling**
   - Simulate synthetic photometry for augmented spectra using JWST NIRCam filtersthroughput curves.
   - Inject Gaussian noise (relative uncertainty ~20%) into synthetic photometry.

5. **Training Automated Machine Learning Regressor**
   - Use AutoML (e.g., XGBoost) to regress from noisy photometry to latent PC coefficients.
   - Augment training data with synthetic photometry and corresponding latent vectors.

6. **Leave-One-Out Cross-Validation (LOOCV)**
   - For each held-out object:
     a. Remove object from training set.
     b. Reconstruct latent manifold using remaining objects.
     c. Train regressor on synthetic + real data (excluding held-out object).
     d. Predict latent coefficients for held-out object's photometry.
     e. Reconstruct spectrum via inverse PCA transform.
     f. Evaluate RMSE and credible interval coverage.

7. **Taxonomic Classification**
   - Train secondary classifier on PCA coefficients using labeled training spectra.
   - Classify held-out objects based on predicted latent coefficients.

8. **Survey Optimization**
   - Enumerate JWST NIRCam filter combinations.
   - Compute information content for each configuration using framework.
   - Select optimal filter sets for maximizing spectral constraint.

9. **Outlier Detection**
   - Analyze posterior distribution of latent variables for new observations.
   - Identify objects with low probability density in latent space as outliers.

**End Algorithm**
