**Algorithm: Probabilistic Spectral Reconstruction**

1. **Define Parametric Spectral Model**  
   - Parameters: Absorption feature position (λ_abs), amplitude of red tail (A_red), smooth blue component amplitude (A_blue).  
   - Model features: Absorption at λ_abs, red tail beyond 700 nm, smooth blue part.

2. **Set Prior Distributions**  
   - Truncated normal distributions for λ_abs, A_red, A_blue with specified min and max bounds.

3. **Initialize Gaussian Process**  
   - Choose kernel type (e.g., Matern kernel) and set hyperparameters to model spectral smoothness.

4. **Model Observed Flux**  
   - For each observed wavelength λ_i:  
     a. Compute predicted flux F_i using the parametric model and current parameters.  
     b. Assume flux follows F_i ~ Normal(μ=F_i, σ=noise_level).

5. **Bayesian Inference with MCMC**  
   - Use Emcee (MCMC sampler):  
      a. For each step:  
         i. Propose new parameters within prior constraints.  
         ii. Compute log probability via sum of log-likelihoods over observed fluxes.  
         iii. Update parameters based on MCMC dynamics.  
      b. Run for a fixed number of iterations or until convergence criteria met.

6. **Posterior Analysis**  
   - Extract posterior distributions of model parameters.  
   - Reconstruct the complete spectrum using the posterior means or medians.

**End Algorithm**
