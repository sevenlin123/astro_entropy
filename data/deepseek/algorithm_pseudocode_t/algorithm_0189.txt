**Algorithm: Probabilistic SED Reconstruction for TNOs**

**Input:**
- Observed flux measurements F
- Measurement uncertainties σ_F
- Priors on SED parameters θ_prior
- Basis functions B for SED parameterization

**Output:**
- Reconstructed SEDs S_median with credible intervals
- Posterior distributions of SED parameters θ_posterior
- Photometric redshifts z_photometric
- Spectral classifications C
- Outlier flags O

**Steps:**

1. **Initialization:**
   - Read input data: F, σ_F, θ_prior, B.

2. **Parameterize the SED:**
   - For each TNO candidate, represent the SED as a linear combination of basis functions B.
   - Determine the number of basis functions and their coefficients θ that best describe the SED.

3. **Construct the Forward Model:**
   - Develop a model that maps the SED parameters θ to observed fluxes F, incorporating ISM extinction.
   - Include distance-dependent reddening using an appropriate extinction law.

4. **Bayesian Inference via MCMC:**
   - Set up the likelihood function based on the forward model and observed data (F, σ_F).
   - Define the prior distribution θ_prior based on known TNO characteristics.
   - Use MCMC (e.g., Metropolis-Hastings) to sample the posterior distribution θ_posterior.

5. **Reconstruct SEDs:**
   - From θ_posterior, compute the median SED and credible intervals.
   - This provides the best estimate of the SED along with uncertainty quantification.

6. **Calculate Photometric Redshifts and Classifications:**
   - Using the reconstructed SEDs, estimate photometric redshifts by comparing observed fluxes with a template spectrum or via spectral fitting.
   - Classify the TNO into spectral types (e.g., based on color or spectral indices).

7. **Outlier Detection:**
   - Compare observed fluxes F with modeled fluxes derived from the reconstructed SEDs.
   - Flag objects where the discrepancy exceeds a predefined threshold as outliers.

8. **Output Results:**
   - Store S_median, credible intervals, θ_posterior, z_photometric, C, and O for each TNO.

**End Algorithm**

**Note:** This pseudocode outlines the core computational steps without including validation procedures, visualization, or detailed MCMC setup, which are addressed in the paper but omitted per instructions.
