Algorithm:

Initialize Gaussian process hyperparameters (e.g., kernel parameters, variance).

For each TNO in the dataset:
    a. Read the sparse photometric observations across multiple bands, including flux measurements and associated uncertainties.
    b. Deconvolve the observed photometric data to estimate the intrinsic light curve:
        i. Model the convolution of the object's true flux with the instrumental PSF.
        ii. Use observed fluxes and the PSF model to solve for the intrinsic light curve shape.
    c. Set up the Gaussian process prior for SED reconstruction:
        i. Define the covariance matrix based on Gaussian process hyperparameters.
        ii. Place a prior on the SED parameters using the Gaussian process.
    d. Forward simulate the expected photometric fluxes:
        i. For each wavelength band, compute the expected flux as the integral of the SED multiplied by the instrumental response.
        ii. Add noise to the simulated fluxes to match the observed data's uncertainty.
    e. Perform Bayesian inversion using MCMC:
        i. Define the likelihood function as the probability of observing the data given the SED and other parameters.
        ii. Define the prior as the Gaussian process prior on the SED.
        iii. Use MCMC (e.g., Metropolis-Hastings) to sample from the posterior distribution of the SED parameters.
    f. Analyze the MCMC samples:
        i. Compute marginal posterior distributions for each SED parameter.
        ii. Calculate confidence intervals (e.g., 16th, 50th, 84th percentiles) for each parameter.
        iii. Assess the fit by checking if the observed data falls within the posterior predictive distribution.
    g. Detect outliers:
        i. If the observed data significantly deviate from the posterior predictive distribution, mark the TNO as an outlier.
    h. Perform Bayesian optimization for observing strategy:
        i. For each possible phase angle and exposure time, compute the expected information gain (e.g., reduction in posterior uncertainty) if the TNO were observed at those parameters.
        ii. Select the phase angles and exposure times that maximize the information gain or minimize the expected uncertainty.

Output the reconstructed SEDs with confidence intervals and the optimized observing strategies.
