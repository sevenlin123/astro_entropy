**Algorithm: Probabilistic SED Reconstruction using Gaussian Processes**

**Inputs:**
- List of objects, each with:
  - `X`: Sorted array of wavelengths
  - `Y`: Array of flux densities
  - `Sigma`: Array of noise variances

**Outputs:**
- For each object:
  - Posterior mean (`μ_post`)
  - Posterior covariance (`K_post`) of the Gaussian Process

**Steps:**

1. **Initialization:**
   - For each object in the list:
     - Read the photometric data points `(λ_i, F_i)` and their associated noise variances `σ_i^2`.
     - Create arrays `X` (wavelengths), `Y` (flux densities), and `Sigma_diag` (diagonal noise matrix).

2. **Gaussian Process Setup:**
   - Choose a kernel function `K(λ, λ'; θ)`, such as the squared exponential kernel.
   - Initialize hyperparameters `θ` (e.g., length scale and variance).

3. **Hyperparameter Optimization:**
   - Compute the covariance matrix `K_ss = K(X, X; θ)`.
   - Form the matrix `C = K_ss + Sigma_diag`.
   - Perform Cholesky decomposition of `C` to compute `L` such that `C = L * L^T`.
   - Calculate the log marginal likelihood: 
     \[
     \text{log\_lik} = 0.5 \times (\text{sum}(log(\text{diag}(L))) - Y^T Y + Y^T C^{-1} Y)
     \]
   - Optimize `θ` to maximize `log_lik` using numerical methods.

4. **Posterior Computation:**
   - After optimizing `θ`, recompute `K_ss` and `Sigma_diag`.
   - Form matrix `C = K_ss + Sigma_diag`.
   - Perform Cholesky decomposition of `C` to get `L_new`.
   - Compute the posterior mean:
     \[
     μ_{\text{post}} = C^{-1} Y = \text{solve}(L_{\text{new}}, \text{solve}(L_{\text{new}}^T, Y))
     \]
   - Compute the posterior covariance:
     \[
     K_{\text{post}} = C^{-1} K_{ss} = \text{solve}(L_{\text{new}}, \text{solve}(L_{\text{new}}^T, K_{ss}))
     \]

5. **Sampling from Posterior:**
   - Draw `N_samples` from a multivariate normal distribution with mean `μ_post` and covariance `K_post`.

6. **Output:**
   - Store `μ_post` and `K_post` for each object.

**Notes:**
- Each object is processed independently to ensure accurate SED recovery.
- Numerical stability can be improved by adding a small jitter to `Sigma_diag` if necessary.
