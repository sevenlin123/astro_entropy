```
algorithm Probabilistic Spectral Reconstruction:
    inputs = [sparse photometric data, measurement uncertainties, interstellar extinction estimates]
    outputs = [reconstructed spectral energy distribution (SED), uncertainty quantification, model selection criteria]
    steps:
        1. Initialize variables and parameters for the probabilistic model.
        2. Read and parse the sparse photometric data.
        3. Preprocess data by correcting for interstellar extinction using provided estimates.
        4. Define the probabilistic model incorporating uncertainties in photometric measurements.
        5. Set up Bayesian posterior distribution for the SED parameters.
        6. Implement Markov Chain Monte Carlo (MCMC) sampling to explore the posterior distribution.
        7. Analyze MCMC samples to estimate the SED and quantify uncertainties.
        8. Perform model selection to determine the best-fitting spectral type.
        9. Output the reconstructed SED, associated uncertainties, and model selection results.
```
