Algorithm PSR-Reconstruction
Input: Sparse photometric data D of trans-Neptunian objects
Output: Estimated spectral features S with uncertainties U

For each object in D:
    1. Obtain sparse photometric measurements (x_measured, y_measured)
    2. Define the full set of wavelengths X where the spectrum will be modeled
    3. For each wavelength in X:
        a. If measured, record y_i
        b. Else, mark as unmeasured (y is unknown)
    4. Create a list Y where measured points have y_i and unmeasured points are marked (e.g., NaN or placeholder)
    5. Create a mask M indicating which points are measured (True/False)
    6. Define the Gaussian process kernel K with parameters θ (e.g., RBF kernel with length scale and variance)
    7. Compute the covariance matrix C = K(X, X) + σ²*I, where σ² is the noise variance
    8. Set the mean function m0(x) = 0
    9. Optimize the hyperparameters θ and σ² by maximizing the marginal likelihood using only the measured data points (where M is True)
    10. Using the optimized GP, compute the posterior mean m* at all X
    11. Compute the posterior covariance matrix C* at all X
    12. Extract spectral features S from m* (e.g., by integrating over X or selecting key points)
    13. Quantify feature uncertainties U from the diagonal of C* at the corresponding points in S

End For

Return S and U
