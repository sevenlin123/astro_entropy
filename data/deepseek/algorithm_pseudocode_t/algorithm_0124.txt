```pseudocode
Algorithm: Probabilistic SED Reconstruction for Trans-Neptunian Objects

Input: Photometric data for each object, including measurements and uncertainties
Output: Reconstructed SED parameters and best-fit SED

For each object do:
    Read photometric data and select spectral windows
    Initialize parameters for modified blackbody and emission features
    Define prior distributions for all parameters
    Construct likelihood function incorporating modified blackbody and features
    Include outlier handling as part of likelihood
    Perform Bayesian inference to compute posterior distributions
    Extract best-fit SED parameters from posterior
    Output reconstructed SED and associated uncertainties
End
```
