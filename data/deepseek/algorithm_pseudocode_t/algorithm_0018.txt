**Algorithm: Probabilistic Spectral Reconstruction**

**Input:**  
- Observed photometric measurements of objects.  
- Precomputed spectral properties of trans-Neptunian objects (TNOs).  
- Taxonomic classes defined by color distributions.  

**Output:**  
- Reconstructed Spectral Energy Distributions (SEDs) with confidence intervals for each object.  

**Step-by-Step Algorithm:**

1. **Precompute Color Relationships:**  
   - Store the spectral properties and color trends of TNOs based on prior knowledge.

2. **Train Gaussian Mixture Models (GMMs):**  
   - For each taxonomic class, fit a GMM to the color data of objects in that class.  
   - Save the GMM parameters for later use.

3. **Process Each Object Individually:**  
   - **a. Extract Photometric Data:**  
     - Retrieve the multi-band photometric measurements of the object.
   
   - **b. Compute Posterior Class Probabilities:**  
     - For each taxonomic class, use the pre-trained GMM to calculate the probability that the object belongs to that class.  

   - **c. Define Bayesian Model for SED Reconstruction:**  
     - **Likelihood:** Define the probability of observing the photometric measurements given the SED parameters.  
     - **Prior:** Incorporate the posterior class probabilities to inform the prior distributions of the SED parameters.  

   - **d. Bayesian Inference with Metropolis-Hastings Algorithm:**  
     - Initialize the SED parameters.  
     - Propose new parameter values.  
     - Compute the acceptance probability using the posterior distribution (likelihood * prior).  
     - Update the parameters if accepted.  
     - Repeat for multiple iterations to obtain posterior samples of the SED parameters.  

   - **e. Derive SED and Uncertainty:**  
     - Use the posterior samples to reconstruct the SED.  
     - Calculate confidence intervals to quantify the uncertainty in the SED reconstruction.  

4. **Output the Results:**  
   - For each object, output the reconstructed SED and associated confidence intervals.  

**End of Algorithm**
