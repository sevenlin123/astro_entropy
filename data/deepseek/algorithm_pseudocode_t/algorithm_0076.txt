**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Input Data:**
   - Sparse photometric time-series data for each object.
   - Orbital period as an unknown parameter.

2. **Initialize Parameters:**
   - Set up prior distributions for all parameters based on domain knowledge.

3. **Periodicity Detection:**
   - Apply the Lomb-Scargle algorithm to identify significant peaks in the periodogram.
   - Determine candidate periods from these peaks.

4. **Probabilistic Light Curve Modeling:**
   - For each candidate period:
     - Use Gaussian Processes (GP) to model the light curve.
     - Define the covariance matrix using an appropriate kernel (e.g., squared exponential).
     - Compute the posterior distribution of light curve parameters given the data.

5. **Parameter Estimation:**
   - Perform Bayesian inference to estimate posterior distributions of orbital period, light curve shape parameters, and hyperparameters of the GP.

6. **Uncertainty Quantification:**
   - Extract uncertainties from the posterior distributions.
   - Assess the reliability of the inferred parameters.

7. **Classification and Taxonomic Assignment:**
   - Compare the posterior distributions with known spectral classes or taxonomic groups.
   - Assign the object to the most probable group based on the posterior probabilities.

8. **Output:**
   - Posterior distributions of key parameters.
   - Classification and taxonomic assignment of the object.

This algorithm efficiently reconstructs spectral information from sparse photometric data using Bayesian methods, enabling robust classification and taxonomic assignments of trans-Neptunian objects.
