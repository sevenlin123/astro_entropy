**Algorithm: Probabilistic Spectral Reconstruction of Trans-Neptunian Objects**

```python
function probabilistic_spectral_reconstruction(photometric_data):
    initialize parameters for SED as piecewise linear function with predefined segments
    define prior distributions for each segment parameter based on known TNO properties
    set up Bayesian model with likelihood function incorporating photometric observations and uncertainties
    sample parameters from posterior distribution using Markov Chain Monte Carlo (MCMC) method
    determine number of optimal segments by evaluating posterior probabilities
    reconstruct SED by averaging over posterior samples
    quantify uncertainties in SED parameters
    return reconstructed SED and uncertainty estimates
end function
```
