```
Initialize parameters θ.

Set convergence threshold ε = 1e-6.

While change in θ > ε:

    total_ELBO = 0

    For each star S:

        ELBO_S = 0

        For each photometric band i:

            Simulate flux f_i(S) using current θ.
            Compute log probability of observed flux y_i(S) given f_i(S) and uncertainty σ_i(S).
            Add log probability to ELBO_S.

        Add ELBO_S to total_ELBO.

    Update θ by maximizing total_ELBO.

    If maximum change in θ < ε:
        Break

Return reconstructed spectral parameters for each star.
```
