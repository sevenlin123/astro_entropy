Algorithm: Probabilistic Spectral Reconstruction of TNOs from Sparse Photometry

For each object in dataset:
    Initialize model parameters for SED including dynamic mixture components
    Simulate fluxes for each photometric band using current parameters
    Compute likelihood of simulated fluxes compared to observed data
    Optimize model parameters via Bayesian posterior maximization
    Reconstruct SED from optimized parameters
    Detect outliers by comparing reconstructed SED with observations
End for
