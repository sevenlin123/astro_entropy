**Algorithm: Probabilistic SED Reconstruction via Adaptive Bayesian Mixture Model**

1. **Initialization**
   - Initialize the Bayesian mixture model with parameters including the number of potential spectral components and priors for each component's parameters (e.g., mean, variance).
   - Set hyperparameters for the mixture model to allow automatic determination of the optimal number of components.

2. **Data Processing**
   - For each trans-Neptunian object:
     - Extract photometric measurements across different bands.
     - Convert photometric data into flux values, accounting for instrument response and calibration.
     - Compute feature vectors representing each object's spectral characteristics (e.g., color indices, photometric variability).

3. **Model Training**
   - Perform Markov Chain Monte Carlo (MCMC) sampling to estimate the posterior distributions of the model parameters.
   - During MCMC iterations:
     - Update the mixture model parameters based on the likelihood of the data given the current parameter values.
     - Adjust the number of spectral components based on the posterior probability of each component being present.
     - Detect outliers by monitoring the likelihood of each object under the current model.

4. **Component Determination**
   - After sufficient MCMC iterations, determine the number of significant spectral components by analyzing the posterior distribution of the mixing coefficients.
   - Retain components with non-negligible posterior probabilities and discard those that contribute minimally to explaining the data.

5. **SED Reconstruction**
   - For each object, reconstruct its SED by combining the retained spectral components weighted by their posterior probabilities.
   - Calculate uncertainties in the reconstructed SEDs using the variance of the posterior distributions obtained during MCMC sampling.

6. **Outlier Flagging**
   - Identify outliers as objects whose likelihood under the inferred model is significantly lower than the majority.
   - Flag these outliers for further investigation or exclusion in subsequent analyses.

7. **Output**
   - Generate files containing the reconstructed SEDs, their uncertainties, and outlier flags for each object.

This algorithm efficiently processes sparse and noisy photometric data to provide robust SED reconstructions, enabling accurate taxonomy and survey optimization for trans-Neptunian objects.
