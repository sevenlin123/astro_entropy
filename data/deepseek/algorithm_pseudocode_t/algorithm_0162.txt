Algorithm: Probabilistic Spectral Reconstruction Framework

Input: Observed photometric data for each TNO
Output: Refined spectrum and associated uncertainties

1. Initialize variables for each observed object:
   - Sparse photometric data

2. Perform probabilistic template matching:
   - For each object, find candidate spectral templates that best match the observed data considering photometric uncertainties and colour variations

3. For each candidate template:
   a. Apply forward-modelling:
      - Simulate observations that align with the provided photometric measurements, incorporating redshift variations due to peculiar velocities, observational conditions, and instrument specifics

   b. Use MCMC to calculate the posterior distribution:
      - Estimate the posterior probabilities of template parameters (redshift, shape factors) to identify the most probable template and quantify uncertainties

4. Reconstruct the spectrum pixel-by-pixel using Gaussian processes:
   - Consider uncertainties in the underlying spectrum and its relationship to observed magnitudes

5. Calculate posterior outlier probabilities for each observation:
   - Determine the likelihood of each observation being an outlier

6. Apply robust statistics to detect and remove outliers:
   - Identify and exclude outliers to improve data quality

7. Refine spectral reconstruction with outliers excluded:
   - Update the spectral reconstruction using the cleaned dataset

8. Output the final spectrum and associated uncertainties:
   - Provide the refined spectrum along with its confidence intervals

End
