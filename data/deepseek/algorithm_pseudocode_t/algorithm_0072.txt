Algorithm: Probabilistic Spectral Reconstruction

Input: 
- Photometric data (sparse, noisy) for each object
- Initial parameters: flux, magnitude, uncertainties

Output:
- Reconstructed spectral energy distribution (SED)
- Intrinsic color indices for taxonomic classification

1. For each object:
   1.1. Initialize Gaussian Mixture Model (GMM) parameters:
        - Number of components K (e.g., K = 3)
        - Mean (μ), variance (σ²), and mixing coefficients (π) for each component
   1.2. Define exponential disk function constraint for SED modeling
   1.3. Set up GMM with constraint that mixing coefficients follow exponential disk function

2. Iterate until convergence:
   2.1. E-step:
       a. Compute responsibilities for each data point using current GMM parameters
   2.2. M-step:
       a. Update GMM parameters (mean, variance, mixing coefficients) based on responsibilities
       b. Apply exponential disk function constraint during parameter update

3. Post-convergence:
   3.1. Compute SED using GMM parameters
   3.2. Determine intrinsic color indices using maximum likelihood mixing coefficients

Return: Reconstructed SED and intrinsic color indices
