**Algorithm: Probabilistic Spectral Reconstruction of Trans-Neptunian Objects**

1. **Initialize Parameters**
   - Set `prior_albedo`, `prior_size`, and `prior_temperature` based on known physical properties of TNOs.
   - Define `basis_functions` using modified Chebyshev polynomials.

2. **Define Basis Function Expansion**
   - Expand the spectral function using the `basis_functions`.
   - Determine the number of coefficients adaptively based on data information content.

3. **Set Up Bayesian Model**
   - Define the likelihood function relating observed photometric fluxes to the predicted fluxes.
   - Incorporate prior distributions for all model parameters.

4. **Markov Chain Monte Carlo (MCMC) Sampling**
   - Initialize MCMC chains with starting values derived from `prior_albedo`, `prior_size`, and `prior_temperature`.
   - Run MCMC to sample the posterior distribution of parameters and coefficients.

5. **Posterior Predictive Distribution**
   - Compute the posterior predictive distribution using MCMC samples.
   - Assess goodness-of-fit by comparing predicted fluxes with observed data.

6. **Outlier Detection**
   - Identify outliers in the data using the posterior predictive distribution.
   - Flag data points that significantly deviate from the predicted fluxes.

7. **Adaptive Basis Function Expansion Adjustment**
   - Adjust the number of basis functions based on the information content of the data.
   - Iterate until convergence or predefined stopping criteria are met.

8. **Final Model Evaluation**
   - Evaluate the final reconstructed SEDs for classification into taxonomic groups.
   - Output the optimized survey strategy based on identified informative bands.

This algorithm outlines the core computational steps of the probabilistic reconstruction framework, focusing on the Bayesian SED modeling and MCMC sampling process.
