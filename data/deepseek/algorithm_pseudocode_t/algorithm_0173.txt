Algorithm: Probabilistic Spectral Reconstruction Framework for Trans-Neptunian Objects

1. Initialize Gaussian Process (GP):
   - Set kernel parameters, e.g., length scale and variance.

2. For each TNO:
   a. Condition GP with sparse photometric flux measurements.
   b. Obtain posterior mean and variance of SED.
   c. Model reflectance spectra with two-component mixture distribution.
   d. Reconstruct SED using posterior GP.
   e. Classify SED into spectral type using pre-trained multinomial logistic regression.
   f. Identify anomalies based on high GP variance.

End
