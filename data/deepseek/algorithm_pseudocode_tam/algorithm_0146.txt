**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data Preparation**:
   - Collect sparse photometric measurements of TNOs.
   - Gather a reference set of near-IR spectra for training.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the reference spectra to obtain principal components (PCs).
   - Use the first 4-5 PCs for dimensionality reduction, capturing dominant spectral variability.

3. **Latent Space Definition**:
   - Project reference spectra onto the PCA basis to derive latent coefficients.
   - Apply Kernel Density Estimation (KDE) on the latent coefficients to define a continuous probability distribution.

4. **Synthetic Photometry Generation**:
   - For each augmented spectrum, convolve with the instrument's filter response functions (e.g., JWST/NIRCam).
   - Add 20% Gaussian noise to simulate realistic photometric uncertainties.

5. **AutoMLRegressor Training**:
   - Train an ensemble of Gradient Boosted Decision Trees (GBDTs) to map sparse photometry to latent coefficients.
   - Use the synthetic photometry and corresponding latent coefficients as training data.

6. **Forward Inference**:
   - For new photometric observations, pass them through the trained AutoMLRegressor to predict latent coefficients.
   - Invert the PCA transform using the predicted coefficients to reconstruct the full spectrum.

7. **Validation and Uncertainty Quantification**:
   - Perform leave-one-out cross-validation to assess reconstruction accuracy (Pearson R, RMSE, NMAE).
   - Draw Monte Carlo samples from the latent coefficient distribution to construct empirical credible intervals.
   - Verify if the original spectrum lies within the predicted credible intervals.

8. **Taxonomic Classification**:
   - Project latent coefficients into a pre-trained classifier to determine the probability distribution over spectral types.
   - Classify the object based on the highest probability taxonomic group.

9. **Outlier Detection**:
   - Flag objects whose spectral type probabilities are negligible across all predefined classes.
   - Identify potential new spectral types or anomalies.

10. **Survey Optimization**:
    - Evaluate different filter configurations to maximize information content for spectral reconstruction.
    - Select optimal filters that provide the tightest credible intervals for efficient observation planning.
