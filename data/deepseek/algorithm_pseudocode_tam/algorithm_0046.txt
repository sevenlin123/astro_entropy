The computational algorithm implements a probabilistic spectral reconstruction framework for Trans-Neptunian Objects (TNOs) using sparse photometry. Here's the pseudocode of the algorithm:

```
Algorithm: Probabilistic Spectral Reconstruction of TNOs

Input: 
- Reference spectra (training set)
- NIRCam filter definitions
- Observed sparse photometric data
Output:
- Reconstructed spectra
- Taxonomic classification probabilities

1. Initialize:
   a. Collect training set of TNO reference spectra.
   b. Define the number of principal components (K) (e.g., 8–10).

2. Preprocess:
   a. Perform Principal Component Analysis (PCA) on the reference spectra to compute principal component basis vectors.
   b. Augment the training set by generating synthetic spectra using non-parametric Kernel Density Estimation (KDE) to create a smooth latent manifold.

3. Training Phase:
   a. For each augmented synthetic spectrum:
      i. Compute the expected photometric measurements by integrating the spectrum through NIRCam filter curves.
      ii. Add Gaussian noise to simulate photometric uncertainties.
   b. Train an AutoML regressor to map the noisy photometry to the PCA coefficients.
   c. Additionally, train a separate AutoML classifier to map the PCA coefficients to taxonomic labels.

4. Validation Phase:
   a. For each spectrum in the test set (held-out for validation):
      i. Remove from the training set.
      ii. Compute photometry based on NIRCam filters.
      iii. Introduce Gaussian noise.
      iv. Pass through the trained regressor to get predicted PCA coefficients.
      v. Project coefficients back to full spectral space using inverse PCA.
      vi. Compare reconstructed spectrum with the actual spectrum to evaluate fidelity.

5. Taxonomic Classification:
   a. For each new observation:
      i. Pass sparse photometric data through the trained encoder to predict latent coefficients.
      ii. Simultaneously pass the predicted coefficients through the classifier to get taxonomic probabilities.

6. Outlier Detection:
   a. For unusual objects:
      i. Analyze photometric properties against the latent manifold.
      ii. Detect if they fall outside typical TNO spectra.

7. Final Adjustment:
   a. Assess residual differences between original and reconstructed spectra.
   b. Fine-tune the prior or adjust hyperparameters if systematic biases are found.

8. Output:
   a. Provide reconstructed spectra and taxonomic classification probabilities.
```

This algorithm efficiently reconstructs full spectra from sparse photometry by leveraging a probabilistic framework based on PCA and Bayesian inference, enabling accurate spectral mapping and taxonomic classification for TNOs.
