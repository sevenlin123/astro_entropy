To implement the probabilistic spectral reconstruction framework for Trans-Neptunian Objects (TNOs), follow these steps:

1. **Preprocess the Training Data**:
   - Select a curated set of 51 high-quality near-infrared TNO spectra representing dominant taxonomic classes.
   - Exclude rare or outlier spectra to focus on common types (e.g., Water, CO₂, Organics).

2. **Perform Principal Component Analysis (PCA)**:
   - Apply PCA to the selected spectra to extract principal components.
   - Determine the number of components (typically 4-5 for core classification, up to 10 for detailed reconstruction).

3. **Generate Synthetic Latent Space**:
   - Use Kernel Density Estimation (KDE) on the PCA coefficients to create a smooth probability distribution.
   - Set the KDE bandwidth to approximately 0.5 for stable results.

4. **Forward Model Photometry**:
   - Simulate photometric observations by convolving the spectra with JWST/NIRCam filter responses.
   - Add 20% Gaussian noise to the synthetic photometry to account for observational uncertainty.

5. **Train the AutoML Regressor**:
   - Use an ensemble of gradient-boosted decision trees (AutoGluon) to regress the noisy photometry onto the latent PCA coefficients.
   - This step maps photometric measurements to the compressed spectral representation.

6. **Validate Using Leave-One-Out Cross-Validation (LOOCV)**:
   - Remove one spectrum at a time from the training set.
   - Test the model's ability to reconstruct the removed spectrum from its synthetic photometry.
   - Assess reconstruction accuracy and credible interval coverage.

7. **Build Taxonomic Classifier**:
   - Train another AutoML model on the PCA coefficients to classify TNO spectra into taxonomic groups (e.g., H₂O, CO₂, Organics).
   - Use the latent space for clearer decision boundaries.

8. **Reconstruct Spectra from Photometry**:
   - For new observations, pass the photometric measurements through the trained regressor to obtain latent coefficients.
   - Project these coefficients back into the original spectrum space using the inverse PCA transform.

9. **Detect Outliers**:
   - Compute the probability density of the latent coefficients for new spectra.
   - Flag as outliers if the density falls below a threshold, indicating unusual spectral types.

10. **Optimize Survey Filters**:
    - Evaluate the information content of each NIRCam filter by measuring how much it constrains the latent coefficients.
    - Prioritize filters that provide the most information for future surveys.
