### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Preprocessing**:
   - Collect a set of reference TNO spectra, denoted as \( S_{\text{reference}} \).
   - Apply Principal Component Analysis (PCA) to \( S_{\text{reference}} \) to obtain principal components \( PC_1, PC_2, ..., PC_K \), where \( K \) is the number of principal components.

2. **Training the Latent Space**:
   - Project \( S_{\text{reference}} \) onto the PCA basis to get latent coefficients \( z \).
   - Use Kernel Density Estimation (KDE) to create a continuous probability distribution over the latent coefficients, smoothing the manifold.

3. **Generating Synthetic Photometry**:
   - For each augmented spectrum, compute the theoretical reflectance in each JWST/NIRCam filter by convolving the spectrum with the filter's throughput curve.
   - Inject Gaussian noise (20% relative reflectance uncertainty) into the synthetic photometry.

4. **Training the AutoML Regressor**:
   - Train an ensemble of gradient-boosted decision trees using the synthetic photometry as input and the latent coefficients as output.

5. **Forward Inference**:
   - For new sparse photometric observations:
     - Pass the photometry through the trained AutoML regressor to predict the latent coefficients \( z_{\text{predicted}} \).
     - Decode \( z_{\text{predicted}} \) using the inverse PCA transform to reconstruct the high-resolution spectrum.

6. **Taxonomic Classification**:
   - Project the predicted latent coefficients into the PCA basis.
   - Classify the spectrum using a pre-trained AutoML classifier based on the latent space representation.

7. **Validation**:
   - Perform Leave-One-Out Cross-Validation (LOOCV) by iterating through each reference spectrum as a test case, ensuring the framework generalizes reliably.

8. **Applications**:
   - **Survey Optimization**: Assess the information content of different filter configurations using mutual information between photometric measurements and latent spectral representations.
   - **Outlier Detection**: Identify unusual objects by clustering or anomaly detection in the latent space and reconstructing their spectra.
