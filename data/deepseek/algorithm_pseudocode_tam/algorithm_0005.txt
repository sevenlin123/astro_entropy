**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

**Input:**  
- Set of reference TNO spectra (training data)  
- Observed sparse photometric measurements (test data)  
- List of photometric filters (e.g., JWST/NIRCam)  

**Output:**  
- Reconstructed full spectra for each object  
- Probabilistic taxonomic classification for each object  

**Steps:**

1. **Preprocessing Training Data:**
   - Apply Principal Component Analysis (PCA) to the reference TNO spectra to extract principal components (PCs).  
   - The number of PCs (K) is determined by evaluating the variance explained, typically K = 4-5 for taxonomic classification and up to 8-10 for improved reconstruction fidelity.  
   - Project each reference spectrum onto the PCA basis to get latent coefficients.

2. **Augment Training Data:**
   - Use Kernel Density Estimation (KDE) with a bandwidth of ~0.5 to generate synthetic latent coefficients from the real coefficients.  
   - This creates a smooth, continuous manifold in the latent space, facilitating robust regression training.

3. **Forward Modeling Photometry:**
   - Convolve each augmented spectrum with the photometric filter throughput curves to compute theoretical reflectance in each filter band.  
   - Inject Gaussian noise (20% relative uncertainty) into the synthetic photometric measurements to simulate real-world observational noise.

4. **Training AutoML Regressor:**
   - Train an ensemble of Gradient Boosted Decision Trees (GBDTs) using AutoGluon to regress from sparse photometric measurements to latent coefficients.  
   - The training dataset consists of noisy synthetic photometry paired with their corresponding latent coefficients.

5. **Reconstructing Spectra:**
   - For each observed photometric measurement:
     - Use the trained AutoML regressor to predict the latent coefficients.  
     - Apply the inverse PCA transform to these coefficients to reconstruct the full spectrum.  
     - The reconstruction inherits the smoothness and physical features of the training population due to the PCA basis.

6. **Probabilistic Taxonomic Classification:**
   - Project the reconstructed latent coefficients into a pre-trained classifier that partitions the latent manifold based on taxonomic labels.  
   - Outputs a probability distribution over spectral types (e.g., H₂O, CO₂, Organics, Methanol).

7. **Cross-Validation (LOOCV):**
   - For each object, remove its spectrum from the training set, retrain the model, and test the reconstruction.  
   - Compare the reconstructed spectrum with the original to assess accuracy and evaluate credible interval coverage (e.g., 95%).

8. **Survey Design and Outlier Detection:**
   - Identify optimal filter combinations by simulating information content and minimizing reconstruction uncertainty.  
   - Detect rare spectral types by exploring extreme latent states that deviate significantly from the main manifold.

**End of Algorithm**
