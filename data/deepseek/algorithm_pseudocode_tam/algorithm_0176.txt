```python
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Initialize Data Preparation:
   - Input: Reference TNO spectra.
   - Normalize spectra by dividing each by its total flux.
   - Convert spectra into a suitable format for PCA analysis.

2. Execute PCA to Define Latent Space:
   - Apply PCA on the normalized spectra.
   - Retrieve principal component coefficients for each spectrum.
   - Save PCA eigenvectors and eigenvalues for later use.

3. Perform Data Augmentation:
   - Compute latent coefficients for each original spectrum.
   - Use KDE with bandwidth 0.5 to estimate the latent coefficient distribution.
   - Generate synthetic latent coefficients to expand the dataset.

4. Develop the Encoder Model:
   - Simulate photometric measurements by convolving synthetic spectra with instrument filters.
   - Add 20% Gaussian noise to these measurements.
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) using the noisy photometry and latent coefficients as inputs.

5. Implement Forward Inference:
   - For new photometric data, use the trained encoder to predict latent coefficients.
   - Transform these coefficients back into full spectra using inverse PCA.
   - Output the reconstructed spectrum as the posterior expectation.

This algorithm systematically reconstructs TNO spectra from sparse photometric data, ensuring accurate propagation of uncertainties and providing a robust framework for spectral analysis.
