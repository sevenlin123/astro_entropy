### Algorithm for Probabilistic Spectral Reconstruction of TNOs from Sparse Photometry

**Step-by-Step Explanation:**

1. **Preprocessing and PCA:**
   - Collect training spectral data of TNOs.
   - Perform PCA to reduce spectral dimensions into latent components.
   - Determine optimal number of PCA components (e.g., 4-5 for classification, 8-10 for detailed reconstruction).

2. **Data Augmentation:**
   - Use Kernel Density Estimation (KDE) to generate synthetic latent points, expanding the training set to improve model generalization.

3. **Model Training:**
   - Train an AutoML regressor to map sparse photometry to latent PCA coefficients.
   - Train a classifier on the latent space to predict spectral taxonomic classes.

4. **Inference Pipeline:**
   - For new photometric data, apply the trained regressor to get latent coefficients.
   - Use inverse PCA to reconstruct the full spectrum.
   - Classify the spectrum using the trained classifier.

5. **Validation and Post-Processing:**
   - Evaluate reconstruction accuracy using metrics like RMSE and credible interval coverage.
   - Check for outliers by assessing latent density.
