### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

**Step-by-Step Explanation:**

1. **Preprocessing of Reference Spectra**:
   - Normalize all reference spectra to unit variance to remove brightness differences.
   - Remove any missing or incomplete data points.

2. **Principal Component Analysis (PCA)**:
   - Apply PCA on the preprocessed reference spectra.
   - Determine the optimal number of principal components (typically 4-10) based on variance explained and scree plot analysis.

3. **Data Augmentation with Kernel Density Estimation (KDE)**:
   - Project the reference spectra onto the PCA latent space.
   - Use non-parametric KDE to generate synthetic latent vectors, creating a continuous manifold.

4. **Synthetic Photometry Generation**:
   - Convolve each synthetic spectrum with the instrumental response functions (e.g., JWST NIRCam filters).
   - Add Gaussian noise (20% relative uncertainty) to simulate realistic photometric measurements.

5. **Training the AutoML Regressor**:
   - Train an ensemble of Gradient-Boosted Decision Trees (GBDTs) using the synthetic photometry and corresponding PCA latent coefficients as input-output pairs.

6. **Forward Inference for Spectral Reconstruction**:
   - For new photometric observations, use the trained regressor to predict latent coefficients.
   - Apply inverse PCA transformation to reconstruct the full spectrum.

7. **LOOCV Validation**:
   - For each reference spectrum, hold it out during training.
   - Reconstruct the spectrum using the model and compare with the original.
   - Compute reconstruction error and check credible interval coverage.

8. **Taxonomic Classification**:
   - Project the predicted latent coefficients into a secondary classifier.
   - Classify the spectrum into predefined taxonomic categories (e.g., Water-type, CO₂-type, Organics-type).
