Algorithm:

1. Initialize Principal Component Analysis (PCA) with a training set of reference TNO spectra. Perform PCA decomposition to derive principal components.

2. Augment the latent space using Kernel Density Estimation (KDE) to create synthetic spectra, ensuring a smooth and continuous manifold.

3. Generate synthetic photometry by convolving each augmented spectrum with NIRCam filter curves and adding 20% Gaussian noise.

4. Train an AutoML regressor to map the synthetic photometry to the PCA coefficients.

5. For new photometric observations, pass them through the trained regressor to predict PCA coefficients.

6. Use inverse PCA transformation on the predicted coefficients to reconstruct the full spectrum.

7. Propagate uncertainty from regression residuals through the inverse PCA transformation to determine the uncertainty in the reconstructed spectrum.

8. Classify the spectrum using a secondary AutoML classifier trained on PCA coefficients and taxonomic labels.

9. Validate reconstruction fidelity using RMSE, credible interval coverage, and spectral feature consistency metrics.

10. Apply the framework to survey optimization by evaluating information content of filter configurations and to detect outliers based on deviation from the latent manifold.
