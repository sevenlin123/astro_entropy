Algorithm:

1. Initialize:
   - Collect training spectra (51 TNO seed spectra).
   - Perform Principal Component Analysis (PCA) on the training spectra to derive principal components.

2. Preprocess:
   - Project the training spectra into the PCA latent space.
   - Apply Kernel Density Estimation (KDE) with a smoothing bandwidth (h ≈ 0.5) to create a smooth prior distribution in the latent space.

3. Generate Synthetic Data:
   - For each augmented spectrum in the latent space:
     - Convolve with NIRCam filter curves to obtain mock photometry.
     - Add 20% Gaussian noise to simulate realistic photometric uncertainties.

4. Train AutoML Regressor:
   - Use synthetic photometry as input and latent coefficients as target.
   - AutoML framework selects optimal model (ensemble of Gradient Boosted Decision Trees).

5. Cross-Validation:
   - Perform Leave-One-Out Cross-Validation (LOOCV):
     - For each held-out spectrum, predict latent coefficients.
     - Reconstruct spectrum using inverse PCA transform.
     - Compute metrics: MAE, RMSE, R², credible interval coverage.

6. Taxonomy Classification:
   - Train secondary classifier on latent space for taxonomic labels.
   - Validate using LOOCV, assess classification accuracy and posterior probabilities.

7. Survey Optimization:
   - Evaluate NIRCam filter configurations by RMSE across training spectra.
   - Identify optimal filter combinations for high-fidelity reconstructions.

8. Outlier Detection:
   - For objects with photometry not fitting the latent manifold, identify low-probability spectral types.
   - Flag for detailed spectroscopic follow-up.

9. Output:
   - For each input photometry, output reconstructed spectrum and taxonomic probabilities.

Result:
- The algorithm provides statistically rigorous spectral reconstructions from sparse photometry, enabling comprehensive analysis of TNO populations in large-scale surveys.
