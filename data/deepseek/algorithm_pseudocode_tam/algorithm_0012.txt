The algorithm implementing the core reconstruction framework is structured as follows:

1. **Preprocess Training Spectra**: Collect and normalize the reference TNO spectra.
2. **Principal Component Analysis (PCA)**: Decompose the preprocessed spectra into principal components.
3. **Density Estimation**: Use Kernel Density Estimation (KDE) to create a continuous latent space from the PCA coefficients.
4. **Train AutoML Regressor**: Develop a model to map sparse photometric data to latent space coordinates.
5. **Reconstruct Spectra**:
   - For each new photometric observation:
     - Predict latent coefficients using the trained regressor.
     - Invert the PCA transformation to retrieve the reconstructed spectrum.
6. **Taxonomic Classification**: Classify the object based on its latent coefficients.
7. **Outlier Detection**: Assess if the object's latent density falls below a predefined threshold.

This structured approach efficiently translates sparse photometric data into detailed spectral reconstructions, enabling comprehensive analysis of TNO compositions.

The algorithm is represented in pseudocode as:

```
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input: Training spectra, sparse photometric observations
Output: Reconstructed spectra, taxonomic classifications, outlier detection

Begin

1. Preprocess the training set of TNO spectra by normalizing and removing anomalies.
2. Perform PCA on the preprocessed spectra to extract principal components, capturing the main spectral variations.
3. Generate a continuous latent space using KDE on the PCA coefficients to define the prior distribution.
4. Train an AutoML regressor to model the mapping from sparse photometric data to the latent PCA coefficients.
5. For each new observation:
    a. Use the regressor to predict the latent coefficients from the sparse photometry.
    b. Apply the inverse PCA transformation to reconstruct the full spectrum.
    c. Classify the object's taxonomic type based on the latent space.
    d. Check if the object is an outlier by comparing latent density to the training distribution threshold.
End
```
