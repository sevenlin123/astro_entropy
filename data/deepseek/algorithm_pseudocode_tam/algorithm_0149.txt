algorithm Probabilistic Spectral Reconstruction from Sparse Photometry:
    input: 
        - Training spectra (S_training)
        - Instrument response functions (filters)
        - Photometric observations (m_new)
    
    output:
        - Reconstructed spectra (S_reconstructed)
        - Taxonomic probabilities (class_probs)
    
    begin
    
    // Phase 1: Latent Space Definition
    1. Load training spectra S_training into memory.
    2. Perform PCA on S_training:
        a. Compute principal components (PCs) = PCA(S_training)
        b. Extract explained variance (explained_variance = PCA.explained_variance())
        c. Store inverse transformation (inverse_PCA = PCA.inverse_transform())
    
    // Phase 2: Data Augmentation
    3. Augment training data using KDE:
        a. Project S_training into latent space: latent_real = PCA.transform(S_training)
        b. Fit KDE to latent_real with bandwidth h = 0.5
        c. Sample synthetic_latent from KDE
        d. Combine synthetic_latent with latent_real for training
    
    // Phase 3: Forward Modeling
    4. Generate synthetic photometry:
        a. For each spectrum in synthetic_latent:
            i. Forward model to photometry using filters
            ii. Add noise (relative reflectance uncertainty of 20%)
    
    // Phase 4: Model Training
    5. Prepare training dataset:
        a. Pair synthetic photometry with corresponding synthetic_latent coefficients
    6. Train AutoML regressor:
        a. regressor = AutoML.train(training_dataset)
    
    // Phase 5: Reconstruction
    7. For each new photometry m_new:
        a. Predict latent coefficients using regressor: latent_pred = regressor.predict(m_new)
        b. Reconstruct spectrum S_reconstructed = inverse_PCA(latent_pred)
    
    // Additional Step: Taxonomic Classification
    8. Classify taxonomic type:
        a. Project latent_pred into taxonomic manifold
        b. class_probs = classifier.predict_proba(latent_pred)
    
    end
