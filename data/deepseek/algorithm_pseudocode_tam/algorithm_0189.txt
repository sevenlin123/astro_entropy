Algorithm:

1. **Input**: Observed photometric data of a trans-Neptunian object (TNO).
2. **Define Latent Space**:
   a. Collect and preprocess a training set of known TNO spectra, excluding rare or outlier types.
   b. Perform Principal Component Analysis (PCA) on the preprocessed spectra to extract principal components, capturing the dominant spectral variations.
3. **Data Augmentation**:
   a. Generate synthetic spectral data by convolving the known spectral features with the instrumental response functions (e.g., JWST/NIRCam filters) and add Gaussian noise to simulate realistic photometric measurements.
4. **Training Phase**:
   a. Use an AutoML regressor (e.g., Gradient Boosted Decision Trees) to train a model mapping the observed photometric data to the latent PCA coefficients.
5. **Inference Phase**:
   a. For the new object, apply the trained AutoML model to predict the latent PCA coefficients from the observed photometric data.
   b. Transform these coefficients back to the spectral space using the inverse PCA transformation to reconstruct the full spectrum.
6. **Output**: Reconstructed spectrum, uncertainties, and taxonomic classification probabilities based on the latent space analysis.
