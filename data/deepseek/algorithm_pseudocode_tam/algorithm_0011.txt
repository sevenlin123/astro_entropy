The algorithm begins by training a PCA model on a set of reference TNO spectra to create a low-dimensional latent space. Then, synthetic photometry is generated by convolving these spectra with JWST NIRCam filter responses. Gaussian noise is added to simulate realistic photometric uncertainties. An AutoML regressor is trained to map this noisy photometry to PCA coefficients. During inference, new photometry is fed through this regressor to predict coefficients, which are inverted using PCA to reconstruct the spectrum. The algorithm also includes a classifier to determine taxonomic types based on the latent space.

```
Algorithm: Probabilistic Spectral Reconstruction from Photometry

Input:
- Reference spectra: Set of TNO near-IR spectra
- Photometry: Observed sparse photometric measurements
- Filter profiles: JWST NIRCam filter responses

Output:
- Reconstructed spectrum: Full spectral energy distribution
- Taxonomic classification: Probabilistic assignment to spectral types

1. Train PCA model:
   a. Decompose reference spectra into principal components (PCs).
   b. Define latent space using top K PCs (e.g., K=5 to 10).

2. Generate synthetic photometry:
   a. Convolve each reference spectrum with filter profiles.
   b. Add Gaussian noise (20% relative uncertainty) to simulate photometric noise.

3. Prepare training data:
   a. Pair each reference spectrum with its corresponding synthetic photometry.
   b. Use as input for AutoML regressor training.

4. Train AutoML regressor:
   a. Learn mapping from noisy photometry to PCA coefficients.
   b. Ensemble of Gradient Boosted Decision Trees used for stability.

5. During inference:
   a. For new photometry:
      i. Predict PCA coefficients using trained regressor.
      ii. Apply inverse PCA transform to reconstruct full spectrum.
      iii. Classify taxonomic type based on latent space distribution.

6. Validate reconstruction:
   a. Use LOOCV to assess fidelity and uncertainty calibration.

End.
```
