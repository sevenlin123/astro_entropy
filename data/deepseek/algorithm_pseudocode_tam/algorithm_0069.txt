Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Initialize:
   - Input: Sparse photometric measurements of a TNO
   - Training Data: Set of reference TNO spectra (e.g., DiSCo-TNO sample)
   
2. Perform Principal Component Analysis (PCA):
   - Train PCA on the reference spectra to obtain principal components (latent space).
   
3. Augment Training Data:
   - Use Kernel Density Estimation (KDE) to create a smooth probability distribution in the latent space, expanding the training set with synthetic data points.
   
4. Generate Synthetic Photometry:
   - For each augmented spectrum, compute the expected photometric measurements by convolving with the instrument's filter response curves (e.g., JWST/NIRCam).
   - Add Gaussian noise (e.g., 20%) to simulate observational uncertainties.
   
5. Train AutoML Regressor:
   - Train an ensemble model (e.g., Gradient-Boosted Decision Trees) to map sparse photometry to latent space coordinates.
   
6. Predict Latent Coordinates:
   - For new photometric data, use the trained regressor to predict latent coefficients.
   
7. Reconstruct Spectrum:
   - Apply inverse PCA transformation to the predicted latent coefficients to obtain the full spectrum.
   
8. Compute Uncertainties:
   - Propagate uncertainties from latent space through PCA to get uncertainties in the reconstructed spectrum.
   
9. Validate:
   - Perform LOOCV to assess reconstruction accuracy and uncertainty coverage.
   
10. Classify Taxonomic Type:
    - Use a secondary classifier trained on latent space to assign probabilities to each taxonomic class.
    
11. Detect Outliers:
    - Calculate Jensen-Shannon divergence between latent distributions to identify anomalous spectra.
