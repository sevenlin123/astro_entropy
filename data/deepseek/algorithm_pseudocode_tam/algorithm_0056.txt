To implement the core reconstruction framework described in the paper, we focus on the steps necessary to reconstruct a spectrum from sparse photometric data. The process involves several key steps: preparing the dataset, training a regressor to map photometry to latent space, and then transforming the latent space back to the full spectrum. Here is the pseudocode for the algorithm:

1. **Prepare Training Data**:
   - **Input**: A set of reference TNO spectra (e.g., 51 spectra).
   - **Output**: Principal Component (PC) decomposition of the spectra.

2. **Perform PCA on Reference Spectra**:
   - Decompose the reference spectra into principal components.
   - Extract the principal component coefficients for each spectrum.

3. **Kernel Density Estimation (KDE) on Latent Space**:
   - Use the principal component coefficients to estimate the probability density in the latent space.
   - This step smooths the distribution, creating a continuous manifold.

4. **Generate Synthetic Photometry**:
   - Convolve each synthetic spectrum with the instrument's filter response curves (e.g., JWST NIRCam filters) to create simulated photometric measurements.

5. **Train AutoML Regressor**:
   - Use the synthetic photometric data to train an ensemble of gradient-boosted decision trees to predict the latent coefficients from photometry.

6. **Apply Regressor to New Photometric Data**:
   - For new photometric observations, use the trained regressor to predict the latent coefficients.

7. **Reconstruct Spectrum Using Inverse PCA**:
   - Transform the predicted latent coefficients back into the full spectrum using the inverse PCA transformation.

8. **Assess Reconstruction Quality**:
   - Compare the reconstructed spectrum with the true spectrum to evaluate accuracy.
