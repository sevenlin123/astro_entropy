### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

**Step-by-Step Pseudocode:**

1. **Input Data Preparation:**
   - Obtain a set of reference TNO spectra (training set).
   - Convert these spectra into photometric measurements using the target instrument's filter response curves (e.g., JWST/NIRCam filters).
   - Introduce Gaussian noise to simulate realistic photometric uncertainties.

2. **Principal Component Analysis (PCA):**
   - Perform PCA on the reference spectra to extract principal components (PCs).
   - Define a latent space using these PCs.

3. **Data Augmentation:**
   - Project the reference spectra onto the latent space.
   - Use Kernel Density Estimation (KDE) to create a smooth probability distribution in the latent space.
   - Generate synthetic latent vectors to augment the training data.

4. **Training the AutoML Regressor:**
   - Train an ensemble of Gradient Boosted Decision Trees (GBDTs) to regress from sparse photometry to latent space coefficients.
   - Use the synthetic data for regularization and stabilization of the regression model.

5. **Likelihood and Posterior Definition:**
   - Define the likelihood function based on the observed photometry.
   - Perform Bayesian inference to compute the posterior distribution of latent coefficients given the photometric observations.

6. **Spectral Reconstruction:**
   - Transform the posterior latent coefficients back into the full spectrum using the inverse PCA transformation.
   - Propagate uncertainties from photometry to the reconstructed spectrum.

7. **Taxonomic Classification:**
   - Train a classifier on the latent space to predict taxonomic categories (e.g., H₂O, CO₂, Organics, Methanol).
   - Use the predicted latent coefficients to classify the spectral type.

8. **Validation and Application:**
   - Perform leave-one-out cross-validation to assess reconstruction accuracy and uncertainty coverage.
   - Apply the framework to identify optimal filter combinations for future surveys and detect spectral outliers.

**End of Algorithm**
