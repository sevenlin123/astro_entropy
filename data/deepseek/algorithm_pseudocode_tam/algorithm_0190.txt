Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Initialize the Principal Component Analysis (PCA) model with a reference set of TNO spectra.
   - Input: Reference TNO spectra
   - Output: PCA basis vectors (principal components)

2. Train an AutoML regressor to map sparse photometric inputs to PCA latent coefficients.
   - Input: Sparse photometric measurements with added noise
   - Output: Trained AutoML regressor (encoder)

3. Augment the training data using Kernel Density Estimation (KDE) in the latent space.
   - Input: Latent coefficients from PCA
   - Output: Synthetic latent samples with smooth probability distribution

4. Perform forward modeling to simulate photometry from augmented spectra.
   - Input: Augmented spectra
   - Output: Simulated photometric measurements

5. For each test observation:
   a. Use the trained AutoML regressor to predict latent coefficients from sparse photometry.
   b. Project the latent coefficients back to the full spectrum using inverse PCA.
   c. Output the reconstructed spectrum and associated uncertainties.

6. Validate the reconstruction using leave-one-out cross-validation metrics (RMSE, credible interval coverage).
