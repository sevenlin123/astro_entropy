```pseudocode
Algorithm Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    Training Spectra Set S = {S_1, S_2, ..., S_N}
    Photometric Observations P = {P_1, P_2, ..., P_M}
    Target Filters F = {F_1, F_2, ..., F_K}

Output:
    Reconstructed Spectra R = {R_1, R_2, ..., R_M}
    Taxonomic Classifications C = {C_1, C_2, ..., C_M}

1. Define Latent Space:
    a. Perform PCA on Training Spectra Set S to extract principal components (PCs).
    b. Select K PCs (e.g., K = 8-10) based on variance explained.
    c. Project each spectrum in S onto the selected K PCs to form latent coefficient matrix L.

2. Augment Training Data:
    a. Apply Kernel Density Estimation (KDE) to latent coefficients in L to create a continuous manifold.
    b. Generate synthetic spectra using the KDE-defined manifold to increase training set size.
    c. Convolve each synthetic spectrum with the instrument's filter transmission curves to simulate photometric measurements.

3. TrainRegressor:
    a. For each augmented spectrum, generate forward-modeled photometry by convolving with target filters F.
    b. Inject Gaussian noise (e.g., 20% relative uncertainty) into the photometric measurements.
    c. Use AutoML (e.g., Gradient-Boosted Decision Trees) to train a regressor mapping noisy photometry to latent coefficients.

4. ForwardInference:
    a. For each object with sparse photometry P_i:
        i. Use the trained regressor to predict latent coefficients θ_i given P_i.
        ii. Project θ_i back through the inverse PCA transform to reconstruct the full spectrum R_i.
        iii. Classify θ_i using a trained classifier to assign a taxonomic label C_i.

5. Output Results:
    a. Collect all reconstructed spectra R and taxonomic classifications C.

End Algorithm
```
