**Algorithm for Probabilistic Spectral Reconstruction of Trans-Neptunian Objects from Sparse Photometry**

1. **Input Data Preparation**
   - Obtain a set of reference TNO spectra.
   - Extract sparse photometric observations from these spectra.

2. **Principal Component Analysis (PCA)**
   - Perform PCA on the reference spectra to derive principal components.
   - Determine the number of principal components (K) that best capture the spectral variability (e.g., 4-5 for taxonomic classification, 8-10 for detailed reconstruction).

3. **Data Augmentation**
   - Project the reference spectra onto the derived PCA latent space.
   - Use Kernel Density Estimation (KDE) to create a smooth probability distribution in the latent space, generating synthetic latent vectors.
   - Inject Gaussian noise (e.g., 20% relative reflectance uncertainty) into synthetic photometry for training robustness.

4. **Training the Encoder**
   - Train an AutoML regressor (e.g., Gradient-Boosted Decision Trees) to map sparse photometry to latent coefficients.
   - Use synthetic photometry and corresponding latent vectors for training.

5. **Forward Modeling**
   - Simulate photometric observations by convolving spectra with JWST/NIRCam filter responses.

6. **Cross-Validation**
   - Apply Leave-One-Out Cross-Validation (LOOCV) to validate the model.
   - For each iteration, exclude one spectrum, use the rest for training, and validate the excluded spectrum.

7. **Spectral Reconstruction**
   - For new photometric observations, predict latent coefficients using the trained encoder.
   - Decode these coefficients back into full spectra using inverse PCA transformation.

8. **Taxonomic Classification**
   - Train a secondary AutoML classifier on the latent coefficients to classify spectra into predefined taxonomic categories (e.g., H₂O, CO₂, Organic, Methanol).
   - Evaluate classification accuracy using LOOCV.

9. **Outlier Detection**
   - Identify spectra whose latent coefficients significantly differ from the training manifold, indicating unusual spectral types.

10. **Survey Optimization**
    - Simulate various filter configurations to assess their information content and optimize for efficient spectral reconstruction.

**End Algorithm**
