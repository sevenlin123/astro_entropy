To implement the core reconstruction framework described in the paper, follow these steps:

1. **Principal Component Analysis (PCA):**
   - Train a PCA model on a set of reference TNO spectra to define a low-dimensional latent space.
   - Use the PCA model to project the reference spectra into this latent space.

2. **Data Augmentation with Kernel Density Estimation (KDE):**
   - Apply KDE to the latent space of the PCA model to create a continuous probability distribution.
   - Generate synthetic latent vectors to augment the training data.

3. **Training the AutoML Regressor:**
   - Convert each augmented synthetic latent vector into synthetic photometry using the NIRCam filter set.
   - Inject Gaussian noise (e.g., 20% uncertainty) into the synthetic photometry.
   - Train an AutoML regressor to predict the latent coefficients from the noisy photometry.

4. **Training the Taxonomic Classifier:**
   - Project the augmented latent vectors into the PCA space.
   - Train a secondary AutoML classifier to classify these latent vectors into taxonomic categories (e.g., H₂O, CO₂, Organic, Methanol).

5. **Reconstruction and Classification Pipeline:**
   - For new photometric observations:
     - Use the trained AutoML regressor to predict the latent coefficients.
     - Apply the inverse PCA transform to obtain the reconstructed spectrum.
     - Use the classifier to determine the taxonomic classification.

**Steps Explained:**

1. **PCA Training:** Reference spectra are projected into a lower-dimensional space, capturing the main spectral variations.

2. **Data Augmentation:** Synthetic latent vectors are generated to smooth the manifold, enhancing the model's stability.

3. **Regressor Training:** The AutoML regressor maps photometry to latent coefficients, incorporating noise to simulate realistic data conditions.

4. **Classifier Training:** Latent vectors are classified into taxonomic groups, leveraging the structured latent space for improved accuracy.

5. **Pipeline Execution:** For new data, latent coefficients are predicted, used to reconstruct the spectrum, and determine the taxonomic class, providing both spectral and compositional information.
