To implement the core reconstruction framework, the algorithm focuses on the Bayesian inference and PCA-based latent space methodology described in the paper. Below is the pseudocode for the algorithm:

Initialize with near-infrared spectra of TNOs, photometric data, and instrument-specific filter profiles.

1. **Training Phase:**
   - Perform Principal Component Analysis (PCA) on a selected set of reference TNO spectra to extract principal components (PCs).
   - Use Kernel Density Estimation (KDE) to smooth the latent space, creating a continuous probability distribution of the spectral manifold.
   - Generate synthetic photometry for each augmented spectrum by convolving with the instrument's filter profiles (e.g., JWST/NIRCam).
   - Introduce noise (e.g., 20% relative reflectance uncertainty) to simulate real photometric uncertainties.
   - Train an AutoML regressor (e.g., Gradient-Boosted Decision Trees) to map photometric inputs to latent coefficients.
   - Train a secondary AutoML classifier for taxonomic classification within the latent space.

2. **Inference Phase:**
   - For new photometric observations:
     - Use the trained AutoML regressor to predict latent coefficients.
     - Apply the inverse PCA transform to reconstruct the full spectrum.
     - Optionally, use the classifier to determine the probability distribution over taxonomic classes.

The algorithm efficiently reconstructs spectra and performs taxonomic classification using the latent space representation and Bayesian principles.
