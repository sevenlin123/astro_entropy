Algorithm:

1. Preprocess the dataset:
   - Apply Principal Component Analysis (PCA) on the reference TNO spectra to derive a set of principal components.
   - Use Kernel Density Estimation (KDE) to create a continuous probability distribution in the latent space.
   - Generate synthetic photometric observations by convolving the spectra with the instrument's filter curves and adding Gaussian noise.

2. Train the AutoML regressor:
   - Use the synthetic photometric data and corresponding PCA coefficients as training inputs.
   - Train an ensemble of gradient-boosted decision trees to predict latent coefficients from photometric inputs.

3. Perform Leave-One-Out Cross-Validation (LOOCV):
   - For each object in the training set:
     a. Remove the object from the training set.
     b. Use the regressor to predict latent coefficients from the synthetic photometry.
     c. Project the latent coefficients back to the full spectrum using inverse PCA.
     d. Compare the reconstructed spectrum with the true spectrum.
     e. Evaluate metrics like RMSE, coverage, and MAD.

4. Classify taxonomic types:
   - Train a secondary classifier on the PCA coefficients to predict taxonomic labels (e.g., Water, CO₂, Organic, Methanol).
   - Use the classifier to assign taxonomic probabilities to new objects.

5. Optimize filters and detect outliers:
   - Analyze the latent manifold to determine the most informative filter configurations.
   - Identify objects whose reconstructed spectra fall outside the manifold as potential outliers.
