**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input:** Sparse photometric measurements of a Trans-Neptunian Object (TNO).

2. **Preprocessing:**
   - Convert photometric measurements into a normalized format suitable for processing.
   - Apply noise considerations if necessary.

3. **Define Latent Space:**
   - Perform Principal Component Analysis (PCA) on a reference set of TNO spectra to extract principal components.
   - Construct a latent space using these components.

4. **Data Augmentation:**
   - Use Kernel Density Estimation (KDE) to generate synthetic data points in the latent space, creating a smooth manifold.
   - Introduce Gaussian noise to simulate real-world photometric uncertainties.

5. **Training Phase:**
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map photometric inputs to latent space coefficients.
   - Ensure model generalization through proper regularization and feature selection.

6. **Reconstruct Spectrum:**
   - Use the trained regressor to predict latent coefficients from the sparse photometry.
   - Apply the inverse PCA transformation to these coefficients to obtain the reconstructed high-resolution spectrum.

7. **Taxonomic Classification:**
   - Project the latent coefficients into a pre-trained classifier to determine the spectral type (e.g., Water-type, CO₂-type, Organics-type).
   - Obtain probability distributions over possible classifications.

8. **Uncertainty Propagation:**
   - Calculate the variance-covariance matrix of the latent coefficients.
   - Transform this matrix through the inverse PCA to estimate uncertainties in the reconstructed spectrum.

9. **Outlier Detection:**
   - Compare the reconstructed spectrum against the expected manifold.
   - Flag objects with significant deviations as outliers for further analysis.

10. **Output:** The reconstructed high-resolution spectrum, associated uncertainties, and taxonomic classification probabilities.
