```plaintext
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input: Set of sparse photometric observations of TNOs, reference spectra, filter response curves

Output: Reconstructed high-resolution spectra and taxonomic classifications

1. Initialize Training Data:
   - Collect N = 51 reference TNO spectra from DiSCo-TNO sample.

2. Perform Principal Component Analysis (PCA):
   - Decompose training spectra into K principal components, capturing dominant spectral variability.

3. Construct Latent Space Prior:
   - Compute PCA scores for training spectra.
   - Apply Kernel Density Estimation (KDE) to scores to create continuous probability distribution.

4. Generate Synthetic Spectra:
   - For each synthetic latent vector sampled from KDE:
     a. Inverse PCA transform to get spectral coefficients.
     b. Convolve with filter responses to compute synthetic photometry.

5. Prepare Training Dataset:
   - Combine synthetic photometric measurements with corresponding PCA targets.

6. Train AutoML Regressor:
   - Use ensemble of gradient-boosted decision trees to regress photometry to latent coefficients.

7. Define Inference Pipeline:
   - For new photometric observations:
     a. Predict latent coefficients using trained regressor.
     b. Inverse PCA transform to reconstruct full spectrum.
     c. Classify spectral type based on latent space.

8. Output Results:
   - Reconstructed spectrum, taxonomic probabilities, and outlier flags.
```
