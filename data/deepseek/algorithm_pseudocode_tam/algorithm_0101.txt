**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Input Data Preparation**
   - Collect and preprocess a set of reference TNO spectra for training.
   - Extract sparse photometric measurements (e.g., 2-6 bands) for target objects.

2. **Principal Component Analysis (PCA)**
   - Perform PCA on the reference spectra to derive principal components (PCs).
   - Determine the optimal number of PCs (K) that balance manifold coverage and numerical stability (typically 5-10).

3. **Latent Space Definition**
   - Project the reference spectra onto the PCA basis to obtain latent coefficients.
   - Use Kernel Density Estimation (KDE) to smooth the latent space, creating a continuous probability distribution.

4. **Synthetic Photometry Generation**
   - Convolve the smoothed spectra with filter transmission curves (e.g., JWST NIRCam) to generate synthetic photometric data.
   - Inject Gaussian noise (e.g., 20%) to simulate realistic observational uncertainties.

5. **Automated Machine Learning (AutoML) Training**
   - Train an ensemble AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to latent coefficients.
   - Simultaneously train a taxonomic classifier using latent space features.

6. **Forward Inference Pipeline**
   - For new photometric observations:
     - Use the trained regressor to predict latent coefficients.
     - Apply inverse PCA transform to reconstruct the full spectrum.
     - Classify the object into taxonomic groups based on latent space features.

7. **Validation and Uncertainty Propagation**
   - Perform Leave-One-Out Cross-Validation (LOOCV) to assess RMSE and credible interval coverage.
   - Evaluate robustness to varying photometric noise and missing data.

8. **Survey Optimization and Outlier Detection**
   - Analyze filter configurations for maximal information content.
   - Identify outliers by detecting posterior distributions diverging from the training manifold.

**End Algorithm**
