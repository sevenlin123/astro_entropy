**Algorithm: Probabilistic Spectral Reconstruction via Bayesian Inference on Reduced Space**

1. **Principal Component Analysis (PCA) Training**: 
   - Train PCA on a comprehensive dataset of near-infrared spectra to derive principal components capturing the essential spectral variability.

2. **Probabilistic Model Setup**: 
   - Construct a probabilistic model using the principal components as latent variables to represent the spectral features.

3. **Bayesian Inference**: 
   - Perform Bayesian inference in the reduced principal component space to estimate the underlying spectral features from sparse photometric observations.

4. **Uncertainty Propagation**: 
   - Account for measurement uncertainties in photometric data within the Bayesian framework to propagate uncertainties in the reconstructed spectra.

5. **Spectral Reconstruction**: 
   - Use the inferred principal components to reconstruct the full spectra, incorporating uncertainties to assess credible intervals.

This algorithm efficiently leverages dimensionality reduction and Bayesian techniques to reconstruct detailed spectra from limited photometric data, enabling taxonomic classification and outlier detection.
