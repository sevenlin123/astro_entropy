**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Preprocess Photometric Data**: Convert photometric measurements into normalized features suitable for the PCA model.

2. **Train PCA Model**: Apply Principal Component Analysis on a training set of near-infrared spectra to derive principal component basis vectors.

3. **Bayesian Inference**: For each object, use Bayesian methods in the PCA latent space to estimate the principal component coefficients based on its photometric data.

4. **Spectral Reconstruction**: Reconstruct the full spectrum by combining the estimated coefficients with the PCA basis vectors.

5. **Uncertainty Propagation**: Calculate uncertainties in the reconstructed spectrum by propagating errors from photometric measurements through the Bayesian model.

This algorithm efficiently reconstructs spectra from sparse photometry, leveraging PCA for dimensionality reduction and Bayesian inference for robust estimation.
