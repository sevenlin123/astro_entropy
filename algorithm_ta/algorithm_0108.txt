### Core Computational Algorithm for Probabilistic Spectral Reconstruction

1. **Preprocessing**:
   - Collect and normalize the input photometric data of TNOs.
   - Remove any outliers or anomalies in the photometric measurements.

2. **Principal Component Analysis (PCA)**:
   - Train a PCA model using a reference set of near-IR spectra.
   - Determine the optimal number of principal components (e.g., 4-5 for classification; 8-10 for detailed reconstruction).
   - Extract the principal component coefficients and loadings from the PCA model.

3. **Bayesian Inference in Reduced Space**:
   - Set up a probabilistic model in the PCA latent space.
   - Define prior distributions for the latent variables based on the reference spectra.
   - Use Markov Chain Monte Carlo (MCMC) or variational inference to perform Bayesian inference.
   - Propagate measurement uncertainties from photometry to the latent space.

4. **Spectral Reconstruction**:
   - Reconstruct the full spectrum for each TNO using the inferred latent variables.
   - Apply uncertainty quantification to the reconstructed spectra.
   - Validate the empirical credible interval coverage (e.g., ~95%).

5. **Survey Optimization**:
   - Quantify the information content of NIRCam filters (e.g., F090W, F115W, etc.) using the framework.
   - Identify optimal filter combinations for maximizing spectral reconstruction fidelity.

6. **Outlier Detection and Rare Spectral Types**:
   - Apply the framework to detect outliers by constraining photometry to select low-probability intermediate models.
   - Reconstruct rare spectral types like peculiar Neptune Trojans by allowing exploration of the continuous spectral manifold.

7. **Posterior Analysis and Reporting**:
   - Summarize the posterior distributions of the latent variables.
   - Generate diagnostic plots and metrics to assess convergence and model fit.
   - Output reconstructed spectra along with associated uncertainties for each TNO.

This algorithm provides a systematic approach to probabilistically reconstructing spectra from sparse photometry, enabling taxonomic classification, survey optimization, and outlier detection for trans-Neptunian objects.
