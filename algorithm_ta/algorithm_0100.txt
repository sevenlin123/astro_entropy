**Algorithm for Probabilistic Spectral Reconstruction**

1. **Preprocess the Spectral Data**: Normalize and align the near-IR spectral data to handle any offsets or distortions.

2. **Principal Component Analysis (PCA)**: Decompose the preprocessed spectral data into principal components (PCs). This captures the main modes of spectral variability.

3. **Bayesian Model Setup**: Define a Bayesian model where the observed photometric data is modeled using the PCA basis. Specify prior distributions for the model parameters.

4. **Bayesian Inference**: Use Markov Chain Monte Carlo (MCMC) or another sampling method to infer the posterior distribution of the PCA coefficients given the photometric data. This step reconstructs the underlying spectral components.

5. **Spectral Reconstruction**: Transform the inferred PCA coefficients back into the full spectral space to obtain the reconstructed spectrum.

6. **Uncertainty Propagation**: Calculate uncertainties in the reconstructed spectra by evaluating the variance in the posterior distributions of the PCA coefficients and propagating these uncertainties through the PCA transformation.

This algorithm efficiently reconstructs the full spectrum from sparse photometry using a probabilistic approach in a reduced PCA space.
