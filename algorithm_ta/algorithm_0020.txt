**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data**: Obtain sparse photometric measurements of trans-Neptunian objects.

2. **PCA Model Initialization**: 
   - Train a Principal Component Analysis (PCA) model on a dataset of near-infrared spectral measurements.
   - Determine the optimal number of principal components (e.g., 8-10) to capture spectral variability.

3. **Bayesian Inference Setup**:
   - Represent the spectral manifold using the PCA latent space.
   - Set up a Bayesian framework to infer latent variables from photometric data, incorporating measurement uncertainties.

4. **Spectral Reconstruction**:
   - Use the trained PCA model to map photometric data into the latent space via Bayesian inference.
   - Reconstruct the full spectral representation from the inferred latent variables.

5. **Uncertainty Quantification**:
   - Propagate measurement uncertainties through the model to assess credible intervals for the reconstructed spectra.

6. **Output**: Generate reconstructed spectra with associated uncertainties, enabling taxonomic classification and outlier detection.
