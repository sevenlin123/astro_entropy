**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Principal Component Analysis (PCA) Training**:  
   - Train a PCA model on a dataset of near-infrared spectra to obtain a reduced-dimensional representation (principal components).

2. **Bayesian Inference in Reduced Space**:  
   - Perform Bayesian inference using the principal components derived from the PCA model to reconstruct full spectra from sparse photometric measurements.  
   - Propagate measurement uncertainties through the Bayesian framework.

3. **Determine Optimal Principal Components**:  
   - Use leave-one-out cross-validation to identify the optimal number of principal components required for accurate spectral reconstruction.  
   - For taxonomic classification, typically 4-5 components are sufficient. For higher fidelity reconstruction, 8-10 components are recommended.

4. **Spectral Reconstruction**:  
   - Reconstruct the full spectrum for each object using the trained PCA model and Bayesian inference.  
   - Quantify the uncertainty (credible intervals) of the reconstructed spectra.

5. **Survey Optimization**:  
   - Apply the framework to evaluate the information content of different observing configurations (e.g., JWST/NIRCam filters).  
   - Identify filter combinations that maximize the ability to reconstruct spectra and classify TNOs.

6. **Outlier Detection**:  
   - Use the reconstructed spectra to detect rare or peculiar objects by identifying cases where the observed photometry significantly deviates from the expected spectral model distribution.

7. **Application to Object Classification**:  
   - Classify objects into taxonomic categories based on their reconstructed spectra.  
   - Identify unusual spectral types by constraining photometry to select low-probability intermediate models.
