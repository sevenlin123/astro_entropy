The algorithm involves preprocessing photometric data, training a PCA model on a reference spectral library, performing Bayesian inference in the latent space to estimate the posterior distributions of the underlying LPC coefficients for each object, and then propagating these uncertainties through the PCA transformation to compute the full spectrum.

Step 1: Preprocess the photometric data into a normalized flux vector. This includes correcting for instrument response, applying zero points, and applying extinction corrections to account for interstellar dust.

Step 2: Train a Principal Component Analysis (PCA) model using a reference spectral library of trans-Neptunian objects. This generates a set of principal components that capture the main spectral variations in the data.

Step 3: For each object, use Bayesian inference in the latent space defined by the PCA model to estimate the posterior distributions of its underlying principal component coefficients (LPCs). This step quantifies the uncertainty in the estimated coefficients.

Step 4: Propagate the uncertainties from the posterior distributions of the LPCs through the PCA transformation to compute the full reconstructed spectrum. This provides both the best estimate of the spectrum and the associated uncertainties.

This process allows for the reconstruction of full spectra from sparse photometric measurements, enabling taxonomic classification, survey optimization, and outlier detection.
