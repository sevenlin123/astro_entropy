**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

**Input:**  
- Sparse photometric measurements of Trans-Neptunian Objects (TNOs)  
- Pre-trained Principal Component Analysis (PCA) model derived from near-infrared (near-IR) spectra  
- Parameters including the number of principal components (e.g., 4-5 for taxonomic classification, up to 8-10 for improved fidelity)  

**Output:**  
- Reconstructed near-IR spectra for each TNO  
- Uncertainty estimates for the reconstructed spectra  
- Probabilistic classification framework for taxonomic analysis  

**Steps:**  
1. **Dimensionality Reduction with PCA:** Apply the pre-trained PCA model to the input sparse photometric data to project it into the lower-dimensional latent space.  
2. **Bayesian Inference in Latent Space:** Perform Bayesian inference within the reduced space to estimate the most probable spectral representation, considering the measurement uncertainties.  
3. **Reconstruct Full Spectra:** Use the posterior distribution from the Bayesian inference to reconstruct the full near-IR spectra.  
4. **Uncertainty Propagation:** Quantify the uncertainties in the reconstructed spectra, ensuring accurate error margins.  
5. **Model Evaluation:** Validate the reconstructed spectra against empirical data to assess credible interval coverage.  
6. **Survey Optimization Application:** Identify optimal filter configurations for future observations by evaluating the information content of different NIRCam filters.  
7. **Outlier Detection:** Utilize the framework to detect unusual spectral types by constraining photometric data and identifying low-probability intermediate models.
