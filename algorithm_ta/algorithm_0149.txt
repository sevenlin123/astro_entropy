Algorithm PSR-TNO  
Input: Sparse photometric data of TNOs, Training set of near-IR spectra  
Output: Reconstructed spectral data with uncertainty estimates  

Steps:  

1. **Preprocessing**:  
    1.1. Obtain and normalize the training set of near-infrared (near-IR) spectra.  
    1.2. Apply Principal Component Analysis (PCA) to reduce the dimensionality of the training spectra, extracting the dominant principal components.  

2. **Model Initialization**:  
    2.1. Construct a probabilistic latent-space model using the PCA-reduced training spectra.  
    2.2. Establish a Bayesian inference framework within this reduced space to model spectral variability.  

3. **Training**:  
    3.1. Train the latent-space model using the preprocessed PCA components to estimate model parameters.  

4. **Data Processing**:  
    4.1. Transform sparse photometric measurements into a compatible format for spectral reconstruction.  
    4.2. Extract features from the photometric data relevant for reconstructing the latent spectral representation.  

5. **Spectral Reconstruction**:  
    5.1. For each TNO:  
        5.1.1. Infer the latent-space representation using the trained model and photometric data.  
        5.1.2. Reconstruct the full near-IR spectrum by mapping the inferred latent variables back to the original spectral space.  
        5.1.3. Propagate measurement uncertainties from the photometric data to the reconstructed spectra to estimate uncertainties.  

6. **Validation (Optional)**:  
    6.1. Conduct leave-one-out cross-validation to evaluate the accuracy of the reconstructed spectra.  
    6.2. Adjust the number of principal components used based on cross-validation results to optimize reconstruction fidelity.  

7. **Output**:  
    7.1. Generate the reconstructed spectra along with their uncertainty estimates.  
    7.2. Optionally, perform outlier detection to identify peculiar spectral types like unusual Neptune Trojans.  

End Algorithm
