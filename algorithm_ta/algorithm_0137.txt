### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Precompute Principal Component Analysis (PCA) Model**  
   - Train a PCA model using a sample of near-infrared (near-IR) spectra of TNOs.  
   - Retain 8–10 principal components to capture high-fidelity spectral reconstruction.  

2. **Extract Photometric Data**  
   - Obtain sparse photometric measurements (e.g., from JWST/NIRCam filters).  
   - Each object has a set of photometric fluxes corresponding to specific wavelengths.  

3. **Map Photometric Fluxes to Latent Space**  
   - Project the photometric data into the precomputed PCA latent space.  
   - Use the PCA components to represent the spectral manifold of TNOs.  

4. **Perform Bayesian Inference in PCA Space**  
   - Apply Bayesian methods to infer the underlying spectral parameters in the latent space.  
   - Propagate measurement uncertainties from photometry to the latent space.  

5. **Reconstruct Full Spectra**  
   - Transform the inferred latent-space parameters back to the original spectral space.  
   - Use the PCA basis vectors to reconstruct the full near-IR spectrum.  

6. **Uncertainty Quantification**  
   - Propagate the uncertainties from the photometric measurements through the Bayesian inference and PCA reconstruction.  
   - Calculate credible intervals for the reconstructed spectra.  

7. **Survey Optimization**  
   - Evaluate the information content of different filter configurations.  
   - Select optimal filter combinations for maximizing spectral reconstruction fidelity.  

8. **Outlier Detection and Rare Spectral Types**  
   - Analyze the latent space to identify objects with unusual spectral properties.  
   - Detect peculiar cases like Neptune Trojans by constraining photometry to select low-probability intermediate models.
