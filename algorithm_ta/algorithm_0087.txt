**Algorithm: Type Ia Supernova Classification**

1. **Data Preprocessing**:
   - Acquire the dataset containing astronomical events with features like light curve patterns and spectral lines.
   - Clean the data by addressing missing values, outliers, and normalizing features.

2. **Feature Extraction**:
   - Extract key features such as light curve rise time, peak brightness, decay time, color evolution, and spectral lines indicative of Type Ia supernovae.

3. **Dimensionality Reduction**:
   - Apply PCA to reduce dimensionality, retaining significant information for classification.

4. **Model Training**:
   - Train a machine learning model (e.g., Random Forest, SVM) on the reduced features, optimizing hyperparameters via cross-validation.

5. **Classification and Validation**:
   - Predict event probabilities using the trained model and evaluate performance metrics (accuracy, precision, recall).

6. **Outlier Detection**:
   - Identify events with low probabilities of being Type Ia supernovae.

7. **Output**:
   - Provide events with predicted probabilities and uncertainties for further analysis.
