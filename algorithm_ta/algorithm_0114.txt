The algorithm begins with preprocessing the sparse photometric data to convert it into a normalized form. Next, Principal Component Analysis (PCA) is applied to a training set of known TNO spectra to create principal components capturing main spectral features. These components are used in a Bayesian framework to model the spectral space, where each object's spectrum is represented as a linear combination of these components. Finally, Bayesian inference reconstructs the spectrum for each TNO using the PCA space and sparse photometric data, propagating measurement uncertainties.
