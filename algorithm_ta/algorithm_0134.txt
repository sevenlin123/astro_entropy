**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Data Preparation**: 
   - Collect a training dataset comprising near-infrared (near-IR) spectra of trans-Neptunian objects (TNOs).

2. **Preprocessing**:
   - Normalize the spectral data to ensure all measurements are on a comparable scale.
   - Remove outliers from the training set to improve model accuracy.

3. **Principal Component Analysis (PCA)**:
   - Apply PCA to the preprocessed training data to extract principal components, capturing the most significant variations in the spectra.

4. **Determine Optimal Components**:
   - Use leave-one-out cross-validation (LOOCV) to identify the optimal number of principal components (typically 4-5 for classification, 8-10 for high-fidelity reconstruction).

5. **Probabilistic Model Construction**:
   - Develop a probabilistic model in the reduced latent space defined by the selected principal components.

6. **Bayesian Inference**:
   - For each TNO, employ Bayesian methods within the latent space to reconstruct the full spectrum using sparse photometric measurements.

7. **Uncertainty Propagation**:
   - Quantify uncertainties in the reconstructed spectra by propagating measurement uncertainties through the model.

8. **Model Application**:
   - Utilize the trained model for tasks such as survey optimization, identifying optimal NIRCam filters, and detecting unusual spectral types (e.g., peculiar Neptune Trojans) by constraining photometry to select low-probability intermediate models.
