The core computational algorithm for the probabilistic spectral reconstruction framework involves the following steps:

1. **Principal Component Analysis (PCA):**
   - Train a PCA model on a reference sample of near-infrared (near-IR) spectra of trans-Neptunian objects (TNOs).
   - This PCA captures the dominant modes of spectral variability in the dataset.

2. **Probabilistic Latent-Space Model:**
   - Represent the spectral data in a reduced dimensional space using the PCA.
   - Construct a probabilistic model in this latent space to quantify the uncertainty and propagate it through the inversion process.

3. **Bayesian Inference in Reduced Space:**
   - Use the probabilistic model to perform Bayesian inference, reconstructing the full spectrum from sparse photometric measurements.
   - This step leverages the reduced-dimensional representation obtained from PCA.

4. **Cross-Validation for Dimensionality Selection:**
   - Determine the optimal number of principal components (e.g., 4-5 for classification, 8-10 for improved fidelity) using leave-one-out cross-validation.

5. **Spectral Reconstruction:**
   - Reconstruct the full spectrum of each TNO using the trained model and available photometric measurements.
   - Propagate measurement uncertainties through the reconstruction process to assess the reliability of the results.

6. **Survey Optimization and Filter Selection:**
   - Apply the framework to evaluate the information content of different filter configurations for future observations.
   - Select optimal filters (e.g., JWST/NIRCam filters like F090W, F115W, F410M, F460M) to maximize the retention of spectral information.

7. **Outlier Detection and Rare Spectral Type Reconstruction:**
   - Allow the model to consider intermediate low-probability solutions to detect and reconstruct rare or peculiar spectral types, such as those of Neptune Trojans.

This structured approach effectively bridges the gap between sparse photometric data and detailed spectral analysis, enabling robust taxonomic classification and compositional mapping of TNOs.
