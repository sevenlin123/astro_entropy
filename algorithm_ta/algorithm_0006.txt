**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Training Phase:**
   - Train a Principal Component Analysis (PCA) model using a reference dataset of near-infrared (near-IR) spectra of trans-Neptunian objects (TNOs).
   - Determine the optimal number of principal components (e.g., 4-5 for taxonomic classification, 8-10 for improved reconstruction fidelity).

2. **Data Processing for Each Object:**
   - Extract sparse photometric measurements of the TNO.
   - Transform the photometric data into a feature vector.

3. **Latent Space Inference:**
   - Project the feature vector into the pre-trained PCA latent space.
   - Perform Bayesian inference in this reduced space to estimate the posterior distribution of the latent variables (principal components).

4. **Spectral Reconstruction:**
   - Reconstruct the full near-IR spectrum using the estimated latent variables from Bayesian inference.
   - Propagate measurement uncertainties from the photometric data to the reconstructed spectrum.

5. **Uncertainty Quantification:**
   - Compute credible intervals for the reconstructed spectrum to assess the uncertainty propagation.

6. **Output:**
   - Generate the reconstructed spectrum and associated uncertainty intervals for each TNO.

This algorithm effectively bridges sparse photometric data with spectral reconstruction, enabling taxonomic classification and outlier detection in minor planets.
