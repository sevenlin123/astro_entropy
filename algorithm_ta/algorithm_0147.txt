**Algorithm for Probabilistic Spectral Reconstruction of TNOs from Sparse Photometry**

1. **Training Principal Component Analysis (PCA):**
   - Obtain a set of near-infrared (NIR) spectra of trans-Neptunian objects (TNOs).
   - Perform PCA on these spectra to derive a reduced set of principal components (PCs) that capture the essential spectral variability. Retain 4-5 PCs for taxonomic classification and 8-10 PCs for improved spectral reconstruction and uncertainty analysis.

2. **Probabilistic Latent-Space Model Construction:**
   - Represent each TNO's spectrum as a linear combination of the selected PCs.
   - Construct a probabilistic model in this latent space, incorporating uncertainties from photometric measurements.
   - Use Bayesian inference to estimate the posterior distribution of the latent variables (PC coefficients) given the observed photometric data.

3. **Reconstruct Full Spectra:**
   - For each object, use the estimated latent variables (from Bayesian inference) to project back into the full spectral space.
   - Propagate measurement uncertainties through the model to provide credible intervals for the reconstructed spectra.

4. **Survey Optimization:**
   - Apply the framework to evaluate the information content of different NIR filter combinations (e.g., JWST/NIRCam filters: F090W, F115W, F410M, F460M).
   - Identify optimal filter configurations that maximize spectral reconstruction fidelity and minimize uncertainty for future surveys.

5. **Outlier Detection and Rare Spectral Types:**
   - Use the probabilistic framework to identify objects with photometric data that poorly fit the majority of spectral models.
   - Reconstruct spectra for these outliers by constraining the latent space to select low-probability intermediate models, enabling detection of rare or peculiar spectral types.

**Output:**
- Reconstructed full spectra for each TNO with associated uncertainties.
- Optimized filter configurations for future surveys.
- Detection of outlier objects with unique spectral characteristics.
