The algorithm begins by training a model using a set of known TNO spectra. PCA is applied to these spectra to create a lower-dimensional representation. The optimal number of principal components is determined, around 4-5 for classification and 8-10 for precise reconstruction. For each new object, its photometric data is mapped into this latent space, and Bayesian inference is used to estimate the underlying spectra, incorporating measurement uncertainties. Finally, the full spectrum is reconstructed. This method also validates using cross-checks and optimizes survey filters, while detecting unusual spectral types by identifying photometry that doesn't fit the learned manifold.
