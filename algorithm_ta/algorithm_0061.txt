**Algorithm: Probabilistic Spectral Reconstruction via Principal Component Analysis**

1. **Principal Component Analysis (PCA) Training**:
   - Train a PCA model on a dataset of near-infrared (near-IR) spectra of trans-Neptunian objects (TNOs).
   - Determine the number of principal components (PCs) needed (e.g., 4-5 for classification, 8-10 for accurate reconstruction).

2. **Latent-Space Representation**:
   - Represent each TNO's spectrum in the reduced PCA space, capturing the dominant spectral variability.

3. **Bayesian Inference in Reduced Space**:
   - Perform Bayesian inference using the PCA-learned manifold to reconstruct full spectra from sparse photometric measurements.
   - Propagate measurement uncertainties through the probabilistic model.

4. **Spectral Manifold Modeling**:
   - Model the spectral manifold of TNOs using the trained PCA representation.

5. **Reconstruction of Full Spectra**:
   - Reconstruct full spectra from sparse photometric data by solving for the most probable spectral configuration in the latent space.

6. **Uncertainty Calibration**:
   - Quantify uncertainties in the reconstructed spectra, ensuring empirical credible-interval coverage (~95%).

7. **Survey Optimization**:
   - Apply the framework to evaluate the information content of different filter configurations (e.g., JWST/NIRCam filters) to optimize future observations.

8. **Outlier Detection**:
   - Detect rare spectral types by identifying objects that constrain photometry to low-probability intermediate models on the spectral manifold.

This structured approach enables mapping the compositional structure of minor planets using sparse photometry, bridging the gap between photometric data and spectroscopic analysis.
