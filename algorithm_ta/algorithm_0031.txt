**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Data Preparation**:
   - Collect sparse photometric measurements of trans-Neptunian objects (TNOs).
   - Gather a reference set of near-infrared (near-IR) spectra for training.

2. **Principal Component Analysis (PCA) Training**:
   - Use the reference near-IR spectra to perform Principal Component Analysis (PCA).
   - Determine the optimal number of principal components (approximately 4-5 for taxonomic classification, up to 10 for detailed reconstruction).

3. **Probabilistic Principal Component Analysis (PPCA) Model Construction**:
   - Train a PPCA model using the PCA-derived latent components.
   - The PPCA captures uncertainty in the spectral decomposition, providing a probabilistic basis for spectral variability.

4. **Bayesian Inference in Latent Space**:
   - For each object, given its sparse photometric measurements, perform Bayesian inference in the PPCA latent space.
   - Recover the latent variables representing the object's spectral parameters, including associated uncertainties.

5. **Spectral Space Transformation**:
   - Project the inferred latent variables back into the original spectral space using the inverse PCA transformation.
   - Generate reconstructed spectra matching the input photometry.

6. **Uncertainty Propagation**:
   - Propagate the uncertainties from the latent space to the spectral domain.
   - Obtain probability distributions over possible spectra consistent with the photometric data.

7. **Output**:
   - Provide reconstructed spectra, associated uncertainties, and probability distributions for each object.

This framework efficiently reconstructs full spectra from sparse photometry, quantifying uncertainties and enabling accurate taxonomic classification and outlier detection of TNOs.
