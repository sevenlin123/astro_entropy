**Algorithm for Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Principal Component Analysis (PCA) Training**:
   - **Input**: Reference set of near-IR spectra of TNOs.
   - **Process**: Perform PCA on the reference spectra to create a reduced-dimensional representation.
   - **Output**: PCA model with selected number of principal components (e.g., 4-5 or 8-10 based on desired accuracy).

2. **Bayesian Inference in PCA Space**:
   - **Input**: Photometric measurements and their uncertainties for an object.
   - **Process**: 
     - Represent the object's spectral information using the pre-trained PCA model.
     - Perform Bayesian inference to determine the posterior distribution of the PCA coefficients based on the photometric data.
   - **Output**: Posterior distributions of PCA coefficients capturing the object's spectral characteristics.

3. **Spectrum Reconstruction**:
   - **Input**: Posterior distributions of PCA coefficients.
   - **Process**: 
     - Map the posterior coefficients back to the original spectral space using the PCA model.
     - Propagate uncertainties from the coefficients' posterior distributions to the reconstructed spectrum.
   - **Output**: Reconstructed spectrum with associated uncertainties.

4. **Survey Optimization Evaluation**:
   - **Process**: Simulate various filter configurations using NIRCam filters.
   - **Output**: Identification of optimal filter combinations for maximizing spectral information.

5. **Outlier Detection**:
   - **Process**: Analyze the compatibility of photometric data with the spectral manifold.
   - **Output**: Detection of peculiar spectral types inconsistent with typical spectral distributions.

This algorithm efficiently reconstructs spectra from sparse photometry, enabling detailed analysis of TNOs' surface compositions.
