**Algorithm for Probabilistic Spectral Reconstruction of Trans-Neptunian Objects**

1. **Build Reference Library**: Construct a reference library containing near-infrared spectra of known trans-Neptunian objects (TNOs).

2. **Principal Component Analysis (PCA)**: Apply PCA to the reference library to extract principal components capturing the major spectral variations.

3. **Sparse Photometric Data Acquisition**: Obtain sparse photometric measurements for each TNO, typically from instruments like JWST/NIRCam.

4. **Projection onto PCA Manifold**: Represent the photometric measurements as projections onto the PCA-derived manifold of the reference library.

5. **Bayesian Inference in PCA Space**: Use Bayesian methods to estimate the posterior distribution of PCA coefficients based on the photometric data.

6. **Spectrum Reconstruction**: Map the estimated PCA coefficients back to the original spectral space to reconstruct the full spectrum.

7. **Uncertainty Propagation and Outlier Detection**: Assess the reliability of the reconstructed spectrum and identify outliers using propagated uncertainties from the Bayesian step.
