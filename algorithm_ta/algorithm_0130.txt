**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Preprocessing**:
   - Apply Principal Component Analysis (PCA) to the training set of near-infrared spectra to derive principal components (PCs).

2. **Model Construction**:
   - Represent each spectrum in the latent space as a linear combination of the selected principal components.
   - Model the latent space using a Gaussian Process with a specified covariance function.

3. **Bayesian Inference**:
   - For each object, compute the likelihood of the latent variables given the observed photometric fluxes.
   - Obtain the posterior distribution of the latent variables using Markov Chain Monte Carlo (MCMC) sampling.

4. **Uncertainty Quantification**:
   - Use the variance-covariance matrix of the MCMC posterior to compute uncertainties in the reconstructed spectra.

This algorithm focuses on the core computational steps for spectral reconstruction, excluding validation procedures.
