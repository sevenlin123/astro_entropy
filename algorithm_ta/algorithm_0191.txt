The core computational algorithm for the probabilistic spectral reconstruction framework involves the following steps:

1. **Preprocessing**:
   - Normalize the near-infrared (NIR) reflectance spectra of trans-Neptunian objects (TNOs) to standardize the data.
   - Extract principal components (PCs) using Principal Component Analysis (PCA). The number of PCs is predefined based on prior knowledge (e.g., 4-5 for taxonomic classification).

2. **Model Construction**:
   - Develop a probabilistic latent-space model utilizing the extracted principal components. This model represents the underlying structure of the spectral data in a lower-dimensional space.

3. **Bayesian Inference**:
   - Use photometric data to perform Bayesian inference within the latent-space model. This step infers the posterior distribution of the principal components, accounting for photometric uncertainties.

4. **Spectral Reconstruction**:
   - Reconstruct the full spectra from the inferred posterior distributions of the principal components.

5. **Uncertainty Propagation**:
   - Calculate uncertainties for each wavelength in the reconstructed spectra by analyzing the variance in the posterior distributions.

These steps form the core method for reconstructing spectra from sparse photometry.
