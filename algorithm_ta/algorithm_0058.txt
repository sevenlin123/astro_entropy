### Algorithm Description

**1. Input Data**  
- Near-infrared (near-IR) photometric measurements of trans-Neptunian objects (TNOs).  
- Training set of near-IR spectra used to build the principal component (PC) model.  

**2. Preprocessing**  
- Normalize and preprocess photometric data to account for observational uncertainties and calibration.  
- Convert photometric measurements into flux densities or magnitudes for consistent spectral analysis.  

**3. Dimensionality Reduction via PCA**  
- Train a PCA model using the reference near-IR spectra dataset.  
- Extract the dominant principal components (4-5 for taxonomic classification; 8-10 for improved reconstruction fidelity).  
- Represent each object's spectral information in the reduced latent space using these principal components.  

**4. Bayesian Inference in the Latent Space**  
- Perform Bayesian inference in the reduced PCA space to reconstruct full spectra from sparse photometric data.  
- Use the posterior distributions of the principal components to quantify uncertainty in the reconstructed spectra.  

**5. Posterior Analysis and Uncertainty Propagation**  
- Analyze the posterior distributions of the PCA coefficients to estimate the uncertainty in the reconstructed spectra.  
- Propagate measurement uncertainties from the photometric data to the reconstructed spectral features.  

**6. Output**  
- Reconstructed full spectra for each TNO with associated uncertainty estimates.  
- Probabilistic classifications based on spectral similarity to known taxonomic groups.  
- Information content analysis for future survey instrument configurations (e.g., JWST/NIRCam filter combinations).
