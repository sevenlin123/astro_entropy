**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Training Phase:**
   - Train a principal component analysis (PCA) model using a set of near-infrared (near-IR) spectra of trans-Neptunian objects (TNOs).
   - Extract principal components (PCs) to represent the spectral manifold of TNOs.
   - Determine the number of PCs needed for taxonomic classification (≈4-5 PCs) and spectral reconstruction fidelity (≈8-10 PCs).

2. **Data Preprocessing:**
   - Collect sparse photometric measurements of TNOs from available data sources.
   - Normalize and preprocess the photometric data to account for measurement uncertainties and noise.

3. **Bayesian Inference in Reduced Space:**
   - Represent each TNO's spectrum in the latent space defined by the PCA model.
   - Perform Bayesian inference to estimate the underlying full spectrum using the sparse photometric data.
   - Propagate measurement uncertainties through the Bayesian framework to quantify uncertainty in the reconstructed spectra.

4. **Spectral Reconstruction:**
   - Use the posterior distribution from the Bayesian inference to reconstruct the full spectrum of each TNO.
   - Validate the empirical credible-interval coverage across wavelengths to ensure accurate uncertainty propagation.

5. **Survey Optimization and Outlier Detection:**
   - Apply the framework to evaluate the information content of different filter configurations (e.g., JWST/NIRCam filters).
   - Identify optimally informative filter combinations for future observations to enhance taxonomic classification.
   - Detect rare spectral types by constraining photometric data to select low-probability intermediate models from the continuous topological manifold.

6. **Output:**
   - Provide reconstructed spectra with associated uncertainties.
   - Deliver optimized filter configurations for survey design.
   - Identify and reconstruct outlier objects with unusual spectral characteristics.

This algorithm efficiently bridges the gap between sparse photometric data and detailed spectral analysis, enabling robust taxonomic studies and survey planning for TNOs.
