**Final Algorithm: Core Reconstruction Framework**

1. **Preprocessing**:
   - Gather a reference spectral library of TNOs with near-IR spectra.
   - Normalize each spectrum by dividing by its median value to adjust for brightness variations.

2. **Training the Model**:
   - Compute principal components (PCs) using PCA on the reference library.
   - Determine the optimal number of PCs (K) using LOOCV.
   - Develop a probabilistic model in the latent space defined by these PCs.
   - Apply Bayesian inference to model the relationship between photometric data and latent variables.
   - Assign prior distributions to latent variables based on training data.

3. **Spectral Reconstruction**:
   - For each test object, perform Bayesian inference to estimate the posterior distributions of latent variables from photometric measurements.
   - Reconstruct the full spectrum using the posterior means of latent variables.
   - Calculate the variance-covariance matrix of latent variables to propagate uncertainty into the reconstructed spectrum.
   - Determine credible intervals for the spectrum to assess confidence.

4. **Validation**:
   - Conduct LOOCV to evaluate the accuracy of reconstructed spectra.
   - Measure RMSE and Pearson correlation coefficients between reconstructed and original spectra.

5. **Outlier Detection**:
   - Examine posterior probabilities of latent variables.
   - Identify objects with significant deviations in posterior probabilities as outliers.

6. **Optimal Filter Selection**:
   - Simulate information content of NIRCam filters.
   - Assess which filter combinations offer the best spectral resolution and minimal uncertainty.
   - Recommend optimal filter configurations for future surveys.

7. **Output**:
   - Deliver reconstructed spectra with credible intervals.
   - Highlight unusual objects detected during outlier analysis.
   - Provide a report on optimal NIRCam filter configurations.
