**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Training Phase**: 
   - **Input**: Near-infrared (NIR) spectra of trans-Neptunian objects (TNOs).
   - **Process**: Use Principal Component Analysis (PCA) to train a model based on the input spectra. The PCA identifies the principal components that capture the spectral variability.
   - **Output**: A set of principal components representing the spectral manifold of TNOs.

2. **Probabilistic Latent-Space Model**:
   - **Input**: Sparse photometric measurements.
   - **Process**: Perform Bayesian inference in the reduced PCA space to reconstruct full spectra. This involves quantifying uncertainty propagation through the latent space.
   - **Output**: Reconstructed spectra along with their associated uncertainties.

3. **Spectral Reconstruction**:
   - **Input**: Photometric data from observations (e.g., JWST/NIRCam filters).
   - **Process**: Apply the trained probabilistic model to the photometric data to infer the most probable underlying spectra, considering the latent space representation.
   - **Output**: Reconstructed full spectra with credible intervals for each wavelength.

4. **Survey Optimization**:
   - **Input**: Information content of NIRCam filters (e.g., F090W, F115W, etc.).
   - **Process**: Evaluate the information gain of each filter configuration to identify the optimal set of filters for maximizing spectral reconstruction fidelity.
   - **Output**: Optimal filter configurations for survey design.

5. **Outlier Detection**:
   - **Input**: Photometric data with constrained measurements.
   - **Process**: Use the probabilistic framework to constrain intermediate models, allowing detection of rare spectral types by identifying low-probability solutions.
   - **Output**: Detection of unusual or rare spectral classes like peculiar Neptune Trojans.

6. **Taxonomic Classification**:
   - **Input**: Reconstructed spectra from the framework.
   - **Process**: Classify TNOs into taxonomic groups using the dominant principal components identified during training.
   - **Output**: Categorized spectral types based on the latent-space representation.

**End of Algorithm**
