**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data**: 
   - Sparse photometric measurements for each trans-Neptunian object (TNO).
   - A training set of reference near-infrared spectra.

2. **Training Phase**:
   - Perform Principal Component Analysis (PCA) on the training set of reference spectra.
   - Determine the optimal number of principal components (e.g., 8-10) using leave-one-out cross-validation (LOOCV) to ensure sufficient spectral reconstruction fidelity.

3. **Latent Space Representation**:
   - Represent each reference spectrum in the PCA latent space, capturing the dominant modes of spectral variability.

4. **Bayesian Inference**:
   - For each TNO, use its sparse photometric data as observations.
   - Perform Bayesian inference in the PCA latent space to estimate the posterior distribution of the principal component coefficients.
   - This involves modeling the relationship between the latent space representation and the observed photometric data.

5. **Spectral Reconstruction**:
   - Reconstruct the full spectrum for each TNO by projecting the posterior mean of the principal component coefficients back into the original spectral space.
   - Propagate measurement uncertainties through the Bayesian inference process to quantify the uncertainty in the reconstructed spectrum.

6. **Output**:
   - For each TNO, produce the reconstructed spectrum along with its associated uncertainties.
   - Use the framework for survey optimization by evaluating the information content of different filter configurations (e.g., JWST/NIRCam filters) to enhance future observations.

This algorithm efficiently bridges the gap between sparse photometric data and detailed spectral reconstruction, enabling robust taxonomic classification and outlier detection for TNOs.
