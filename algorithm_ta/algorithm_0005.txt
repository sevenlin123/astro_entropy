**Algorithm: Probabilistic Spectral Reconstruction via Latent Space Inference**

1. **Input Data**: Obtain a dataset of near-infrared (near-IR) spectra of trans-Neptunian objects (TNOs).

2. **Principal Component Analysis (PCA)**:
   - **Training**: Apply PCA to the training set of near-IR spectra.
   - **Latent Space Representation**: Transform the original spectra into a reduced-dimensional latent space using the principal components.

3. **Bayesian Inference**:
   - Perform Bayesian inference in the latent space. This involves modeling the spectral manifold and inferring the most probable latent variables given the observed photometric measurements.
   - Propagate measurement uncertainties through this inference step.

4. **Spectral Reconstruction**:
   - Reconstruct the full spectra from the inferred latent variables.
   - Compute the uncertainties associated with the reconstructed spectra.

5. **Output**:
   - Generate the reconstructed spectra.
   - Provide the associated uncertainty estimates for each reconstructed spectrum.

This algorithm effectively leverages sparse photometric data to probabilistically reconstruct high-fidelity spectra, enabling taxonomic classification and other analyses despite limited spectroscopic observations.
