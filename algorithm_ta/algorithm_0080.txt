The core reconstruction framework algorithm involves the following steps:

1. **Principal Component Analysis (PCA) Training**: 
   - Train a PCA model on a reference set of near-infrared spectra to capture the primary modes of spectral variation.

2. **Project Photometric Data**:
   - Transform sparse photometric measurements into the latent space defined by the PCA model.

3. **Bayesian Inference**:
   - Perform Bayesian inference in the PCA space to estimate the latent variables, accounting for photometric uncertainties.

4. **Spectral Reconstruction**:
   - Reconstruct the full spectrum using the estimated latent variables and the PCA basis vectors.

5. **Uncertainty Propagation**:
   - Compute uncertainties in the reconstructed spectrum by considering the propagation of errors from photometry and the PCA model.
