**Algorithm: Probabilistic Spectral Reconstruction of TNOs**

1. **Initialize Gaussian Process (GP):**
   - Set kernel with specific parameters (e.g., squared exponential).
   - Define hyperparameters with priors (e.g., variance, length scale).

2. **For each object:**
   a. **Input:** Sparse photometric observations.
   b. **Outlier Detection:**
      i. Apply Gaussian Mixture Model (GMM) to photometric magnitudes.
      ii. Identify outlier indices via highest posterior probability of GMM component.
   c. **Condition GP:**
      i. Remove identified outliers from data.
      ii. Update GP with remaining data points.
   d. **Spectral Template Evaluation:**
      i. For each template in spectral library:
         - Calculate data likelihood using template and current GP.
         - Compute log-likelihood for template weights.
      ii. Perform Hamiltonian Monte Carlo (HMC):
         - Sample posterior distributions of template weights and GP hyperparameters.
         - Update hyperparameters via HMC iterations.
   e. **Reconstruct SED:**
      i. Combine spectral templates using sampled weights.
      ii. Compute posterior mean SED and associated uncertainties.

3. **Output:** Reconstructed SEDs, uncertainty measures, and outlier flags.
