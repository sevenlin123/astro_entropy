For each object in dataset:
    Initialize parameters: T1, T2, x, σ with prior distributions
    For each spectrum component in model:
        Forward model the SED using the blackbody components
        Compute the likelihood of observed flux given the model
    Perform MCMC sampling to estimate posterior distributions
    Generate posterior predictive distributions
End for each object

For all objects:
    For each population class:
        Compute the posterior probability of the class using the parameters' posteriors
    Determine the class with maximum posterior probability
    Flag objects with probabilities below a threshold as outliers
End for all objects
