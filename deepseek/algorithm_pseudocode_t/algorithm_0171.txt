**Pseudocode Algorithm for Core Reconstruction Framework**

1. **Preprocess Data**:
   - Align sparse photometric measurements into a consistent system.
   
2. **Define Basis Functions**:
   - Select basis functions suitable for the spectral domain.
   
3. **Construct Gaussian Process Model**:
   - Expand the SED into the chosen basis functions.
   - Formulate the GP model incorporating these basis functions.
   
4. **Set Up Likelihood Function**:
   - Define the likelihood based on observed photometric data.
   
5. **Assign Prior Distributions**:
   - Specify prior distributions for model parameters.
   
6. **Run MCMC Sampler**:
   - Use MCMC to sample posterior distributions of parameters.
   
7. **Extract SEDs from Posterior Samples**:
   - Reconstruct SEDs using the sampled parameters.
   
8. **Perform Probabilistic Clustering**:
   - Group similar SEDs to identify spectral classes.
   
9. **Detect Outliers**:
   - Identify SEDs that do not fit into any cluster.

This structured approach outlines the core computational steps for the probabilistic framework described in the paper.
