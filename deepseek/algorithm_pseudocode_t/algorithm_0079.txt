**Algorithm: Probabilistic Spectral Reconstruction via Bayesian Mixture Model**

1. **Initialization**:
   - Define the number of mixture components, \( K \).
   - Set prior distributions for albedo (\( p \)), phase curve amplitude (\( q \)), and thermal emission (\( r \)).
   - Initialize hyperparameters for the Gaussian mixture model.

2. **Data Preparation**:
   - Input sparse photometric data matrix \( X \) with dimensions \( N \times D \), where \( N \) is the number of objects and \( D \) is the number of photometric bands.
   - Each entry \( X_{i,j} \) represents the observed flux in band \( j \) for object \( i \).

3. **Prior Setup**:
   - For each component \( k \) in 1..K:
     - Define mean (\( \mu_k \)) and variance (\( \sigma_k^2 \)) for the Gaussian distribution.
     - Assign prior probabilities \( \pi_k \) such that \( \sum_{k=1}^K \pi_k = 1 \).

4. **Bayesian Parameter Estimation**:
   - For each object \( i \):
     - Compute the likelihood contribution for each component \( k \):
       \[ p(X_i | \mu_k, \sigma_k^2) \]
     - Calculate the posterior probability of each component:
       \[ P(k | X_i) = \frac{\pi_k \cdot p(X_i | \mu_k, \sigma_k^2)}{\sum_{k'=1}^K \pi_{k'} \cdot p(X_i | \mu_{k'}, \sigma_{k'}^2)} \]

5. **Reconstruct Spectral Energy Distribution (SED)**:
   - For each object \( i \):
     - Combine contributions from all components weighted by their posterior probabilities:
       \[ SED_i = \sum_{k=1}^K P(k | X_i) \cdot \text{Gaussian}_k \]
     - Extract albedo, phase curve, and thermal emission parameters from the posterior distributions.

6. **Output**:
   - Generate reconstructed SEDs for all objects.
   - Optionally, identify outliers based on low posterior probabilities.

**End Algorithm**
