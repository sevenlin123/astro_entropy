```pseudocode
Algorithm: Probabilistic Spectral Reconstruction of TNOs

Input: List of TNO objects, each with sparse photometric measurements across N bands.

Output: Reconstructed spectra, uncertainties, confidence scores, outlier flags.

For each TNO in list:
    Initialize variables:
        photometry = array of photometric measurements across bands.
        K = number of spectral components (initially unknown).
    
    For each band i in 1 to N:
        Define Gaussian Process (GP) prior:
            Kernel: e.g., RationalQuadratic with parameters θ_i.
            Mean function: weighted sum of template spectra, m_i(x) = Σ w_j * s_j(x).
        
    Determine optimal K:
        For K in 1 to max_components:
            Compute marginal likelihood of data under K-component model.
        Select K with highest evidence.
    
    Set up mixture model with K components:
        Each component k has GP with kernel and mean function.
        Mixing weights w_k, constrained to Σw_k = 1.
    
    Bayesian inference:
        For each component k:
            Sample posterior of w_k and GP hyperparameters θ_k using MCMC.
            Track posterior distributions.
        
        Compute ELBO to monitor convergence.
    
    Reconstruct spectrum:
        Reconstructed_spect = E[Σw_k * GP_k(x)]
        Variance = Var(Σw_k * GP_k(x))
    
    Outlier detection:
        For each band i:
            Compute log_predictive = log(p(photometry_i | reconstructed_spect))
            If log_predictive < threshold: mark as outlier.
    
    Assign confidence score:
        confidence = min(log_predictive across bands)
    
    Output: reconstructed_spect, variance, confidence, outlier_flags.
```
