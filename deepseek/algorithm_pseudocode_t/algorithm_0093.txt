**Pseudocode Algorithm for Probabilistic Spectral Reconstruction**

1. **Initialize Data and Wavelengths**
   - Read sparse photometric measurements `y` and corresponding wavelengths `λ`.

2. **Define Gaussian Process Model**
   - Set up the Gaussian process with kernel parameters and noise variance as hyperparameters `θ`.

3. **Specify Likelihood Function**
   - Assume `y ~ N(f(λ), σ²)` where `f(λ)` is the latent SED and `σ²` is the noise variance.

4. **Set Prior Distributions**
   - Assign priors to hyperparameters `θ`, such as Jeffreys' or uniform priors.

5. **Compute Posterior via Bayesian Inference**
   - Calculate the posterior distribution of `θ` and `f(λ)` using the marginal likelihood.

6. **Optimize Hyperparameters**
   - Find `θ*` by maximizing the marginal likelihood using numerical methods.

7. **Reconstruct SED**
   - Predict `f(λ)` using the posterior predictive distribution with optimized `θ*`.

8. **Calculate Uncertainty Propagation**
   - Obtain the variance of the posterior predictive distribution to represent uncertainty in `f(λ)`.

9. **Perform Outlier Detection**
   - For each measurement, compute posterior probability `p(y_i | f(λ))`. Flag as outlier if below threshold.

10. **Evaluate Band Contributions**
    - Measure each band's information gain to assess its contribution to the SED reconstruction.

**End of Algorithm**
