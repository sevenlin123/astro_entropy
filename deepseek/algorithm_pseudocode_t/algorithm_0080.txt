The core computational algorithm is implemented using the Expectation-Maximization (EM) algorithm applied to a Gaussian Mixture Model. Here is the pseudocode for the algorithm:

```python
initialize the Gaussian Mixture Model with K components Θ = {θ₁, θ₂, ..., θ_K}
while not converged:
    for each object x in the dataset D:
        compute the posterior probabilities γ_z(x) for each component z using the current Θ
    for each component z:
        compute the weights w_z = sum_{x} γ_z(x)
        if w_z < threshold: remove component z
        else: update θ_z using the EM step
    compute the log-likelihood LL
    if |ΔLL| < tolerance or max iterations reached: break
end while
assign each object x to the component with the highest γ_z(x)
output the refined component parameters Θ and the spectral classifications
```

This algorithm initializes the Gaussian components, iteratively updates their parameters using the EM technique, and assigns each object to the most probable component until convergence.
