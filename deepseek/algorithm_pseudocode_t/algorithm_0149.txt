**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Initialization**:
   - Define the parameter space θ, including spectral features and systematics.
   - Set up the forward model M(θ) relating SED to observed magnitudes.
   - Incorporate uncertainties in measurements and photometric system.

2. **Pixel-Based Modeling**:
   - For each wavelength pixel i:
     - Compute flux f_i = M(θ) * t_i + noise, where t_i is transmission curve.
     - Forward model includes extinction and systematics.

3. **Bayesian Inference Setup**:
   - Define prior distributions P(θ).
   - Specify likelihood function L(data | θ) based on sparse photometry.
   - Construct posterior distribution P(θ | data) ∝ L × P(θ).

4. **Nested Sampling Algorithm**:
   - Implement a trans-dimensional nested sampling method (e.g., slice sampling, parallel tempering):
     - Loop over parameters:
       - Sample θ from prior, adjusting for constraints.
       - Evaluate the posterior P(θ | data).
       - Sort and remove samples to maintain nested order.
       - Accumulate evidence for Bayesian hypothesis testing.
     - Determine credible intervals for parameters.

5. **Integration Over Parameter Space**:
   - Integrate posterior distribution to compute marginal probabilities for features.
   - Use integration techniques compatible with high-dimensional spaces.

6. **Output**:
   - Generate reconstructed SEDs for each object.
   - Compute credible intervals and feature probabilities.

7. **End**
