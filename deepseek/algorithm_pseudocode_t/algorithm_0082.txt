**Algorithm: Probabilistic Spectral Reconstruction using Gaussian Processes and Dirichlet Process Mixture Model**

1. **Initialize Input Data**
   - Input: Sparse photometric measurements of trans-Neptunian objects (X), associated uncertainties (σ), and spectral parameter uncertainties (Σ).
   - Output: Joint probability distribution over spectral energy distributions (SEDs) and number of spectral classes.

2. **Infer Number of Spectral Classes using Dirichlet Process Mixture Model (DPM)**
   - Define prior parameters for DPM, e.g., concentration parameter α.
   - Use DPM to cluster objects into spectral classes, inferring the optimal number of classes K.

3. **Reconstruct Individual Spectral Energy Distributions (SEDs) using Gaussian Processes (GPs)**
   - For each spectral class k ∈ {1, ..., K}:
     - Extract subset of objects belonging to class k.
     - Train a GP using the photometric data X_k and uncertainties σ_k.
     - Determine GP hyperparameters (e.g., length scale l, noise variance θ) via maximum likelihood estimation or other methods.
     - Use GP to predict SEDs for objects in class k, incorporating spectral parameter uncertainties Σ.

4. **Compute Joint Probability Distribution over SEDs and Number of Components**
   - Combine probabilities from DPM and GPs into a joint distribution.
   - Calculate posterior probabilities for each object’s membership in each spectral class and its corresponding SED.

5. **Derive Posterior Distributions**
   - For each object, calculate the posterior probability distribution over SEDs considering all possible spectral classes and their associated uncertainties.
   - Quantify overall uncertainty in spectral reconstruction by integrating over all possible configurations.

6. **Output Results**
   - Provide reconstructed SEDs for each object along with their uncertainty estimates.
   - Include the inferred number of spectral classes and the probability distribution over the number of components.

This algorithm efficiently combines probabilistic clustering and Gaussian processes to reconstruct spectral energy distributions from sparse photometric data, enabling robust taxonomic classification and outlier detection.
