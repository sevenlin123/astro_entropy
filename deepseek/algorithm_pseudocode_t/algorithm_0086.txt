Algorithm Core Reconstruction Framework:

1. Precompute Training Data:
   - For each simulation index i from 1 to N_train:
       a. Generate SED parameters (sed_params_i) according to a prior distribution.
       b. Simulate flux measurements (flux_i) using a forward model.
       c. Store (flux_i, sed_params_i) in the training dataset.

2. Train Gaussian Process Emulator:
   - Initialize Gaussian Process Emulator (GPE) with input dimension equal to the number of flux bands and output dimension equal to the number of SED parameters.
   - For each entry in the training dataset:
       a. Train GPE with input flux measurements and output SED parameters.

3. Perform Nested Sampling Inference:
   - Define the prior distribution for SED parameters.
   - Define the observed flux measurements (obs_flux).
   - Implement nested sampling algorithm NS, initializing it with the prior distributions and the observed flux.
   - For each iteration in NS:
       a. Propose new SED parameters within the prior distribution.
       b. Use the GPE to compute the likelihood: likelihood = GPE.query(new_sed_params, obs_flux).
       c. Compute log-likelihood: log_likelihood = log(likelihood).
       d. Update the nested sampler's live points using log_likelihood.
   - Continue until the nested sampling converges.

4. Output:
   - Posterior distribution of SED parameters (sed_params_posterior).
   - Bayesian evidence.
