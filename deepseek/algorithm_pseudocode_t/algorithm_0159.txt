**Algorithm: Probabilistic Spectral Reconstruction**

1. **Gaussian Process (GP) Training and Hyperparameter Optimization**
   - Input: Reference spectra dataset.
   - Initialize GP with a chosen kernel (e.g., squared exponential).
   - Optimize GP hyperparameters (e.g., kernel scales, noise variance) using maximum likelihood estimation on the reference spectra.

2. **Forward Model Development**
   - Define a forward model that maps spectral parameters to observed photometric magnitudes.
   - Incorporate photometric system specifics (e.g., instrument response, zero points, flux calculations).

3. **Bayesian Inference with MCMC Sampling**
   - Set up the posterior distribution combining the GP prior and the forward model.
   - Include priors on spectral parameters (e.g., uniform or informed priors).
   - Use Markov Chain Monte Carlo (MCMC) to sample the posterior distribution of spectral parameters.

4. **Posterior Sample Generation and Uncertainty Quantification**
   - Draw posterior samples from the MCMC chains.
   - Calculate quantiles (e.g., 16th, 50th, 84th percentiles) to determine the median spectrum and confidence intervals.

5. **Spectral Feature Selection via Statistical Testing**
   - Compute significant spectral features (e.g., emission lines, spectral indices) from posterior samples.
   - Apply statistical tests (e.g., t-test, ANOVA) to identify features robust for taxonomic classification.

**Output:** Posterior-sampled spectra, feature-selected results, uncertainty quantified.
