Algorithm: Probabilistic Spectral Reconstruction of TNOs

1. Initialize Gaussian Process (GP) with kernel parameters.
   - Select appropriate kernel (e.g., squared exponential) to model SED smoothness.
   - Set initial hyperparameters (e.g., length scale, variance).

2. For each TNO:
   a. Input: Observed flux measurements across multiple photometric bands.
   b. Construct SED using GP:
      i. GP prior represents the smooth variation of the SED.
   c. Forward model mapping:
      i. Create matrix M encoding the relationship between bands and wavelengths.
      ii. Compute expected fluxes from proposed SED using M.
   d. Bayesian inference update:
      i. Calculate posterior distribution of SED parameters given observed fluxes.
   e. Spectral deconvolution:
      i. Correct observed fluxes using instrument response functions.
   f. Compute confidence intervals:
      i. Extract variance from GP predictions to determine uncertainty ranges.
   g. Synthetic photometry generation:
      i. Use reconstructed SED to predict fluxes in observed bands.
   h. Outlier detection:
      i. Compare synthetic fluxes with observed values.
      ii. Identify discrepancies beyond tolerance as outliers.

End Algorithm
