**Algorithm: Core Reconstruction Framework Using Gaussian Processes and Variational Autoencoders**

1. **Train the Variational Autoencoder (VAE):**
   - Input: Sparse photometric time series, brightness variation, spectral energy distribution, and orbital elements.
   - Output: Latent feature representation for each object.
   - Objective: Learn the mapping from observed data to latent features.

2. **Extract Latent Features:**
   - For each object, encode its input data through the pre-trained VAE to obtain latent features.

3. **Train Gaussian Process (GP):**
   - Input: Latent features obtained from the VAE.
   - Output: Predicted physical parameters (e.g., albedo, size, temperature).
   - Objective: Model the dependency between latent features and physical parameters, providing uncertainty quantification.

4. **Predict Physical Parameters:**
   - For each object, use the latent features to make predictions via the GP, obtaining the reconstructed parameters and their associated uncertainties.

This algorithm effectively combines the multi-modal data processing capability of VAEs with the uncertainty quantification of GPs, enabling robust reconstruction of physical parameters for trans-Neptunian objects.
