**Algorithm: Probabilistic Spectral Reconstruction of Trans-Neptunian Objects**

1. **Initialization**
   - Input: Observed photometric data of TNOs, spectral library templates, redshift information
   - Output: Reconstructed SEDs with uncertainties

2. **For Each Object**
   - Initialize variables for SED, measurement errors, and ISM extinction

3. **Spectral Basis Function Matching**
   - Decompose observed photometry into a linear combination of basis functions derived from spectral libraries
   - Compute probability distribution for each spectral feature

4. **Bayesian Inference for Template Matching**
   - Apply Bayesian inference to estimate posterior probabilities over template matches
   - Determine emission probabilities per spectral feature

5. **Uncertainty Marginalization**
   - Integrate over uncertainties in photometric measurements
   - Model ISM extinction effects, compute posterior probabilities considering extinction curves

6. **Optimization and Combination**
   - Combine all probabilities to form the posterior distribution of SED
   - Quantify uncertainties in the reconstructed SEDs

7. **Output**
   - Generate reconstructed SEDs with uncertainty quantification for each object

**End Algorithm**
