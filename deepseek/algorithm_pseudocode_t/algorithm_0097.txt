**Algorithm: Probabilistic Spectral Reconstruction**

**Initialize Parameters**
Set mixture model components, means, variances, and weights.

**For Each Object**
1. Read photometric data.
2. Detect spectral features to determine candidate wavelengths.
3. Apply adaptive grid sampling to select optimal wavelengths.
4. Fit sparse mixture of Gaussians to photometric data.
5. Perform Bayesian inference to compute posterior distributions of parameters.
6. Quantify uncertainty using posterior distributions.

**End For Each Object**

**Output**
Reconstructed spectra with uncertainty estimates.
