Algorithm: Probabilistic Spectral Reconstruction Framework

1. Initialize input data: Read photometric time series of TNOs into lightCurveData.

2. Preprocessing:
   a. De-trend light curves by removing systematic variations (e.g., linear trends).
   b. Normalize each light curve to zero mean and unit variance.
   c. Correct instrumental artifacts by clipping outliers beyond a certain sigma level.

3. Model Setup:
   a. Define Gaussian Process (GP) kernel with hyperparameters (e.g., squared exponential kernel).
   b. Specify mixture distribution to model photometric band relationships.
   c. Define prior distributions for SED, systematics, and GP hyperparameters.

4. Bayesian Inference:
   a. Initialize HMC sampler with starting parameters.
   b. Run HMC sampler for fixed iterations, adapting step size during burn-in.
   c. Collect posterior samples of all parameters.

5. Posterior Analysis:
   a. Compute marginal likelihoods for systematics and hyperparameters.
   b. Assess MCMC convergence using Gelman-Rubin statistic.
   c. Calculate Bayes factors to compare models based on systematics.

6. SED Reconstruction:
   a. For each posterior sample, predict SED using GP.
   b. Compute median and credible intervals (e.g., 68%, 95%) for SED across samples.

7. Outlier Detection:
   a. Use forward model to predict photometric measurements from SED.
   b. Identify outliers by comparing observed data with predictions.

8. Output results: Reconstructed SEDs, uncertainties, and outlier flags.
