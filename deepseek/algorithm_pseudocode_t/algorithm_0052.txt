Algorithm: Probabilistic Spectral Reconstruction

1. Initialize Gaussian Process (GP) parameters and priors.

3. Collect all SEDs into a feature matrix X.
4. Determine the optimal number of clusters k:
     a. For each candidate k from 1 to max_clusters:
          i. Fit a k-component Gaussian Mixture Model (GMM) using the EM algorithm on X.
          ii. Compute the model evidence for the k-component GMM.
     b. Select k_star as the number of clusters with the highest model evidence.
5. Refit the GMM with k = k_star components on the feature matrix X.
6. For each object i:
     a. Calculate the posterior probabilities of belonging to each cluster using the trained GMM.
     b. Assign object i to the cluster with the highest posterior probability.
7. Output the cluster assignments for each object and their estimated redshifts.
