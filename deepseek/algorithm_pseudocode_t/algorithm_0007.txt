```pseudocode
Algorithm: Probabilistic Spectral Reconstruction

Input:
- Observed photometric data for objects
- Forward model parameters (continuum and emission lines)
- Prior distributions for physical parameters

Output:
- Posterior distribution of physical parameters
- Probabilistic spectral classification

Begin:

For each object in dataset:

    Initialize parameters:
        - Physical parameters (e.g., temperature, abundance, etc.)
        - Probability distributions for each parameter based on priors

    Perform Bayesian inference:
        For each iteration:
            Sample parameters from prior distributions
            Evaluate forward model using sampled parameters
            Compute likelihood of observed data given sampled parameters
            Update posterior distribution using Bayesian evidence

    After convergence:
        Extract posterior means and uncertainties for each parameter
        Calculate probabilities of spectral classification by combining posterior distributions

End

Return:
- Posterior distributions for physical parameters
- Probabilities of spectral classifications
