**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Input Data**: 
   - Observed flux measurements at sparse wavelengths.
   - Prior knowledge of possible spectral components (e.g., thermal emission, reflected light).

2. **Initialize Gaussian Process Regression (GPR)**:
   - Define the covariance function (kernel) to capture spectral variability.
   - Set hyperparameters based on prior knowledge or literature.

3. **Spectral Decomposition**:
   - Decompose the observed fluxes into spectral components using GPR.
   - Each component represents a physical property (e.g., thermal emission, reflected light).

4. **Bayesian Hypothesis Testing for Outliers**:
   - For each data point, compute the posterior probability of it being an outlier.
   - Compare the null hypothesis (no outlier) against the alternative hypothesis (outlier).
   - Flag points where the alternative hypothesis is significantly favored.

5. **Spectral Deconvolution**:
   - Remove identified outliers from the data.
   - Use the remaining data to estimate the true spectral energy distribution (SED) via GPR.
   - Apply deconvolution techniques to resolve the underlying spectral features.

6. **Reconstruct Physical Parameters**:
   - Use the deconvolved SED to infer effective temperature, radius, and albedo.
   - Employ uncertainty quantification to assess the reliability of the inferred parameters.

7. **Output**:
   - Probabilistic SED reconstruction.
   - Inferred physical parameters with uncertainties.
   - List of outlier measurements.

8. **End**
