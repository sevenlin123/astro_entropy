**Algorithm: Probabilistic Spectral Reconstruction of Trans-Neptunian Objects**

1. **Model Photometric Fluxes**: Treat each observed photometric flux as a Poisson-distributed measurement with a rate equal to the flux count.

2. **Segment Spectral Energy Distribution (SED)**: Represent the SED as a piecewise power-law function divided into multiple segments, where each segment is defined as \( F_\nu(\nu) = A_i \cdot \nu^{k_i} \) with amplitude \( A_i \) and spectral index \( k_i \).

3. **Define Priors**: Assign prior distributions to parameters \( A_i \) and \( k_i \) for each segment. Typically, uniform priors are used unless additional information specifies otherwise.

4. **Compute Likelihoods**: For each segment, calculate the likelihood based on the observed fluxes. The likelihood function for each observed count \( x \) is given by \( \mathcal{L} \propto \exp(-\mu) \cdot \mu^x \), where \( \mu \) is the expected count.

5. **Perform Bayesian Inference**: Update the parameters \( A_i \) and \( k_i \) using Bayesian inference. Combine the prior distributions with the likelihood to obtain posterior distributions for each parameter.

6. **Calculate Posterior Probabilities for Taxonomic Classes**: For each taxonomic class (e.g., neutral or red slopes), integrate the posterior distribution of \( k_i \) over the range specific to that class to determine the posterior probability for the class.

7. **Classify Objects**: Classify the object into the taxonomic class with the highest posterior probability.

8. **Detect Outliers**: Flag objects as outliers if the highest posterior probability across all classes falls below a predetermined threshold.

9. **Output Results**: Provide the classified taxonomic class and indicate whether the object is an outlier.

This structured approach efficiently reconstructs the SED using a piecewise power-law model, enabling robust classification and outlier detection based on sparse photometric data.
