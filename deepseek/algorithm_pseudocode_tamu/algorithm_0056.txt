```pseudocode
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input: 
    - Sparse photometric measurements (m)
    - Pre-trained PCA model with principal components (PCs)
    - Training set of reference spectra (S_train)

Output:
    - Reconstructed spectrum (S_recon)
    - Uncertainty estimates (σ)
    - Probabilistic taxonomic classification (C_classify)

1. Initialize the PCA model using the reference spectra (S_train):
    a. Compute principal components (PCs) to define the latent space.
    b. Train a Kernel Density Estimator (KDE) on the latent coefficients to form a continuous prior distribution.

2. Forward modeling:
    a. Simulate synthetic photometry (m_synthetic) for each augmented spectrum by convolving with instrument-specific filter responses.
    b. Inject Gaussian noise (relative uncertainty ~20%) to simulate observational uncertainties.

3. Training phase:
    a. Use AutoML regressor (e.g., Gradient Boosted Decision Trees) to learn the mapping from sparse photometry (m) to latent coefficients (z).
    b. Augment training data with synthetic samples generated from the KDE prior to enhance manifold coverage and model stability.

4. Inference phase:
    a. For new photometric observations (m_new):
        i. Predict latent coefficients (z_pred) using the trained AutoML regressor.
        ii. Sample from the posterior distribution of z using a Gaussian Copula framework to preserve physical dependencies.
    b. Project the latent coefficients through the inverse PCA transform to obtain the reconstructed spectrum (S_recon).
    c. Propagate uncertainties through the transformation to estimate spectral uncertainties (σ).

5. Taxonomy classification:
    a. Apply the trained taxonomic classifier on the latent coefficients to obtain probability distributions over spectral types.
    b. Classify the object into the most probable taxonomic category.

6. Validation and applications:
    a. Perform leave-one-out cross-validation (LOOCV) to assess reconstruction accuracy and uncertainty calibration.
    b. Evaluate taxonomic classification accuracy.
    c. Identify outliers by analyzing posterior distributions in latent space.
    d. Optimize survey configurations by evaluating filter sensitivity and information content.

End Algorithm
```
