Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Observed photometric measurements m
    - Training set of reference spectra S_train
    - Filter response functions for NIRCam filters

Output:
    - Reconstructed spectrum S_recon
    - Classification probabilities for taxonomic types

Steps:

1. Preprocessing:
    a. Normalize photometric measurements to reflectance units.
    b. Apply noise injection (20% relative uncertainty) to simulate real photometry.

2. Latent Space Definition:
    a. Perform Principal Component Analysis (PCA) on S_train to obtain basis vectors.
    b. Determine optimal number of principal components K (via LOOCV).

3. Data Augmentation:
    a. Generate synthetic latent vectors using KDE on PCA coefficients of S_train.
    b. Forward model synthetic spectra through NIRCam filters to create mock photometry.

4. Model Training:
    a. Use AutoML regressor (e.g., XGBoost) to train mapping from photometry to latent coefficients.
    b. Train taxonomic classifier on latent space.

5. Inference:
    a. Encode observed photometry m into latent space using trained regressor.
    b. Decode latent coefficients into full spectrum S_recon via inverse PCA.
    c. Classify spectrum into taxonomic groups using latent classifier.

6. Uncertainty Quantification:
    a. Sample posterior distribution of latent coefficients using Gaussian Copula.
    b. Propagate uncertainties to reconstruct spectrum and compute credible intervals.
