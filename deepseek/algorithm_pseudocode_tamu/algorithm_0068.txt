### Algorithm: Probabilistic Spectral Reconstruction Framework

#### Input:
- Observed photometry vector **m** (sparse multi-band measurements)
- Pre-trained Principal Component Analysis (PCA) model with eigenvectors **U** and eigenvalues **Σ**
- Trained AutoML regressor (Encoder) that maps photometry to latent coefficients
- Synthetic training data generated via forward modeling and KDE augmentation
- Latent manifold defined by PCA basis and Gaussian Copula for posterior sampling

#### Output:
- Reconstructed full spectrum **S** with uncertainties
- Posterior distribution over latent coefficients
- Probabilistic taxonomic classification

#### Steps:

1. **Forward Modeling and Synthetic Data Generation**:
   - For training, generate synthetic photometry **m_synthetic** by convolving PCA-projected spectra with instrument response functions (e.g., JWST/NIRCam filters).
   - Inject Gaussian noise (20% relative reflectance uncertainty) into **m_synthetic** to simulate real-world photometric uncertainties.

2. **Latent Space Definition**:
   - Project training spectra into a low-dimensional PCA space to obtain latent coefficients **z**.
   - Use Kernel Density Estimation (KDE) with Gaussian kernels to create a continuous probability distribution over the latent space, ensuring smooth interpolation between discrete training examples.

3. **Model Training**:
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to learn the mapping from **m** to latent coefficients **z**.
   - Augment training data using synthetic latent samples generated from KDE to improve model robustness in low-sample regime.

4. **Inference Phase**:
   - For a new photometric observation **m_new**, predict latent coefficients **z_pred** using the trained AutoML regressor.
   - Apply inverse PCA transformation to **z_pred** to reconstruct the full spectrum **S_reconstructed**.

5. **Uncertainty Quantification**:
   - Sample the joint posterior distribution of **z** using Gaussian Copula, preserving physical dependencies between latent dimensions.
   - Generate multiple realizations of **S_reconstructed** to construct confidence intervals and assess uncertainty propagation.

6. **Taxonomic Classification**:
   - Project **z_pred** into the pre-trained taxonomic classifier to obtain probability distribution over spectral types (e.g., H₂O, CO₂, Organics, Methanol).

7. **Validation**:
   - Compare **S_reconstructed** with ground-truth spectrum using RMSE, PCC, and credible interval coverage metrics.
   - Perform leave-one-out cross-validation (LOOCV) across training set to assess model generalization and calibration.

8. **Applications**:
   - **Survey Optimization**: Compute Fisher Information Matrix (FIM) for different filter configurations to identify optimal observing strategies.
   - **Outlier Detection**: Flag objects with posterior distributions lying outside high-density regions of the latent manifold as potential spectral outliers.
