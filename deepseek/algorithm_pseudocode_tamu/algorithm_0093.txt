```plaintext
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Initialize:
   - Obtain a sample of reference TNO near-IR spectra.
   
2. Perform Principal Component Analysis (PCA):
   - Compute principal components (PCs) from the reference spectra, capturing dominant spectral variations.
   
3. Construct Latent Space:
   - Use PCA to project reference spectra into a low-dimensional latent space.
   - Augment the latent space using Kernel Density Estimation (KDE) to create a continuous probability distribution.
   
4. Generate Synthetic Training Data:
   - Forward model synthetic photometry by convolving spectra with instrumental filter responses (e.g., JWST/NIRCam).
   - Add Gaussian noise (relative uncertainty ~20%) to simulate observational uncertainties.
   
5. Train AutoML Regressor:
   - Use an ensemble of gradient-boosted decision trees to map sparse photometry to latent space coefficients.
   
6. Validate via Leave-One-Out Cross-Validation (LOOCV):
   - For each held-out spectrum, compute RMSE, credible interval coverage, and taxonomic classification accuracy.
   
7. Reconstruct Spectra:
   - For new photometric observations, predict latent coefficients using the trained regressor.
   - Apply inverse PCA transformation to obtain full spectrum reconstruction.
   - Sample posterior distributions using Gaussian Copula to quantify uncertainties.
   
8. Perform Taxonomic Classification:
   - Classify objects based on latent coefficients to determine spectral type probabilities.
   
9. Applications:
   a. Identify optimal filter configurations for future surveys using Fisher Information Matrix.
   b. Detect outliers by assessing deviations from the learned spectral manifold.
```
