**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **PCA Initialization**
   - Input: Reference spectra dataset.
   - Apply Principal Component Analysis (PCA) to obtain principal components (PCs) and transformation matrices.
   
2. **Data Augmentation**
   - Using Kernel Density Estimation (KDE) on PCA coefficients of reference spectra, generate synthetic data points.
   
3. **Model Training**
   - For each synthetic spectrum:
     - Generate synthetic photometry by convolving with filter response curves, adding 20% Gaussian noise.
     - Pair synthetic photometry with corresponding PCA coefficients.
   - Train an AutoML regressor (e.g., XGBoost) on the paired dataset to map photometry to PCA coefficients.
   
4. **Forward Inference**
   - For new photometric data:
     - Use the trained regressor to predict PCA coefficients.
     - Reconstruct the full spectrum using inverse PCA transformation.
     
5. **Posterior Sampling**
   - Use Gaussian Copula to sample from the joint posterior of PCA coefficients.
   - Calculate uncertainty intervals (e.g., 68%, 95%) for the reconstructed spectrum.
   
6. **Output**
   - Return reconstructed spectrum and uncertainty intervals.

This algorithm efficiently reconstructs high-resolution spectra from sparse photometry using a Bayesian framework and manifold learning, enabling probabilistic characterization of trans-Neptunian objects.
