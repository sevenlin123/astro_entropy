Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- Training Spectra: Set of reference TNO near-IR spectra (seed data)
- Observed Photometry: Sparse multi-band photometric measurements
- Filter Responses: Effective throughput curves of observation instruments (e.g., JWST NIRCam)

Output:
- Reconstructed Spectrum: Full spectral energy distribution with uncertainty quantification
- Taxonomic Classification: Probabilistic assignment to spectral types (H₂O, CO₂, Organics, Methanol)
- Informative Filter Configuration: Optimal filter set for maximizing spectral information content

Steps:

1. Latent Space Definition:
   a. Perform Principal Component Analysis (PCA) on the training spectra to extract principal components (PCs).
   b. Use Kernel Density Estimation (KDE) to create a continuous probability distribution in the latent space defined by the PCs.

2. Synthetic Data Generation:
   a. For each point in the latent space, generate synthetic photometry by forward modeling through the instrument filter responses.
   b. Inject Gaussian noise into the synthetic photometry to simulate observational uncertainties.

3. Model Training:
   a. Train an automated machine learning regressor (e.g., AutoGluon) to map observed photometry to latent space coordinates.
   b. Simultaneously train a classifier to assign taxonomic labels based on the latent space coordinates.

4. Leave-One-Out Cross-Validation:
   a. For each held-out spectrum, retrain the regressor and classifier using the remaining data.
   b. Validate reconstruction accuracy and uncertainty quantification metrics (RMSE, PCC, CIC).

5. Reconstruction Pipeline:
   a. For new photometric observations:
      i. Predict latent coordinates using the trained regressor.
      ii. Project latent coordinates through inverse PCA to reconstruct the full spectrum.
      iii. Sample from the joint posterior distribution using Gaussian Copula to generate uncertainty intervals.

6. Application:
   a. Survey Optimization:
      i. Identify filter configurations that maximize information content for spectral reconstruction.
      ii. Select optimal filters (e.g., F090W, F115W, F410M, F460M) based on expected information gains.

   b. Outlier Detection:
      i. Analyze posterior distributions to identify objects with spectral types deviating from the manifold.
      ii. Detect rare spectral types by constraining photometry to select low-probability intermediate models.

End.
