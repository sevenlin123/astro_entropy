**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Principal Component Analysis (PCA):**
   - **Input:** Reference TNO spectra dataset.
   - **Output:** Latent space defined by principal components (PCs).
   - **Process:** Train PCA on the spectral data to obtain eigenvalues, eigenvectors, and latent coefficients for each spectrum.

2. **Data Augmentation with Kernel Density Estimation (KDE):**
   - **Input:** Latent coefficients from PCA.
   - **Output:** Enhanced latent manifold with synthetic samples.
   - **Process:** Apply KDE with a Gaussian kernel to smooth the probability density, creating a continuous manifold.

3. **Forward Modeling for Synthetic Photometry:**
   - **Input:** Augmented latent spectra and instrument filter responses.
   - **Output:** Synthetic photometric measurements with added noise.
   - **Process:** Convolve each spectrum with the filter transmission curves, inject Gaussian noise (relative uncertainty ~20%), and generate a training database.

4. **Automated Machine Learning (AutoML) Regression Training:**
   - **Input:** Synthetic photometry and corresponding latent coefficients.
   - **Output:** Trained encoder model mapping photometry to latent space.
   - **Process:** Use AutoML (e.g., XGBoost, Neural Networks) to train a regressor on the augmented dataset.

5. **Leave-One-Out Cross-Validation (LOOCV):**
   - **Input:** Original 51 TNO spectra.
   - **Output:** Model validation metrics (RMSE, credible interval coverage).
   - **Process:** For each object, remove it from training, retrain the model, and evaluate reconstruction accuracy.

6. **Spectral Reconstruction:**
   - **Input:** New sparse photometric observations.
   - **Output:** Posterior distribution of latent coefficients and reconstructed spectrum.
   - **Process:** Use the trained encoder to predict latent coefficients, apply inverse PCA to reconstruct the full spectrum, and sample from the posterior using Gaussian Copula to account for dependencies.

7. **Taxonomic Classification:**
   - **Input:** Predicted latent coefficients.
   - **Output:** Probability distribution over spectral types.
   - **Process:** Classify the latent space projections using a secondary AutoML classifier trained on labeled spectral types.

8. **Survey Optimization and Outlier Detection:**
   - **Input:** Filter sensitivity analysis.
   - **Output:** Optimal filter configurations and identified rare spectral types.
   - **Process:** Assess filter contributions to reconstruction fidelity and detect outliers via low posterior probabilities in the latent space.
