```
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- Training set of reference TNO spectra (seed spectra)
- Observed sparse photometric measurements (input_photometry)
- NIRCam filter set specifications

Output:
- Reconstructed high-resolution spectrum
- Probabilistic taxonomic classification
- Confidence intervals for spectral features

Steps:

1. Preprocessing:
   a. Normalize and preprocess reference spectra and photometry data.
   
2. Latent Space Definition:
   a. Perform Principal Component Analysis (PCA) on the seed spectra to extract principal components (PCs).
   b. Construct a latent space using the PCs, representing the reduced spectral manifold.
   
3. Data Augmentation:
   a. Use Kernel Density Estimation (KDE) to generate synthetic latent vectors, expanding the training dataset.
   
4. Model Training:
   a. Forward model synthetic spectra through NIRCam filters to generate training photometry with added noise (relative uncertainty ~20%).
   b. Train an AutoML regressor (ensemble of gradient-boosted trees) to map input photometry to latent coefficients.
   
5. Bayesian Inference:
   a. For each test case:
      i. Remove the test spectrum from the training set.
      ii. Use the trained regressor to predict latent coefficients from input photometry.
      iii. Apply inverse PCA transform to reconstruct the full spectrum.
   b. Sample the joint posterior of latent coefficients using Gaussian Copula to quantify uncertainties.
   
6. Taxonomic Classification:
   a. Train a separate AutoML classifier on the latent space to predict taxonomic categories.
   b. Provide posterior probabilities for each taxonomic label.
   
7. Validation:
   a. Perform Leave-One-Out Cross-Validation (LOOCV) to assess reconstruction accuracy and uncertainty coverage.
   
8. Information Content Analysis:
   a. Compute Mutual Information between NIRCam filters and latent coefficients to evaluate filter utility.
   
9. Outlier Detection:
   a. Calculate Mahalanobis distance of test spectra from the latent prior distribution.
   b. Identify outliers based on distance thresholds.
   
10. Output:
    a. Return reconstructed spectrum, confidence intervals, taxonomic probabilities, and outlier status.
```

```plaintext
ALGORITHM STRUCTURE:
- The algorithm begins with preprocessing and defining a latent space through PCA.
- Synthetic data augmentation enhances the training set for low-sample issues.
- An AutoML regressor learns the mapping from photometry to latent space.
- Bayesian inference reconstructs full spectra with uncertainty quantification.
- A classifier operates on the latent space for taxonomic predictions.
- Extensive validation and analysis steps ensure robust performance.
```
