### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

#### 1. **Training Phase**
   - **Input:** Set of reference TNO spectra, photometric observations, and filter responses.
   - **Output:** Trained encoder-decoder model and latent space representation.
   
   1. **Principal Component Analysis (PCA):**
      - Perform PCA on the reference spectra to obtain principal components (PCs).
      - Extract top K PCs (e.g., 4-5 for classification, 8-10 for fidelity).
   
   2. **Latent Space Definition:**
      - Project reference spectra onto the top K PCs to get latent coefficients.
      - Use Kernel Density Estimation (KDE) to create a smooth prior distribution in the latent space.
   
   3. **Forward Modeling:**
      - Simulate photometric observations by convolving spectra with filter responses.
      - Inject Gaussian noise (e.g., 20% relative uncertainty) to mimic real-world measurements.
   
   4. **AutoML Regressor Training:**
      - Train an ensemble of gradient-boosted decision trees to map noisy photometry to latent coefficients.
      - Use synthetic data generated from the latent space for training stability.
   
   5. **Classifier Training:**
      - Train a secondary AutoML classifier on the latent coefficients to predict taxonomic labels.

#### 2. **Reconstruction Phase**
   - **Input:** New sparse photometric observations.
   - **Output:** Reconstructed spectrum and taxonomic classification.
   
   1. **Predict Latent Coefficients:**
      - Pass photometric data through the trained encoder to obtain latent coefficient estimates.
   
   2. **Generate Ensembles:**
      - Sample from the posterior distribution using a Gaussian Copula to account for dependencies.
   
   3. **Inverse PCA Transform:**
      - Project the sampled latent coefficients back to the full spectrum using the PCA basis.
   
   4. **Taxonomic Classification:**
      - Classify the object by evaluating the latent coefficients against the trained classifier.

#### 3. **Evaluation Phase**
   - **Input:** Leave-one-out validation data.
   - **Output:** RMSE, credible interval coverage, and classification accuracy.
   
   1. **LOOCV Iterations:**
      - Remove one spectrum, train models on the remaining data, and reconstruct the held-out spectrum.
   
   2. **Performance Metrics:**
      - Compute RMSE across the spectrum.
      - Assess credible interval coverage (e.g., 95% intervals).
      - Measure taxonomic classification accuracy.

#### 4. **Application Phase**
   - **Inputs:** New photometric observations, filter configurations.
   - **Outputs:** Optimized filter sets, outlier detection, compositional maps.
   
   1. **Survey Optimization:**
      - Evaluate information content of filter configurations using the trained framework.
   
   2. **Outlier Detection:**
      - Identify rare spectral types by constraining photometry and sampling low-probability regions.
   
   3. **Compositional Mapping:**
      - Apply the framework to large datasets to map TNO diversity across the Solar System.

```python
function Train_Framework(reference_spectra, filter_responses):
    # Step 1: PCA on reference spectra
    pca = PCA(n_components=K)
    latent_coefficients = pca.fit_transform(reference_spectra)
    
    # Step 2: Create prior distribution using KDE
    kde = KDE(latent_coefficients)
    
    # Step 3: Generate synthetic photometry
    synthetic_photometry = []
    for spec in augmented_latent:
        convolved_spec = convolve(spec, filter_responses)
        noisy_phot = add_noise(convolved_spec, sigma=0.2)
        synthetic_photometry.append(noisy_phot)
    
    # Step 4: Train AutoML regressor
    regressor = AutoMLRegressor()
    regressor.fit(synthetic_photometry, latent_coefficients)
    
    # Step 5: Train classifier
    classifier = AutoMLClassifier()
    classifier.fit(latent_coefficients, taxonomic_labels)
    
    return pca, regressor, classifier, kde
```

```python
function Reconstruct_Spectrum(new_photometry, pca, regressor, classifier, kde):
    # Step 1: Predict latent coefficients
    predicted_latent = regressor.predict(new_photometry)
    
    # Step 2: Generate posterior samples
    samples = kde.sample(n_samples=100, x=predicted_latent)
    
    # Step 3: Inverse PCA transform
    reconstructed_spectra = [pca.inverse_transform(sample) for sample in samples]
    
    # Step 4: Classify taxonomic type
    taxonomic_prediction = classifier.predict(predicted_latent)
    
    return reconstructed_spectra, taxonomic_prediction
```

```python
function Validate_Framework(reference_spectra, filter_responses):
    # Step 1: Initialize validation metrics
    rmse = 0
    coverage = 0
    accuracy = 0
    
    # Step 2: LOOCV loop
    for i in range(len(reference_spectra)):
        # Remove one spectrum
        train_spectra = np.delete(reference_spectra, i, axis=0)
        
        # Retrain models
        pca, regressor, classifier, kde = Train_Framework(train_spectra, filter_responses)
        
        # Reconstruct held-out spectrum
        photometry = get_photometry(reference_spectra[i])
        recon_spectra, recon_label = Reconstruct_Spectrum(photometry, pca, regressor, classifier, kde)
        
        # Evaluate metrics
        rmse += mean_squared_error(reference_spectra[i], recon_spectra.mean(axis=0))
        coverage += check_credential_intervals(reference_spectra[i], recon_spectra)
        accuracy += accuracy_score([true_label[i]], [recon_label])
    
    # Step 3: Normalize metrics
    rmse /= len(reference_spectra)
    coverage /= len(reference_spectra)
    accuracy /= len(reference_spectra)
    
    return rmse, coverage, accuracy
```
