Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Input: Sparse photometric measurements of a Trans-Neptunian Object (TNO)
2. Initialize:
   a. Load reference TNO spectra and compute Principal Component Analysis (PCA)
   b. Determine optimal number of principal components (PCs) based on explained variance
   c. Train an autoencoder using reference spectra to create a latent space representation
   d. Construct a kernel density estimate (KDE) of the latent space from PCA coefficients

3. Forward Modeling:
   a. Simulate synthetic photometry for each augmented spectrum by convolving with instrument filter responses (e.g., JWST/NIRCam)
   b. Inject Gaussian noise with relative reflectance uncertainty (e.g., 20%) into synthetic photometry

4. Training:
   a. Use synthetic photometry and corresponding PCA coefficients to train an automated machine learning (AutoML) regressor (e.g., Gradient Boosted Decision Trees)
   b. Train a secondary AutoML classifier to partition the latent space for taxonomic classification

5. Inference:
   a. Pass sparse photometric measurements through the trained regressor to predict latent space coordinates
   b. Apply inverse PCA transformation to reconstruct the full spectrum
   c. Sample posterior distributions of latent coordinates using Gaussian Copula to generate confidence intervals
   d. Classify spectral type using latent space coordinates

6. Output: Reconstructed spectrum, confidence intervals, and taxonomic classification
