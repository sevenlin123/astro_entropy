### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

```plaintext
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Set of reference TNO spectra S_ref
    - Observed photometric measurements m
    - NIRCam filter responses
    - Training parameters

Output:
    - Reconstructed spectrum S_hat
    - Uncertainty estimates
    - Taxonomic classification probabilities

1. **Preprocessing**
    a. Normalize and bin reference spectra S_ref to match NIRCam filter bands.
    b. Convert observed photometry m into reflectance or flux densities.

2. **Principal Component Analysis (PCA)**
    a. Train PCA on S_ref to obtain principal components (PCs) and eigenvalues.
    b. Project reference spectra onto PCA space to get latent coefficients.

3. **Latent Space Construction**
    a. Augment latent coefficients using Kernel Density Estimation (KDE) to form a continuous manifold.
    b. Define Gaussian kernel for smooth density estimation.

4. **Forward Modeling**
    a. Simulate synthetic photometry from augmented latent spectra by convolving with NIRCam filter responses.
    b. Inject Gaussian noise (20% relative uncertainty) into synthetic photometry.

5. **AutoML Regressor Training**
    a. Train ensemble of gradient-boosted decision trees (e.g., XGBoost) to map noisy photometry to latent coefficients.
    b. Optimize hyperparameters using validation set.

6. **Leave-One-Out Cross-Validation (LOOCV)**
    a. Remove one reference spectrum.
    b. Augment remaining latent coefficients using KDE.
    c. Forward model to generate mock photometry with noise.
    d. Use trained regressor to predict latent coefficients from mock photometry.
    e. Inverse transform to reconstruct spectrum S_hat.
    f. Compute error metrics (MAE, RMSE) between S_hat and held-out spectrum.

7. **Optimal Principal Components Selection (k)**
    a. Incrementally increase k starting from 2.
    b. Evaluate MAE for each k using LOOCV.
    c. Select smallest k where MAE saturates.

8. **Reconstruction**
    a. For new photometry m, predict latent coefficients using trained regressor.
    b. Apply inverse PCA transform to obtain S_hat.
    c. Sample from joint posterior using Gaussian Copula for uncertainty quantification.

9. **Taxonomic Classification**
    a. Project predicted latent coefficients into taxonomic manifold.
    b. Classify using pre-trained AutoML classifier to assign probabilities to taxonomic groups.

10. **Output**
    a. Return reconstructed spectrum S_hat.
    b. Return uncertainty intervals.
    c. Return taxonomic classification probabilities.

End Algorithm
```
