**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Preparation**
   - Collect sparse photometric measurements for trans-Neptunian objects (TNOs).
   - Define a set of filters corresponding to the photometric bands (e.g., JWST/NIRCam filters).

2. **Principal Component Analysis (PCA)**
   - Train PCA on a reference set of TNO spectra to reduce dimensionality.
   - Determine the optimal number of principal components (e.g., 4-10) based on variance explained and LOOCV results.

3. **Latent Space Definition**
   - Project reference spectra into the PCA-defined latent space.
   - Apply Kernel Density Estimation (KDE) to estimate the probability density in the latent space.

4. **Data Augmentation**
   - Generate synthetic spectra by sampling the latent space using the estimated KDE.
   - Forward simulate photometric measurements for each synthetic spectrum using the target instrument's filter response.

5. **Model Training**
   - Use AutoML (e.g., Gradient Boosted Decision Trees) to train a regressor that maps photometric inputs to latent space coefficients.
   - Incorporate simulated photometric noise (e.g., 20% relative uncertainty) during training.

6. **Inference Phase**
   - For new photometric data:
     a. Predict latent coefficients using the trained regressor.
     b. Apply inverse PCA transformation to reconstruct the full spectrum.
     c. Sample the posterior distribution of latent coefficients to generate uncertainty estimates.

7. **Output**
   - Reconstructed spectrum with associated uncertainty intervals.
   - Probabilistic taxonomic classification based on latent space analysis.

**Steps Explained:**

- **PCA Training:** Reduces high-dimensional spectra to a manageable number of principal components, capturing the most significant variations.
- **KDE Augmentation:** Creates a smooth manifold of possible spectra, enhancing the model's ability to handle sparse data.
- **AutoML Regression:** Learns the mapping from photometry to spectral features, enabling reconstruction even with limited input bands.
- **Inverse PCA:** Converts latent coefficients back into full spectra, leveraging the physical structure of the data.
- **Posterior Sampling:** Provides uncertainty quantification by exploring the latent space probabilistically.

This algorithm efficiently bridges sparse photometric data to detailed spectral reconstruction, facilitating taxonomic classification and outlier detection in TNO studies.
