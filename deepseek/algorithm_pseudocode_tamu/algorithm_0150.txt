Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input: 
- Sparse photometric observations (bands)
- Training set of reference spectra
- NIRCam filter set parameters

Output:
- Reconstructed full spectrum
- Taxonomic classification probabilities

Steps:

1. Preprocessing:
   a. Apply Principal Component Analysis (PCA) to the training spectra to obtain principal components (PCs).
   b. Select the optimal number of PCs (K) based on reconstruction fidelity and validation.

2. Latent Space Construction:
   a. Project the reference spectra onto the selected PCs to form the initial latent space.
   b. Augment the latent space using Kernel Density Estimation (KDE) to create a continuous probability distribution.

3. Synthetic Training Database:
   a. Generate synthetic spectra by sampling the augmented latent space.
   b. Forward model these synthetic spectra through the NIRCam filters to simulate photometric observations.
   c. Add Gaussian noise (20% relative uncertainty) to the synthetic photometry.

4. Model Training:
   a. Train an AutoML regressor (ensemble of gradient-boosted decision trees) to map synthetic photometry to latent coefficients.
   b. Optimize model hyperparameters using cross-validation on the synthetic database.

5. Inference Pipeline:
   a. For new photometric observations:
      i. Predict latent coefficients using the trained regressor.
      ii. Sample the joint posterior distribution of latent coefficients using Gaussian Copula to account for dependencies.
      iii. Project the sampled latent coefficients back to the full spectrum via inverse PCA transformation.

6. Taxonomic Classification:
   a. Train a separate classifier on the latent space to predict taxonomic probabilities.
   b. Provide classification results alongside spectral reconstruction.

7. Validation:
   a. Perform leave-one-out cross-validation by iteratively removing each target spectrum from training, retraining the model, and reconstructing the held-out spectrum.

End
