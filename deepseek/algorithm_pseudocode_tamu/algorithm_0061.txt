```plaintext
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Input: Observed photometric measurements of a trans-Neptunian object (TNO).

2. Initialize:
   - Pretrained Principal Component Analysis (PCA) model trained on a reference sample of TNO spectra.
   - Kernel Density Estimation (KDE) model built from the PCA coefficients of the reference sample.
   - Synthetic training data generated by sampling the latent space defined by the PCA and KDE.

3. Forward Modeling:
   - Simulate photometric measurements for each synthetic spectrum by convolving with the instrument response (e.g., JWST/NIRCam filters).
   - Inject Gaussian noise with 20% relative uncertainty into the simulated photometry to account for observational errors.

4. Training:
   - Use AutoML regressor (ensemble of gradient-boosted decision trees) to train a model mapping noisy photometry to latent PCA coefficients.
   - Augment the training set with synthetic data to improve model generalization in low-sample regime.

5. Inference:
   - For new photometric observations:
     a. Predict latent PCA coefficients using the trained AutoML regressor.
     b. Sample the joint posterior distribution of latent coefficients using Gaussian Copula to account for dependencies.
     c. Project the latent coefficients through inverse PCA transform to reconstruct the full spectrum.

6. Output:
   - Reconstructed spectrum with propagated uncertainties.
   - Probabilistic taxonomic classification based on latent space prediction.

7. Validation Metrics:
   - Normalized Root Mean Square Error (NRMSE) for spectral reconstruction.
   - Empirical credible interval coverage assessment.
   - Taxonomic classification accuracy based on posterior probabilities.
```

Pseudocode:

function spectral_reconstruction(photometry):
    # Step 1: Normalize photometric measurements
    normalized_phot = normalize(photometry)

    # Step 2: Predict latent PCA coefficients
    latent_coeffs = auto_mlRegressor.predict(normalized_phot)

    # Step 3: Sample posterior distribution
    samples = gaussian_copula_sampler(latent_coeffs)

    # Step 4: Reconstruct spectra from samples
    reconstructed_spectra = [inverse_pca_transform(sample) for sample in samples]

    # Step 5: Calculate uncertainties
    uncertainty_intervals = calculate_uncertainty(reconstructed_spectra)

    # Step 6: Perform taxonomic classification
    taxonomic_probs = taxonomic_classifier.predict_proba(latent_coeffs)

    return reconstructed_spectra, uncertainty_intervals, taxonomic_probs
