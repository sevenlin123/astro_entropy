### Pseudocode Algorithm for Probabilistic Spectral Reconstruction from Sparse Photometry

**Algorithm: Probabilistic Spectral Reconstruction (PSR)**
```python
Function PSR(photometry, spectral_library):
    1. **Principal Component Analysis (PCA) on Spectral Library**:
        a. Compute PCA on the reference spectral library to obtain principal components (PCs) and loadings.
        b. Determine the optimal number of PCs (K) based on explained variance or cross-validation.

    2. **Training Phase**:
        a. Augment the training data using Kernel Density Estimation (KDE) on the PCA latent space to create synthetic spectra.
        b. Forward model synthetic photometry by convolving augmented spectra with instrument throughput curves (e.g., JWST NIRCam filters).
        c. Inject Gaussian noise into synthetic photometry to simulate real observational uncertainties.
        d. Train an automated machine learning regressor (e.g., AutoGluon) to map photometric inputs to PCA latent coefficients.

    3. **Inference Phase**:
        a. For new photometric observations, predict latent coefficients using the trained regressor.
        b. Perform inverse PCA transform using predicted coefficients to reconstruct the full spectrum.
        c. Sample posterior uncertainty via Gaussian Copula to generate confidence intervals.

    4. **Taxonomic Classification**:
        a. Train a classifier on the PCA latent space to assign taxonomic labels (e.g., H₂O, CO₂, Organic).
        b. Predict taxonomic probabilities for inferred latent coefficients.

    5. **Optional Applications**:
        a. **Survey Optimization**: Evaluate different filter configurations to maximize information content.
        b. **Outlier Detection**: Flag objects with low posterior density in latent space as potential outliers.

    Return reconstructed_spectrum, taxonomic_prediction, uncertainty_intervals
```

**Explicit Computational Steps:**

1. **PCA Initialization**:
   - Input the spectral library and compute PCA to extract eigenvectors (principal components) and eigenvalues.
   - Select the number of components (K) that captures sufficient spectral variance (e.g., 8–10 components for high fidelity).

2. **Data Augmentation**:
   - Use KDE on the PCA latent space of the spectral library to generate synthetic data points, ensuring a smooth distribution.
   - Forward model these synthetic spectra through the instrument response functions to simulate photometric measurements.

3. **Regressor Training**:
   - Combine real and synthetic photometric data with corresponding PCA coefficients as labels.
   - Train an ensemble regressor (e.g., XGBoost, Neural Networks) to learn the mapping from photometry to latent space.

4. **Spectral Reconstruction**:
   - For a new object, input its photometric measurements into the trained regressor to obtain latent coefficients.
   - Apply inverse PCA to reconstruct the full spectrum from the coefficients.

5. **Uncertainty Propagation**:
   - Sample the joint posterior of latent coefficients using Gaussian Copula to account for dependencies.
   - Generate multiple realizations of the spectrum to compute credible intervals.

6. **Classification**:
   - Project the reconstructed latent coefficients into a pre-trained classifier to determine taxonomic affiliation.

7. **Applications**:
   - **Optimization**: Test various filter sets to identify those maximizing spectral information content.
   - **Outlier Detection**: Assess posterior density in latent space to identify unusual objects.

This algorithm provides a structured approach to reconstructing detailed spectra from sparse photometric data, enabling taxonomic classification and outlier detection while quantifying uncertainties.
