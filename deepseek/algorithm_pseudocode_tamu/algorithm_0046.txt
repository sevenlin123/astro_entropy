Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Observed photometric measurements (sparse)
    - Training set of reference TNO spectra
    - Principal Component Analysis (PCA) basis derived from training set
    - Synthetic data augmented using Kernel Density Estimation (KDE)
    - AutoML regressor trained on encoded features

Output:
    - Reconstructed spectrum with uncertainty estimates
    - Probabilistic taxonomic classification

Steps:

1. **Dimensionality Reduction (Latent Space Definition)**:
    a. Apply PCA to the training set of TNO spectra to obtain principal components.
    b. Use the resulting eigenvectors as a basis for the latent space.

2. **Data Augmentation**:
    a. Generate synthetic latent vectors using KDE on the PCA coefficients of the training set.
    b. Inject Gaussian noise into synthetic photometry to simulate observational uncertainties.

3. **Forward Modeling**:
    a. Simulate photometric observations from synthetic spectra by convolving with instrument-specific filter responses.

4. **Training Phase**:
    a. Train an AutoML regressor (e.g., gradient-boosted decision trees) to map sparse photometry to latent space coefficients.
    b. Simultaneously train a classifier to partition the latent space into taxonomic classes.

5. **Inference Phase**:
    a. For new photometric observations:
        i. Predict latent coefficients using the trained regressor.
        ii. Project the latent coefficients back to the full spectrum via inverse PCA transformation.
    b. Sample the posterior distribution of latent coefficients using Gaussian Copula to quantify uncertainties.

6. **Uncertainty Quantification**:
    a. Construct empirical credible intervals from posterior samples.
    b. Evaluate coverage and fidelity against reference spectra.

7. **Taxonomy Classification**:
    a. Use the latent space classifier to predict taxonomic probabilities.
    b. Identify outliers based on deviation from expected distributions.

8. **Survey Optimization & Outlier Detection**:
    a. Assess information content of different filter configurations.
    b. Detect anomalous spectra by their low probability in the latent manifold.
