### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Training Phase**:
   - **Input**: A set of reference TNO spectra (N = 51) and corresponding photometric measurements.
   - **Output**: A probabilistic model for spectral reconstruction.

2. **Principal Component Analysis (PCA)**:
   - Project the reference spectra onto a low-dimensional latent space using PCA.
   - Determine the number of principal components (K) that capture the dominant spectral variability (K ≈ 4-5 for classification, up to K ≈ 8-10 for improved fidelity).

3. **Data Augmentation with KDE**:
   - Generate synthetic spectra by applying Kernel Density Estimation (KDE) to smooth the latent space.
   - Use a Gaussian kernel with a bandwidth (h) optimized for the dataset (e.g., h ≈ 0.5).

4. **Forward Modeling**:
   - Simulate photometric measurements for each augmented spectrum by convolving with the instrument response functions (JWST/NIRCam filters).
   - Inject Gaussian noise (relative uncertainty ≈ 20%) into the synthetic photometry to account for observational uncertainties.

5. **Training the AutoML Regressor**:
   - Train an ensemble of gradient-boosted decision trees (e.g., XGBoost) to map sparse photometry to latent PCA coefficients.
   - Use the augmented synthetic data for robust training in the low-sample regime.

6. **Inverse PCA Transform**:
   - Develop an inverse transformation from latent coefficients to full-resolution spectra using the PCA basis.

7. **Validation Phase**:
   - Perform Leave-One-Out Cross-Validation (LOOCV):
     - For each test spectrum:
       - Remove it from the training set.
       - Generate synthetic data using the remaining N-1 spectra.
       - Re-train the regressor and predict latent coefficients for the test spectrum.
       - Reconstruct the full spectrum using the inverse PCA transform.

8. **Posterior Sampling**:
   - Use a Gaussian Copula framework to sample the joint posterior distribution of latent coefficients.
   - Ensure the reconstructed spectra remain within physically viable regions of the manifold.

9. **Taxonomic Classification**:
   - Train a secondary classifier on the latent manifold to predict taxonomic groups (e.g., H₂O, CO₂, Organic types).
   - Assess classification confidence for each test case.

10. **Performance Metrics**:
    - Compute Reconstruction Error (NRMSE), Feature Preservation Score (FPS), Uncertainty Coverage (UC), Taxonomic Confidence (TC), and Outlier Detection Rate (ODR).

11. **Applications**:
    - **Survey Optimization**: Identify optimal filter configurations for future TNO surveys.
    - **Outlier Detection**: Flag spectra falling outside credible intervals for targeted follow-up.

12. **Final Output**:
    - For each input photometric observation:
      - Provide a reconstructed spectrum.
      - Offer a probability distribution over taxonomic classes.
      - Deliver credible intervals for key spectral features.
