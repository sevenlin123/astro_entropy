   - Inject Gaussian noise (relative uncertainty ~20%) into synthetic photometry for robustness.

3. Train AutoML regressor:
   - Use gradient-boosted decision trees to map sparse photometry to latent coefficients.
   - Input: noisy synthetic photometry; Output: latent coefficients.

4. Forward modeling for likelihood approximation:
   - Simulate photometric observations by convolving spectra with NIRCam filter curves.
   - Use synthetic data to construct implicit likelihood mapping.

5. Perform Bayesian inference:
   - Predict latent coefficients from observed photometry using the trained regressor.
   - Apply inverse PCA transform to reconstruct high-resolution spectrum.

6. Quantify uncertainties:
   - Sample joint posterior distribution using Gaussian Copula to maintain physical dependencies.
   - Generate credible intervals for reconstructed spectra.

7. Classify spectral type:
   - Map latent coefficients to predefined taxonomic groups (Water, CO₂, Organics, Methanol).
   - Output probability distribution over spectral types.

8. Validate using LOOCV:
   - Remove one spectrum, reconstruct, and compare with original.
   - Measure nRMSE, credible interval coverage, and classification accuracy.

9. Applications:
   - Optimize filter configurations for maximal information content.
