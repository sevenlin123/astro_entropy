3. **Forward Modeling and Noise Injection**:

4. **Regressor Training**:

5. **Prediction and Reconstruction**: 
   - For each new photometric observation, predict the latent variables using the trained regressor. Reconstruct the full spectrum using inverse PCA and propagate uncertainties through posterior sampling.

6. **Output Results**: 
   - Compile the reconstructed spectra and their associated uncertainties for all test cases.
