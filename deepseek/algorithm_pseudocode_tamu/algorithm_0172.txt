```
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Photometric measurements (sparse) of a TNO
    - Pre-trained PCA model derived from reference spectra
    - Pre-trained AutoML regressor (Encoder)
    - Pre-computed forward modeling of photometry through NIRCam filters
    
Output:
    - Reconstructed spectrum with uncertainty estimates
    - Taxonomic classification probabilities
    
Steps:

1. **Forward Modeling**:
    a. Simulate photometric observations using the NIRCam filter set based on the input photometric measurements.
    b. Apply Gaussian noise with 20% relative uncertainty to simulate observational conditions.

2. **Latent Space Inference**:
    a. Use the AutoML regressor (Encoder) to predict the latent coefficients from the noisy photometric inputs.
    b. Generate an ensemble of latent coefficient samples by incorporating the posterior uncertainties.

3. **Spectral Reconstruction**:
    a. Project the predicted latent coefficients back into the full spectrum space using the inverse PCA transform.
    b. Apply a Gaussian Copula to maintain physical dependencies between spectral features, ensuring samples stay within the learned manifold.

4. **Uncertainty Quantification**:
    a. Compute the 95% credible intervals for each wavelength bin from the reconstructed spectrum ensemble.
    b. Validate empirical coverage of credible intervals against the held-out spectrum.

5. **Taxonomic Classification**:
    a. Pass the mean latent coefficients through a pre-trained classifier to predict taxonomic probabilities (e.g., Water-type, CO₂-type, Organic-type).
    
6. **Output**:
    a. Return the reconstructed spectrum, credible intervals, and taxonomic probabilities.
```

This algorithm encapsulates the core computational steps required for spectral reconstruction, focusing solely on the inversion process from photometry to spectrum while leveraging pre-trained components for efficiency.
