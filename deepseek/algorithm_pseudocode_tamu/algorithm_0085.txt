Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Input: Sparse photometric measurements of TNOs
2. Initialize: 
   a. Training set of reference TNO spectra
   b. Principal Component Analysis (PCA) on the training spectra to obtain latent space
   c. Synthetic data generation using Kernel Density Estimation (KDE) for latent space regularization
3. Forward Model:
   a. Simulate photometric data from synthetic spectra using target instrument filter set (e.g., JWST/NIRCam)
   b. Inject Gaussian noise (20% relative uncertainty) into simulated photometry
4. Training Phase:
   a. Use AutoML regressor (e.g., XGBoost) to learn mapping from noisy photometry to latent coefficients
   b. Construct implicit likelihood via simulation-based inference
5. Inference Phase:
   a. For new photometric data, predict latent coefficients using trained regressor
   b. Apply inverse PCA transform to reconstruct full spectrum
   c. Sample posterior distribution of latent variables using Gaussian Copula to quantify uncertainties
6. Output: Reconstructed spectrum with uncertainties, taxonomic probability distribution

End Algorithm
