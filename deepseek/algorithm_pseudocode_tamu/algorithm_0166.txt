### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

#### Input:
- **Photometric Observations**: A set of sparse photometric measurements for a trans-Neptunian object (TNO).
- **Training Spectra**: A sample of reference TNO spectra used to construct the PCA basis.
- **Filter Set**: The set of photometric filters used to generate synthetic photometry for training.

#### Output:
- **Reconstructed Spectrum**: A full-resolution spectrum of the TNO.
- **Taxonomic Classification**: Probabilistic assignment of the object to a spectral type (e.g., Water-type, CO₂-type, Organics-type).

---

#### Step-by-Step Computational Steps:

1. **Preprocessing**:
   - Normalize the photometric observations to reflectance or flux densities.
   - Convert the photometric data into a format suitable for the AutoML regressor.

2. **Latent Space Definition**:
   - Perform **Principal Component Analysis (PCA)** on the training spectra to reduce the spectral dimensionality.
     - Extract principal components (PCs) that capture the dominant modes of spectral variability.
   - Use **Kernel Density Estimation (KDE)** on the PCA coefficients of the training spectra to define a continuous probability distribution in the latent space.
     - The bandwidth of the KDE is optimized (e.g., h ≈ 0.5) to ensure smooth interpolation between training examples.

3. **Data Augmentation**:
   - Generate synthetic training data by sampling from the KDE-defined latent distribution.
   - Forward-model these synthetic spectra through the photometric filters to produce synthetic photometric observations.
   - Inject Gaussian noise (e.g., 20% relative reflectance uncertainty) into the synthetic photometry to simulate observational errors.

4. **Model Training**:
   - Train an **Automated Machine Learning (AutoML) regressor** (e.g., ensemble of gradient-boosted decision trees) to map sparse photometric inputs to the latent PCA coefficients.
   - Use the synthetic photometry and corresponding PCA coefficients for training to ensure the model generalizes well to real data.

5. **Forward Inference**:
   - For a new photometric observation:
     - Pass the photometric data through the trained regressor to predict the latent PCA coefficients.
     - Apply **inverse PCA transformation** to reconstruct the full-resolution spectrum.
     - Use a **Gaussian Copula** to sample the joint posterior distribution of the latent coefficients, generating an ensemble of possible spectra while preserving physical constraints.

6. **Taxonomic Classification**:
   - Project the predicted latent coefficients into a pre-trained taxonomic classifier.
   - Assign probabilities to each spectral type based on the latent space distribution.

7. **Uncertainty Quantification**:
   - Calculate credible intervals for the reconstructed spectrum by analyzing the ensemble of possible reconstructions.
   - Validate the empirical coverage of these intervals (e.g., 95% coverage across wavelengths).

---

### Pseudocode:

```python
function probabilistic_spectral_reconstruction(photometry):
    # Step 1: Preprocess photometric data
    normalized_photometry = preprocess(photometry)

    # Step 2: Define latent space using PCA and KDE
    if not hasattr(model, 'pca'):
        model.pca = train_pca(reference_spectra)
    pca_coefficients_mean, pca_coefficients_variance = infer_latent(
        model.regressor, normalized_photometry
    )

    # Step 3: Reconstruct full spectrum from latent space
    reconstructed_spectrum = inverse_pca(model.pca, pca_coefficients_mean)
    uncertainty_intervals = sample_ensemble(
        model.gaussian_copula, pca_coefficients_mean, pca_coefficients_variance
    )

    # Step 4: Classify taxonomic type
    taxonomic_probabilities = model.classifier.predict_proba(pca_coefficients_mean)

    return reconstructed_spectrum, taxonomic_probabilities, uncertainty_intervals
```

### Explanation:

- **PCA and KDE**: Reduce the spectral dimensionality and define a smooth manifold for spectral variability.
- **Synthetic Data**: Augment the training set to handle sparse data and simulate realistic photometric uncertainties.
- **AutoML Regressor**: Learn the mapping from photometric inputs to spectral latent space, enabling robust predictions.
- **Inverse PCA**: Reconstruct the full spectrum from the latent coefficients, inheriting physical constraints from the training data.
- **Gaussian Copula**: Sample the posterior distribution of latent coefficients to quantify uncertainties while preserving physical correlations.
- **Taxonomic Classification**: Classify the object based on its position in the latent space, providing probabilistic assignments to spectral types.

This algorithm efficiently bridges the gap between sparse photometric data and detailed spectral reconstruction, enabling quantitative analysis of TNO surface compositions.
