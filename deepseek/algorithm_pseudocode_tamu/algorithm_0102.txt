Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Principal Component Analysis (PCA) Initialization**:
   - Input: Reference TNO spectra dataset
   - Output: Principal Component (PC) basis vectors (eigenvectors) and latent space representation
   - Perform PCA on the dataset to reduce dimensionality into a low-dimensional latent space.
   - Determine the number of significant principal components (K) based on explained variance.

2. **Kernel Density Estimation (KDE) Augmentation**:
   - Input: Latent coefficients from PCA initialization
   - Output: Enhanced latent manifold with smooth probability distribution
   - Apply Gaussian KDE to generate synthetic latent vectors, effectively interpolating between real observations.
   - Set the bandwidth (h) to ensure balanced smoothing between fidelity and global manifold continuity.

3. **Forward Modeling for Synthetic Photometry**:
   - Input: Enhanced latent vectors from KDE
   - Output: Simulated photometric measurements with noise
   - Convolve each enhanced spectrum with the instrumental response (e.g., JWST/NIRCam filters).
   - Inject Gaussian noise (relative uncertainty ~20%) into the synthetic photometry to simulate real-world observational uncertainties.

4. **Automated Machine Learning (AutoML) Training**:
   - Input: Synthetic photometric data paired with latent coefficients
   - Output: Trained regressor model (Encoder) mapping photometry to latent space
   - Use an ensemble of gradient-boosted decision trees (e.g., XGBoost) to train the regressor on the paired dataset.
   - Optimize hyperparameters automatically to avoid overfitting and enhance generalization.

5. **Leave-One-Out Cross-Validation (LOOCV)**:
   - Input: Original TNO spectra dataset
   - Output: Model evaluation metrics (NRMSE, ECI coverage, classification accuracy)
   - For each held-out object, remove it from the training set, regenerate synthetic data using the remaining objects, and validate reconstruction performance.
   - Calculate reconstruction error using NRMSE, assess ECI coverage for key spectral features, and evaluate taxonomic classification accuracy.

6. **Spectral Reconstruction**:
   - Input: Observed photometric measurements
   - Output: Reconstructed spectrum and uncertainty estimates
   - Use the trained AutoML regressor to predict latent coefficients from the observed photometry.
   - Apply inverse PCA transformation to recover the full spectrum.
   - Sample the joint posterior distribution of latent coefficients using a Gaussian Copula framework to generate an ensemble of reconstructions and quantify uncertainties.

7. **Taxonomic Classification**:
   - Input: Reconstructed latent coefficients
   - Output: Probabilistic taxonomic labels
   - Train a secondary AutoML classifier on the latent space to partition the manifold into taxonomic groups (H₂O, CO₂, Organic, Methanol).
   - Predict probability distributions for spectral types based on the latent state.

8. **Survey Optimization and Outlier Detection**:
   - Input: Filter configurations and observed photometry
   - Output: Optimized filter combinations and detected outliers
   - Compute Fisher Information Matrix (FIM) for different filter sets to identify optimal configurations maximizing spectral distinction.
   - Detect outliers by evaluating the probability density of latent states against the learned manifold.

End of Algorithm
