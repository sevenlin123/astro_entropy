Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- Training Spectra: Set of reference TNO spectra S_train
- Photometric Observations: Sparse photometry m_test for objects to reconstruct
- NIRCam Filter Curves: Set of filter transmission curves
- Number of Principal Components (K): Typically 4–10

Output:
- Reconstructed Spectra: High-resolution reflectance spectra S_recon for each test object
- Classification Probabilities: Probabilities for each taxonomic class (e.g., H2O, CO2, Organic, Methanol)
- Uncertainty Estimates: Empirical credible intervals for each wavelength

Steps:

1. Preprocessing:
   a. Normalize training spectra to reflectance units.
   b. Extract NIRCam filter response for each training spectrum.

2. Latent Space Definition:
   a. Perform Principal Component Analysis (PCA) on S_train to obtain principal components (PCs).
   b. Use Kernel Density Estimation (KDE) to construct a continuous prior distribution in the latent space defined by the PCs.
   
3. Synthetic Data Generation:
   a. For each spectrum in the latent space, generate synthetic photometry by convolving with NIRCam filter curves.
   b. Add Gaussian noise (20% relative reflectance uncertainty) to simulate real-world photometric uncertainties.

4. Model Training:
   a. Train an AutoML regressor (e.g., XGBoost) to map sparse photometry to latent PCA coefficients.
   b. Simultaneously train a taxonomic classifier in the latent space to predict class probabilities.

5. Inference for Test Objects:
   a. For each m_test:
      i. Predict latent coefficients using the trained regressor.
      ii. Project these coefficients back to full spectral space via inverse PCA.
      iii. Sample the posterior distribution using Gaussian Copula to generate multiple reconstructions.
      iv. Compute empirical credible intervals for each wavelength.
      
6. Taxonomic Classification:
   a. Use the latent space classifier to predict class probabilities for each test object.
   
7. Validation (not shown in final output):
   a. Perform LOOCV to assess reconstruction fidelity and coverage.
   b. Evaluate classification accuracy against ground truth labels.

End
