### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

**Objective:** Reconstruct high-resolution near-IR spectra of trans-Neptunian objects (TNOs) from sparse photometric observations using a Bayesian framework.

**Steps:**

1. **Training Data Preparation:**
   - Collect a reference dataset of TNO near-IR spectra (e.g., DiSCo-TNO sample).
   - Exclude outlier spectral types to focus on dominant taxonomic classes.

2. **Principal Component Analysis (PCA):**
   - Perform PCA on the reference spectra to obtain principal components (PCs) representing spectral variability.
   - Determine the number of PCs (e.g., 4–10) that capture significant spectral structure.

3. **Latent Space Definition:**
   - Use PCA eigenvectors to define a low-dimensional latent space.
   - Apply Kernel Density Estimation (KDE) to create a continuous probability distribution over the latent space, approximating the spectral manifold.

4. **Forward Modeling:**
   - Simulate photometric observations by convolving reference spectra with filter responses (e.g., JWST/NIRCam filters).
   - Add Gaussian noise (e.g., 20% relative uncertainty) to simulate real-world photometric uncertainties.

5. **Automated Machine Learning (AutoML) Training:**
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to latent space coordinates.
   - Use synthetic data generated from PCA and KDE to augment training.

6. **Bayesian Inference:**
   - For new photometric observations, predict latent coefficients using the trained regressor.
   - Apply inverse PCA transform to reconstruct the full spectrum.
   - Sample the posterior distribution using a Gaussian Copula to quantify uncertainties.

7. **Taxonomic Classification:**
   - Classify the object into spectral types (e.g., H₂O, CO₂, Organic) based on latent space coordinates.

**End of Algorithm**
