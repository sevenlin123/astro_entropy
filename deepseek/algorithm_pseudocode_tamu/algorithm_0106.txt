Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Initialize Parameters:
   - Training dataset: Set of reference TNO spectra.
   - Number of principal components (K): Typically 4-10.
   - Photometric bands: Define the filters used for observations.

2. Perform Principal Component Analysis (PCA):
   a. Decompose the training spectra into principal components to form a low-dimensional latent space.
   b. Extract principal component coefficients (latent variables) for each spectrum.

3. Data Augmentation using Kernel Density Estimation (KDE):
   a. Generate synthetic latent vectors by sampling the KDE distribution built from the real latent coefficients.
   b. Augment the training dataset with these synthetic latents.

4. Train Automated Machine Learning (AutoML) Regressor:
   a. Use the augmented latent space and corresponding synthetic photometry to train an ensemble regressor (e.g., XGBoost) to map photometric inputs to latent space coefficients.
   b. Implement AutoML to optimize hyperparameters and model architecture.

5. Forward Modeling:
   a. Simulate photometric observations by convolving synthetic spectra with the instrument's filter transmission curves (e.g., JWST/NIRCam).
   b. Inject Gaussian noise (relative uncertainty ~20%) into the simulated photometry to account for observational uncertainties.

6. Leave-One-Out Cross-Validation (LOOCV):
   a. For each spectrum in the training set:
      i. Exclude the spectrum from the training set.
      ii. Recompute the latent manifold using the remaining data.
      iii. Retrain the regressor on the augmented dataset.
      iv. Predict latent coefficients and reconstruct the spectrum using the excluded spectrum's photometry.
      v. Validate reconstruction accuracy and credible interval coverage.

7. Spectral Reconstruction:
   a. For new photometric observations:
      i. Pass the photometry through the trained regressor to predict latent coefficients.
      ii. Apply the inverse PCA transform to reconstruct the full spectrum.
      iii. Generate an ensemble of reconstructions using Gaussian Copula sampling to quantify uncertainties.

8. Taxonomic Classification:
   a. Project the predicted latent coefficients into a pre-trained classifier.
   b. Determine the probability distribution over spectral types (e.g., H₂O, CO₂, Organics).

9. Outlier Detection:
   a. Calculate the probability density of the object's latent state under the KDE prior.
   b. Flag objects with densities below a threshold (e.g., 0.05) as outliers.
   c. Visually inspect reconstructed spectra for unexpected features.

10. Filter Configuration Optimization:
    a. Quantify the information content of different photometric band combinations.
    b. Identify filter sets that maximize spectral reconstruction fidelity and outlier detection capability.

End Algorithm
