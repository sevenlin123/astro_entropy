### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

```python
1. **Principal Component Analysis (PCA) Initialization**:
   - Train PCA on a reference set of TNO spectra to extract principal components (eigenvectors and eigenvalues).
   - Determine the optimal number of principal components (K) through validation (e.g., LOOCV).

2. **Data Augmentation via Kernel Density Estimation (KDE)**:
   - Project the reference spectra onto the PCA latent space.
   - Use KDE with a Gaussian kernel to create a smooth, continuous probability distribution in the latent space.
   - Ensure the bandwidth (h) is appropriately tuned to maintain physical plausibility.

3. **Forward Modeling and Synthetic Data Generation**:
   - For each augmented latent vector, forward-simulate photometry by convolving with the instrument's filter response curves (e.g., JWST NIRCam).
   - Inject Gaussian noise (e.g., 20% relative uncertainty) into the synthetic photometry to simulate observational noise.

4. **Training the AutoML Regressor**:
   - Use the synthetic photometry and corresponding latent vectors as training data.
   - Train an ensemble of gradient-boosted decision trees (AutoML) to regress from photometric inputs to latent coefficients.

5. **Bayesian Inference for Spectral Reconstruction**:
   - For new photometric observations:
     - Predict latent coefficients using the trained regressor.
     - Sample the joint posterior distribution of the latent coefficients using Gaussian Copula to account for correlations.
     - Apply the inverse PCA transformation to reconstruct the full spectrum.
     - Generate confidence intervals based on the posterior samples.

6. **Taxonomic Classification**:
   - Train a secondary classifier on the PCA latent space to predict taxonomic classes (e.g., H₂O, CO₂, Organic, Methanol) using the reference labels.
   - For new observations, classify using the predicted latent coefficients.

7. **Validation and Uncertainty Assessment**:
   - Perform LOOCV to validate the reconstruction accuracy and uncertainty calibration.
   - Calculate RMSE and Pearson correlation coefficient for spectral fidelity.
   - Check credible interval coverage (e.g., 95% coverage) to assess uncertainty reliability.

8. **Applications**:
   - **Survey Optimization**: Evaluate information content of different filter configurations using the framework.
   - **Outlier Detection**: Identify rare spectral types by assessing posterior probabilities of latent states.
   - **Classification**: Assign taxonomic labels based on the predicted probabilities from the latent space.

This algorithm provides a systematic approach to reconstructing TNO spectra from sparse photometric data while accounting for uncertainties and enabling downstream applications like taxonomy and survey design.
