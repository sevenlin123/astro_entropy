Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Input Preparation**
   - Read sparse photometric measurements of TNOs.
   - Load reference near-infrared spectra for training.

2. **Principal Component Analysis (PCA)**
   - Train PCA on the reference spectra to define a low-dimensional latent space.
   - Determine the optimal number of principal components (e.g., 4-5 for classification, 8-10 for high fidelity).

3. **Data Augmentation via Kernel Density Estimation (KDE)**
   - Project reference spectra onto the PCA latent space.
   - Use Gaussian KDE to create a smooth probability distribution in the latent space.
   - Set bandwidth (e.g., 0.5) to balance smoothing and fidelity.

4. **Forward Modeling Synthetic Photometry**
   - Simulate photometric measurements for each augmented spectrum using NIRCam filter responses.
   - Inject Gaussian noise (e.g., 20% relative uncertainty) to reflect observational realism.

5. **Training the AutoML Regressor**
   - Use AutoGluon to train an ensemble model (e.g., Gradient Boosted Decision Trees) mapping noisy photometry to latent coefficients.
   - Perform internal cross-validation during training.

6. **Bayesian Inference and Reconstruction**
   - For each new photometric observation:
     a. Predict latent coefficients using the trained regressor.
     b. Sample the joint posterior distribution of latent variables using Gaussian Copula.
     c. Apply inverse PCA transformation to reconstruct full spectra.
     d. Calculate 95% credible intervals.

7. **Taxonomic Classification**
   - Train a secondary classifier on the latent space to predict taxonomic categories (e.g., H₂O, CO₂, Organics).
   - Output probability distribution over spectral types.

8. **Validation and Outlier Detection**
   - Use LOOCV to assess reconstruction accuracy and empirical credible interval coverage.
   - Compute normalized log-likelihood ratio for outlier detection in the latent space.

9. **Filter Optimization**
   - Quantify information content of NIRCam filters using Fisher Information.
   - Identify optimal filter combinations for maximizing taxonomic discrimination.

10. **Output**
    - Provide reconstructed spectra, credible intervals, taxonomic probabilities, and outlier scores.
