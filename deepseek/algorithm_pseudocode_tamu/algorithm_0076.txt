**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data Preparation**
   - Obtain a set of reference TNO spectra.
   - Extract sparse photometric measurements for target objects.

2. **Principal Component Analysis (PCA)**
   - Train PCA on the reference spectra to define a low-dimensional latent space.
   - Determine the number of principal components (typically 4-10) based on reconstruction fidelity and cross-validation.

3. **Data Augmentation with Kernel Density Estimation (KDE)**
   - Project reference spectra onto the PCA latent space.
   - Apply KDE to create a smooth probability distribution in the latent space, augmenting the training data.

4. **Training the AutoML Regressor**
   - Use the augmented latent data and corresponding forward-modeled photometry to train an ensemble of gradient-boosted decision trees.
   - Inject Gaussian noise (20% relative uncertainty) into synthetic photometry to simulate real-world observational conditions.

5. **Forward Modeling and Simulation-Based Inference**
   - Simulate photometric observations by convolving spectra with instrument-specific filter responses.
   - Use the AutoML regressor to map sparse photometry to latent coefficients, approximating the implicit likelihood.

6. **Spectral Reconstruction**
   - Apply the inverse PCA transform to the predicted latent coefficients to reconstruct the full spectrum.
   - Generate an ensemble of reconstructions using a Gaussian Copula framework to sample the joint posterior distribution.

7. **Taxonomic Classification**
   - Train a secondary classifier on the PCA latent space to predict taxonomic labels.
   - Output probability distributions over spectral types for each object.

8. **Validation and Uncertainty Quantification**
   - Compute Root Mean Squared Error (RMSE) between reconstructed and ground-truth spectra.
   - Assess empirical coverage of 95% credible intervals across wavelengths.
   - Evaluate taxonomic confidence through correct label probabilities.

9. **Application-Specific Processing**
   - For survey optimization, evaluate filter contributions to reconstruction fidelity.
   - For outlier detection, analyze posterior probabilities to identify objects diverging from the training manifold.

**End of Algorithm**
