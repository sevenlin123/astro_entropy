**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data**
   - `photometry`: Sparse photometric measurements of a TNO.
   - `training_spectra`: Set of reference TNO spectra used for model training.
   - `filters`: Specifications of photometric filters used (e.g., JWST/NIRCam).

2. **Preprocessing**
   a. **Principal Component Analysis (PCA)**
      - Apply PCA to `training_spectra` to obtain principal components (PCs).
      - Determine the number of PCs (K) that capture the dominant spectral variability (e.g., 4-5 PCs for basic reconstruction, up to 10 for improved fidelity).

3. **Training Phase**
   a. **Latent Space Definition**
      - Project `training_spectra` onto the PCA space to get latent coefficients.
      - Augment the latent space using Kernel Density Estimation (KDE) to create a smooth manifold.

   b. **Synthetic Data Generation**
      - Forward model the synthetic photometry by convolving the augmented spectra with the filter transmission curves.
      - Add Gaussian noise (20% relative reflectance uncertainty) to simulate realistic photometric uncertainties.

   c. **AutoMLRegressor Training**
      - Train an ensemble of gradient-boosted decision trees (e.g., XGBoost) to map sparse photometry to latent coefficients.

4. **Inference Phase**
   a. **Predict Latent Coefficients**
      - Use the trained AutoMLRegressor to predict latent coefficients from `photometry`.

   b. **Reconstruct Spectrum**
      - Apply the inverse PCA transformation to the predicted latent coefficients to obtain the full spectrum.

   c. **Uncertainty Quantification**
      - Sample the joint posterior distribution of latent coefficients using a Gaussian Copula framework.
      - Generate an ensemble of reconstructed spectra to compute credible intervals.

5. **Classification (Optional)**
   a. **Latent Space Classification**
      - Predict taxonomic probabilities by evaluating the position of the latent coefficients in the trained manifold.

6. **Output**
   - `reconstructed_spectrum`: High-resolution spectrum reconstructed from sparse photometry.
   - `credible_intervals`: Uncertainty bounds on the reconstructed spectrum.
   - `taxonomic_prediction`: Probabilistic classification of the spectral type.

**Note:** This algorithm assumes precomputed PCA components and forward-modeling setup. The actual implementation would involve additional steps for cross-validation and hyperparameter tuning during the training phase.
