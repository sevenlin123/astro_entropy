### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Initialize Principal Component Analysis (PCA):**
   - Train PCA on a reference dataset of TNO spectra to derive principal components (eigenvectors and eigenvalues).
   - Determine the optimal number of principal components (K) based on explained variance and cross-validation.

2. **Data Augmentation via Kernel Density Estimation (KDE):**
   - Project reference spectra onto PCA latent space.
   - Apply KDE to generate synthetic latent vectors, creating a smooth continuous manifold.
   - Inject Gaussian noise (20% relative uncertainty) into synthetic photometry derived from these latent vectors.

3. **Train Machine Learning Regressor:**
   - Use synthetic photometry (with noise) and corresponding PCA coefficients as training data.
   - Train an ensemble of gradient-boosted decision trees (e.g., XGBoost) to map photometric inputs to latent coefficients.

4. **Inverse PCA Transformation:**
   - For new photometric observations, predict latent coefficients using the trained regressor.
   - Apply inverse PCA to reconstruct the full spectrum from predicted coefficients.

5. **Uncertainty Quantification:**
   - Sample the joint posterior distribution of latent coefficients using Gaussian Copula.
   - Generate multiple reconstructions to estimate credible intervals.

6. **Taxonomic Classification (Optional):**
   - Train a classifier on PCA coefficients of labeled reference spectra.
   - Classify new objects based on their predicted latent coefficients.

7. **Cross-Validation and Calibration:**
   - Perform leave-one-out cross-validation to validate reconstruction accuracy.
   - Adjust model parameters and noise levels as needed to ensure credible interval coverage (~95%).

8. **Application Scenarios:**
   - **Survey Optimization:** Identify optimal filter combinations for future observations.
   - **Outlier Detection:** Detect unusual spectral types by identifying deviations from the latent manifold.
