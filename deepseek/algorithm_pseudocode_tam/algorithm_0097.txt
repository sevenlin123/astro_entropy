**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data Preparation**:
   - Obtain a set of reference TNO spectra (training set).
   - Extract sparse photometric measurements for these spectra using JWST/NIRCam filter bands.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the reference spectra to derive principal components.
   - Determine the number of components (e.g., 4-5 for taxonomy, 8-10 for detailed reconstruction).

3. **Latent Space Construction**:
   - Project the reference spectra onto the derived PCA components.
   - Use Kernel Density Estimation (KDE) to create a smooth probability distribution in the latent space.
   - Adjust KDE bandwidth to ensure stable manifold generation without overfitting.

4. **Synthetic Photometry Generation**:
   - For each augmented spectrum, convolve with JWST/NIRCam filter responses to generate theoretical reflectance.
   - Add Gaussian noise (e.g., 20%) to simulate realistic photometric uncertainties.

5. **Model Training**:
   - Train an AutoML regressor (e.g., Gradient-Boosted Decision Trees) to map sparse photometry to PCA coefficients.
   - Train a secondary classifier in the latent space to predict taxonomic categories.

6. **Reconstruction Process**:
   - For new photometric observations:
     - Pass through the trained AutoML regressor to obtain predicted PCA coefficients.
     - Apply inverse PCA transformation to reconstruct the full spectrum.
     - Propagate uncertainties to compute empirical credibility intervals.

7. **Validation and Application**:
   - Perform Leave-One-Out Cross-Validation (LOOCV) to assess RMSE and coverage.
   - Use the framework for survey optimization and outlier detection by analyzing the latent space distribution.

**End Algorithm**
