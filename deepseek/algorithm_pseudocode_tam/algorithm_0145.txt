**Algorithm: Probabilistic Spectral Reconstruction Framework**

**Step-by-Step Pseudocode:**

1. **Initialize Training Dataset**:
   - Collect a sample of known TNO spectra (e.g., 51 seed spectra).
   - Exclude outliers and rare spectral types to focus on dominant taxonomic classes.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the collected spectra to obtain principal components (PCs).
   - PCs represent the main axes of spectral variability within the training set.
   - Select the appropriate number of PCs (e.g., 8-10) based on explained variance.

3. **Kernel Density Estimation (KDE)**:
   - Project the training spectra onto the PCA latent space.
   - Use KDE to estimate the probability density of the latent space, creating a smooth manifold.

4. **Synthetic Data Generation**:
   - For each augmented spectrum, convolve with JWST/NIRCam filter curves to simulate observed photometry.
   - Inject Gaussian noise (e.g., 20% relative uncertainty) to mimic real photometric measurements.
   - Create a training dataset of noisy photometric observations paired with ground truth latent coefficients.

5. **Automated Machine Learning (AutoML) Training**:
   - Train an AutoML regressor (e.g., using AutoGluon) to map sparse photometry to latent space coefficients.
   - Use the synthetic noisy photometry as input features and latent coefficients as target labels.

6. **Leave-One-Out Cross-Validation (LOOCV)**:
   - For each spectrum, remove it from the training set and evaluate the model's ability to reconstruct the latent coefficients.
   - Compute error metrics (e.g., RMSE, MAE) and credible interval coverage.

7. **Spectral Reconstruction**:
   - For new photometric observations, use the trained AutoML model to predict latent coefficients.
   - Apply inverse PCA transform to obtain the reconstructed spectrum.

8. **Taxonomic Classification**:
   - Train a secondary classifier on the latent space to predict taxonomic group (e.g., H₂O, CO₂, Organics, Methanol).
   - Use predicted latent coefficients as features.

9. **Outlier Detection**:
   - Analyze objects' positions in the latent space to identify outliers.
   - Outliers may represent rare spectral types or anomalies.

10. **Survey Optimization**:
    - Simulate different JWST/NIRCam filter configurations.
    - Evaluate their effectiveness in distinguishing taxonomic groups and optimizing spectral reconstruction fidelity.

11. **Probabilistic Uncertainty Quantification**:
    - Propagate photometric uncertainties through the reconstruction process.
    - Provide credible intervals for reconstructed spectra and classification probabilities.

12. **Output**:
    - For each object, output the reconstructed spectrum, taxonomic classification, and associated uncertainties.

**End Algorithm**
