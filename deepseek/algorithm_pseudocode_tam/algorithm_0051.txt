Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- Set of reference TNO spectra
- Sparse photometric observations
- List of photometric filters (e.g., JWST/NIRCam)

Output:
- Reconstructed spectral reflectance curves
- Taxonomic classification probabilities

Steps:

1. Principal Component Analysis (PCA):
   a. Perform PCA on the reference spectra to obtain principal components (PCs).
   b. Define latent space using the top K PCs (K determined by LOOCV).
   
2. Data Augmentation (Optional):
   a. Project reference spectra onto the latent space to get latent coefficients.
   b. Use Kernel Density Estimation (KDE) to generate synthetic latent vectors, expanding the training dataset.
   
3. Training the AutoML Regressor:
   a. For each synthetic latent vector, compute corresponding photometry by convolving with filter response functions.
   b. Inject Gaussian noise (20% relative uncertainty) into synthetic photometry.
   c. Train an ensemble of Gradient Boosted Decision Trees (GBDTs) to regress from sparse photometry to latent coefficients.
   
4. Inference Pipeline:
   a. For new photometric observations:
      i. Pass photometry through trained regressor to predict latent coefficients.
      ii. Apply inverse PCA transform to obtain reconstructed spectral reflectance.
      iii. Compute posterior probabilities for taxonomic classification using latent space.
   
5. Validation (LOOCV):
   a. Remove one spectrum from the training set.
   b. Validate using the remaining N-1 spectra.
   c. Repeat for all spectra in the training set.

End
