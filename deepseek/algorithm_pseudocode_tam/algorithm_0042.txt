The algorithm below outlines the core steps of the probabilistic spectral reconstruction framework for Trans-Neptunian Objects (TNOs) from sparse photometry. The method combines Principal Component Analysis (PCA) for dimensionality reduction, followed by automated machine learning (AutoML) regression to infer latent spectral coefficients. These coefficients are then used to reconstruct the full spectrum via inverse PCA transformation.

```

Algorithm: Probabilistic Spectral Reconstruction Framework

Input:
- Observed photometric measurements for a TNO
- Pre-trained PCA model derived from a reference spectral dataset
- Pre-trained AutoML regressor mapping photometry to PCA coefficients
- Synthetic photometric data generated from PCA manifold augmentation

Output:
- Reconstructed high-resolution spectrum
- Probabilistic taxonomic classification of the TNO

1. Preprocessing:
   a. Normalize the observed photometric measurements to reflectance units.
   
2. Latent Space Inference:
   a. Pass the observed photometric measurements through the AutoML regressor to predict latent PCA coefficients.
   
3. Spectral Reconstruction:
   a. Apply the inverse PCA transformation to the predicted latent coefficients to obtain the reconstructed spectrum.
   
4. Taxonomic Classification (Optional):
   a. Project the latent coefficients into a pre-trained taxonomic classifier to predict the spectral type and associated probabilities.
   
5. Uncertainty Quantification:
   a. Calculate the 95% credible intervals for the reconstructed spectrum using the posterior distribution derived from the AutoML regression.
   
6. Outlier Detection (Optional):
   a. Assess the probability density of the latent coefficients in the trained manifold. Low-density regions indicate outliers.
   
7. Return the reconstructed spectrum, taxonomic probabilities, and credibility intervals.

End.
```
