The algorithm is as follows:

1. **Principal Component Analysis (PCA):**
   - Input a sample of near-infrared spectra of trans-Neptunian objects.
   - Perform PCA to reduce the spectral data into a set of principal components (latent space).
   - The latent space is represented by coefficients that describe each spectrum as a linear combination of these components.

2. **Data Augmentation using Kernel Density Estimation (KDE):**
   - Project the PCA coefficients of the training spectra into a latent space.
   - Use KDE to create a smooth probability distribution in this latent space.
   - Generate synthetic latent vectors by sampling from this distribution, effectively creating a continuous manifold.

3. **Synthetic Photometry Generation:**
   - For each synthetic latent vector, project it back to the full spectral space using inverse PCA.
   - Convolve the resulting spectrum with the instrument's filter response curves (e.g., JWST/NIRCam filters) to compute the expected photometric magnitudes.
   - Add Gaussian noise to the synthetic photometry to simulate realistic observational uncertainties.

4. **Training the AutoML Regressor:**
   - Use the synthetic photometry (with noise) as input features.
   - The target is the corresponding latent coefficients from the synthetic vectors.
   - Train an ensemble of gradient-boosted decision trees (AutoGluon framework) to regress from photometry to latent coefficients.

5. **Reconstruction Pipeline:**
   - For a new object, obtain its sparse photometric measurements.
   - Pass these measurements through the trained AutoML regressor to predict the latent coefficients.
   - Apply inverse PCA using these coefficients to reconstruct the full spectral energy distribution.

6. **Taxonomic Classification (Optional):**
   - Project the latent coefficients of the reconstructed spectrum into the trained taxonomic classifier.
   - The classifier predicts the probability distribution over spectral types (e.g., Water-type, CO2-type, Organics-type).

7. **Validation and Uncertainty Quantification:**
   - Compare the reconstructed spectra with the ground truth (if available) to assess reconstruction fidelity.
   - Calculate root-mean-square error (RMSE) and empirical credible-interval coverage (ECC) to evaluate the accuracy and uncertainty calibration of the reconstructions.
