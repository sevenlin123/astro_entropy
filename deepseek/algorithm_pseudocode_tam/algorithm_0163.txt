Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
    - Reference Spectra: Collection of TNO spectra (e.g., 51 known objects)
    - Photometric Filters: Set of NIRCam filters used for observations
    - Number of Principal Components (K): Typically 8-10 for high fidelity

Output:
    - Reconstructed Spectra: High-resolution spectra for each object
    - Taxonomic Classifications: Probabilistic assignment to spectral types (Water, CO2, Organics, Methanol)

Steps:

1. **Preprocess Reference Spectra:**
    a. Normalize and align spectra to a common wavelength grid.
    b. Remove any obvious outliers or anomalies not representative of the population.

2. **Principal Component Analysis (PCA):**
    a. Compute PCA on the preprocessed reference spectra.
    b. Determine the optimal number of principal components (K) using explained variance or cross-validation criteria.

3. **Generate Synthetic Latent Space:**
    a. Project the reference spectra onto the top K principal components to get latent scores.
    b. Apply Kernel Density Estimation (KDE) with bandwidth h = 0.5 to smooth the latent space distribution.
    c. Sample additional points from the smoothed latent distribution to create a training set.

4. **Forward Model Synthetic Photometry:**
    a. For each augmented spectrum, convolve with NIRCam filter transmission curves to compute synthetic photometric magnitudes.
    b. Inject Gaussian noise with 20% relative uncertainty to simulate real-world observational errors.

5. **Train AutoML Regressor:**
    a. Use the synthetic photometry and corresponding latent scores as input-output pairs.
    b. Train an ensemble of Gradient Boosted Decision Trees using AutoGluon framework.
    c. Validate the model using leave-one-out cross-validation on the reference spectra.

6. **Predict Latent Coefficients from Photometry:**
    a. For new photometric observations, pass through the trained regressor to obtain predicted latent coefficients.
    b. Use the inverse PCA transform to reconstruct the full spectrum.

7. **Project to Taxonomic Classes:**
    a. Classify the predicted latent coefficients into predefined taxonomic categories.
    b. Compute probabilities for each category to determine the most likely spectral type.

8. **Evaluate Reconstruction Quality:**
    a. Compare reconstructed spectra with original reference spectra.
    b. Assess empirical credible interval coverage to validate uncertainty estimates.

End.
