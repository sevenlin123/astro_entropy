The algorithm extracts the core computational steps of the probabilistic spectral reconstruction framework for Trans-Neptunian Objects. It leverages PCA for dimensionality reduction, employs an AutoML regressor to map sparse photometry to PCA coefficients, and reconstructs full spectra by inverting the PCA transform.

```plaintext
Algorithm: Probabilistic Spectral Reconstruction Framework

1. Initialize with reference spectra of TNOs:
   - Load training set of known high-resolution spectra.

2. Perform Principal Component Analysis (PCA):
   - Decompose the training spectra into principal components to define a latent space.

3. Data Augmentation:
   - Use Kernel Density Estimation (KDE) to generate synthetic spectra from the latent space, expanding the training dataset.

4. Synthetic Photometry Generation:
   - For each augmented spectrum, compute synthetic photometric measurements by convolving with instrument filter responses.

5. AutoML Regressor Training:
   - Train an ensemble model (e.g., AutoGluon) to regress from photometric inputs to PCA coefficients.

6. Reconstruction Pipeline:
   - For new photometric observations:
     a. Use the trained regressor to predict latent coefficients.
     b. Invert the PCA transform to reconstruct the high-resolution spectrum.

7. Output:
   - Provide reconstructed spectra and probabilistic taxonomic classifications.
```
