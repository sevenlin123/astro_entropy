2. Perform Principal Component Analysis (PCA) to derive principal components.
3. Augment the dataset using Kernel Density Estimation (KDE) to create synthetic spectra.
4. Convolve each spectrum with NIRCam filter curves to generate synthetic photometry.
5. Add Gaussian noise to photometric data to simulate observational uncertainty.
6. Train an AutoML regressor to map photometric inputs to latent PCA coefficients.
7. For new observations:
   a. Pass sparse photometry through the regressor to predict latent coefficients.
   b. Apply inverse PCA to obtain reconstructed spectra.
8. Validate via LOOCV to determine optimal number of principal components and assess reconstruction accuracy.
9. Use the latent space for taxonomic classification by training a classifier on PCA coefficients.
10. Apply framework for survey optimization and outlier detection.

End.
