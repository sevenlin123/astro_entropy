**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Training Phase:**
   - **Input:** Reference spectra of TNOs, filter transmission curves, and noise levels.
   - **Output:** Trained AutoML regressor and inverse PCA transform.
     1. Perform Principal Component Analysis (PCA) on the reference spectra to derive principal components (latent space).
     2. Augment the latent space using Kernel Density Estimation (KDE) to smooth the probability distribution.
     3. Generate synthetic photometry by convolving augmented spectra with instrument filters and adding Gaussian noise.
     4. Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map synthetic photometry to latent coefficients.
     5. Validate the model using leave-one-out cross-validation.

2. **Reconstruction Phase:**
   - **Input:** Observed sparse photometric measurements.
   - **Output:** Reconstructed spectrum and taxonomic classification.
     1. Use the trained regressor to predict latent coefficients from observed photometry.
     2. Apply the inverse PCA transform to obtain the reconstructed spectrum.
     3. Classify the object into taxonomic groups (e.g., H₂O, CO₂, Organics) based on latent coefficients.
