**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

**Input:**
- Set of reference TNO spectra (training set)
- Observed sparse photometric measurements (input for reconstruction)
- Principal Component Analysis (PCA) parameters
- Machine learning model configuration

**Output:**
- Reconstructed high-resolution spectrum
- Probabilistic taxonomic classification
- Uncertainty estimates

**Steps:**

1. **Principal Component Analysis (PCA):**
   - Train PCA on the reference TNO spectra to define a low-dimensional latent space.
   - Extract principal components (eigenvectors) that capture the major spectral variations.

2. **Data Augmentation (Optional):**
   - Use Kernel Density Estimation (KDE) to generate synthetic spectra based on the PCA latent space, ensuring a smooth manifold for training stability.
   - Inject Gaussian noise (e.g., 20% relative reflectance uncertainty) to simulate realistic photometric noise.

3. **Training the AutoML Regressor:**
   - Map the sparse photometric data to the latent PCA coefficients using an ensemble of gradient-boosted decision trees.
   - The regressor learns the non-linear relationship between photometric inputs and latent space representations.

4. **Forward Modeling Synthetic Photometry:**
   - For each augmented spectrum, compute the expected photometric measurements by convolving with the instrument's filter curves (e.g., JWST/NIRCam).
   - This step simulates the observed photometric data from the true spectra.

5. **Reconstruction Pipeline:**
   - For new sparse photometric inputs:
     a. Use the trained AutoML regressor to predict the latent coefficients.
     b. Apply the inverse PCA transform to obtain the reconstructed high-resolution spectrum.
     c. Propagate uncertainties through the latent space to compute credible intervals.

6. **Taxonomic Classification:**
   - Project the latent coefficients into a classifier trained on the taxonomic labels (e.g., H₂O, CO₂, Organic).
   - Output the probability distribution over spectral types.

7. **Uncertainty Calibration and Validation:**
   - Perform leave-one-out cross-validation (LOOCV) to assess reconstruction accuracy and credible interval coverage.
   - Evaluate the maximum a posteriori (MAP) spectrum and compare with the true spectrum.

8. **Survey Optimization and Outlier Detection:**
   - Determine the optimal set of filters by analyzing the information content (number of principal components) required for accurate reconstruction.
   - Detect outliers by identifying objects whose latent positions fall outside the expected manifold.

**End of Algorithm**
