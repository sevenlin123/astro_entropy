### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Training Phase**:
   - **Step 1**: Collect and preprocess a set of reference TNO spectra.
   - **Step 2**: Perform Principal Component Analysis (PCA) on the preprocessed spectra to obtain principal components (PCs).
   - **Step 3**: Use Kernel Density Estimation (KDE) on the PCA coefficients to define a continuous probability distribution over the latent spectral manifold.
   - **Step 4**: Generate synthetic photometry for each augmented spectrum by convolving the spectra with the instrument's filter throughput curves (e.g., JWST NIRCam).
   - **Step 5**: Inject Gaussian noise (20% relative reflectance uncertainty) into the synthetic photometry to simulate real-world observational noise.
   - **Step 6**: Train an AutoML regressor (e.g., Gradient-Boosted Decision Trees) to map sparse photometry to latent PCA coefficients.
   - **Step 7**: Train a secondary AutoML classifier to partition the latent manifold into taxonomic classes (e.g., H₂O, CO₂, Organics).

2. **Reconstruction Phase**:
   - **Step 1**: For a new photometric observation:
     - **Step 1.1**: Use the trained AutoML regressor to predict the latent PCA coefficients.
     - **Step 1.2**: Project the predicted latent coefficients back into the full spectral space using the inverse PCA transform to obtain the reconstructed spectrum.
   - **Step 2**: Simultaneously use the trained classifier to predict the taxonomic class probabilities from the latent coefficients.

3. **Validation and Uncertainty Propagation**:
   - **Step 1**: Perform Leave-One-Out Cross-Validation (LOOCV) to assess reconstruction accuracy and empirical credible-interval coverage.
   - **Step 2**: Bootstrap resample the AutoML-predicted latent coefficients to estimate uncertainties in the reconstructed spectra.

### Pseudocode Representation:

```python
function train_and_reconstruct(spectra, photometry_bands, filter_curves):
    # Step 1: Preprocess spectra
    normalized_spectra = preprocess(spectra)

    # Step 2: PCA decomposition
    pca = PCA(n_components=K)
    pca_components = pca.fit_transform(normalized_spectra)

    # Step 3: KDE on PCA coefficients
    kde = KDE(bandwidth=0.5)
    kde.train(pca_components)

    # Step 4: Generate synthetic photometry
    synthetic_photometry = []
    for spec in pca.inverse_transform(kde.sample()):
        convolved = convolve(spec, filter_curves)
        noisy_phot = add_noise(convolved, noise_level=0.2)
        synthetic_photometry.append(noisy_phot)

    # Step 5: Train AutoML regressor
    regressor = AutoMLRegressor()
    regressor.fit(synthetic_photometry, pca_components)

    # Step 6: Train taxonomic classifier
    classifier = AutoMLClassifier()
    classifier.fit(pca_components, taxonomic_labels)

    return regressor, classifier

function reconstruct_spectrum(photometry, regressor, classifier, pca):
    # Step 1: Predict latent coefficients
    latent_coefficients = regressor.predict(photometry)

    # Step 2: Reconstruct spectrum
    reconstructed_spectrum = pca.inverse_transform(latent_coefficients)

    # Step 3: Classify taxonomic type
    taxonomic_class = classifier.predict(latent_coefficients)

    return reconstructed_spectrum, taxonomic_class

```

### Explanation:

- **Training Phase**: The algorithm starts by preprocessing the reference spectra and decomposing them into principal components using PCA. A KDE is then applied to the PCA coefficients to create a smooth probability distribution. Synthetic photometry is generated by convolving the spectra with instrument filters and adding noise to simulate real observations. An AutoML regressor and classifier are trained to map photometry to latent coefficients and taxonomic classes, respectively.

- **Reconstruction Phase**: Given new photometric data, the regressor predicts the latent coefficients, which are then inverted using PCA to reconstruct the full spectrum. The classifier simultaneously identifies the taxonomic class.

- **Validation**: LOOCV is used to validate the framework's accuracy, and bootstrapping estimates the uncertainties in the reconstructed spectra.
