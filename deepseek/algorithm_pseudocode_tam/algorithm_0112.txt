To implement the core reconstruction framework, the following steps are executed:

1. **Principal Component Analysis (PCA):**
   - Train PCA on a set of reference TNO spectra to create a low-dimensional latent space.
   - Determine the number of principal components (e.g., 4-5 for classification, 8-10 for reconstruction).
   
2. **Data Augmentation:**
   - Use Kernel Density Estimation (KDE) on the PCA latent space to generate synthetic latent vectors.
   - Ensure the bandwidth (e.g., h = 0.5) balances smoothness and fidelity to original data.

3. **Synthetic Photometry Generation:**
   - Convolve the synthetic spectra with NIRCam filter curves to simulate photometric measurements.
   - Inject Gaussian noise (e.g., 20% relative reflectance uncertainty) to account for observational noise.

4. **Training the AutoML Regressor:**
   - Use the AutoGluon framework to train an ensemble of Gradient-Boosted Decision Trees (GBDTs) mapping sparse photometry to latent coefficients.
   - Hyperparameters are automatically tuned for optimal performance.

5. **Taxonomic Classifier Training:**
   - Train a secondary AutoML classifier on the latent space to predict taxonomic labels (e.g., Water, CO₂, Organic, Methanol).

6. **Reconstruction and Classification:**
   - For new photometric observations, predict latent coefficients using the regressor.
   - Inverse transform these coefficients using PCA to reconstruct the full spectrum.
   - Classify the object's taxonomic group using the latent space classifier.

7. **Validation via LOOCV:**
   - Evaluate reconstruction accuracy and uncertainty calibration using leave-one-out cross-validation.

Algorithm in Pseudocode:

```pseudocode
Function CoreReconstructionFramework():
    Inputs:
        - ReferenceSpectra: Set of TNO spectra
        - NIRCamFilters: Filter curves for JWST/NIRCam
        - PhotometricNoise: Gaussian noise level (e.g., 20%)

    Steps:
    1. Perform PCA on ReferenceSpectra to extract Principal Components (PCs).
    2. Determine optimal number of PCs (e.g., 4-5 for classification, 8-10 for reconstruction).
    3. Project ReferenceSpectra into the PCA latent space.
    4. Apply KDE to the latent space to generate synthetic data, tuning bandwidth for stability.
    5. Forward model synthetic spectra through NIRCamFilters to simulate photometry.
    6. Add Gaussian noise to simulated photometry based on specified noise level.
    7. Train AutoGluon regressor on the augmented dataset to map photometry to latent coefficients.
    8. Train taxonomic classifier on the latent space using labels from ReferenceSpectra.
    9. For new photometric data:
        a. Use regressor to predict latent coefficients.
        b. Apply inverse PCA transform to reconstruct full spectrum.
        c. Use classifier for taxonomic prediction.
    10. Validate using LOOCV to assess reconstruction accuracy and uncertainty propagation.

    Outputs:
        - Reconstructed spectra for TNOs
        - Probabilistic taxonomic classifications
        - Quantified reconstruction fidelity and uncertainty
```
