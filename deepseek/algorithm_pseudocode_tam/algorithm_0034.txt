**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data Preparation**:
   - Collect sparse photometric measurements (e.g., 2-6 photometric points) for each object.
   - Retrieve reference TNO spectra (e.g., 51 spectra) for training.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the reference spectra to define a low-dimensional latent space.
   - Select the number of principal components (e.g., 4-10) based on explained variance and reconstruction fidelity.

3. **Data Augmentation**:
   - Project the reference spectra onto the PCA latent space.
   - Apply Kernel Density Estimation (KDE) with a bandwidth (e.g., h ≈ 0.5) to create a smooth probability distribution in the latent space.
   - Generate synthetic latent vectors by sampling from the KDE to augment the training data.

4. **Synthetic Photometry Generation**:
   - Convolve each augmented spectrum with the instrumental response functions (e.g., JWST NIRCam filters) to simulate observed photometry.
   - Add Gaussian noise (e.g., 20% relative uncertainty) to the synthetic photometry to account for observational uncertainties.

5. **Training the AutoML Regressor**:
   - Use the synthetic photometry and corresponding latent vectors to train an ensemble of Gradient-Boosted Decision Trees (GBDTs).
   - The regressor maps sparse photometry to latent space coordinates.

6. **Training the Taxonomic Classifier**:
   - Train a secondary AutoML classifier on the PCA latent space to predict taxonomic labels (e.g., H2O, CO2, Organics, Methanol).
   - The classifier uses the latent coordinates as features.

7. **Reconstruction Pipeline**:
   - For new photometric observations:
     - Use the trained regressor to predict latent coefficients.
     - Apply the inverse PCA transform to reconstruct the full spectrum.
     - Use the classifier to predict taxonomic probabilities.

8. **Performance Metrics Calculation**:
   - Use Leave-One-Out Cross-Validation (LOOCV) to assess RMSE, credible interval coverage, and taxonomic classification accuracy.

**Output**:
- Reconstructed high-resolution spectra for each object.
- Probabilistic taxonomic classification.
- Quantitative measures of reconstruction fidelity and classification accuracy.

**Notes**:
- The algorithm focuses on the core computational steps without validation or visualization.
- It bridges sparse photometry and high-resolution spectroscopy, enabling statistical rigorous spectral reconstruction and taxonomy identification.
