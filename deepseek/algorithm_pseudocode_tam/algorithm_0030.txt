The algorithm begins by performing Principal Component Analysis (PCA) on a set of reference TNO spectra to create a low-dimensional latent space. This space is used as a prior probability distribution. Next, synthetic photometry is generated by convolving the spectra with instrument filters and adding noise. An AutoML regressor is trained to map sparse photometry to PCA coefficients. During prediction, the photometry is converted to latent coefficients, and the inverse PCA transform reconstructs the spectrum. The process includes cross-validation and uncertainty propagation.

```python
Algorithm:
1. Initialize the training dataset with reference TNO spectra.
2. Perform PCA on the spectra to obtain principal components.
3. Generate synthetic photometry for each augmented spectrum using instrument-specific filters and inject noise.
4. Train an AutoML regressor to map sparse photometry to PCA coefficients.
5. Validate the model using LOOCV to ensure reliability.
6. For new photometric observations:
   a. Use the AutoML regressor to predict PCA coefficients.
   b. Apply inverse PCA to reconstruct the full spectrum.
   c. Propagate uncertainties to assess reconstruction reliability.
```
