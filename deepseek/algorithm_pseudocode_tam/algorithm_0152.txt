The algorithm described in the paper involves using a probabilistic framework to reconstruct the spectra of trans-Neptunian objects (TNOs) from sparse photometric data. Here's a step-by-step breakdown of the computational steps involved in the core reconstruction framework:

### Algorithm Steps:

1. **Data Preparation**:
   - Gather a set of reference TNO spectra (e.g., 51 spectra).
   - Extract a subset of these spectra to serve as the training set.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the training spectra to identify the principal components that explain the majority of the spectral variability.
   - Determine the number of principal components (e.g., 4-5 for basic classification, 8-10 for improved fidelity).

3. **Latent Space Definition**:
   - Use the identified principal components to define a low-dimensional latent space.
   - Apply Kernel Density Estimation (KDE) on the latent coordinates derived from the PCA to create a smooth probability distribution representing the possible states of the latent space.

4. **Synthetic Data Generation**:
   - Generate synthetic photometric data by forward modeling the spectra through the target instrument's filters (e.g., JWST/NIRCam).
   - Inject Gaussian noise (e.g., 20% relative reflectance uncertainty) into the synthetic photometry to simulate realistic observational uncertainties.

5. **Model Training**:
   - Train an AutoML regressor (e.g., using AutoGluon) to map the sparse photometric inputs to the latent space coordinates.
   - Additionally, train a classifier within the latent space to predict taxonomic labels (e.g., H₂O, CO₂, Organics, Methanol).

6. **Forward Inference**:
   - For new photometric observations, pass the sparse data through the trained regressor to predict the latent coordinates.
   - Use the predicted latent coordinates to project back into the full spectral domain via inverse PCA transformation.

7. **Posterior Processing**:
   - Calculate the posterior distribution of the reconstructed spectrum.
   - Compute credible intervals (e.g., 16th, 50th, 84th percentiles) to assess the uncertainty and coverage of the reconstruction.
   - Evaluate the taxonomic classification probabilities to identify the spectral type.

8. **Validation and Applications**:
   - Perform leave-one-out cross-validation (LOOCV) to assess the model's generalization performance.
   - Use the framework for survey optimization by evaluating different filter configurations.
   - Detect outliers by analyzing the posterior distributions and their deviation from the expected manifold.
