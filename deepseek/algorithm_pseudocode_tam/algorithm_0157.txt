To implement the core reconstruction framework, follow these steps:

1. **Principal Component Analysis (PCA):**
   - Input the observed near-infrared spectra of TNOs.
   - Apply PCA to extract latent coefficients that capture the dominant spectral variability.

2. **Data Augmentation with KDE:**
   - Use Kernel Density Estimation (KDE) to create a smooth probability distribution in the latent space.
   - Sample synthetic latent vectors to augment the training data.

3. **Synthetic Photometry Generation:**
   - Convolve each synthetic spectrum with NIRCam filter response functions.
   - Add Gaussian noise (20% relative uncertainty) to simulate real photometric measurements.

4. **Train AutoML Regression Model:**
   - Train an ensemble of Gradient-Boosted Decision Trees (AutoGluon) to map noisy photometry to latent coefficients.

5. **Inverse PCA Transform:**
   - Use the trained regression model to predict latent coefficients from new photometric data.
   - Reconstruct the full spectrum by applying the inverse PCA transformation.

6. **Taxonomic Classification (Optional):**
   - Train a classifier using latent mean coefficients to predict taxonomic labels (e.g., H₂O, CO₂, Organic types).

**Result:** Accurate reconstruction of TNO spectra and taxonomic classification from sparse photometry.

**Algorithm:**

1. **Input Data Preparation:**
   - Load the reference spectra of TNOs.
   - Apply continuum correction to isolate surface reflectance.

2. **PCA Dimensionality Reduction:**
   - Perform PCA on the corrected spectra.
   - Extract principal components to form the latent space.

3. **Latent Space Augmentation:**
   - Compute the KDE of the latent coefficients.
   - Sample synthetic latent vectors to create augmented training data.

4. **Synthetic Photometry Simulation:**
   - For each synthetic latent vector, decode to a spectrum.
   - Convolve with NIRCam filter profiles to generate reflectances.
   - Add 20% Gaussian noise to simulate photometric uncertainty.

5. **Training the AutoML Regressor:**
   - Use AutoGluon to train a model mapping noisy photometry to latent coefficients.
   - Validate using LOOCV to assess reconstruction accuracy.

6. **Spectral Reconstruction:**
   - For new photometric data, predict latent coefficients.
   - Reconstruct the full spectrum using inverse PCA.

7. **Taxonomic Classification (Optional):**
   - Train a classifier on the latent means.
   - Classify new objects based on their latent projections.

8. **Outlier Detection (Optional):**
   - Compute latent density for new objects.
   - Identify low-density regions as outliers.

**End Algorithm**
