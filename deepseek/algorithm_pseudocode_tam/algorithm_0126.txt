To implement the core reconstruction framework, we follow these steps:

1. **Principal Component Analysis (PCA):**
   - Train PCA on a reference set of TNO spectra to create a low-dimensional latent space.

2. **Data Augmentation with Kernel Density Estimation (KDE):**
   - Use KDE to smooth the latent space, generating synthetic spectra for training.

3. **Likelihood Function Setup:**
   - Simulate photometric measurements by convolving spectra with instrument filters and adding noise.

4. **AutoML Regressor Training:**
   - Train an ensemble of gradient-boosted decision trees to map photometry to latent coefficients.

5. **Reconstruct Spectra:**
   - For new photometry, predict latent coefficients and invert PCA to get the reconstructed spectrum.

6. **Taxonomic Classification:**
   - Classify the object's taxonomic type based on the latent space representation.
