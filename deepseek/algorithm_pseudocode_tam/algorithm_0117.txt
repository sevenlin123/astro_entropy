### Algorithm

**Algorithm**: Probabilistic Spectral Reconstruction Framework

1. **Input**: Sparse photometric measurements of TNOs, reference spectra, and filter definitions for the target instrument (e.g., JWST/NIRCam).

2. **Preprocessing**:
   - Perform Principal Component Analysis (PCA) on the reference spectra to derive principal components (PCs).
   - Select the number of PCs (e.g., 4-5 for classification, 8-10 for high-fidelity reconstruction).

3. **Training the Latent Space Model**:
   - Use Kernel Density Estimation (KDE) on the PCA coefficients derived from the reference spectra to define a smooth prior distribution in the latent space.

4. **Synthetic Photometry Generation**:
   - For each spectrum in the latent space, generate synthetic photometric measurements by convolving the spectrum with the instrument's filter response curves.
   - Inject Gaussian noise (e.g., 20% relative uncertainty) into the synthetic photometry to simulate realistic observational noise.

5. **AutoML Regression Training**:
   - Train an ensemble of Gradient-Boosted Decision Trees (GBDTs) using the synthetic photometry as inputs and the PCA coefficients as outputs. This step maps photometric data to latent space coordinates.

6. **Taxonomic Classification Training**:
   - Train another AutoML classifier on the PCA coefficients to classify the spectra into predefined taxonomic groups (e.g., Water-type, CO₂-type, Organics-type).

7. **Reconstruction Process**:
   - For new sparse photometric data:
     a. Use the trained AutoML regressor to predict the latent coefficients.
     b. Apply the inverse PCA transform to reconstruct the full spectrum.
     c. Use the taxonomic classifier to predict the spectral type.

8. **Uncertainty Quantification**:
   - Propagate photometric uncertainties through the AutoML models to estimate uncertainties in the latent coefficients and the reconstructed spectrum.

9. **Output**: Reconstructed spectrum, taxonomic classification, and associated uncertainties.

**End of Algorithm**
