### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

**Step-by-Step Pseudocode:**

1. **Training Phase:**
   - **Input:** Set of reference TNO spectra (`spectra_set`), known taxonomic labels (`labels`), and JWST/NIRCam filter responses (`filters`).
   - **Output:** Trained AutoML regressor (`regressor`), inverse PCA transform (`inverse_pca`), and taxonomic classifier (`classifier`).
     1.1. Perform **Principal Component Analysis (PCA)** on `spectra_set` to derive latent space representation (`principal_components`). The number of components is determined to be 8-10 to ensure high-fidelity reconstruction.
     1.2. Apply **Kernel Density Estimation (KDE)** on the latent coordinates derived from `principal_components` to create a smooth probability distribution (`latent_prior`), setting a bandwidth of 0.5 for stability.
     1.3. Generate **synthetic photometry** by convolving each augmented spectrum with the NIRCam filter responses, introducing 20% Gaussian noise to simulate observational uncertainty.
     1.4. Train **AutoML regressor** (`regressor`) to map sparse photometric measurements to latent coefficients, using an ensemble of gradient-boosted decision trees.
     1.5. Retrain **PCA** excluding each object iteratively (LOOCV) to validate reconstruction fidelity.
     1.6. Train **taxonomic classifier** (`classifier`) on the latent space to predict spectral types, using labels from `labels`.
   
2. **Reconstruction Phase:**
   - **Input:** Observed photometric measurements (`obs_photometry`).
   - **Output:** Reconstructed spectrum (`reconstructed_spectrum`), taxonomic probabilities (`taxonomy_probs`), and uncertainty estimates.
     2.1. Use the trained `regressor` to predict latent coefficients from `obs_photometry`.
     2.2. Project the latent coefficients through the inverse PCA transform (`inverse_pca`) to obtain the full spectrum.
     2.3. Pass the latent coefficients to the `classifier` to get taxonomic probabilities.
     2.4. Calculate the Root Mean Square Error (RMSE) between `reconstructed_spectrum` and the ground truth (if available).
     2.5. Assess the credible interval coverage to evaluate uncertainty calibration.

3. **Outlier Detection:**
   - **Input:** `reconstructed_spectrum`, latent coefficients.
   - **Output:** Flag indicating outlier status.
     3.1. Compute statistical tests on latent coefficients, such as extreme value analysis or Mahalanobis distance.
     3.2. If the posterior in latent space is inconsistent with `latent_prior`, flag as outlier.

4. **Survey Optimization:**
   - **Input:** Filter configurations.
   - **Output:** Recommended filter set.
     4.1. For each filter configuration, simulate photometric measurements using reference spectra.
     4.2. Use the trained framework to reconstruct spectra and compute RMSE and uncertainty metrics.
     4.3. Select filters that minimize RMSE and maximize information content for taxonomic classification.

**End of Algorithm**
