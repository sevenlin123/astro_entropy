Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- Sparse photometric measurements (m)
- Precomputed PCA basis (principal_components)
- Number of principal components (K)

Output:
- Reconstructed high-resolution spectrum (S)
- Uncertainty estimates (σ)
- Posterior probabilities for spectral types

Steps:
1. Initialize the latent space with principal components derived from reference spectra.
2. Use an AutoML regressor to map sparse photometry (m) to latent coefficients (z).
   a. Predict latent coefficients z using the trained regressor.
3. Project the latent coefficients z through the inverse PCA transform to reconstruct the full spectrum S.
4. Compute uncertainty estimates σ by propagating the variance in the latent space through the inverse PCA transformation.
5. Optional: Classify the spectrum into predefined taxonomic classes using a trained classifier based on the latent coefficients.
6. Return the reconstructed spectrum S, uncertainty estimates σ, and posterior probabilities for spectral types.

End.
