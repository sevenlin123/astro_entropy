Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Read TNO spectral data from literature.
2. Perform PCA on spectral data to derive principal components.
3. Apply Kernel Density Estimation (KDE) to PCA latent coefficients to create a smooth prior distribution.
4. Simulate photometric measurements by convolving each spectrum with NIRCam filter responses and adding Gaussian noise.
5. Train AutoGluon regressor to map noisy photometric data to latent PCA coefficients.
6. For new photometric data:
   a. Use the trained regressor to predict latent coefficients.
   b. Invert PCA transform using the predicted coefficients to obtain reconstructed spectrum.
   c. Classify the spectrum into taxonomic type using latent space.
