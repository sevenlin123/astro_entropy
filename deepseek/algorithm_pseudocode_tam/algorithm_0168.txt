**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Principal Component Analysis (PCA) Training**
   - Input: Reference spectra of TNOs
   - Output: Principal components (eigenvectors and eigenvalues)
     ```python
     Perform PCA on the reference spectra to derive the principal components.
     ```

2. **Data Augmentation**
   - Input: Latent coefficients from PCA
   - Output: Synthetic latent coefficients with added noise
     ```python
     Use Kernel Density Estimation (KDE) to sample synthetic latent coefficients, introducing a smoothing bandwidth (e.g., h = 0.5).
     ```

3. **Synthetic Photometry Generation**
   - Input: Synthetic spectra, instrument filters (e.g., JWST NIRCam)
   - Output: Noisy photometric measurements
     ```python
     Convolve each synthetic spectrum with the instrument's filter transmission curves to simulate observed photometry. Add Gaussian noise with a relative uncertainty of 20% to the photometric data.
     ```

4. **AutoML Regressor Training**
   - Input: Noisy photometric measurements and corresponding latent coefficients
   - Output: Trained regressor model
     ```python
     Train an AutoML regressor (e.g., Gradient-Boosted Decision Trees) to map photometric inputs to latent coefficients.
     ```

5. **Spectral Reconstruction**
   - Input: New sparse photometric observations
   - Output: Reconstructed spectrum
     ```python
     Use the trained regressor to predict latent coefficients from the new photometry. Invert the PCA transformation using these coefficients to obtain the full spectrum.
     ```

This algorithm efficiently reconstructs high-resolution spectra from sparse photometric data, leveraging PCA for dimensionality reduction and AutoML for robust regression.
