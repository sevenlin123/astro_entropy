**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

**Step-by-Step Explanation:**

1. **Obtain Training Data**: Gather a sample of near-infrared TNO spectra for training purposes.

2. **Principal Component Analysis (PCA)**: Decompose the training spectra into principal components to create a low-dimensional latent space representation.

3. **Project Spectra into Latent Space**: Convert each original spectrum into its corresponding latent space coordinates using the PCA.

4. **Kernel Density Estimation (KDE)**: Apply KDE to the latent space to create a smooth probability distribution, expanding the dataset to include synthetic spectra.

5. **Generate Synthetic Spectra**: Sample from the augmented latent space to produce synthetic spectra.

6. **Forward Model Synthetic Spectra**: Simulate the process of obtaining photometric observations by convolving the synthetic spectra with instrument filter curves.

7. **Add Noise to Synthetic Photometry**: Introduce Gaussian noise to the photometric data to simulate real-world observational uncertainties.

8. **Train AutoML Regressor**: Develop a machine learning model to map the noisy photometric data to latent space coefficients.

9. **Train Taxonomic Classifier**: Train another model to classify spectra into predefined taxonomic groups using the latent space features.

10. **Leave-One-Out Cross-Validation (LOOCV)**: Assess the model's accuracy by iteratively holding out one spectrum and validating the reconstruction against the original.

11. **Reconstruct Spectra**: For new photometric data, use the trained regressor to predict latent coefficients and then invert the PCA to obtain the full spectrum.

12. **Classify Taxonomic Group**: Optionally, apply the taxonomic classifier to determine the object's spectral type.

**Pseudocode:**

```python
function spectral_reconstruction():
    1. Load training_spectra
    2. Perform PCA on training_spectra to get principal_components
    3. Project training_spectra into latent_space using principal_components
    4. Apply KDE to latent_space projections to create smooth_prior_distribution
    5. Generate synthetic_spectra by sampling from smooth_prior_distribution
    6. Forward_model synthetic_spectra through instrument_filters to get synthetic_photometry
    7. Add gaussian_noise to synthetic_photometry
    8. Train auto_ml_regressor to map synthetic_photometry to latent_space coefficients
    9. Train auto_ml_classifier on latent_space to classify taxonomic_groups
    10. Validate using LOOCV:
        a. For each spectrum in training_spectra:
            i. Hold out the spectrum
            ii. Use auto_ml_regressor to predict latent_coefficients from photometry
            iii. Invert PCA to reconstruct spectrum
            iv. Compare reconstructed spectrum with original
    11. For new_photometry:
        a. Use auto_ml_regressor to predict latent_coefficients
        b. Invert PCA to get reconstructed_spectrum
        c. (Optional) Use auto_ml_classifier to determine taxonomic_class
    return reconstructed_spectrum, taxonomic_class
```
