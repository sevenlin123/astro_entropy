### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Initialize Training Data**:
   - Gather a reference set of 51 TNO spectra (seed population).
   - Exclude rare spectral types and outliers to focus on dominant taxonomic classes.

2. **Principal Component Analysis (PCA)**:
   - Apply PCA to the reference spectra to extract principal components.
   - Determine the optimal number of components (K) through cross-validation (e.g., 4-5 for classification, 8-10 for detailed reconstruction).

3. **Kernel Density Estimation (KDE) Augmentation**:
   - Project reference spectra onto the PCA latent space.
   - Use KDE to smooth the latent space, generating synthetic spectra to augment the training dataset.
   - Set the bandwidth (h) to 0.5 for stable manifold representation.

4. **Generate Synthetic Photometry**:
   - For each augmented spectrum, compute reflectance in JWST NIRCam filters.
   - Introduce 20% Gaussian noise to simulate observational uncertainties.

5. **Train AutoML Regressor**:
   - Use the synthetic photometry and corresponding PCA coefficients to train an ensemble model (e.g., Gradient Boosted Decision Trees).
   - The model maps sparse photometry to latent coefficients.

6. **Construct Taxonomy Classifier**:
   - Train a secondary AutoML classifier on the PCA coefficients to predict taxonomic labels (e.g., H₂O, CO₂, Organic types).

7. **Forward Inference Pipeline**:
   - For new photometric observations:
     - Pass photometry through the trained regressor to predict latent coefficients.
     - Project these coefficients back to full spectra using inverse PCA.
     - Simultaneously classify the spectral type using the latent coefficients.

8. **Evaluate Reconstruction**:
   - Measure empirical credible interval coverage across wavelengths.
   - Use LOOCV to assess taxonomic classification accuracy and feature detection fidelity.

9. **Output**:
   - Provide reconstructed spectra, taxonomic probabilities, and feature measurements for each object.
