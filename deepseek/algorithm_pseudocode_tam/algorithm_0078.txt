**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Initialize Data Structures**:
   - Gather a set of reference TNO spectra.
   - Define the target instrument's filter response curves (e.g., JWST NIRCam).

2. **Perform Principal Component Analysis (PCA)**:
   - Apply PCA to the reference spectra to extract principal components (latent space).
   - Store the PCA transformation matrix and means.

3. **Density Estimation with KDE**:
   - Project the reference spectra onto the PCA latent space.
   - Perform Kernel Density Estimation (KDE) on the latent coefficients to create a smooth probability distribution.

4. **Generate Synthetic Spectra**:
   - Sample from the KDE to create synthetic latent coefficients.
   - Project these samples back into the spectral space using inverse PCA.

5. **Simulate Photometric Data**:
   - Convolve each synthetic spectrum with the instrument's filter response curves to obtain synthetic photometric measurements.

6. **Add Noise to Synthetic Data**:
   - Inject Gaussian noise with a specified relative uncertainty (e.g., 20%) into the synthetic photometric data to simulate real-world uncertainties.

7. **Train AutoML Regressor**:
   - Train an ensemble of models (e.g., Gradient Boosted Decision Trees) using the synthetic photometric data as inputs and latent coefficients as targets.

8. **Construct Taxonomic Classifier**:
   - Project the reference spectra and their taxonomic labels into the latent space.
   - Train a classifier (e.g., logistic regression, random forest) on the latent coefficients to classify spectra into predefined taxonomic groups.

9. **Reconstruct and Classify New Observations**:
   - For new sparse photometric observations:
     a. Use the trained AutoML regressor to predict latent coefficients.
     b. Invert the PCA transform to obtain the reconstructed spectrum.
     c. Apply the taxonomic classifier to the latent coefficients to determine the spectral type.

10. **Output**:
    - Provide the reconstructed spectrum and associated taxonomic probabilities for each new observation.

This algorithm outlines the core steps for reconstructing high-resolution spectra and classifying TNOs based on sparse photometric data, leveraging PCA and AutoML techniques.
