Initialize PCA basis with reference spectra:
1. Load reference spectra of TNOs.
2. Perform PCA to determine principal components (latent space).
3. Project reference spectra into PCA latent space.

Generate synthetic training dataset:
1. Use Kernel Density Estimation (KDE) to create a smooth density model of the latent space.
2. Sample synthetic latent coordinates from the KDE model.

Forward model photometry:
1. Convolve each synthetic spectrum with NIRCam instrument throughput curves to simulate photometric fluxes.
2. Calculate reflectance for each band using the formula: reflectance = sum(spectrum * throughput) / sum(throughput).

Add noise to photometry:
1. Inject Gaussian noise with 20% relative uncertainty into the synthetic photometry.

Train AutoML regressor:
1. Use synthetic photometry as input features and latent coefficients as target.
2. Train an ensemble of models (e.g., Gradient Boosted Decision Trees) using AutoGluon.

Train taxonomic classifier:
1. Use latent coefficients as features and taxonomic labels as target.
2. Train a classifier using AutoGluon.

Perform Leave-One-Out Cross-Validation:
1. For each spectrum in the reference set:
   a. Remove it from the dataset.
   b. Generate its noise-free photometry using NIRCam throughput.
   c. Use AutoML regressor to predict latent coefficients.
   d. Reconstruct the spectrum from predicted latent coefficients.
   e. Compute RMSE between original and reconstructed spectrum.

Applications:
1. Survey optimization: Evaluate different NIRCam filter combinations to find those that minimize RMSE in latent space.
2. Outlier detection: Identify objects with latent distributions differing significantly from known classes.

This algorithm efficiently bridges sparse photometric data to detailed spectral reconstructions, enabling taxonomic classification and survey optimization for TNOs.
