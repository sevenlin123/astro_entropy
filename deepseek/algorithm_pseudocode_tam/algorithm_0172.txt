**Algorithm for Probabilistic Spectral Reconstruction of TNOs from Sparse Photometry**

**Step-by-Step Explanation:**

1. **Principal Component Analysis (PCA):**
   - Train PCA on a set of reference TNO spectra to reduce them into a low-dimensional latent space.
   - The latent space is defined by principal components capturing the main spectral variations.

2. **Kernel Density Estimation (KDE):**
   - Use the latent coefficients from PCA to create a probability distribution (smooth manifold).
   - This distribution helps in generating synthetic latent vectors to augment the training data.

3. **Synthetic Photometry Generation:**
   - For each augmented spectrum, compute the theoretical reflectance through forward modeling with NIRCam filters.
   - Inject Gaussian noise (20% relative uncertainty) to simulate real photometric measurements.

4. **AutoML Regressor Training:**
   - Train an ensemble of gradient-boosted decision trees to map sparse photometry to latent coefficients.
   - This model learns the nonlinear relationship between photometric inputs and the latent space.

5. **Inverse PCA Transformation:**
   - Convert the predicted latent coefficients back into full-resolution spectra using the inverse PCA transform.
   - The reconstructed spectra inherit the smoothness and physical features of the training data.

6. **Taxonomic Classification:**
   - Train a secondary classifier on the latent space to predict taxonomic probabilities for each object.

7. **Cross-Validation and Metrics Evaluation:**
   - Validate using LOOCV to assess reconstruction accuracy, uncertainty calibration, and taxonomic classification accuracy.

**Pseudocode Implementation:**

```python
def probabilistic_spectral_reconstruction():
    # Step 1: Perform PCA on reference spectra
    reference_spectra = load_reference_spectra()
    pca = PCA(n_components=K)  # K is chosen based on variance explained
    latent_coefficients = pca.fit_transform(reference_spectra)

    # Step 2: Generate synthetic latent space using KDE
    kde = KernelDensityEstimator(bandwidth=0.5)
    kde.fit(latent_coefficients)
    synthetic_latents = kde.sample(num_synthetic_samples)

    # Step 3: Compute synthetic photometry with noise
    synthetic_photometry = []
    for latent in synthetic_latents:
        spectrum = pca.inverse_transform(latent)
        observed_m = forward_model(spectrum, NIRCam_filters)
        add_noise(observed_m, noise_level=0.2)  # 20% relative noise
        synthetic_photometry.append(observed_m)

    # Step 4: Train AutoML regressor to map photometry to latents
    regressor = AutoMLRegressor()
    regressor.fit(synthetic_photometry, synthetic_latents)

    # Step 5: Inference for new object
    new_photometry = get_new_observation()
    predicted_latents = regressor.predict(new_photometry)
    reconstructed_spectrum = pca.inverse_transform(predicted_latents[0])

    # Step 6: Taxonomic classification
    taxonomic_probs = classifier.predict_proba(reconstructed_spectrum)

    # Step 7: Evaluate using LOOCV
    cv_metrics = evaluate_LOOCV()

    return reconstructed_spectrum, taxonomic_probs, cv_metrics

probabilistic_spectral_reconstruction()
```

**Explanation:**

- **PCA Training:** Reduces high-dimensional spectra into manageable latent components.
- **KDE Augmentation:** Smooths the latent space, aiding model regularization and preventing overfitting.
- **Synthetic Photometry:** Simulates realistic noisy data for robust training.
- **AutoML Regressor:** Efficiently maps sparse inputs to latent space, enabling accurate spectral reconstruction.
- **Taxonomic Classification:** Provides probabilistic taxonomic assignments based on the latent features.
- **Evaluation:** Ensures the model performs well across different metrics, crucial for validation.
