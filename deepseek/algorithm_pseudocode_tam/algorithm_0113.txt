The algorithm implements a Bayesian framework for reconstructing TNO spectra from sparse photometry. It uses PCA for dimensionality reduction and an AutoML regressor to predict latent coefficients. The steps are:

1. **Training Phase**:
   - Extract PCA basis from reference spectra.
   - Generate synthetic photometry from augmented spectra.
   - Train the AutoML regressor to map photometry to latent coefficients.
   
2. **Inference Phase**:
   - Predict latent coefficients from new photometry.
   - Reconstruct full spectra using inverse PCA.
   - Classify spectral types based on latent space.

```python
Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input: Observed photometric measurements (m), PCA basis (U), synthetic data (X_synthetic), and AutoML regressor (model)

Output: Reconstructed spectrum (S), spectral type probabilities (P)

1. Training Phase:

    1.1. Load reference spectra (S_train).
    
    1.2. Perform PCA on S_train to obtain basis U.
    
    1.3. Project S_train onto U to get latent coefficients z_train.
    
    1.4. Augment z_train using Kernel Density Estimation (KDE) to generate X_synthetic.
    
    1.5. Simulate photometry for X_synthetic by convolving with instrument filters and adding noise.
    
    1.6. Train AutoML regressor model to predict latent coefficients from photometry.
    
2. Inference Phase:

    2.1. For new photometry m:
    
        2.1.1. Use model to predict latent coefficients z_hat.
        
        2.1.2. Propagate uncertainties from z_hat to S using inverse PCA transform.
        
        2.1.3. Classify spectral type from z_hat.
        
    2.2. Output S, uncertainties, and spectral type probabilities P.
```
