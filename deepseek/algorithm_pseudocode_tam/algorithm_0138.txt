```python
Define PCA basis using reference TNO spectra:
    Train PCA on 51 seed spectra to extract principal components (PCs).
    
Generate synthetic training data:
    Project seed spectra onto PCA latent space.
    Use Kernel Density Estimation (KDE) to create smooth probability distribution.
    Sample 10,000 synthetic spectra from this distribution.

Create synthetic photometry:
    Convolve each synthetic spectrum with NIRCam filter responses.
    Add 20% Gaussian noise to simulate realistic photometric uncertainties.

Train AutoML regressor:
    Use ensemble of gradient-boosted decision trees to regress from photometry to latent coefficients.
    Input features: sparse photometric measurements.
    Output labels: latent PCA coefficients.

Perform LOOCV validation:
    For each seed spectrum:
        Remove from training set.
        Generate photometry for remaining spectra.
        Predict latent coefficients for test spectrum.
        Convert to full spectrum using inverse PCA.
        Compute Pearson r, RMSE, credibility coverage.

Output:
    Reconstructed spectra with uncertainties.
    Probabilistic taxonomic classification.
