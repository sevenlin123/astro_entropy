Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- Observed photometric measurements (sparse)
- Pre-trained PCA basis (principal components)
- Probability distribution of latent coefficients (from KDE or GMM)
- Target spectral resolution

Output:
- Reconstructed high-resolution spectrum
- Probabilistic taxonomic classification

Steps:

1. Initialize:
   - Load PCA basis derived from reference TNO spectra.
   - Set up probability distribution for latent space (using KDE or GMM).
   - Define forward modeling through NIRCam filters.

2. Prepare Data:
   - Input photometric measurements normalized by solar flux.
   - Inject Gaussian noise (20% uncertainty) into synthetic photometry.

3. AutoML Training:
   - Train an ensemble of Gradient Boosted Decision Trees (AutoGluon) to map photometric inputs to latent coefficients.
   - Augment training data using synthetic latent vectors generated from the probability distribution.

4. Bayesian Inference:
   - For each photometric observation:
      a. Predict latent coefficients using the trained AutoML model.
      b. Project latent coefficients through inverse PCA transform to get spectral reconstruction.
      c. Compute posterior probabilities of spectral types using latent space classifier.

5. Validation and Output:
   - Compare reconstructed spectra with ground truth using LOOCV.
   - Calculate empirical credible intervals.
   - Classify spectral types based on posterior probabilities.
   - Output reconstructed spectrum and taxonomic probabilities.

End Algorithm
