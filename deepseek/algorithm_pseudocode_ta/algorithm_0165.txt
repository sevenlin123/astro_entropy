**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data**:
   - Training set of TNO near-IR spectra.
   - Sparse photometric measurements for target TNO.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the training set of near-IR spectra.
   - Determine the number of principal components (n_components) based on cross-validation results (e.g., 4-5 for taxonomic classification, 8-10 for high-fidelity reconstruction).

3. **Latent-Space Model Construction**:
   - Represent the spectral manifold in the reduced PCA space.
   - Define a probabilistic model that captures the latent structure of the spectral data.

4. **Bayesian Inference**:
   - Use the sparse photometric measurements as inputs.
   - Perform Bayesian inference in the PCA-reduced latent space to reconstruct the full spectrum.
   - Propagate measurement uncertainties through the inference process.

5. **Reconstruction**:
   - Reconstruct the full spectrum of the target TNO using the inferred parameters from the latent space.
   - Optionally adjust the number of components used for reconstruction (e.g., 8-10 for higher fidelity).

6. **Uncertainty Calibration**:
   - Calculate the uncertainties associated with the reconstructed spectrum.
   - Ensure that the empirical credible-interval coverage is approximately 95% across wavelengths.

7. **Output**:
   - Provide the reconstructed spectrum and associated uncertainties.
   - Include additional outputs like optimized filter configurations for future surveys if applicable.

This algorithm effectively bridges the gap between sparse photometric data and detailed spectral reconstruction, enabling robust taxonomic classification and survey optimization for TNOs.
