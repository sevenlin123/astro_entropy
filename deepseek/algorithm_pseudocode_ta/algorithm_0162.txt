**Algorithm: Probabilistic Spectral Reconstruction Framework**

**Initialization:**
1. Precompute PCA basis vectors using a reference spectral library of TNOs.
   - PCA_basis ∈ ℝ^{D×K}, where D is the number of wavelengths and K is the number of PCA components (e.g., 4-10).

**Processing each object:**
For each object i = 1 to N_obj:
   
   **Input:** Sparse photometric measurements (photometry_i ∈ ℝ^{N_phot}) and their uncertainties.

   **Step 1:** Compute an initial latent space estimate (z_i⁰ ∈ ℝ^K).
      - Project photometric measurements into the latent space (e.g., via a mapping function).

   **Step 2:** Perform Bayesian inference to update z_i.
      - Define likelihood function linking z_i to observed photometry, considering uncertainties.
      - Prior over z_i is Gaussian (mean 0, variance determined by PCA).
      - Posterior p(z_i | photometry_i) is sampled using MCMC.

   **Step 3:** Draw MCMC samples: {z_i^m}_{m=1}^M.
   
   **Step 4:** Reconstruct spectrum for each sample.
      - s_i^m = PCA_basis * z_i^m^T.

   **Step 5:** Compute posterior predictive distribution.
      - Extract median spectrum and credible intervals.

**Output:** For each object, the median spectrum and credible intervals.

**End of Algorithm**
