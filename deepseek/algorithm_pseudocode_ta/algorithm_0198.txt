Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

Input:
- TrainingSpectra: Matrix of reference near-IR spectra
- PhotometricMeasurements: Sparse photometric data for target objects
- MeasurementUncertainties: Associated uncertainties for the photometric measurements

Output:
- ReconstructedSpectra: Full reconstructed spectra for each object
- Uncertainties: Estimated uncertainties on the reconstructed spectra

Steps:

1. Preprocessing:
   - Normalize TrainingSpectra to ensure comparable data ranges.
   
2. Dimensionality Reduction (Principal Component Analysis):
   - Compute Principal Components (PCs) using TrainingSpectra.
   - Extract the top K PCs, where K is determined via LOOCV (e.g., K=4-5 for classification, K=8-10 for detailed reconstruction).

3. Probabilistic Model Construction:
   - Represent the spectral manifold in the reduced PCA space.
   - Define the probability distribution over the latent PCA coefficients based on the observed photometric measurements.

4. Bayesian Inference:
   - Perform Bayesian estimation to infer the latent variables (PCA coefficients) from the photometric data.
   - Utilize prior distributions informed by the training data and measurement uncertainties.

5. Spectrum Reconstruction:
   - Map the inferred PCA coefficients back to the original spectral space.
   - Combine contributions from each PC to reconstruct the full spectrum.

6. Uncertainty Propagation:
   - Calculate uncertainties on the reconstructed spectra by propagating the measurement uncertainties through the probabilistic model.
   - Quantify the uncertainty contribution from each step of the reconstruction process.

7. Validation and Output:
   - Assess the empirical credible interval coverage (e.g., ~95% across wavelengths).
   - Output the ReconstructedSpectra and associated uncertainties for each object.

End Algorithm
