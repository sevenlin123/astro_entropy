**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Training Phase**:
   - **Input**: Collection of near-IR spectra of TNOs.
   - **Output**: Principal Component (PC) decomposition.
     ```
     Train PCA on the spectral dataset.
     Extract principal components (PCs) up to a determined number (e.g., 4-5 for classification).
     ```

2. **Reconstruction Phase**:
   - **For each object**:
     - **Input**: Observed photometric measurements.
     - **Steps**:
       a. **Forward Model Setup**:
          - Relate photometric bands to PCA basis vectors projected into those bands.
        b. **Bayesian Inference**:
           - Define prior distributions over latent variables (coefficients in PCA decomposition).
           - Formulate likelihood based on observed photometric data and forward model.
           - Compute posterior using Bayes' theorem.
       c. **Mapping to Original Space**:
          - Use posterior coefficients to reconstruct full spectrum via PCA basis.
       d. **Uncertainty Propagation**:
          - Calculate uncertainties using posterior covariance matrix.
     - **Output**: Reconstructed spectrum and associated uncertainties.

3. **Final Output**:
   - **Output**: Reconstructed spectra for all objects along with their uncertainties.

This structured approach ensures accurate reconstruction of TNO spectra from sparse photometric data using Bayesian inference in a PCA latent space, propagating uncertainties appropriately.
