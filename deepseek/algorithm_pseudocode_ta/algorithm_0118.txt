**Algorithm: Probabilistic Spectral Reconstruction**

**Inputs:**
- Reference Spectra: Set of known TNO spectra.
- Photometric Data: Sparse photometric measurements for each object.
- Measurement Uncertainties: Associated uncertainties in photometric data.

**Outputs:**
- Reconstructed Spectra: Full spectra for each object.
- Uncertainties: Associated uncertainties in reconstructed spectra.
- Optimal PCA Components: Number of PCA components determined by LOOCV.

**Steps:**

1. **Preprocess:**
   - Perform PCA on Reference Spectra:
     - Compute covariance matrix.
     - Calculate eigenvectors and eigenvalues.
     - Sort eigenvectors by descending eigenvalues.

2. **Determine Optimal PCA Components via LOOCV:**
   - For each possible 'k':
     - Remove one spectrum from Reference Spectra.
     - Reconstruct the removed spectrum using remaining 'k' PCA components.
     - Evaluate reconstruction quality using metrics like RMSE or likelihood ratio.
   - Select 'k' that balances complexity and accuracy.

3. **Bayesian Inference for Each Object:**
   - Extract photometric data and uncertainties.
   - Initialize prior distributions (e.g., zero mean, unit variance).
   - For each wavelength band:
     - Map photometric data to PCA space.
     - Update posterior distributions using photometric data and uncertainties.
     - Use Gaussian likelihoods for Bayesian updates.

4. **Reconstruct Spectra:**
   - Using optimal 'k', perform Bayesian inference.
   - Reconstruct full spectra using the latent space mapping.
   - Compute uncertainties via uncertainty propagation.

5. **Applications:**
   - **Outlier Detection:** Identify objects with posterior distributions differing from the majority.
   - **Survey Optimization:** Analyze information content of JWST/NIRCam filters to determine optimal configurations.

**Output:** Reconstructed Spectra, their uncertainties, and optimal PCA configuration.
