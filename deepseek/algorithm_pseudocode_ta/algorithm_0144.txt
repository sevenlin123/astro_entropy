**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Preprocess Photometric Data**:
   - Normalize photometric flux measurements.
   - Address and handle missing data points.

2. **Principal Component Analysis (PCA)**:
   - Compute PCA on reference near-IR spectra.
   - Identify optimal number of Principal Components (PCs) through cross-validation.

3. **Probabilistic Latent Space Model**:
   - Represent each spectrum with latent variables (PC coefficients).
   - Define prior distributions over these latent variables.
   - Model photometric measurement uncertainties.

4. **Bayesian Inference for Each Object**:
   - Estimate posterior distribution of latent variables using observed photometry.
   - Reconstruct full spectra by projecting latent variables back into spectral space.

5. **Uncertainty Propagation**:
   - Calculate uncertainty in reconstructed spectra considering latent space variance.

6. **Spectral Reconstruction Validation**:
   - Assess reconstruction quality by comparing with original spectra (if available).

7. **Survey Optimization Application**:
   - Evaluate information content of NIRCam filters (e.g., F090W, F115W).
   - Select optimal filter configurations for future observations.

8. **Reconstruct Rare Spectral Types**:
   - Consider low-probability intermediate models.
   - Use photometric data to explore spectral manifold topology and reconstruct rare types.

**End Algorithm**
