**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Precompute PCA Latent Space**
   - Input: Training set of manually classified TNO spectra.
   - Perform Principal Component Analysis (PCA) to extract principal components (latent space representation).

2. **Develop Probabilistic Model**
   - Construct a probabilistic model (e.g., Gaussian Process) using the principal components derived from PCA.
   - This model represents the reduced spectral manifold of TNOs.

3. **Bayesian Inference for Each Object**
   - For each trans-Neptunian object:
     a. Acquire sparse photometric measurements.
     b. Utilize the probabilistic model to perform Bayesian inference, obtaining posterior distributions of the principal components.

4. **Spectral Reconstruction**
   - Reconstruct the full near-infrared spectrum using the inferred posterior distributions of the principal components.

5. **Uncertainty Propagation**
   - Propagate photometric measurement uncertainties through the probabilistic model to determine confidence intervals on the reconstructed spectrum.

6. **Output**
   - Generate reconstructed spectra and their associated uncertainty intervals.

This algorithm focuses on the core computational steps for spectral reconstruction, excluding validation and visualization procedures.
