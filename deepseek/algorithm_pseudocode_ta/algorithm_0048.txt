**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Initialize Parameters**
   - Load sparse photometric data for each trans-Neptunian object (TNO)
   - Load Principal Components (PCs) matrix derived from a reference spectral library
   - Load noise covariance matrix for photometric uncertainties

2. **Process Each Object Individually**
   - **Extract Data**: Retrieve photometric fluxes and their associated uncertainties
   - **Project onto Spectral Manifold**: Map photometric data into the PCA space using the precomputed PCs
   - **Bayesian Inference in PCA Space**
     - Define prior distribution as a multivariate normal, centered at the origin, with covariance proportional to the inverse of PCA loadings
     - Define likelihood as a multivariate normal, where the mean is the linear combination of PCs and covariance is diagonal, matching noise levels
     - Compute posterior distribution over PCA coefficients using Bayes' theorem
   - **Transform Back to Spectral Space**: Use inverse PCA transformation on posterior coefficients to obtain reconstructed spectra
   - **Calculate Uncertainties**: Determine spectral uncertainties (e.g., standard deviations) from the posterior variances

3. **Determine Outlier Status**
   - For each reconstructed spectrum, compute the probability of it belonging to its posterior distribution
   - Compare probability against a threshold (e.g., 0.05); if below, classify as outlier
   - Record outlier probabilities

4. **Output Results**
   - Provide reconstructed spectra along with their uncertainties
   - Supply outlier probabilities for each object

**End Algorithm**
