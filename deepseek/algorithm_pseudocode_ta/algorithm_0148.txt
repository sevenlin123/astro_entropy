**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Preprocess Photometric Data**: Normalize and prepare the photometric measurements for analysis.

2. **Train Principal Component Model**: Using a set of reference near-infrared spectra, compute the principal component representation (PCA).

3. **Transform Photometry to Latent Space**: Project the photometric data onto the principal component manifold learned from the reference spectra.

4. **Perform Bayesian Inference**: In the reduced latent space, apply Bayesian methods to infer the most probable principal components, incorporating measurement uncertainties.

5. **Reconstruct Full Spectra**: Using the inferred latent space parameters, reconstruct the full spectral representation while propagating uncertainties.

6. **Output Reconstructed Spectra**: Deliver the reconstructed spectra along with their associated uncertainties.

**End Algorithm**
