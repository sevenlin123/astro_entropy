**Algorithm: Probabilistic Spectral Reconstruction**

**Step 1: Principal Component Analysis (PCA)**
1. Train a PCA model on a dataset of TNO near-infrared spectra.
2. Extract the top `k` principal components (PCs) where `k` is determined to be 4-5 for taxonomic classification and 8-10 for improved reconstruction fidelity.

**Step 2: Probabilistic Model Construction in Latent Space**
1. Represent each TNO spectrum in the reduced PCA space as a vector of latent variables.
2. Develop a probabilistic model in this latent space to describe the distribution of these vectors.

**Step 3: Bayesian Inference**
1. Perform Bayesian inference to estimate the latent variables given observed sparse photometric data.
2. Propagate measurement uncertainties through the Bayesian posterior.

**Step 4: Spectrum Reconstruction**
1. Map the inferred latent variables back to the high-dimensional spectral space.
2. Generate reconstructed spectra based on the inferred latent variable distributions.

**End Algorithm**
