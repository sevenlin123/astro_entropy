**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. Train a PCA model on a set of reference near-IR spectra.
2. For each object, obtain sparse photometric measurements.
3. Project the photometric data into the PCA space to obtain latent variables.
4. Perform Bayesian inference in the latent space to estimate latent variables considering uncertainties.
5. Reconstruct the full spectrum using the estimated latent variables and the PCA basis vectors.
6. Propagate measurement uncertainties from photometric measurements to the spectral reconstruction.
7. Validate the empirical credible intervals for the reconstructed spectra.

**End Algorithm**
