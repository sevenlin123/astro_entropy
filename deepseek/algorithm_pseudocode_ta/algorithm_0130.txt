**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

**Step 1: Data Preprocessing**
- Convert raw photometric measurements into a standardized format.
- Normalize and align data to match spectral resolution.

**Step 2: Principal Component Analysis (PCA)**
- Apply PCA to a training set of TNO near-IR spectra.
- Determine the number of principal components (4-5 for taxonomic classification, 8-10 for improved fidelity).
- Extract the principal component matrix.

**Step 3: Latent Space Representation**
- Project photometric data into the PCA-derived latent space.
- Represent each object with a low-dimensional vector in this space.

**Step 4: Bayesian Inference**
- Set up a Bayesian model using the latent space representation.
- Define priors based on the training set statistics.
- Perform Markov Chain Monte Carlo (MCMC) sampling to estimate posterior distributions of latent variables.

**Step 5: Spectral Reconstruction**
- Map the posterior latent variables back to the original spectral space.
- Reconstruct full spectra using the inverse PCA transformation.
- Quantify uncertainties during the reconstruction process.

**Step 6: Measurement Uncertainty Propagation**
- Incorporate photometric uncertainties into the Bayesian model.
- Propagate these uncertainties through the inversion process to obtain uncertainty estimates on reconstructed spectra.

**Step 7: Outlier Detection and Model Selection**
- Analyze posterior probabilities to identify unusual spectral types.
- Detect outliers by comparing model posterior probabilities against expected distributions.

**End Algorithm**
