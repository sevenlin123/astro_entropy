**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data:**
   - Training Sample: A set of near-infrared (NIR) spectra.
   - Photometric Observations: Sparse photometric measurements for trans-Neptunian objects (TNOs).

2. **Principal Component Analysis (PCA):**
   - Perform PCA on the training set of NIR spectra.
   - Extract principal components (PCs) to represent the spectral manifold of TNOs.
   - Determine the optimal number of PCs (e.g., 4-5 for taxonomic classification; 8-10 for high-fidelity reconstruction).

3. **Probabilistic Latent-Space Model:**
   - Represent the spectral manifold in a reduced space using the extracted PCs.
   - Establish a probabilistic mapping from photometric measurements to the latent space of spectral components.

4. **Bayesian Inference:**
   - Use the reduced spectral space to perform Bayesian inference for spectral reconstruction.
   - Propagate measurement uncertainties from photometric data through the latent space model.

5. **Reconstruct Spectra:**
   - For each TNO, reconstruct its full spectrum by solving for the latent variables (PCs) that best explain the observed photometric data.
   - Compute credible intervals to assess the uncertainty in the reconstructed spectra.

6. **Survey Optimization:**
   - Apply the framework to evaluate the information content of NIRCam filters (e.g., F090W, F115W, F410M, F460M).
   - Identify optimal filter configurations for maximizing spectral reconstruction fidelity.

7. **Outlier Detection and Rare Spectral Types:**
   - Allow the model to consider low-probability intermediate states in the latent space.
   - Use the framework to detect and reconstruct rare spectral types by constraining photometric data to unusual regions of the spectral manifold.

8. **Output:**
   - Reconstructed spectra for each TNO.
   - Credible intervals indicating the uncertainty in the reconstructed spectra.
   - Optimized survey configurations for future observations.

This algorithm bridges the gap between sparse photometric data and detailed spectral information, enabling robust spectral reconstruction and taxonomic classification of TNOs.
