**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data**:
   - Training set of near-IR spectra (S).
   - Observed sparse photometric measurements (P).

2. **Preprocessing**:
   - Convert S into a principal component (PC) representation:
     - Compute principal components using a method like PCA.
     - Retain 4-5 dominant components for taxonomic classification.
     - Retain 8-10 components for improved reconstruction fidelity.

3. **Model Construction**:
   - Train a probabilistic latent-space model using the PC representation of S.
   - Define the spectral manifold of TNOs based on these PCs.

4. **Bayesian Inference**:
   - Perform Bayesian inference in the reduced PC space.
   - Reconstruct full spectra from P while propagating measurement uncertainties.

5. **Reconstruction**:
   - For each object:
     - Use the probabilistic framework to infer the most likely spectral model.
     - Quantify uncertainty through posterior distributions.

6. **Survey Optimization**:
   - Evaluate the information content of different NIRCam filters.
   - Identify optimal filter combinations (e.g., F090W, F115W, F410M, F460M).

7. **Outlier Detection and Rare Type Reconstruction**:
   - Apply the framework to photometric data constrained to low-probability intermediate models.
   - Detect and reconstruct rare spectral types like 2006~RJ$_{103}$ and 2011~SO$_{277}$.

8. **Output**:
   - Reconstructed spectra with credible intervals.
   - Optimized filter configurations.
   - Identified outlier and rare spectral types.
