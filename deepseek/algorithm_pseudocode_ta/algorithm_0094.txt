**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Input Data Preparation**
   - Read sparse photometric measurements of trans-Neptunian objects (TNOs).
   - Convert photometric data into a format compatible with the latent-space model.

2. **Principal Component Analysis (PCA) Training**
   - Obtain a pre-trained PCA model using a sample of near-infrared (near-IR) spectra of TNOs.
   - The PCA model reduces spectral variability into principal components (PCs).

3. **Latent-Space Model Construction**
   - Construct a probabilistic latent-space framework using the PCA-derived PCs.
   - This framework models the spectral manifold of TNOs in a reduced dimensional space.

4. **Bayesian Inference**
   - Perform Bayesian inference in the reduced latent space to reconstruct full spectra from sparse photometric data.
   - Propagate measurement uncertainties through the Bayesian inference process.

5. **Cross-Validation (Optional for Core Algorithm but Included for Validation in the Paper)**
   - Apply leave-one-out cross-validation to assess the accuracy of spectral reconstruction and uncertainty propagation.
   - Validate that the number of principal components (approximately 4-5 for taxonomic classification and 8-10 for improved fidelity) effectively captures the spectral variability.

6. **Spectral Reconstruction**
   - Use the trained model to reconstruct full near-IR spectra for each TNO based on sparse photometry.
   - Ensure reconstructed spectra achieve ~95% credible-interval coverage across wavelengths.

7. **Survey Optimization and Filter Selection**
   - Evaluate the information content of JWST/NIRCam filters (e.g., F090W, F115W, F410M, F460M).
   - Identify optimal filter configurations for maximizing spectral reconstruction fidelity and taxonomic classification.

8. **Outlier Detection and Rare Spectral Type Reconstruction**
   - Allow the model to constrain photometry to select low-probability intermediate models from the continuous spectral manifold.
   - Detect and reconstruct rare spectral types, such as peculiar Neptune Trojans, by leveraging the probabilistic framework.

9. **Output**
   - Generate reconstructed spectra, associated uncertainties, and optimal survey configurations.
   - Provide outputs for taxonomic classification and outlier detection.

**End of Algorithm**
