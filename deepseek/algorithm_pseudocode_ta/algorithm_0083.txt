**Algorithm: Spectral Reconstruction from Sparse Photometry**

**Input:**  
- `sparse_photometry`: List of tuples containing `(wavelength, flux, error)` for each object.

**Output:**  
- `reconstructed_spectrum`: Array of flux values across all wavelengths.

**Steps:**

1. **Initialization:**
   - Set `num_pc` to the number of principal components (e.g., 8 for high-fidelity reconstruction).
   - Load the pre-trained principal component basis vectors (`pc_basis`), each of length `n_wavelengths`.

2. **Processing Each Object:**
   - For each object, extract its `sparse_photometry` data.
   - Construct matrix `X` where each row corresponds to a `(wavelength, flux, error)` tuple:
     - Each entry `X[i][j] = pc_basis[j][wavelength_i]`.
   - Extract `y` as the array of flux measurements.
   - Extract `sigma` as the array of measurement errors.

3. **Bayesian Inference:**
   - Compute `XTX = transpose(X) @ X`.
   - Scale `XTX` by dividing by `sigma^2`: `scaled_XTX = XTX / sigma^2`.
   - Compute the prior precision matrix: `I_tau = identity_matrix(num_pc) * (1 / tau^2)`.
   - Calculate `Precision = scaled_XTX + I_tau`.
   - Invert `Precision` to get the posterior covariance matrix: `Sigma_post = inv(Precision)`.
   - Compute the posterior mean of the coefficients: 
     \[
     mu\_post = Sigma\_post @ ( transpose(X) @ y / sigma^2 )
     \]

4. **Spectrum Reconstruction:**
   - For each wavelength:
     - Reconstruct flux by summing contributions from each PC basis vector weighted by `mu_post`.
     - `flux[wavelength] = sum(mu_post[j] * pc_basis[j][wavelength] for j in 0..num_pc-1)`.

5. **Output:**
   - Collect all reconstructed spectra and return.

**Pseudocode:**

```pseudocode
Function SpectralReconstruction(sparse_photometry):
    For each object in sparse_photometry:
        X = Matrix of size (m x num_pc)
        For each (wavelength, flux, error) in object's photometry:
            X_row = [pc_basis[0][wavelength], ..., pc_basis[num_pc-1][wavelength]]
            Add to X matrix
        y = [flux values]
        sigma = [error values]
        Compute XTX = transpose(X) * X
        scaled_XTX = XTX / sigma^2
        I_tau = identity_matrix(num_pc) * (1 / tau^2)
        Precision = scaled_XTX + I_tau
        Sigma_post = inv(Precision)
        mu_post = Sigma_post * (transpose(X) * y / sigma^2)
        reconstructed_spectrum = []
        For each wavelength:
            flux = sum(mu_post[j] * pc_basis[j][wavelength] for j in 0..num_pc-1)
            Append flux to reconstructed_spectrum
        Output reconstructed_spectrum
    End
```

This algorithm efficiently reconstructs full spectra from sparse photometric data using Bayesian inference in a reduced principal component space, enabling robust spectral analysis for trans-Neptunian objects.
