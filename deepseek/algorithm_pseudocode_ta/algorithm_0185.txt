**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Principal Component Analysis (PCA):**
   - Train PCA on a collection of near-infrared spectral datasets to derive principal components (PCs) capturing the spectral variability.

2. **Bayesian Inference Setup:**
   - Represent each spectrum as a weighted combination of the precomputed PCA components.
   - Define a Bayesian model where photometric measurements inform the posterior distribution of the PCA weights.

3. **Spectral Reconstruction:**
   - For each object, perform Bayesian inference using photometric data to estimate the PCA weight distribution.
   - Reconstruct the full spectrum by combining these estimated weights with the PCA components.

4. **Uncertainty Propagation:**
   - Calculate uncertainties in the reconstructed spectrum by propagating uncertainties from the estimated PCA weights.

**End Algorithm**
