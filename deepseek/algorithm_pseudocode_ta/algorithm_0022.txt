**Algorithm: Probabilistic Spectral Reconstruction**

1. **Training Phase:**
   - **Step 1:** Collect a reference set of near-infrared spectra.
   - **Step 2:** Preprocess the spectral data:
     - Handle missing values through imputation or removal.
     - Normalize the data to have zero mean and unit variance.
   - **Step 3:** Perform Principal Component Analysis (PCA) on the preprocessed spectral data to obtain principal components (PCs), their loadings, and the latent variables for the reference spectra.
   - **Step 4:** Store the PCA model for use in the inference phase.

2. **Inference Phase:**
   - **Step 1:** For each object to reconstruct:
     - Obtain the sparse photometric flux measurements.
     - If necessary, preprocess the flux measurements similarly to the training data.
   - **Step 2:** Use Bayesian inference to estimate the latent variables (principal component coefficients) based on the photometric data, determining their posterior distribution.
   - **Step 3:** Reconstruct the full spectrum by projecting the estimated latent variables back into the original spectral space using the PCA model.
   - **Step 4:** Propagate uncertainties from the photometric measurements through the PCA transformation to compute the uncertainties of the reconstructed spectrum using techniques like the Delta method.
   - **Step 5:** Output the reconstructed spectrum along with its associated uncertainties.
