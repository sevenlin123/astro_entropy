Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. Train Principal Component Analysis (PCA) model:
   - Input: Reference sample of near-infrared spectra of trans-Neptunian objects.
   - Output: Trained PCA model with principal components.

2. For each object:
   a. Input: Observed sparse photometric data.
   b. Project photometric data into the PCA latent space:
      - Convert observed fluxes into latent variables using the trained PCA model.

3. Bayesian Inference in latent space:
   a. Using the projected latent variables as inputs:
      - Perform Bayesian inference to estimate posterior distributions of the latent variables.
      - Consider measurement uncertainties in photometric data during inference.

4. Spectrum Reconstruction:
   a. Map inferred latent variables back into the spectral space.
   b. Reconstruct the full spectrum using the inverse PCA transformation.

5. Uncertainty Propagation:
   a. Propagate photometric uncertainties through the inferred latent variables.
   b. Calculate uncertainty in the reconstructed spectrum.

6. Output:
   a. Reconstructed spectrum.
   b. Associated uncertainties.
   c. Latent variable posteriors.
