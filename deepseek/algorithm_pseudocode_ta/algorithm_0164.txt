**Probabilistic Spectral Reconstruction (PSR) Algorithm**

**Input:**
- `TrainingSet`: Collection of near-infrared spectra.
- `PhotometryData`: Collection of objects with photometric measurements (flux and filter information).
- `FilterSpecifications`: Specifications of photometric filters, including their transmission curves.

**Output:**
- `ReconstructedSpectra`: For each object, the reconstructed full spectrum.

**Steps:**

1. **Preprocess Training Set for PCA:**
   - Compute the mean spectrum, `μ_S`.
   - Center each spectrum by subtracting `μ_S`.
   - Construct a data matrix `D` where each row is a centered spectrum.
   - Compute the covariance matrix `C` of `D`.
   - Diagonalize `C` to obtain eigenvalues `Λ` and eigenvectors `V`.
   - Sort `Λ` and `V` in descending order of eigenvalues.
   - Select top K eigenvectors from `V` (e.g., K=5 for taxonomic classification).

2. **Precompute Filter Coefficients:**
   - For each filter `F_i`:
     - Compute `c_i = dot(F_i, μ_S)`.
     - For each `k` in 1..K:
       - Compute `a_ik = dot(F_i, V[:,k])`.

3. **Process Each Object:**
   - Extract photometric measurements: list of `flux_i` and corresponding filters.
   - For each filter used:
     - Retrieve precomputed `c_i` and `a_ik`.
     - Note measurement uncertainty `σ_i`.

   - **Bayesian Inference Setup:**
     - For each `z_k` in latent space (k=1..K):
       - Prior: Gaussian(0, 1/`Λ_k`).
     - For each filter `i`:
       - Likelihood: Normal(`flux_i` | `c_i` + sum(`a_ik` * `z_k`), `σ_i^2`).

   - **Perform MCMC Sampling:**
     - Initialize `z = [0, ..., 0]`.
     - For a number of iterations:
       - Propose new `z'` by adding a small perturbation.
       - Compute log-likelihood for `z'`.
       - Compute log-prior for `z'`.
       - Compute log-posterior: log-likelihood + log-prior.
       - Accept or reject based on Metropolis criterion.

   - **Compute Posterior Predictive Distribution:**
     - For each sample `z`, compute `S = μ_S + sum(z_k * V[:,k])`.
     - Take the mean of `S` across all samples for the reconstructed spectrum.

4. **Output:**
   - Reconstructed spectra for all objects.

**Note:** The choice of K (e.g., 4-5 or 8-10) depends on the application, as per the study's requirements.
