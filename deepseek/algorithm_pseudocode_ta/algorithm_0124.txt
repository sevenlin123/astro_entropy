Algorithm ProbabilisticSpectralReconstruction:

1. Train PCA Model:

   a. Initialize with set of reference spectra.

   b. Compute mean spectrum.

   c. Center spectra by subtracting the mean.

   d. Compute covariance matrix.

   e. Perform PCA to obtain principal components.

   f. Select K components (e.g., K=5 or 10).

2. For each object:

   a. Input sparse photometric data.

   b. Project data into PCA space.

   c. Perform Bayesian inference in PCA space.

   d. Reconstruct full spectrum.

   e. Output spectrum and uncertainties.

This algorithm captures the core steps of the probabilistic spectral reconstruction framework described in the paper.
