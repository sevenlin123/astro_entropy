```
algorithm CoreSpectralReconstruction
    input:
        spectralData: collection of TNO near-IR spectra
        photometricData: sparse photometric measurements for each object

    1. Read spectralData into a matrix where each row represents a spectrum and each column a wavelength.
    2. Perform Principal Component Analysis (PCA) on the spectralData matrix to extract principal components (PCs).
    3. Select the number of significant PCs (e.g., 4-5) based on variance explained.
    4. Construct a probabilistic latent-space model using the selected PCs.
    5. For each object in the dataset:
        a. Obtain the object's sparse photometric measurements.
        b. Project the photometric data onto the latent space defined by the PCA.
        c. Perform Bayesian inference within the latent space to estimate the underlying spectral parameters.
        d. Propagate photometric uncertainties to the spectral estimates through the latent model.
        e. Reconstruct the full spectrum using the estimated latent parameters.
    6. Output the reconstructed spectra and their uncertainties.

    end algorithm
```
