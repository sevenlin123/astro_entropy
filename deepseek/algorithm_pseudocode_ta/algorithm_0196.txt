**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Training Principal Component Analysis (PCA):**
   - Input: Dataset of near-infrared (NIR) spectra of trans-Neptunian objects (TNOs).
   - Perform PCA to obtain principal components (PCs) that capture the spectral variability.
     - Output: Set of principal components (e.g., 4-5 PCs for taxonomic classification, 8-10 PCs for improved reconstruction).

2. **Spectral Manifold Modeling:**
   - Represent the spectral manifold in the reduced PCA space.
     - Each object's spectrum is modeled as a linear combination of the PCA basis vectors.

3. **Bayesian Inference in Reduced Space:**
   - For each TNO:
     - Input: Photometric measurements (sparse observations).
     - Express photometric measurements in terms of the PCA components.
     - Perform Bayesian inference to estimate the most probable PCA coefficients, incorporating measurement uncertainties.
       - Utilize prior distributions informed by the PCA training data.
       - Compute posterior distributions of the PCA coefficients.

4. **Spectrum Reconstruction:**
   - Using the inferred PCA coefficients from Bayesian inference:
     - Reconstruct the full spectrum by combining the PCA basis vectors weighted by their coefficients.
     - Propagate uncertainties through the reconstruction process to provide credible intervals.

5. **Output:**
   - Reconstructed spectra for each TNO with associated uncertainties.
   - Probabilistic classifications based on the latent-space model.

This algorithm effectively maps sparse photometric data into a reduced spectral space, enabling robust spectral reconstruction and classification of trans-Neptunian objects.
