**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **PCA Model Training**
   - Input: Set of known TNO spectra.
   - Output: Principal Component (PC) basis vectors.
   - Steps:
     1. Normalize and preprocess the input spectra.
     2. Compute the covariance matrix of the spectra.
     3. Perform Principal Component Analysis (PCA) to derive the top N principal components (N ≈ 4-5 for classification, 8-10 for higher fidelity).
     4. Store the PC basis vectors for later use.

2. **Project Photometric Data into Latent Space**
   - Input: Observed photometric measurements.
   - Output: Projected latent space representation.
   - Steps:
     1. Convert photometric data into flux values across relevant bands.
     2. Project the flux values onto the precomputed PCA basis vectors.
     3. Obtain the latent space representation of the photometric data.

3. **Bayesian Inference in Reduced Space**
   - Input: Projected latent space representation.
   - Output: Posterior distributions of spectral components.
   - Steps:
     1. Define a probabilistic model in the reduced PCA space.
     2. Use Bayesian inference to estimate the posterior distributions of the underlying spectral components.
     3. Incorporate measurement uncertainties from photometric data into the inference process.
     4. Obtain posterior means and variances for each component.

4. **Reconstruct Full Spectrum**
   - Input: Posterior distributions of spectral components.
   - Output: Reconstructed spectrum with associated uncertainties.
   - Steps:
     1. Combine the estimated components using the precomputed PCA basis vectors.
     2. Compute the full reconstructed spectrum.
     3. Propagate the uncertainties from the posterior distributions to the reconstructed spectrum.
     4. Validate empirical credible interval coverage (≈95%).

**End Algorithm**
