**Algorithm: Probabilistic Spectral Reconstruction for Trans-Neptunian Objects**

1. **Input Data**: Obtain sparse photometric time-series data from surveys like LSST.

2. **Parameter Initialization**: 
   - Define SED parameters (e.g., splines, polynomial coefficients).
   - Set initial values for interstellar extinction (Av, Rv) and instrumental noise (Gaussian, Poisson).

3. **Construct Forward Model**: 
   - Propagate light through interstellar medium using Cardelli extinction.
   - Account for instrumental noise in photometric measurements.

4. **Bayesian Inference Setup**: 
   - Use MCMC to sample posterior distributions of SED parameters.
   - Incorporate prior constraints on TNO SED shapes and colors.

5. **MCMC Sampling**: 
   - Generate samples of SED parameters consistent with observed data and priors.
   - Quantify parameter uncertainties.

6. **SED Reconstruction**: 
   - Reconstruct SEDs from sampled parameters.
   - Apply probabilistic modeling to include uncertainties.

7. **Taxonomic Classification**: 
   - Classify TNOs into spectral classes using reconstructed SEDs and color indices.

8. **Survey Optimization**: 
   - Determine optimal observing bands and cadences using the forward model.

9. **Outlier Detection**: 
   - Identify SEDs inconsistent with the model, marking peculiar objects.

10. **Output**: 
    - Provide reconstructed SEDs, classification, optimized survey strategy, and outliers.
