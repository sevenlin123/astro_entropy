**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Input Data**: Sparse photometric measurements of trans-Neptunian objects.

2. **Template Library**: A collection of pre-defined spectral templates representing different spectral classes.

3. **Hierarchical Model Initialization**:
    - Use a Dirichlet Process prior to initialize the spectral classes.
    - The number of classes is not fixed and can grow as more data is processed.

4. **Bayesian Inference Setup**:
    - Define the probabilistic model for spectral energy distribution (SED) using Bayesian techniques.
    - The model incorporates the template spectra and the sparse photometric data.

5. **Spectral Class Assignment**:
    - For each object, compute the posterior probability of belonging to each spectral class using the hierarchical model.
    - Assign the object to the class with the highest posterior probability.

6. **Outlier Detection**:
    - Compute the posterior probabilities of all classes for each object.
    - Identify outliers as objects whose posterior probabilities are significantly lower than expected under the model.

7. **Iterative Refinement**:
    - Repeatedly refine the spectral classes and posterior probabilities until convergence.
    - This step ensures that the model accurately captures the underlying structure of the data.

8. **Output**:
    - Provide the reconstructed spectral type for each object.
    - Include outlier flags for objects identified as inconsistent with the learned classes.

9. **End**: The algorithm completes after processing all objects and providing the final spectral reconstructions and outlier detections.
