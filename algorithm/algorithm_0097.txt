Algorithm Steps:

1. Input sparse multi-band photometric data of TNOs with low SNRs.

2. Initialize a probabilistic model based on Gaussian mixtures for each spectral band.

3. For each spectral band, apply the Gaussian mixture model to model the spectral features.

4. Implement a grid search over parameters, including:
   - Number of spectral components
   - Level of regularization

5. For each parameter combination in the grid:
   - Train the Gaussian mixture model on the spectral data
   - Evaluate the model fit
   - Determine the optimal number of components and regularization level

6. Once optimal parameters are determined, reconstruct the spectra using the trained model.

7. Use the reconstructed spectra to infer taxonomic classifications of TNOs.

8. Apply the framework to determine the optimal number of bands for survey design.

9. Perform outlier detection on the reconstructed spectra.

10. Output the reconstructed spectra, taxonomic classifications, optimal band selection, and identified outliers.
