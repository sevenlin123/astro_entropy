### Core Reconstruction Algorithm

1. **Training Data Preparation**:
   - **Seed Spectra**: Use a curated sample of 51 TNO spectra, focusing on dominant types (Water, CO₂, Organics).
   - **Principal Component Analysis (PCA)**: Apply PCA to the seed spectra to derive principal components ( latent space representation).

2. **Prior Definition**:
   - **Latent Space**: Construct a continuous probability distribution in the PCA latent space using Kernel Density Estimation (KDE) to augment the sparse training data.

3. **Forward Modeling**:
   - **Synthetic Photometry**: For each augmented spectrum, compute expected photometric magnitudes using the JWST NIRCam filter response curves.

4. **Noise Injection**:
   - Add 20% Gaussian noise to synthetic photometry to simulate realistic observational uncertainties.

5. **AutoML Regression**:
   - Train an ensemble of gradient-boosted decision trees (AutoGluon) to map noisy photometry to latent PCA coefficients.

6. **Inverse PCA Transform**:
   - Use the trained PCA model to reconstruct high-resolution spectra from predicted latent coefficients.

7. **Taxonomic Classification**:
   - Train a secondary classifier on the latent space to predict taxonomic categories (e.g., Water, CO₂, Organics) from photometric inputs.

8. **Performance Evaluation**:
   - Validate the method using leave-one-out cross-validation, measuring reconstruction accuracy, uncertainty calibration, and taxonomic classification success.

9. **Application Scenarios**:
   - **Survey Optimization**: Identify optimal NIRCam filter combinations based on variance contribution to the latent manifold.
   - **Outlier Detection**: Flag objects whose posterior probabilities in latent space fall outside the expected distribution.

This algorithm bridges the gap between sparse photometry and detailed spectroscopy, enabling robust spectral reconstruction and taxonomic classification of TNOs.
