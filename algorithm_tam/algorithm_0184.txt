**Algorithm for Probabilistic Spectral Reconstruction of TNOs from Sparse Photometry**

1. **Data Collection and Preprocessing:**
   - Gather a set of near-infrared spectra of TNOs (e.g., 51 representative spectra).
   - These spectra are used to define the initial latent space via PCA.

2. **Principal Component Analysis (PCA):**
   - Apply PCA to the collected spectra to derive principal components.
   - Use the top K principal components (determined via LOOCV, e.g., K=5-10) to create a reduced-dimensional latent space.

3. **Prior Definition:**
   - Project the PCA-derived latent coefficients into a probability distribution using Kernel Density Estimation (KDE).
   - This distribution serves as the prior for the Bayesian framework.

4. **Synthetic Data Generation:**
   - For each latent vector in the prior, generate synthetic photometry by convolving the corresponding spectrum with the filter throughput of the target instrument (e.g., JWST/NIRCam).
   - Introduce Gaussian noise (e.g., 20% relative uncertainty) to simulate realistic photometric observations.

5. **Automated Machine Learning (AutoML) Training:**
   - Train an ensemble regressor (e.g., Gradient-Boosted Decision Trees) to map sparse photometric inputs to the latent space coordinates.
   - Use the synthetic photometry and corresponding latent vectors as the training dataset.

6. **Inverse PCA Transform:**
   - After predicting latent coordinates from new photometric observations, apply the inverse PCA transformation to reconstruct the full spectrum.
   - This process leverages the physical smoothness and absorption features inherent in the PCA basis.

7. **Taxonomic Classification:**
   - Train a separate classifier within the latent space to assign taxonomic labels (e.g., H₂O, CO₂, Organics, Methanol) based on the mean latent coefficients.
   - The classifier operates on the latent space, enhancing decision boundary distinctiveness.

8. **Reconstruction and Validation:**
   - For each held-out spectrum in LOOCV, reconstruct the spectrum and assess RMSE and credible interval coverage.
   - Validate taxonomic classification accuracy on held-out data.

9. **Applications:**
   - **Survey Optimization:** Identify optimal JWST/NIRCam filters for TNO observations to maximize spectral reconstruction fidelity.
   - **Outlier Detection:** Use the framework to detect and reconstruct rare spectral types by exploring the latent manifold beyond typical morphologies.

10. **Output:**
    - For each new photometric observation, output the reconstructed spectrum, taxonomic probabilities, and confidence measures.
