### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Preprocess Reference Spectra**:
   - Remove outliers and normalize the reference spectra dataset.

2. **Principal Component Analysis (PCA)**:
   - Apply PCA to the preprocessed spectra to extract dominant eigenvectors (principal components).
   - Retain 4-5 components for initial analysis; increase up to 10 for improved fidelity.

3. **Generate Synthetic Latent Space**:
   - Perform Kernel Density Estimation (KDE) on the PCA coefficients of the reference spectra.
   - Determine optimal bandwidth (e.g., ~0.5) through experimentation.

4. **Simulate Photometric Observations**:
   - Convolve each synthetic spectrum with the instrument's filter response curves.
   - Add 20% Gaussian noise to simulate realistic photometric uncertainties.

5. **Train AutoML Regressor**:
   - Use an ensemble of Gradient Boosted Decision Trees to regress from simulated photometry to latent coefficients.
   - Include noise in photometry to prevent overfitting.

6. **Reconstruct Spectra for New Observations**:
   - For each new photometric observation:
     a. Predict latent coefficients using the trained regressor.
     b. Project the latent coefficients back to the original spectral space via inverse PCA.
     c. Optionally, classify the spectral type using a secondary AutoML classifier trained on the latent manifold.

7. **Validation**:
   - Use leave-one-out cross-validation (LOOCV) to validate by comparing reconstructed spectra with original reference spectra.

This structured approach efficiently bridges sparse photometric data with detailed spectral reconstruction, enabling probabilistic constraints on surface compositions of TNOs.
