### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

#### Input:
- Observed photometric measurements of a TNO object
- Trained PCA basis derived from reference spectra
- AutoML regressor mapping photometry to latent coefficients
- Taxonomy classifier for spectral type prediction

#### Output:
- Reconstructed high-resolution spectrum
- Probabilistic taxonomic classification

### Step-by-Step:

1. **Latent Space Definition**:
   - Project reference spectra into a PCA basis to define a low-dimensional latent space.
   
2. **Data Augmentation**:
   - Generate synthetic latent vectors using Kernel Density Estimation (KDE) to smooth the latent distribution.
   
3. **Forward Modeling**:
   - Simulate photometric measurements for each synthetic spectrum by convolving with filter responses.
   
4. **Training the Regressor**:
   - Use AutoML to train a model that maps noisy photometry to latent coefficients.
   
5. **Inference**:
   - Apply the trained regressor to observed photometry to predict latent coefficients.
   
6. **Reconstruct Spectrum**:
   - Decode the predicted latent coefficients using inverse PCA to obtain the full spectrum.
   
7. **Taxonomic Classification**:
   - Classify the latent state to determine the TNO's spectral type (e.g., H₂O, CO₂, Organic).
   
8. **Uncertainty Propagation**:
   - Quantify uncertainties in the reconstructed spectrum by considering photometric noise and model variance.

### Final Output:
- Reconstructed spectrum with uncertainties
- Probabilistic taxonomic classification
