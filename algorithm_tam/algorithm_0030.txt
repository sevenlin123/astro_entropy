### Algorithm Steps:

1. **Data Preparation:**
   - Select a set of reference TNO spectra for training (e.g., 51 spectra).
   - Exclude rare or outlier spectral types to focus on dominant taxonomic classes.

2. **Principal Component Analysis (PCA):**
   - Perform PCA on the selected reference spectra to reduce dimensionality.
   - Determine the number of principal components (e.g., 8–10) that capture the relevant spectral variability.

3. **Latent Space Definition:**
   - Use Kernel Density Estimation (KDE) on the PCA latent coefficients to create a smooth probability distribution representing the spectral manifold.
   - Set the KDE bandwidth (e.g., h ≈ 0.5) to balance local fidelity and global smoothness.

4. **Synthetic Data Generation:**
   - For each augmented spectrum, generate synthetic photometry by convolving with the instrument's filter curves (e.g., JWST/NIRCam).
   - Inject Gaussian noise (e.g., 20% relative uncertainty) to simulate realistic photometric uncertainties.

5. **AutoML Model Training:**
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to PCA latent coefficients.
   - Augment training data with synthetic photometry and latent coefficients derived from KDE.

6. **Taxonomic Classifier Training:**
   - Train a secondary AutoML classifier to partition the latent space based on taxonomic labels (e.g., H₂O, CO₂, Organic, Methanol).

7. **Forward Inference Pipeline:**
   - For new photometric observations:
     a. Pass photometry through the trained AutoML regressor to predict latent coefficients.
     b. Project latent coefficients through inverse PCA to reconstruct the full spectrum.
     c. Simultaneously pass latent coefficients to the classifier for taxonomic classification.

8. **Validation and Calibration:**
   - Perform leave-one-out cross-validation (LOOCV) to assess reconstruction accuracy and uncertainty calibration.
   - Ensure empirical credible-interval coverage (~95%) validates the true spectrum lies within the confidence intervals.

9. **Applications:**
   - Use the framework for survey optimization by evaluating filter configurations.
   - Detect outliers or rare spectral types by analyzing Bayesian posterior probabilities.

10. **Output:**
    - Reconstructed spectra with uncertainty estimates.
    - Probabilistic taxonomic classifications.
    - Optimized filter configurations for future surveys.
