### Algorithm Description: Probabilistic Spectral Reconstruction Framework

1. **Data Preparation**:
   - Collect a sample of near-infrared spectra of TNOs.
   - Exclude rare spectral types and outliers to focus on dominant taxonomic classes (e.g., Water-type, CO₂-type, Organics-type).

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the collected spectra to create a low-dimensional latent space.
   - Determine the number of principal components (e.g., 4-5 for taxonomic classification, 8-10 for improved reconstruction).

3. **Training Data Augmentation**:
   - Use Kernel Density Estimation (KDE) to generate synthetic latent vectors, creating a smooth manifold that interpolates between real spectra.
   - Inject Gaussian noise (20% relative uncertainty) into synthetic photometry to simulate real-world observational noise.

4. **Model Training**:
   - Train an AutoML regressor (e.g., Gradient-Boosted Decision Trees) to map sparse photometry to PCA latent coefficients.
   - Simultaneously train a taxonomic classifier in the latent space for spectral type prediction.

5. **Spectral Reconstruction**:
   - For new photometric observations, use the trained AutoML regressor to predict latent coefficients.
   - Apply the inverse PCA transform to reconstruct the full spectrum from the latent coefficients.

6. **Taxonomic Classification**:
   - Use the latent coefficients from the reconstructed spectrum to classify the taxonomic type using the pre-trained classifier.

7. **Validation and Metrics**:
   - Perform leave-one-out cross-validation to assess reconstruction accuracy and uncertainty coverage.
   - Compute Root Mean Square Error (RMSE) and check credible interval coverage for each spectrum.

8. **Applications**:
   - Optimize filter configurations for future surveys by evaluating mutual information between photometric bands and latent spectral coefficients.
   - Detect outliers by identifying spectra with latent coefficients outside the main manifold.

9. **Output**:
   - Provide reconstructed spectra, taxonomic probabilities, and outlier flags for each object.

This algorithm effectively bridges sparse photometry and detailed spectral analysis, enabling efficient exploration of TNO surface compositions in large-scale surveys.
