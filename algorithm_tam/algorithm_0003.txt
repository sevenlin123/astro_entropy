### Core Reconstruction Algorithm

1. **Principal Component Analysis (PCA):**
   - Perform PCA on a set of reference TNO spectra to extract the dominant spectral variability modes.
   - Use the top K principal components (K ≈4-5 for classification, up to 10 for detailed reconstruction) to define a low-dimensional latent space.

2. **Latent Space Construction:**
   - Project the reference spectra into the latent space defined by the PCA.
   - Augment the latent space using Kernel Density Estimation (KDE) to create a continuous probability distribution, ensuring smooth transitions between spectral types.

3. **Synthetic Photometry Generation:**
   - Forward model the reference spectra through the NIRCam filter set to generate synthetic photometric measurements.
   - Inject noise (~20% relative uncertainty) to simulate realistic photometric observations.

4. **AutoMLRegressor Training:**
   - Train an ensemble of Gradient-Boosted Decision Trees (GBDTs) and Neural Networks using the synthetic photometry and corresponding latent coefficients.
   - The regressor maps sparse photometry to latent space coordinates.

5. **Bayesian Inference for Spectral Reconstruction:**
   - For new photometric observations, use the trained regressor to predict latent coefficients.
   - Apply the inverse PCA transform to reconstruct the full spectrum.
   - Propagate uncertainties from photometry to the reconstructed spectrum through the posterior distribution.

6. **Taxonomic Classification:**
   - Classify the latent coefficients using a secondary AutoML classifier trained on the taxonomic labels of the reference spectra.
   - Output a probability distribution over taxonomic types for each object.

7. **Outlier and Rare Object Detection:**
   - Analyze the posterior probabilities in the latent space during inference.
   - Identify objects projecting to low-density regions, indicating rare or unusual spectral types.

8. **Survey Optimization:**
   - Evaluate filter configurations for their ability to disentangle taxonomic clusters in the latent space.
   - Select optimal filter sets to maximize information content for taxonomic classification and spectral reconstruction.

9. **Uncertainty Analysis and Error Propagation:**
   - Examine the variance-covariance matrix of the posterior distribution to assess sensitivity of spectral features to photometric uncertainties.
   - Quantify the confidence in reconstructed spectral features and taxonomic assignments.

**Output:** For each TNO, the algorithm provides:
- A high-fidelity reconstructed spectrum.
- A probability distribution over taxonomic types (Water, CO₂, Organic, Methanol).
- Flags for outlier detection and recommendations for spectroscopic follow-up.
