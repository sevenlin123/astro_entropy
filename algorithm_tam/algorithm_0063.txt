The core computational algorithm involves the following steps:

1. **Principal Component Analysis (PCA)**: Perform PCA on a set of reference TNO spectra to create a low-dimensional latent space. This space captures the main variations in spectral data.

2. **Data Augmentation with Kernel Density Estimation (KDE)**: Use KDE to generate synthetic latent vectors, expanding the training dataset and creating a smooth probability distribution in the latent space.

3. **AutoML Regression**: Train an ensemble of gradient-boosted decision trees (AutoML) to map sparse photometric inputs to latent coefficients, enabling the prediction of latent variables from photometry.

4. **Spectral Reconstruction**: Convert predicted latent coefficients back to full spectra using the inverse PCA transform, reconstructing high-dimensional spectra from the latent space.

5. **Taxonomic Classification**: Classify objects based on latent coefficients, determining their spectral type by analyzing the latent space.

6. **Validation and Outlier Detection**: Use LOOCV to assess reconstruction accuracy and detect outliers by identifying photometric data that cannot be reconciled with the spectral manifold.
