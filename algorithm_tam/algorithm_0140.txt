**Algorithm: Probabilistic Spectral Reconstruction of Trans-Neptunian Objects from Sparse Photometry**

1. **Training Set Initialization**: Begin with a training set of observed TNO spectra, each associated with metadata.

2. **Principal Component Analysis (PCA)**: Apply PCA to the training spectra to extract principal components, capturing major spectral variations.

3. **Kernel Density Estimation (KDE)**: Construct a smooth probability distribution in the PCA latent space using KDE to generate synthetic data.

4. **Synthetic Photometry Generation**: Convolve each augmented spectrum with instrument filter responses (e.g., JWST/NIRCam) to simulate photometric measurements.

5. **AutoML Regressor Training**: Train an AutoML regressor (e.g., AutoGluon) to map synthetic photometry to latent PCA coefficients.

6. **Reconstruct Full Spectra**: For new photometric data, use the regressor to predict latent coefficients and invert PCA to obtain full spectra.

7. **Taxonomic Classification Training**: Train a classifier within the latent space to classify spectral types (e.g., H2O, CO2) based on latent coefficients.

8. **Validation via LOOCV**: Validate using leave-one-out cross-validation to ensure accurate and reliable results.

9. **Survey Optimization**: Determine optimal filters by evaluating information content for spectral reconstruction.

10. **Outlier Detection**: Use the probabilistic framework to detect and reconstruct rare spectral types by exploring the latent space.

**Outputs**: Reconstructed spectra, taxonomic probabilities, and evaluations for optimal filter configurations.
