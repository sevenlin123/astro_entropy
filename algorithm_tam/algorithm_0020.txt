### Algorithm Description: Probabilistic Spectral Reconstruction Framework

1. **Input Data**: Sparse photometric measurements of trans-Neptunian objects (TNOs) in specific filters (e.g., JWST/NIRCam).

2. **Training Phase**:
   - **Principal Component Analysis (PCA)**:
     - Apply PCA to a set of reference TNO spectra to derive principal components (latent space).
     - The number of components (K) is determined based on explained variance (~4-5 for taxonomy, ~8-10 for accurate reconstruction).
   - **Density Estimation**:
     - Use Kernel Density Estimation (KDE) on the latent space of the PCA to create a continuous probability distribution, augmenting the training data for robust regression.
   - **Model Training**:
     - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to PCA latent coefficients.
     - Train a separate AutoML classifier to categorize objects into spectral types based on latent coefficients.

3. **Inference Phase**:
   - **Forward Modeling**:
     - Convert observed photometry through the trained AutoML regressor to obtain latent coefficients.
   - **Spectrum Reconstruction**:
     - Project the latent coefficients back to the full spectrum using the inverse PCA transform.
   - **Classification**:
     - Use the trained classifier to predict the taxonomic type based on the latent coefficients.

4. **Validation**:
   - Perform leave-one-out cross-validation to assess reconstruction accuracy and credible interval coverage.
   - Analyze spectral features and slopes to validate the reconstructed spectra.

5. **Applications**:
   - **Survey Design**: Optimize filter configurations for future surveys by evaluating information content.
   - **Outlier Detection**: Identify rare spectral types by detecting anomalies in the latent space.

This structured approach efficiently reconstructs detailed spectra from sparse photometry, providing a robust framework for TNO taxonomy and survey planning.
