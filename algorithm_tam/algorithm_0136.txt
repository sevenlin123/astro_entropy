**Algorithm Description: Probabilistic Spectral Reconstruction Framework**

1. **Preprocessing Step (Training Phase):**
   - Apply Principal Component Analysis (PCA) to a set of reference TNO spectra to extract principal components, defining a low-dimensional latent space.
   - Augment the training data using Kernel Density Estimation (KDE) to create a smooth probability distribution in the latent space, enabling the generation of synthetic spectra.

2. **Synthetic Photometry Generation (Training Phase):**
   - For each augmented spectrum, compute the expected photometric measurements by convolving the spectrum with the instrument's (e.g., JWST/NIRCam) filter curves.
   - Introduce Gaussian noise (relative reflectance uncertainty ~20%) to simulate realistic photometric observations.

3. **AutoML Encoder Training:**
   - Train an ensemble of gradient-boosted decision trees using the synthetic photometry and corresponding latent coefficients to map photometric measurements to latent space coordinates.

4. **Taxonomic Classifier Training:**
   - Train a separate AutoML classifier to map latent coefficients to taxonomic classes (e.g., H₂O, CO₂, Organic, Methanol) based on the reference spectra's known labels.

5. **Processing New Observations (Inference Phase):**
   - For new photometric data, use the trained encoder to predict latent coefficients.
   - Reconstruct the full spectrum by applying the inverse PCA transform to the predicted latent coefficients.
   - Classify the spectrum into taxonomic groups using the trained classifier.

6. **Uncertainty Quantification (Planned Future Step):**
   - Incorporate photometric noise properties into the probabilistic framework to quantify uncertainties in reconstructed spectra.

7. **LOOCV Assessment (Training Phase):**
   - Perform leave-one-out cross-validation by iteratively removing each reference spectrum, retraining the encoder and classifier, and evaluating reconstruction accuracy and taxonomic classification.

8. **Outlier Detection:**
   - Identify objects with uncertain taxonomic probabilities or unusual spectral features, marking them for potential spectroscopic follow-up.

9. **Optimal Filter Configuration:**
   - Simulate various filter configurations to determine the optimal set for maximizing spectral reconstruction fidelity and efficiency in photometric surveys.

10. **Applications and Limitations:**
    - The framework provides tools for taxonomic classification, survey optimization, and outlier detection, though it is dependent on the quality of the training data and computationally intensive due to repeated model training in LOOCV.
