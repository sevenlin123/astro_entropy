### Algorithm Description

1. **Initialize**: Start by selecting the reference spectra of TNOs, specifically focusing on dominant taxonomic classes such as Water-type, CO₂-type, and Organics-type.

2. **Preprocess data**: Collect and prepare the near-infrared (near-IR) spectra of TNOs, ensuring they are normalized and formatted appropriately for PCA analysis.

3. **PCA on reference spectra**: Apply Principal Component Analysis (PCA) to the reference spectra to derive a low-dimensional latent space. This reduces the spectral data into principal components that capture the major variations in the spectra.

4. **Define latent manifold via KDE**: Use Kernel Density Estimation (KDE) to create a smooth probability distribution over the latent space defined by the PCA. This step generates a continuous manifold that helps in stabilizing the regression model.

5. **Generate synthetic photometry for training**: Forward model the synthetic photometry by convolving the spectra with the instrumental response of the target instrument (like JWST/NIRCam) and add noise to simulate realistic photometric observations.

6. **Train AutoML regressor**: Utilize an AutoML framework (e.g., AutoGluon) to train a regressor (e.g., Gradient Boosted Decision Trees) that maps the sparse photometric inputs to the latent coefficients in the PCA space.

7. **Perform LOOCV for validation**: Evaluate the model using Leave-One-Out Cross-Validation (LOOCV) to assess reconstruction fidelity, credible interval coverage, and taxonomic classification accuracy.

8. **Posterior sampling for spectral reconstruction**: Use the trained AutoML regressor to predict latent coefficients from new photometric data, then apply the inverse PCA transform to reconstruct the full spectra.

9. **Classify spectral type using latent manifold**: Employ a secondary classifier trained on the latent space to predict the taxonomic type (e.g., Water-type, CO₂-type, Organics-type) based on the latent coefficients.

10. **Output reconstructed spectra and taxonomic probabilities**: Provide the reconstructed spectra along with their associated uncertainties and the probabilistic taxonomic classification results.
