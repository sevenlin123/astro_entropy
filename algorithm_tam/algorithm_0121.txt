**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Input Data**: Sparse photometric measurements of a trans-Neptunian object (TNO).

2. **Training Phase**:
   - **Data Collection**: Gather a sample of known TNO spectra (e.g., 51 reference spectra).
   - **Dimensionality Reduction**: Perform Principal Component Analysis (PCA) on the reference spectra to define a low-dimensional latent space. This space is represented by principal components capturing the main spectral variations.
   - **Data Augmentation**: Use Kernel Density Estimation (KDE) on the PCA coefficients to create synthetic spectra, expanding the training dataset and ensuring a smooth manifold for the latent space.
   - **Model Training**: Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to PCA latent coefficients.

3. **Forward Inference**:
   - **Encoding**: Convert sparse photometric data into latent coefficients using the trained AutoML model.
   - **Decoding**: Project the latent coefficients back into the full spectral space using the inverse PCA transformation to reconstruct the high-resolution spectrum.
   - **Uncertainty Propagation**: Compute credible intervals for the reconstructed spectrum by sampling from the posterior distribution of latent coefficients.

4. **Post-Processing**:
   - **Taxonomic Classification**: Classify the spectrum into predefined taxonomic categories (e.g., Water-type, CO₂-type, Organics-type) using a secondary classifier trained on latent space features.
   - **Validation**: Compare reconstructed spectra with original data to assess accuracy and uncertainty coverage (e.g., check if original spectra lie within 95% credible intervals).

5. **Applications**:
   - **Survey Optimization**: Evaluate different photometric filter configurations to determine the most informative setups for spectral reconstruction.
   - **Outlier Detection**: Identify unusual spectral types by analyzing density in the latent space, highlighting objects that deviate from typical patterns.

6. **Output**: For each TNO, produce a reconstructed spectrum, associated uncertainties, and taxonomic classification based on sparse photometric input.
