### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

**Step-by-Step Pseudocode:**

1. **Input Data**
   - Reference Spectra: Collection of high-resolution near-IR spectra of TNOs.
   - Instrument Filters: Filter responses (e.g., JWST/NIRCam) to generate photometric measurements.
   - Observational Uncertainty: Noise level (e.g., 20% reflectance uncertainty).

2. **Compute Principal Component Analysis (PCA)**
   - **Input:** Reference Spectra
   - **Output:** Principal Components (PCs), Loadings, Explained Variance.

3. **Kernel Density Estimation (KDE) on PCA Coefficients**
   - **Input:** PCA Coefficients from Reference Spectra.
   - **Parameter:** Bandwidth (e.g., h = 0.5).
   - **Output:** Smooth probability distribution over latent space.

4. **Generate Synthetic Spectra**
   - For each point in the latent distribution:
     - Apply inverse PCA transform to get synthetic spectrum.
     - Convolve with instrument filters to compute synthetic photometry.

5. **Add Noise to Synthetic Photometry**
   - Inject Gaussian noise to simulate observational uncertainties.

6. **Prepare Training Dataset**
   - Combine noisy synthetic photometry and true PCA coefficients.

7. **Train AutoML Regressor**
   - **Inputs:** Noisy photometry.
   - **Target:** True PCA coefficients.
   - **Model:** AutoML (e.g., Gradient Boosted Decision Trees).

8. **Leave-One-Out Cross-Validation (LOOCV)**
   - For each reference spectrum:
     - Remove it from the dataset.
     - Repeat Steps 3-7 with the remaining data.
     - Validate model performance.

9. **Reconstruct Spectrum for New Observation**
   - **Input:** Observed photometry.
   - **Predict:** PCA coefficients using regressor.
   - **Inverse PCA:** Obtain reconstructed spectrum.

10. **Taxonomy Classification**
    - Use the predicted PCA coefficients to classify the object into taxonomic categories (e.g., H₂O, CO₂, Organic, Methanol).

### Pseudocode:

function spectral_reconstruction_framework():
    // 1. Compute PCA
    pca = compute_pca(reference_spectra)

    // 3. Generate synthetic spectra and photometry
    synthetic_spectra = []
    synthetic_photometry = []
    for each point in kde:
        spectrum = inverse_pca(point, pca)
        photometry = convolve_with_filters(spectrum, instrument_filters)
        append photometry to synthetic_photometry
        append spectrum to synthetic_spectra
    
    // 4. Add noise to photometry
    noisy_photometry = add_gaussian_noise(synthetic_photometry, noise_level)
    
    // 5. Prepare training data
    training_data = combine(noisy_photometry, pca_coefficients)
    
    // 6. Train AutoML regressor
    regressor = train_automl(training_data, target=pca_coefficients)
    
    // 7. LOOCV
    for each spectrum in reference_spectra:
        remove spectrum
        perform steps 3-6 with remaining data
        validate model
    
    // 8. Reconstruct spectrum
    observed_photometry = input_photometry()
    predicted_coeffs = regressor.predict(observed_photometry)
    reconstructed_spectrum = inverse_pca(predicted_coeffs, pca)
    
    // 9. Classify taxonomy
    taxonomic_class = classifier.predict(predicted_coeffs)
    
    return reconstructed_spectrum, taxonomic_class
