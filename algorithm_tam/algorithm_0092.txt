**Algorithm: Probabilistic Spectral Reconstruction Framework**

**Step-by-Step Description:**

1. **Principal Component Analysis (PCA):**
   - Train PCA on a set of reference TNO near-infrared spectra to capture the dominant spectral variability.
   - Use PCA to project the reference spectra into a low-dimensional latent space (e.g., 4-10 principal components).

2. **Data Augmentation:**
   - Apply Kernel Density Estimation (KDE) on the PCA latent coordinates to generate synthetic training data, creating a smooth probability distribution that fills gaps between observed spectra.

3. **Synthetic Photometry Generation:**
   - Forward model the augmented spectra through the JWST/NIRCam filter set to compute synthetic photometric measurements.
   - Inject Gaussian noise (e.g., 20% relative uncertainty) to simulate real photometric conditions.

4. **AutoML Regression (Encoder):**
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map the noisy synthetic photometry to the PCA latent coefficients.
   - This step transforms sparse photometry into latent space representations.

5. **Taxonomic Classifier Training:**
   - Train a separate AutoML classifier on the latent space to predict taxonomic labels (e.g., Water, CO₂, Organic) using the PCA coefficients.

6. **Reconstruction Pipeline:**
   - For new photometric observations, use the trained AutoML regressor to predict latent coefficients.
   - Project these coefficients back to the full spectral space using inverse PCA to obtain reconstructed spectra.

7. **Validation and Uncertainty Quantification:**
   - Perform leave-one-out cross-validation to assess reconstruction accuracy.
   - Compute metrics like RMSE, PCC, CS, and EC to evaluate the statistical reliability of the reconstructions.

8. **Survey Optimization and Outlier Detection:**
   - Use the framework to evaluate different photometric filter configurations for maximizing spectral information.
   - Identify outliers by constraining photometry to select low-probability latent models.

**Final Output:**
The algorithm outputs reconstructed spectra and taxonomic classifications from sparse photometry, providing a statistically rigorous method to study TNO compositions in large-scale surveys.
