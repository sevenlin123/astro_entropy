### Core Reconstruction Algorithm Steps

1. **Training Data Preparation**:
   - Collect a reference set of TNO spectra from observations (e.g., JWST/NIRCam).
   - Exclude rare or singular spectral types to focus on dominant taxonomic classes.

2. **Principal Component Analysis (PCA)**:
   - Apply PCA to the reference spectra to extract principal components (latent space).
   - Determine the number of components (K) that best capture spectral variability (found K=8–10 for high fidelity).

3. **Data Augmentation**:
   - Use Kernel Density Estimation (KDE) on the PCA latent space to create synthetic spectra.
   - Inject realistic noise (e.g., 20% relative uncertainty) into synthetic photometry for training robustness.

4. **Model Training**:
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map photometric inputs to PCA latent coefficients.
   - Simultaneously train a classifier on the latent space to assign taxonomic labels.

5. **Reconstruction Pipeline**:
   - For new photometric observations, predict latent coefficients using the trained regressor.
   - Project the latent coefficients back to the full spectrum via inverse PCA transformation.

6. **Bayesian Inference**:
   - Perform posterior sampling to quantify uncertainties in reconstructed spectra.
   - Validate against the original spectrum using metrics like NRMSE and credible interval coverage.

7. **Applications**:
   - Optimize survey filters by evaluating information content.
   - Detect outliers by identifying deviations from the spectral manifold.

This structured approach efficiently bridges sparse photometry to detailed spectral reconstruction, enabling statistically rigorous analysis of TNOs and other minor planets.
