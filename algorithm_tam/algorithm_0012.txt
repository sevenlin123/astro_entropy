**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Data Preparation**:
   - Gather a set of reference TNO spectra (e.g., 51 high-quality near-infrared spectra).
   - Exclude outliers and rare spectral types to focus on dominant classes (e.g., H₂O, CO₂, Organic, Methanol).

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the reference spectra to extract principal components (PCs).
   - PCs represent the main sources of spectral variability, capturing 4-5 dominant modes for basic classification and 8-10 for improved fidelity.

3. **Density Estimation**:
   - Project the reference spectra onto the PCA latent space.
   - Use Kernel Density Estimation (KDE) to create a smooth probability distribution in the latent space, augmenting the training data.

4. **Synthetic Photometry Generation**:
   - Forward-model the augmented spectra through the JWST/NIRCam filter set to simulate photometric measurements.
   - Add Gaussian noise (20% uncertainty) to simulate realistic photometric observations.

5. **Automated Machine Learning (AutoML) Training**:
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to latent PCA coefficients.
   - Train a secondary AutoML classifier to predict taxonomic classes using the latent space.

6. **Reconstruction Pipeline**:
   - For new photometric observations:
     - Use the trained regressor to predict latent coefficients.
     - Apply inverse PCA to reconstruct the full spectrum.
     - Classify the object into taxonomic categories based on latent space features.

7. **Validation and Performance Assessment**:
   - Conduct leave-one-out cross-validation (LOOCV) to measure RMSE, credible interval coverage, and classification accuracy.
   - Compare reconstructed spectra with direct JWST/NIRSpec observations for verification.

8. **Applications**:
   - Optimize survey filters by evaluating information content.
   - Detect outliers and rare spectral types by constraining photometric inputs.
   - Enable bulk classification of TNOs from photometric surveys.

**Output**:
- Reconstructed spectra with uncertainty quantification.
- Probabilistic taxonomic classifications.
- Optimized photometric survey configurations.
