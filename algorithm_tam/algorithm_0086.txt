### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Training Data Preparation**:
   - Collect a sample of near-infrared spectra of trans-Neptunian objects (TNOs).
   - Exclude rare and outlier spectral types to focus on dominant taxonomic classes.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the collected spectra to reduce dimensionality.
   - Determine the optimal number of principal components (e.g., 4-5 for classification, 8-10 for high-fidelity reconstruction).

3. **Latent Space Definition**:
   - Use the principal components to define a low-dimensional latent space.
   - Apply Kernel Density Estimation (KDE) to smooth the distribution of latent coefficients, creating a continuous manifold.

4. **Synthetic Photometry Generation**:
   - For each spectrum in the latent space, convolve it with the filter curves of the target instrument (e.g., JWST/NIRCam) to generate synthetic photometric measurements.
   - Add Gaussian noise (e.g., 20% relative uncertainty) to simulate realistic photometric uncertainties.

5. **Automated Machine Learning (AutoML) Training**:
   - Train an AutoML regressor (e.g., Gradient-Boosted Decision Trees) to map sparse photometry to latent coefficients.
   - Augment the training data with synthetic spectra and their corresponding photometry.

6. **Classification Model Training**:
   - Train a secondary AutoML classifier on the latent space to predict taxonomic classes (e.g., H₂O, CO₂, Organic types).

7. **Reconstruction Pipeline**:
   - For new photometric observations, predict the latent coefficients using the trained regressor.
   - Project the predicted coefficients through the inverse PCA to reconstruct the full spectrum.
   - Simultaneously classify the spectral type using the latent space classifier.

8. **Validation and Uncertainty Quantification**:
   - Conduct leave-one-out cross-validation (LOOCV) to assess reconstruction accuracy and empirical coverage.
   - Propagate photometric uncertainties through the model to estimate uncertainties on the reconstructed spectra.

9. **Survey Optimization and Outlier Detection**:
   - Use the framework to evaluate different filter configurations for maximizing information content.
   - Detect outliers by identifying spectra whose reconstructions fall outside the expected posterior distributions.

### Summary of Steps:
- **Dimensionality Reduction**: PCA is used to create a latent space capturing the main spectral variations.
- **Data Augmentation**: Synthetic photometry is generated to expand the training set while introducing realistic noise.
- **Machine Learning**: AutoML models are trained for mapping photometry to latent coefficients and for taxonomic classification.
- **Reconstruction**: The latent coefficients are inverted using PCA to reconstruct high-resolution spectra.
- **Validation**: LOOCV ensures robust evaluation of the model's performance.
- **Applications**: The framework optimizes survey strategies and detects rare spectral types.

This algorithm bridges the gap between sparse photometry and detailed spectral analysis, enabling efficient and accurate characterization of TNOs' surface compositions.
