The algorithm can be summarized in structured steps as follows:

1. **Training Data Preparation**
   - Collect a seed set of 51 TNO near-infrared spectra from the DiSCo-TNO sample.
   - Exclude rare spectral types and outliers to focus on dominant taxonomic classes (Water-type, CO₂-type, Organics-type).

2. **Principal Component Analysis (PCA)**
   - Perform PCA on the training spectra to obtain principal components.
   - Use the principal components to define a low-dimensional latent space representing the spectral manifold.

3. **Data Augmentation**
   - Apply Kernel Density Estimation (KDE) with a bandwidth of ~0.5 to generate synthetic latent vectors.
   - Ensure smooth interpolation between seed spectra while maintaining physically plausible morphologies.

4. **Forward Modeling**
   - Simulate photometric observations by convolving augmented spectra with JWST NIRCam filter responses.
   - Inject 20% Gaussian noise into the synthetic photometry to account for observational uncertainties.

5. **AutoML Regression Training**
   - Train an ensemble of Gradient-Boosted Decision Trees (GBDTs) to regress from sparse photometry to latent PCA coefficients.
   - Use AutoGluon framework for automated model selection and hyperparameter tuning.

6. **Inverse PCA Transform**
   - Develop an inverse PCA pipeline to project the predicted latent coefficients back to full-resolution spectra.
   - Ensure the reconstructed spectra inherit physical smoothness and absorption features from the training data.

7. **Taxonomic Classification**
   - Train a secondary AutoML classifier on the latent PCA space to predict taxonomic labels (e.g., H₂O, CO₂, Organic, Methanol).
   - Use cross-validation to assess classification accuracy independently from reconstruction metrics.

8. **Bayesian Inference**
   - Perform spectral reconstruction using the trained AutoML encoder and inverse PCA decoder.
   - Propagate photometric uncertainties into the posterior distribution of latent coefficients for accurate uncertainty calibration.

9. **Leave-One-Out Cross-Validation (LOOCV)**
   - Evaluate reconstruction fidelity using normalized RMSE and empirical credible-interval coverage.
   - Assess taxonomic classification accuracy through independent LOOCV iterations.

10. **Applications**
    - **Survey Optimization**: Identify optimal JWST/NIRCam filter configurations for maximizing information content.
    - **Outlier Detection**: Detect unusual spectral types through posterior analysis of latent coefficients.
    - **Synthetic Spectra Simulation**: Generate test cases for refining detection algorithms and assessing systematics.

The algorithm efficiently bridges sparse photometric data with detailed spectral reconstructions, enabling robust taxonomic classification and outlier detection in TNO studies.
