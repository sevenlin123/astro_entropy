The algorithm begins by training a Principal Component Analysis (PCA) model using a set of reference TNO spectra. This reduces the spectral data into a low-dimensional latent space. Kernel Density Estimation (KDE) is then applied to this latent space to create a continuous probability distribution, serving as the prior for Bayesian inference. Synthetic photometry is generated by convolving the spectra with instrument response functions, incorporating noise to simulate real观测 uncertainties. An AutoML regressor is trained to map sparse photometric inputs to the latent coefficients. During inference, new photometry is used to predict latent coefficients, which are transformed back into full spectra using inverse PCA. Uncertainty estimates and taxonomic classifications are derived from the posterior distribution of latent variables. The framework is validated through leave-one-out cross-validation, ensuring reliable reconstruction and classification accuracy.
