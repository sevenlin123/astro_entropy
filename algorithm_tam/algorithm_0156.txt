### Algorithm Description

1. **Data Preparation**:
   - Gather a set of reference near-infrared spectra of TNOs, specifically focusing on dominant taxonomic classes (e.g., Water-type, CO₂-type, Organics-type).
   - Exclude outliers and rare spectral types to maintain a representative training set.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the reference spectra to identify principal components that capture the main modes of spectral variability.
   - Use the top 4-5 principal components for basic taxonomic classification and up to 10 components for detailed spectral reconstruction.

3. **Kernel Density Estimation (KDE) Augmentation**:
   - Apply KDE to the latent coefficients obtained from PCA to create a smooth probability distribution, augmenting the training data.
   - Choose an appropriate bandwidth (e.g., h ≈ 0.5) to balance smoothing and fidelity to the original data.

4. **Synthetic Photometry Generation**:
   - Convolve the augmented spectra with the instrument-specific filter curves (e.g., JWST/NIRCam) to generate synthetic photometric measurements.
   - Introduce Gaussian noise (e.g., 20% relative uncertainty) to simulate real-world photometric errors.

5. **Automated Machine Learning (AutoML) Training**:
   - Use an AutoML framework (e.g., AutoGluon) to train a regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to PCA latent coefficients.
   - Train a secondary classifier within the latent space to predict taxonomic labels.

6. **Forward Modeling and Inference**:
   - For new photometric observations, predict latent coefficients using the trained AutoML regressor.
   - Project these coefficients back to the full spectrum using inverse PCA to reconstruct the high-resolution spectrum.
   - Simultaneously, use the latent classifier to determine the taxonomic classification of the object.

7. **Validation and Performance Metrics**:
   - Conduct leave-one-out cross-validation to assess RMSE, coverage of credible intervals, and taxonomic accuracy.
   - Compare performance with traditional methods (e.g., PCR, DNN, SI) to validate the framework's effectiveness.

8. **Survey Optimization and Outlier Detection**:
   - Identify optimal photometric filter configurations for future surveys using the framework.
   - Detect rare spectral types by identifying outliers in the latent manifold.

### Output

The described algorithm implements a probabilistic framework combining PCA, AutoML, and Bayesian inference to reconstruct TNO spectra from sparse photometry, enabling taxonomic classification, survey optimization, and outlier detection.
