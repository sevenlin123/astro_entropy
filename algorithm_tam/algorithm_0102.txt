### Algorithm: Probabilistic Spectral Reconstruction of Trans-Neptunian Objects from Sparse Photometry

**Step-by-Step Description:**

1. **Principal Component Analysis (PCA):**
   - Train a PCA model on a reference set of TNO near-infrared spectra to capture the main spectral variations.
   - Use the PCA to define a low-dimensional latent space, where each eigenvector represents a mode of spectral variability.

2. **Data Augmentation:**
   - Generate synthetic latent vectors using Kernel Density Estimation (KDE) to create a continuous probability distribution in the latent space.
   - This augmentation helps stabilize the training of the machine learning model by interpolating between the reference spectra.

3. **Forward Modeling:**
   - Simulate photometric observations by convolving the synthetic spectra with the instrument's filter curves (e.g., JWST/NIRCam).
   - Add Gaussian noise to these synthetic photometric measurements to account for observational uncertainties.

4. **Training the AutoML Regressor:**
   - Use an ensemble of Gradient-Boosted Decision Trees (GBDTs) to regress from the noisy photometric measurements to the latent space coefficients.
   - The model learns the mapping from sparse photometry to the latent space, enabling spectral reconstruction.

5. **Bayesian Inference:**
   - Perform posterior sampling in the latent space to reconstruct the full spectrum.
   - Propagate uncertainties from the photometric measurements to the reconstructed spectrum using the posterior distribution of latent coefficients.

6. **Taxonomic Classification:**
   - Classify the object into predefined taxonomic groups (e.g., H₂O, CO₂, Organics) by evaluating the latent coefficients.
   - Use a secondary classifier trained on the latent space to determine the probability distribution over spectral types.

7. **Reconstruction and Validation:**
   - Project the predicted latent coefficients back through the inverse PCA transform to obtain the reconstructed spectrum.
   - Validate the framework using leave-one-out cross-validation (LOOCV) to assess reconstruction fidelity and uncertainty coverage.

8. **Applications:**
   - **Survey Optimization:** Identify optimal filter configurations for future surveys by quantifying the information content of different photometric bands.
   - **Outlier Detection:** Detect rare spectral types by analyzing the posterior probabilities in the latent space, identifying objects with unusual spectral characteristics.

This algorithm bridges the gap between sparse photometric data and detailed spectral analysis, providing a robust framework for TNO taxonomy, survey design, and outlier detection.
