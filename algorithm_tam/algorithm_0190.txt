The algorithm begins by training a Principal Component Analysis (PCA) model on a set of reference TNO spectra to define a low-dimensional latent space. Next, synthetic photometry is generated by convolving these spectra with the instrument's filter curves and adding noise. An AutoML regressor is trained to map this noisy photometry to the latent coefficients. For each new observation, the regressor predicts the latent coefficients, which are then transformed back to reconstruct the full spectrum using inverse PCA. Uncertainty quantification is performed by analyzing the variance in the latent space and PCA transformation. Finally, the reconstructed spectrum is validated against the true spectrum through leave-one-out cross-validation.
