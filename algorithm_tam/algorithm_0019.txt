The computational algorithm for the core reconstruction framework can be outlined as follows:

1. **Latent Space Preparation**:
   - Perform Principal Component Analysis (PCA) on a set of reference TNO spectra to create a low-dimensional latent space. This space captures the dominant spectral variability relevant for taxonomic classification.

2. **Data Augmentation**:
   - Use Kernel Density Estimation (KDE) on the PCA latent space to generate synthetic data, introducing noise to simulate real photometric uncertainties. This step ensures the training data reflects realistic observational conditions.

3. **Model Training**:
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) using the synthetic photometry data. The model maps sparse photometric inputs to the latent space coordinates defined by PCA.

4. **Spectral Reconstruction**:
   - For new photometric observations, the AutoML model predicts the latent coefficients. These coefficients are then transformed back to full spectra using inverse PCA, reconstructing the high-resolution reflectance spectrum.

5. **Taxonomic Classification**:
   - Utilize an AutoML classifier trained on the latent space to assign taxonomic labels to the objects based on their latent coordinates, providing a probabilistic classification.

This structured approach enables the framework to accurately reconstruct TNO spectra and classify their taxonomic types from sparse photometric data, bridging the gap between photometry and detailed spectroscopy.
