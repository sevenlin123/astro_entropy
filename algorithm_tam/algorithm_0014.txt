The algorithm begins by applying Principal Component Analysis (PCA) to a set of reference TNO spectra, creating a low-dimensional latent space. This latent space captures the main variations in spectral data. Next, synthetic photometry is generated by convolving these spectra with the instrument's filter responses. An automated machine learning (AutoML) regressor is trained to map this photometric data to the latent space. During inference, new photometric observations are converted to latent variables using this regressor, then transformed back to full spectra using inverse PCA. Uncertainties are propagated through the process, ensuring accurate reconstruction and classification.
