### Algorithm: Probabilistic Spectral Reconstruction Framework

1. **Principal Component Analysis (PCA) Training**:
   - Train PCA on a set of reference TNO spectra to create a low-dimensional latent space.
   - Use Kernel Density Estimation (KDE) to generate synthetic latent coefficients, creating a smooth manifold.

2. **Synthetic Photometry Generation**:
   - For each augmented spectrum, compute synthetic photometry using NIRCam filter throughputs.
   - Add Gaussian noise (20% reflectance uncertainty) to simulate realistic photometric observations.

3. **AutoML Regressor Training**:
   - Train an ensemble of Gradient-Boosted Decision Trees (GBDTs) to map sparse photometry to latent coefficients.
   - Use synthetic photometry with added noise as training data.

4. **Inverse PCA Transform**:
   - Apply the inverse PCA transform to the predicted latent coefficients to reconstruct full spectra.
   - Use 10 principal components for optimal balance of accuracy and computational efficiency.

5. **Taxonomic Classification**:
   - Train a secondary AutoML classifier on the latent manifold to predict taxonomic labels (e.g., H₂O, CO₂, Organics).
   - Classify new observations based on their latent coefficients.

6. **Validation and Testing**:
   - Perform LOOCV to evaluate reconstruction fidelity.
   - Test framework with known outliers and different instrumental setups to ensure adaptability.

### Key Features:
- Combines Bayesian inference with PCA and AutoML for robust spectral reconstruction.
- Handles sparse photometry efficiently by leveraging latent space representation.
- Provides probabilistic taxonomic classification alongside spectral reconstructions.
- Designed for scalability and generalization across different observational data.
