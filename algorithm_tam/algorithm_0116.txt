### Algorithm Steps for Probabilistic Spectral Reconstruction

1. **Define the Spectral Manifold**:
   - **Principal Component Analysis (PCA)**: Apply PCA on a reference set of TNO spectra to extract principal components (latent space).
   - **Kernel Density Estimation (KDE)**: Use KDE on the PCA coefficients to create a smooth probability distribution representing physically plausible spectra.

2. **Simulate Synthetic Photometry**:
   - **Forward Modeling**: Convolve the synthetic spectra (from PCA and KDE) with NIRCam filter curves to generate expected photometric measurements.
   - **Noise Injection**: Add Gaussian noise with a relative uncertainty of ~20% to simulate realistic observational conditions.

3. **Train the AutoML Regressor**:
   - **Data Preparation**: Pair each synthetic spectrum with its corresponding noisy photometric measurements.
   - **Model Training**: Use AutoML (e.g., Gradient Boosted Decision Trees) to train a regressor mapping photometry to PCA coefficients.

4. **Train Taxonomic Classifier**:
   - **Feature Extraction**: Project PCA coefficients into a classifier using AutoML.
   - **Classification**: Map the PCA coefficients to predefined taxonomic labels (e.g., H₂O, CO₂, Organic).

5. **Reconstruct Spectra and Classify**:
   - **Inference**: For new photometric data, predict the latent PCA coefficients using the trained regressor.
   - **Spectrum Reconstruction**: Apply inverse PCA to reconstruct the full spectrum.
   - **Taxonomic Identification**: Use the classifier to determine the probability distribution of taxonomic types.

This algorithm effectively transforms sparse photometry into detailed spectral information, enabling robust analysis of TNO surface compositions.
