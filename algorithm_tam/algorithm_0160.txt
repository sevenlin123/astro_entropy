The algorithm described in the paper focuses on reconstructing the spectral energy distribution of trans-Neptunian objects (TNOs) from sparse photometric measurements using a Bayesian framework. The steps involve defining a latent space through Principal Component Analysis (PCA) based on a set of reference TNO spectra. This latent space is augmented using non-parametric Kernel Density Estimation (KDE) to create a continuous manifold. An automated machine learning (AutoML) regressor is trained to map sparse photometric inputs to the latent coefficients. The framework includes a taxonomy classifier that operates within the latent space to predict spectral types. The core computational steps are as follows:

1. **Latent Space Definition**: Perform PCA on a set of reference TNO spectra to derive principal components, capturing the main spectral variations. Use KDE to smooth the latent distribution, creating a continuous manifold.

2. **Data Augmentation**: Generate synthetic photometric data by forward modeling the augmented spectra through the target instrument's filter curves, introducing noise to simulate real-world uncertainties.

3. **Model Training**: Train an AutoML regressor to map sparse photometric inputs to latent coefficients. A secondary classifier is trained to predict taxonomic labels based on the latent coordinates.

4. **Inference and Reconstruction**: For new photometric observations, predict latent coefficients using the trained regressor, project these into full spectra via inverse PCA, and classify the spectral type.

5. **Validation and Uncertainty Quantification**: Assess the framework's performance using leave-one-out cross-validation, measuring reconstruction accuracy and credible interval coverage.

The algorithm efficiently bridges sparse photometry and detailed spectral analysis, enabling statistically rigorous reconstruction and classification of TNO spectra.
