**Probabilistic Spectral Reconstruction Algorithm for Trans-Neptunian Objects**

**Step-by-Step Algorithm Description:**

1. **Training Data Preparation:**
   - Collect and preprocess a set of reference TNO spectra (e.g., 51 spectra) representing dominant taxonomic classes.
   - Exclude outliers and rare spectral types to define a "clean" latent space.

2. **Principal Component Analysis (PCA):**
   - Apply PCA to the training spectra to extract principal components (PCs).
   - The number of PCs is determined through analysis (approximately 4-5 PCs for classification, 8-10 for detailed reconstruction).

3. **Latent Space Construction:**
   - Use Kernel Density Estimation (KDE) to create a continuous probability distribution in the PCA latent space.
   - Adjust KDE bandwidth to balance smoothing and fidelity to the training data.

4. **Synthetic Photometry Generation:**
   - Forward model the synthetic spectra through the target instrument's filters (e.g., JWST/NIRCam) to compute mock photometric measurements.
   - Inject noise (e.g., 20% relative uncertainty) to simulate real observational conditions.

5. **AutoML Model Training:**
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to PCA latent coefficients.
   - Additionally, train a classifier within the latent space for taxonomic classification.

6. **Reconstruction Pipeline:**
   - For new photometric observations:
     - Use the trained AutoML regressor to predict latent coefficients.
     - Project these coefficients back through PCA to reconstruct the full spectrum.
     - Simultaneously classify the spectral type using the latent space classifier.

7. **Validation and Error Assessment:**
   - Perform Leave-One-Out Cross-Validation (LOOCV) to assess reconstruction accuracy.
   - Compute metrics such as RMSE in latent space, error in key spectral features, and taxonomic misclassification rates.

8. **Applications:**
   - **Survey Optimization:** Evaluate different filter configurations to maximize spectral reconstruction fidelity.
   - **Outlier Detection:** Identify objects with latent states outside the expected distribution, indicating unusual compositions.

**End of Algorithm Description**
