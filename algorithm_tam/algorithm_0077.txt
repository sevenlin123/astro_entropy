**Algorithm for Probabilistic Spectral Reconstruction of Trans-Neptunian Objects from Sparse Photometry**

1. **Input Data Preparation:**
   - Collect sparse photometric measurements of TNOs.
   - Retrieve reference TNO spectra from the DiSCo-TNO sample.

2. **Training Data Processing:**
   - Apply Principal Component Analysis (PCA) to the reference spectra to extract principal components (latent space).
   - Generate synthetic training data by forward modeling the spectra using the PCA basis and the target instrument's filter characteristics (e.g., JWST/NIRCam).

3. **Data Augmentation:**
   - Use Kernel Density Estimation (KDE) to smooth the latent distribution of the PCA coefficients, creating a continuous manifold.

4. **Model Training:**
   - Format the data into a table with photometric measurements as features and PCA coefficients as labels.
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map photometric inputs to latent coefficients.

5. **LOOCV Assessment:**
   - Perform leave-one-out cross-validation by removing each object from the training set, generating synthetic photometry, and validating the reconstructed spectrum against the real one.

6. **Spectral Reconstruction:**
   - For new photometric observations, predict latent coefficients using the trained regressor.
   - Transform these coefficients back to the full spectrum using inverse PCA.

7. **Taxonomy Classification:**
   - Classify the predicted latent space coordinates into taxonomic categories (e.g., H₂O, CO₂, Organics) using a secondary AutoML classifier.

8. **Outlier Detection:**
   - Compute log-likelihood scores during photometric-to-latent inference to identify objects with low probability membership in the learned distribution.

9. **Survey Optimization:**
   - Evaluate different filter configurations to maximize spectral reconstruction fidelity, guiding optimal survey design.

10. **Output:**
    - Reconstructed spectra, taxonomic probabilities, outlier flags, and optimized filter configurations.

This algorithm provides a robust framework for reconstructing spectra and classifying TNOs from sparse photometry, enabling efficient and accurate analysis of their surface compositions.
