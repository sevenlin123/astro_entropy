2. **Principal Component Analysis (PCA):**
   - Apply PCA to the training spectra to extract principal components (PCs) that capture the main spectral variations.
   - Determine the number of PCs needed for adequate reconstruction (e.g., 4-5 for general use, up to 8-10 for improved fidelity).

3. **Density Estimation:**
   - Use Kernel Density Estimation (KDE) on the PCA latent space to create a continuous probability distribution, enabling generation of synthetic latent vectors.

4. **Synthetic Photometry Generation:**
   - Simulate photometric data for each augmented spectrum by convolving with NIRCam filter responses.
   - Introduce noise (e.g., 20% relative uncertainty) to simulate realistic observational conditions.

5. **Automated Machine Learning (AutoML) Training:**
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to PCA latent coefficients.
   - Simultaneously train a classifier to predict taxonomic types using the latent space.

6. **Inference Pipeline:**
   - For new photometric observations:
     - Use the trained AutoML regressor to predict latent coefficients.
     - Project these coefficients through inverse PCA to reconstruct the full spectrum.
     - Apply the classifier to determine the probable taxonomic classification.

7. **Validation and Outlier Detection:**
   - Validate using leave-one-out cross-validation to assess reconstruction accuracy (nRMSE, credible interval coverage).
   - Identify outliers based on low probability density in the latent space.

8. **Survey Optimization and Application:**
   - Evaluate different filter configurations to optimize information content for spectral reconstruction.
   - Apply the framework to detect rare spectral types and guide follow-up spectroscopy for unusual objects.
