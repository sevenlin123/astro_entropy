The core computational algorithm for the probabilistic spectral reconstruction framework involves the following steps:

1. **Principal Component Analysis (PCA)**: Apply PCA to a set of reference TNO spectra to obtain principal components, capturing the main variations in the spectral data.

2. **Kernel Density Estimation (KDE)**: Use KDE on the latent PCA coefficients to create a continuous probability distribution, augmenting the training data to handle sparse inputs.

3. **Synthetic Photometry Generation**: Convolve the augmented spectra with the instrument's filter response (e.g., JWST/NIRCam) and add noise to simulate realistic photometric observations.

4. **AutoML Regressor Training**: Train an AutoML model (e.g., Gradient Boosted Decision Trees) to map the noisy photometric inputs to the latent PCA coefficients.

5. **Spectral Reconstruction**: For new photometric data, use the trained regressor to predict the latent coefficients and reconstruct the full spectrum via inverse PCA transformation.

This algorithm efficiently bridges the gap between sparse photometry and detailed spectral reconstruction, enabling accurate characterization of TNO surface compositions.
