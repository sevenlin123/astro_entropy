### Algorithm for Probabilistic Spectral Reconstruction of TNOs from Sparse Photometry

1. **Input Data Preparation**:
   - Collect sparse photometric observations of TNOs.
   - Obtain a reference set of near-infrared spectra for training.

2. **Principal Component Analysis (PCA) Training**:
   - Perform PCA on the reference spectra to extract principal components.
   - Determine the optimal number of principal components (4-5 for taxonomy, 8-10 for high-fidelity reconstruction).

3. **Latent Space Construction**:
   - Use the principal components to define a low-dimensional latent space.
   - Apply Kernel Density Estimation (KDE) to create a continuous probability distribution in the latent space, augmenting the training data.

4. **AutoML Regressor Training**:
   - Train an ensemble of gradient-boosted decision trees (AutoML) to map sparse photometry to latent space coordinates.
   - Augment the training set with synthetic photometry derived from the expanded latent space.

5. **Inverse PCA Transform**:
   - For each object, use the trained AutoML model to predict latent coefficients from sparse photometry.
   - Apply the inverse PCA transform to obtain the reconstructed spectrum.

6. **Bayesian Inference**:
   - Perform Bayesian inference to quantify uncertainties in the reconstructed spectrum, incorporating measurement noise.

7. **Validation and Metrics**:
   - Use leave-one-out cross-validation (LOOCV) to assess reconstruction accuracy.
   - Compute metrics such as RMSE, PCC, credibility interval coverage, and feature discriminability.

8. **Survey Optimization and Outlier Detection**:
   - Identify optimal filter configurations for future surveys.
   - Detect outliers by evaluating KL divergence between observed and expected latent distributions.

9. **Taxonomic Classification**:
   - Classify objects into predefined spectral types using the latent space representation.

10. **Output**:
    - Provide reconstructed spectra, taxonomic classifications, and uncertainty estimates for each object.
