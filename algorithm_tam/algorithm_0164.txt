**Algorithm: Probabilistic Spectral Reconstruction Framework**

1. **Training Data Preparation**:
   - Collect and preprocess a set of reference TNO spectra, focusing on dominant taxonomic classes (e.g., Water-type, CO₂-type, Organics-type).
   - Exclude rare or outlier spectral types to ensure the latent space represents common patterns.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the preprocessed spectra to derive principal components (latent space).
   - Determine the optimal number of components (K) using LOOCV, typically between 4 to 10, balancing fidelity and computational efficiency.

3. **Density Estimation**:
   - Use Kernel Density Estimation (KDE) on the latent space to create a smooth probability distribution.
   - Adjust the bandwidth (h) to avoid overfitting or oversmoothing, finding h ≈ 0.5 as suitable.

4. **Synthetic Data Generation**:
   - Generate synthetic spectra using the inverse PCA transform with samples from the latent density model.
   - Convolve these spectra with instrument-specific filter responses (e.g., JWST/NIRCam) to create synthetic photometry with added noise (~20% relative uncertainty).

5. **Model Training**:
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map synthetic photometry to latent coefficients.
   - Simultaneously train a taxonomic classifier on the latent space for spectral type prediction.

6. **Reconstruction Pipeline**:
   - For new photometric observations, predict latent coefficients using the trained regressor.
   - Apply inverse PCA transform to obtain the reconstructed spectrum.
   - Use the taxonomic classifier to predict the spectral type probabilities.

7. **Performance Evaluation**:
   - Validate using LOOCV, computing RMSE, MAD, uncertainty coverage, and classification accuracy.
   - Compare results against independent test spectra to assess generalization.

8. **Applications**:
   - Optimize survey filters for maximum information content.
   - Detect and reconstruct rare spectral types by identifying low-probability intermediate models.
   - Utilize synthetic spectra for forward modeling and data augmentation.

9. **Implementation**:
   - The pipeline is optimized for computational efficiency, suitable for processing large datasets on standard hardware.

This structured approach effectively bridges the gap between sparse photometric data and detailed spectral reconstruction, enabling robust taxonomic classification and advancing the study of TNOs.
