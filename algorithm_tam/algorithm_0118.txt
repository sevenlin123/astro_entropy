The core computational algorithm for the probabilistic spectral reconstruction framework involves the following steps:

1. **Principal Component Analysis (PCA) Training**:
   - Train a PCA model on a set of reference TNO spectra to create a low-dimensional latent space. This space captures the main spectral variations relevant for taxonomic classification.

2. **Data Augmentation**:
   - Use Kernel Density Estimation (KDE) on the PCA latent coefficients to generate synthetic data, expanding the training set for better model generalization without introducing new spectral types.

3. **Synthetic Photometry Generation**:
   - For each augmented spectrum, compute the expected photometric measurements by convolving the spectrum with the instrument's filter response curves (e.g., JWST/NIRCam).
   - Add Gaussian noise to simulate realistic photometric uncertainties, ensuring the model can handle observational noise.

4. **AutoML Model Training**:
   - Train an ensemble of Gradient Boosted Decision Trees (GBDTs) using the synthetic photometry as inputs and the PCA latent coefficients as targets. This forms the encoder regressor mapping photometry to latent space.
   - Simultaneously train a separate AutoML classifier to predict taxonomic labels based on the latent space.

5. **Reconstruction Pipeline**:
   - For new photometric observations, use the trained encoder regressor to predict the latent coefficients.
   - Apply the inverse PCA transformation to these coefficients to reconstruct the full spectrum.
   - Use the classifier to determine the taxonomic label probabilities.

6. **Uncertainty Propagation**:
   - Quantify the uncertainty in the reconstructed spectrum by analyzing the variance in the latent space predictions.

7. **Validation and Application**:
   - Evaluate the framework using leave-one-out cross-validation to assess reconstruction accuracy and uncertainty coverage.
   - Apply the framework to identify optimal filter configurations for surveys and detect rare spectral types by constraining photometric data to select low-probability models.

This structured approach effectively bridges sparse photometry with detailed spectral analysis, enabling accurate reconstruction and classification of TNO spectra.
