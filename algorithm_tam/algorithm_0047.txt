### Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry

1. **Data Preparation**:
   - Collect sparse photometric measurements of TNOs from observations (e.g., JWST/NIRCam).
   - Obtain a reference set of near-IR spectra for TNOs, excluding rare or outlier types.

2. **Principal Component Analysis (PCA)**:
   - Perform PCA on the reference spectra to reduce dimensionality.
   - Determine the number of principal components (4-5 for classification, 8-10 for accurate reconstruction).

3. **Latent Space Definition**:
   - Use PCA to project reference spectra into a low-dimensional latent space.
   - Apply Kernel Density Estimation (KDE) to create a smooth probability distribution in this latent space, augmenting the training data.

4. **AutoML Model Training**:
   - Train an AutoML regressor (e.g., Gradient Boosted Decision Trees) to map sparse photometry to latent space coordinates.
   - Simultaneously train a classifier on the latent space to predict taxonomic categories.

5. **Forward Modeling**:
   - For each photometric observation, use the trained AutoML model to predict latent coefficients.
   - Apply inverse PCA to reconstruct the full spectrum from the predicted latent coefficients.

6. **Validation and Uncertainty Quantification**:
   - Perform LOOCV to assess reconstruction accuracy and feature recovery.
   - Compute credible intervals for each wavelength to evaluate uncertainty calibration.

7. **Applications**:
   - Optimize filter configurations for future surveys based on information content.
   - Classify TNOs into taxonomic types using the latent space.
   - Detect outliers by identifying objects with latent coefficients outside the modeled manifold.

This algorithm enables the reconstruction of detailed spectra from sparse photometric data, facilitating taxonomic classification and survey optimization for TNOs.
