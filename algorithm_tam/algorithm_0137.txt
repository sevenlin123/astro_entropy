**Algorithm: Probabilistic Spectral Reconstruction from Sparse Photometry**

1. **Training Data Preparation:**
   - Collect a seed set of near-infrared spectra of TNOs, focusing on dominant taxonomic types (e.g., H₂O, CO₂, Organics).
   - Exclude rare or outlier spectral types to avoid biasing the PCA.

2. **Principal Component Analysis (PCA):**
   - Perform PCA on the training spectra to derive principal components (latent space).
   - Determine the number of components (4-5 for classification; 8-10 for high fidelity).

3. **Density Estimation:**
   - Use Kernel Density Estimation (KDE) on the latent coefficients to create a smooth probability distribution.
   - Select bandwidth (e.g., h ≈ 0.5) for optimal smoothing without overfitting.

4. **Synthetic Photometry Generation:**
   - Forward-model each synthetic spectrum by convolving with NIRCam filter curves.
   - Add Gaussian noise (e.g., 20% uncertainty) to simulate realistic photometric measurements.

5. **Automated Machine Learning (AutoML) Training:**
   - Train an ensemble regressor (e.g., Gradient-Boosted Decision Trees) to map sparse photometry to latent coefficients.
   - Use the synthetic photometry and true latent coefficients as training data.

6. **Inference Pipeline:**
   - For new photometric observations:
     - Predict latent coefficients using the trained AutoML regressor.
     - Apply inverse PCA transform to reconstruct the full spectrum.
     - Simultaneously classify the spectral type using a latent space classifier.

7. **Cross-Validation:**
   - Perform LOOCV to validate the model.
   - Metrics include RMSE, Pearson correlation, ECI coverage, and Manhattan distance.

8. **Applications:**
   - Optimize filter configurations for future surveys.
   - Detect outliers by identifying spectra outside the learned manifold.

**Steps Explained:**
- **PCA and Latent Space:** Reduce spectral data to principal components to capture major variations.
- **Density Estimation:** Create a smooth distribution for the latent space using KDE.
- **Synthetic Photometry:** Simulate realistic photometric data from synthetic spectra.
- **AutoML Training:** Learn mapping from photometry to latent space for reconstruction.
- **Reconstruction and Classification:** Use the learned model to predict spectra and classify types from photometry.

**Outputs:**
- Reconstructed spectra with uncertainties.
- Probabilistic taxonomic classifications.
- Optimized filter configurations and detected outliers.

This algorithm effectively bridges sparse photometry and detailed spectroscopy, enabling robust analysis of TNO surface compositions.
