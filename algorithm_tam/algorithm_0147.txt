**Computational Algorithm Steps:**

1. **Perform PCA on Reference Spectra**: Apply Principal Component Analysis to a set of reference TNO spectra to create a low-dimensional latent space representation.

2. **Augment Training Data with KDE**: Use Kernel Density Estimation to generate synthetic latent vectors, creating a smooth probability distribution in the latent space, thereby expanding the training dataset.

3. **Train AutoML Regressor**: Utilize an Automated Machine Learning (AutoML) framework, such as Gradient-Boosted Decision Trees, to map sparse photometric inputs to the latent space coefficients.

4. **Generate Synthetic Photometry**: Convolve reference spectra with instrumental throughput curves (e.g., JWST/NIRCam filters) to produce synthetic photometric measurements. Introduce noise to simulate real-world observational uncertainties.

5. **Predict Latent Coefficients**: For new photometric observations, use the trained regressor to predict the corresponding latent coefficients.

6. **Reconstruct Spectrum via Inverse PCA**: Transform the predicted latent coefficients back into the full spectral space using the inverse Principal Component transform to obtain the reconstructed spectrum.

7. **Classify Taxonomic Type**: Apply a classifier trained on the latent space to predict the taxonomic type (e.g., H₂O, CO₂, Organic) of the TNO based on the latent coefficients.
